# 汽车嵌入式工程师知识库

> 面向 AUTOSAR 汽车软件工程师（英飞凌 TC377 + NXP S32K，BSW/CDD 方向）的个人知识资产，
> 以软件工程方式治理：设计规范、质量审核流程与渐进式改造计划齐备。
> 日常主线：CAN/LIN 通讯配置与诊断；补强线：MCAL 与硬件基础。

## 如何使用

- 入口：[知识库 README](嵌入式工程师知识库/README.md) · [知识地图](嵌入式工程师知识库/00-总览/知识地图.md) · [学习路线图](嵌入式工程师知识库/00-总览/学习路线图.md) · [术语表](嵌入式工程师知识库/00-总览/术语表.md)
- 学习优先级：**P0 补短板** 03 硬件 → 04 MCAL → 02 芯片；**P1 深主业** 05 网络 → 06 诊断 → 07 BSW；**P2 长线** 08 OS、11 功能安全；日常沉淀 09 踩坑案例 + 12 项目复盘
- 笔记自带 `> 等级：Lx ｜ 前置：链接` 头部行，按需爬坡、不必顺序修完

## 治理方式（像软件项目一样维护）

- **设计规范**：笔记骨架"首尾固定 + 中段菜单"；命名 `序号-主题.md`；图表用 PlantUML / WaveDrom 内嵌正文（见[图表规范与模板](嵌入式工程师知识库/00-总览/图表规范与模板.md)）
- **质量审核**：审核规范（spec / checklist / tasks）+ 机器审计脚本（死链扫描、头部行检查、编码检查），本地维护、不入库
- **改造计划**：13 区资源化重组、知识库成长路线导航层改造，本地维护、不入库

## 版本控制约定

- **入库**：Markdown 笔记与 README 索引、`_images/` 截图、`examples/` 代码示例
- **不入库**：`.trae/` 工作区（治理文档与审计脚本）；13 区标准原件 / 芯片手册 / 电子书等大体积二进制（`*.pdf`、`*.zip` 等，见 `.gitignore`）——版权与体积原因仅本地留存，对应阅读笔记与下载渠道索引照常入库
