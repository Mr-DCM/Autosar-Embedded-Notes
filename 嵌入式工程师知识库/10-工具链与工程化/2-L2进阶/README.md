# 2-L2进阶

> 上级目录：[10-工具链与工程化](../README.md)

## 本带定位

从"会用工具"到"懂工具为什么这么转"：读懂 Makefile/CMake 的调度逻辑、看懂 TASKING/GCC 的编译选项与 map 清单、把 DaVinci/EB tresos 的配置生产线接入 CI、用 MISRA 工具链在编译前拦风险、把重复劳动沉淀成脚本。面向真实 AUTOSAR 工程的交付节奏。

**主等级声明**：本带主等级【L2】；无 L3 碎片，更深的工具话题（编译器优化对时序的影响、全量 CI 流水线设计等）靠工程实践推进，见 [3-L3高级](../3-L3高级/README.md)。

## 坡道说明

- **何时进本带**：[1-L1基础](../1-L1基础/README.md) 两目录过关——独立跑通编译烧录闭环、Git 分支策略能讲清楚。
- **何时离开去下一带**：能不查资料说出一次增量编译哪些文件会重编及为什么；map 文件里能查到任意函数/变量的地址与大小；能给团队搭一条"配置变更→生成→编译→静态分析"的本地流水线。
- **建议顺序**：构建系统 → 编译器 → 代码质量 → AUTOSAR配置工具；辅助脚本沉淀按需穿插，遇到第三次重复劳动就回来翻。
