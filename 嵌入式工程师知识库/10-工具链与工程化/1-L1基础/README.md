# 1-L1基础

> 上级目录：[10-工具链与工程化](../README.md)

## 本带定位

先把"手上的家伙"用顺：双平台官方 IDE 建工程到烧录调试一条龙跑通，再用 Git 把源码与 ARXML 都管起来。目标是脱离"照着手册点按钮"，能独立完成一次改码→提交→编译→烧录的闭环。

**主等级声明**：本带主等级【L1→L2】过渡带——工具操作入门是 L1，分支策略与 ARXML 版本管理已属 L2 话题，读完即具备进 L2 的资格。

## 坡道说明

- **何时进本带**：[入门导读](../00-入门导读/01-从敲下编译到烧进板子-工具链全景.md) 读完后认得七件套，但没独立跑通过任何一个平台的编译烧录。
- **何时离开去下一带**：能在 IDE 里找到编译命令与链接脚本、能解释一次 merge 的来龙去脉、能说清 ARXML 入库的流派取舍——即可进 [2-L2进阶](../2-L2进阶/README.md)。
- **建议顺序**：IDE → Git与版本管理；Git 三篇内部按序号推进，第三篇（ARXML）可与 2-L2 的 AUTOSAR配置工具 对照着读。
