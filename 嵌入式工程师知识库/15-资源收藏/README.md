# 15-资源收藏

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

全库的资源导航区：官方文档入口、优质博客与网站、开源项目、视频课程四类链接索引 + 一篇讲"怎么挑、怎么消化"的区级导读。本区不教新知识——01~12 区的知识点在本区只留下"去哪查一手资料"的坐标；13 区管标准与书籍的**阅读笔记**，本区管**入口**，两区互补。每篇笔记按"资源清单表（名称/入口/是什么/何时用/替代品）+ 精选点评 + 避坑"的条目式写作，入口只记官方域名级别，不记会失效的深链。

## 组织说明：本区按资源类型组织，不分带

本区**不做物理四带分带**（没有 1-L1基础/2-L2进阶/3-L3高级 目录），原因：资源类内容天然平铺——一个入口的价值在"何时用"而不在"难度"，按类型（官方文档/博客/开源/视频）组织才符合"按需检索"的使用姿势，强行分带反而把一个入口图撕成三份。全库唯一保留的是 `00-入门导读/`（讲信息食谱与搜商方法论）。篇目头部仍按全库惯例挂 `> 等级：Lx` 行，但这里的等级只表示**消化成本**（基本都是 L1 检索型），不表达目录位置。

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：先读 [信息食谱](00-入门导读/01-信息食谱-如何挑选与消化资源.md)，学会分层与查证再谈收藏；
2. [官方文档](官方文档/README.md)：四篇入口地图按手头平台优先——做 TC377 先读 [英飞凌](官方文档/01-英飞凌.md)，做 S32K 先读 [NXP](官方文档/02-NXP.md)；
3. [开源项目](开源项目/README.md) / [优质博客与网站](优质博客与网站/README.md)：按当前问题检索（排障找工具→开源项目；入门找解读→博客索引）；
4. [视频课程](视频课程/README.md)：想被带着过一遍某主题时再查，警惕标题党。

> 坡道只保证"第一次进区有路可走"；日常使用是检索式的——问题 → 索引表 → 入口域名。
