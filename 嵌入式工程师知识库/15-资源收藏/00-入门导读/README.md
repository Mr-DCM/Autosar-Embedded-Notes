# 00-入门导读

> 上级目录：[15-资源收藏](../README.md)

## 定位

**一篇建立"资源观"的区级导读。** 本区是全库唯一按需检索型资料区，不教新知识，教"怎么找、怎么挑、怎么消化"：用信息食谱金字塔（主食=官方文档/骨架=标准/肉=书/调味=博客视频，可信度与消化成本双轴）给资源定份额；配搜商三件套（怎么搜：官方域名优先与 site: 操作符；去哪搜：AUTOSAR/Infineon/NXP/Vector/ASAM/CiA 入口地图；搜到怎么消化：主食三遍法与个人索引）；最后给一份防迷路清单，避开二手翻译过时、标题党课程、深链失效、版本错配这些收藏夹杀手。读完你拿着任何新主题都知道第一手资料去哪找、二手信息信几分。

- 主等级：**L1**（前置：无，可从零直接读；若已读过 [00-总览知识地图](../../00-总览/知识地图.md) 更佳——本文把那边的"资源入口"坐标展开成方法论）；
- 何时进：收藏夹里堆了几百条链接却从不回看、遇到问题只会百度前三条、分不清该信官方手册还是知乎回答、被"三天精通"课程割过韭菜——都从这里起步；
- 何时离开：能复述四层食谱的份额与可信度排序、说出官方入口地图、对任何二手结论先问"版本号是多少"，就可以按需检索本区其余笔记了——导读讲方法，不罗列资源明细。

## 读完去向（按需检索）

导读是本区唯一需要顺序读的内容，之后进入按需检索模式：

- **查官方文档入口**：[官方文档](../官方文档/README.md)——英飞凌/NXP/Vector/AUTOSAR 四篇入口地图；
- **找博客/论坛/社区**：[优质博客与网站](../优质博客与网站/README.md)——调味层资源与可信度标注；
- **找开源工具**：[开源项目](../开源项目/README.md)——CAN/UDS/OS 真实开源项目的"何时用/替代品"对照；
- **找课程**：[视频课程](../视频课程/README.md)——以"类型+平台+搜索关键词"组织，不虚构具体链接；
- 标准与书籍的深度阅读笔记在 [13 区](../../13-标准与书籍笔记/README.md)，与本区"入口"互补：13 区管"读后感"，本区管"去哪找"。
