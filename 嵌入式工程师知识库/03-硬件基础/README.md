# 03-硬件基础

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

本区是 **P0 补短板区**：面向 AUTOSAR 软件工程师的硬件知识，目标 = **够用 + 能与硬件工程师对话**——不求设计电路、画板子，但求看懂原理图、听懂硬件术语、在排障与评审桌上不说外行话。内容从汽车电路实例入手的电路基本功（原"电路基础"，已并入本带结构）到 ECU 供电、PCB 常识，全部围绕"软件读到的 0/1 与电压值"这条主线。

## 入门坡道（软件工程师补硬件的推荐顺序）

1. **[00-入门导读：从一块 ECU 板开始](00-入门导读/01-从一块ECU板开始.md)**——先有板子地图，一小时；
2. **[电压电流与基本定律](1-L1基础/电压电流与基本定律/README.md)**——欧姆定律、分压/分流、功率，软件换算的出处；
3. **[上拉下拉电阻](1-L1基础/上拉下拉电阻/README.md)**——输入引脚为什么总挂一只电阻；
4. **[原理图阅读](1-L1基础/原理图阅读/README.md)**——元器件符号、MCU 最小系统、数据手册读法，能独立看图；
5. 进 **[L2 带·电源电路](2-L2进阶/电源电路/README.md)** 起按需深入：做供电/采集相关功能读模拟电路（ADC），做通讯/驱动排障读 MOS 与 ECU 硬件常识。
