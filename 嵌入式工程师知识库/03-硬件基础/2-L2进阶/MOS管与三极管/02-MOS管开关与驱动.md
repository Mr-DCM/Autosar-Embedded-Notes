# MOS 管开关与驱动

> 一句话定位：电压控制的电子开关——栅极不取电流、无存储时间、导通损耗 I²R，是 ECU 功率开关与 DCDC 功率级的主角；理解"栅极是电容"就看懂了它的一切驱动问题。
> 等级：L2 ｜ 前置：[三极管开关应用](01-三极管开关应用.md)

## 原理

MOSFET（Metal-Oxide-Semiconductor Field-Effect Transistor，金属氧化物半导体场效应管）靠栅极电压建立的电场控制漏源沟道，三个电极：G（Gate 栅极）、D（Drain 漏极）、S（Source 源极）。

NMOS 与 PMOS 符号与导通条件（| 表示体二极管 Body Diode，集成在管内、方向固定不可选）：

```
NMOS（低边开关常用）                PMOS（高边开关常用）

    +12V (KL30)                        +12V (KL30)
       │                                  │
    [负载 R_L]                            │
       │                                  D
       │ D                                │
驱动 ─[Rg]─ G      体二极管: S→D        [负载 R_L]
       │ S        （阴极在 D）            │
       │                                  S ──→ 驱动 ─[Rg]─ G
      GND                                 │      （PMOS：Vgs < Vgs(th) 导通，
                                            GND    即栅极要拉到低于电源）
```

导通条件与方向速记：

| 器件 | 导通条件 | 常用位置 | 体二极管方向 |
|---|---|---|---|
| NMOS | Vgs > Vgs(th)，且 Vgs 越大 Rds(on) 越小 | 低边（源极接地，栅极给正压） | S 为阳极、D 为阴极（S→D 导通） |
| PMOS | Vsg > \|Vgs(th)\|（栅极比源极低足够多） | 高边（源极接电源，栅极拉低） | D 为阳极、S 为阴极（D→S 导通） |

两个关键认识：

1. **Vgs(th) 是"开始出现沟道"的门槛，不是"完全导通"点**。手册里 Rds(on) 是在 Vgs=10V（标准电平管）或 Vgs=4.5V（逻辑电平管）下标定的。Vgs(th) 典型 2~4V 的标准管，用 3.3V GPIO 直接驱动只会得到一个半开的"大电阻"。
2. **体二极管方向决定拓扑**：低边 NMOS 正常工作时体二极管反向偏置不起作用；但若把普通 NMOS 放高边且源极浮起，体二极管可能在断开时仍给负载供 电，开关"关不住"。

### 栅极是电容：驱动电流决定开关速度

栅极与源极之间是二氧化硅绝缘层，等效为电容 Ciss（输入电容，典型几百 pF~十几 nF）。想让它"开"，就是把栅极电容充到目标电压；想"关"就是放电：

```
开通/关断时间 ≈ Qg / I_drive
Qg（总栅极电荷）：小信号管 ~1nC，功率管几十 nC（以器件手册为准）
```

- MCU GPIO 驱动能力典型 ±4~±8mA → 直驱 50nC 的大功率管，t = 50nC/4mA ≈ 12.5μs——**这就是"MCU 直驱大 MOS 很慢"的原因**：开关过程拖得很长，管子长时间停留在线性区，损耗大、发烫，根本做不了 PWM。
- 专用栅极驱动器（Gate Driver）峰值电流 1~4A，才能把几十 nC 的管子在几十 ns~百 ns 内开关，DCDC/电机 PWM 都靠它。
- 直驱只适合小信号 MOS（Qg ~ 1nC 级）做低速事件开关。

### 栅极外围两电阻

```
驱动器/GPIO ──[Rg 串联]──┬── G 栅极
                         │
                     [Rgs 下拉 10k~100k]
                         │
                        GND（或源极）
```

- **串联电阻 Rg（典型 10~100Ω）**：抑制栅极振铃（栅极电感+电容在快速边沿下振荡）、与栅极电容组成 RC 控制开关边沿速度（越大越慢、EMC 越好但开关损耗越大）、限制驱动器峰值电流。取值是"损耗 vs EMC"的折中，以驱动器手册推荐为准。
- **下拉电阻 Rgs（典型 10k~100k）**：驱动器未上电/高阻/MCU 复位时把栅极钳在源极电位，**防止栅极浮空导致误导通**——栅极是高阻节点，悬空时靠寄生电荷就可能半开。直觉：下拉越小越保险，但驱动器要持续灌更多电流、开关损耗略增。

### 高低边拓扑初步

| 拓扑 | 器件 | 驱动难点 | 典型用途 |
|---|---|---|---|
| 低边（NMOS 接地侧） | NMOS，S 接 GND | 简单：栅极给 0/5V(10V) 即可 | 继电器、LED、喷油嘴历史方案 |
| 高边（PMOS 电源侧） | PMOS，S 接 +12V | 简单：栅极拉到 12V 关断、拉到 GND 导通 | 电源开关、防反接 |
| 高边（NMOS+电荷泵） | NMOS，S 随负载浮动 | 需自举/电荷泵把栅极抬到高于源极 | 智能高边开关、半桥/全桥 |

详见 [03-高边低边驱动](03-高边低边驱动.md)。

## 计算与选型

### 算例 1：导通损耗 P = I² × Rds(on)

风扇负载 10A，选 10mΩ NMOS（Vgs=10V 条件）：

- 导通损耗 P = 10² × 0.01 = 1W；
- 同样 10A 若用 2mΩ 管：P = 0.2W——Rds(on) 差 5 倍，损耗差 5 倍，热设计完全不同；
- 对比三极管：Vce_sat=0.2V 时 P = 0.2×10 = 2W，MOS 优势随电流增大而扩大。

### 算例 2：栅极电荷与开关时间

- MCU GPIO（±4mA）直驱 Qg=50nC 功率管：t_sw ≈ 50nC/4mA = 12.5μs → 只能做 kHz 以下低速开关，PWM 不可用；
- 栅极驱动器（±2A）：t_sw ≈ 50nC/2A = 25ns → 足够支撑几百 kHz PWM；
- 结论写进驱动需求：**PWM 频率上限由"驱动电流 × Qg"决定的开关时间加上死区余量共同决定，不是软件想配多高就多高**。

### 算例 3：逻辑电平核对

3.3V GPIO 直驱 NMOS：

- 标准电平管（Vgs(th)=2~4V，Rds(on)@10V 标定）：3.3V 下可能半开，Rds(on) 数倍恶化 → 禁用；
- 逻辑电平管（Rds(on)@2.5V 或 @4.5V 标定，Vgs(th)≤1.5V）：3.3V 下可用，但仍要核对手册在 Vgs=3.3V 的 Rds(on) 曲线（以器件手册为准）。

选型检查表：

| 检查项 | 经验准则 |
|---|---|
| Vds | ≥ 2× 电源电压（感性负载看钳位后再核，见 04 篇） |
| Id | ≥ 2× 负载电流（考虑散热降额） |
| Rds(on) | 用**实际 Vgs** 下的手册值，按 P=I²R 算热 |
| Qg/Ciss | 决定驱动方式：小 Qg 可 MCU 直驱，大 Qg 必须驱动器 |
| Vgs(th) | 只判断"能不能开始导通"，不能用来算损耗 |
| 封装热阻 | θja/θjc 核算 Tj = Ta + P×θja ≤ 125°C（车规，以规范为准） |

## ECU 实例

- KL30 输入防反接：PMOS 高边（导通压降远低于二极管，12V/5A 时二极管损 0.7×5=3.5W，PMOS 5mΩ 只损 0.125W）；
- 常电/IGN 电源切换：PMOS 高边开关 + 栅极下拉/上拉决定默认态；
- 车灯、加热、电机等 5~20A 负载：智能高边开关（内部 NMOS+电荷泵+诊断，见 03 篇）；
- DCDC 功率级、电机半桥：分立 NMOS + 专用半桥栅极驱动器（自举供电）；
- 车规功率 MOS：AEC-Q101 认证，封装 TO-220/DFN/SO-8 派生，Rds(on) 从毫欧到百毫欧覆盖。

## 与软件的关联

1. **PWM 频率上限由硬件决定**：fsw 上限 ≈ 1/(t_on+t_off+死区+裕量)。软件把 Pwm_SetPeriodAndDuty 配到硬件开关能力之上，波形会失真（占空比到不了 0/100%）、管子过热。配置前先看原理图上驱动器+MOS 的组合能力（以器件手册为准）。
2. **死区时间由关断特性决定**：半桥上下管切换必须留死区，防止"直通"（两管同时导通短路母线）。死区 ≥ 最坏关断时间 + 栅极振铃收敛时间，硬件定好范围后软件/MCAL 在范围内选，不是软件随意设 0。
3. **默认态**：PWM 外设初始化前的 GPIO 安全态 + 栅极下拉电阻共同保证上电瞬间功率管不误导通；EcuM 下电序列要把 PWM 输出禁掉再断电源轨。
4. **故障反馈**：智能高边/半桥驱动的 FAULT 引脚接 GPIO 中断或 ADGIO 轮询，进 Dem 报 DTC（链路见 03 篇）。
5. **MCU 直驱边界意识**：Qg 小的低速开关管可以 GPIO 直驱；一旦原理图上是功率管+驱动器，软件必须按"驱动器使能时序"操作（先使能驱动器再给 PWM）。

## 易错点与陷阱

- 用 Vgs(th) 判断"3.3V 能驱动"：Vgs(th)=1V 的管子在 Vgs=3.3V 的 Rds(on) 可能仍是 10V 标定值的 3~5 倍，必须查实际 Vgs 下的曲线（以器件手册为准）。
- 忽略体二极管：普通 NMOS 放高边"关不断"（体二极管始终给负载供电）；半桥体二极管换流要算反向恢复损耗。
- 栅极悬空：贴装后栅极无直流通路，静电/干扰电荷积累导致误导通，批量炸管——Rgs 下拉是必选项不是可选项。
- Rg 盲目取 0Ω：开关边沿过陡 → 振铃 + EMC 恶化；盲目取 1kΩ：开关太慢 → 线性区损耗发烫。按驱动器手册/实测振铃调。
- MCU 直驱大 MOS 还把 PWM 配到 20kHz：开关损耗把管子烧了还以为是负载问题。
- PMOS 高边导通条件记反：Vgs 要"负够"，即栅极拉到接近 GND 才充分导通，3.3V MCU 直接驱动 12V PMOS 高边是经典错误（需要电平移位）。

## 面试高频题

1. **Q：MOS 和三极管做开关的本质区别？**
   A：BJT 电流控制（需持续基极电流），有存储时间限制频率，导通压降 Vce_sat 固定；MOS 电压控制（栅极是电容，稳态几乎不取电流），无存储电荷可高频开关，导通损耗 I²Rds(on) 且毫欧级管子在大电流下损耗更低。

2. **Q：为什么 MCU 不能直接驱动大功率 MOS 做高速 PWM？**
   A：栅极电容需要充放电，开关时间 ≈ Qg/I_drive。大功率管 Qg 几十 nC，GPIO 只有几 mA，开关过程拖到 μs 级，管子长时间停留线性区损耗剧增。必须用峰值安培级的栅极驱动器。

3. **Q：栅极串联电阻和下拉电阻各起什么作用？**
   A：串联电阻抑制栅极振铃、限制驱动峰值电流、控制开关边沿（损耗与 EMC 折中，典型 10~100Ω）；下拉电阻在驱动端高阻/复位时把栅极钳到源极电位，防止浮空误导通（典型 10k~100k）。

4. **Q：Vgs(th) 是什么？能用它判断 3.3V 能否驱动吗？**
   A：Vgs(th) 是漏极开始出现沟道、电流达到手册定义微安级的门槛电压。它只说明"开始导通"，完全导通要看实际 Vgs 下的 Rds(on) 曲线；3.3V 驱动必须选逻辑电平管并核对 Vgs=3.3V 的 Rds(on)（以器件手册为准）。

5. **Q：NMOS 为什么适合低边、PMOS 适合高边？**
   A：NMOS 源极接地时栅极只需 0→10V 的普通电平即可控制，驱动容易，所以放低边；PMOS 源极接电源，栅极拉低即 Vgs 为负、符合其导通极性，不需要自举/电荷泵就能做简单高边；高边 NMOS 性能更好但驱动复杂，故集成在智能高边开关里用电荷泵解决。
