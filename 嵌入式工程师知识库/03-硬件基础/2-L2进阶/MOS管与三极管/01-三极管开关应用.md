# 三极管开关应用（NPN 共射开关）

> 一句话定位：用"小电流（基极）控制大电流（集电极）"的电子开关，ECU 里驱动继电器、蜂鸣器、指示灯的经典电路，也是理解 MOS 驱动的起点。
> 等级：L2 ｜ 前置：[欧姆定律与功率](../../1-L1基础/电压电流与基本定律/01-欧姆定律与功率.md)

## 原理

三极管（BJT，Bipolar Junction Transistor，双极结型晶体管）做开关时只工作在两个极端状态：

| 工作区 | 条件 | 表现 | 等效 |
|---|---|---|---|
| 截止区 | Ib = 0 | Ic ≈ 0，Vce ≈ 电源电压 | 开关断开 |
| 饱和区 | Ib 足够大 | Vce 压到 Vce_sat（典型 0.1~0.3V，以器件手册为准） | 开关闭合 |
| 放大区 | 介于两者之间 | Ic = β×Ib | 禁止停留（线性区发热） |

NPN 共射开关（Common Emitter，发射极接地、负载挂集电极）：

```
                 +12V (KL30)
                    │
        ┌───────────┴───────────┐
        │                       │
        │                       │ D1 续流二极管（感性负载必加，见 04 篇）
        │                  ┌────┴────┐
        │                  │  -->|   │  ← 阴极朝 +12V（反向并联在线圈两端）
        │                  └────┬────┘
   [R_L 继电器线圈]             │
        │                       │
        └───────────┬───────────┘
                    │
                    C  集电极 Collector
   GPIO ────[Rb]───B  Q1（NPN，如 MMBT3904）
                    E  发射极 Emitter
                    │
                   GND
```

导通链条：GPIO 输出高（Von=3.3V）→ Vbe 钳位在约 0.7V → 基极电阻上承受 (Von−0.7V) → 产生 Ib → 只要 Ib 足够，管子进入饱和，负载电流由电源经负载直接流到地。

饱和判据（核心公式）：

```
Ib ≥ Ic / β          （β 用手册最小值 hFE_min）
工程余量：Ib ≥ (Ic / β) × (2~5)
```

β（hFE，直流电流放大系数）不是常数：随 Ic、温度、批次大幅波动，小信号管典型 100~300，但 datasheet 承诺的最小值可能只有 50~100。**设计一律用 hFE_min，绝不用典型值。**

### 开关波形三段

集电极电流对基极指令的响应不是瞬时的，分三段：开通延迟（载流子渡越建流）、存储时间（饱和电荷泄放，最慢的一段）、下降时间：

```wavedrom
{signal: [
  {name: 'Ib 基极电流', wave: '01..........0...'},
  {name: 'Ic 集电极电流', wave: '0...1.......10..'},
  {name: 'Vce 集射电压', wave: '1...0.......01..'}
], head: {text: '三极管开关波形三段：开通延迟 / 存储时间 ts / 下降时间', tick: 1}, foot: {text: 'Ib 下降沿后 Ic 仍维持的那段时间 = 存储时间 ts'}}
```

- 开通延迟 + 上升：ns~百 ns 量级，通常不是瓶颈；
- **存储时间 ts：μs 量级**，根源是饱和时基区积累了过剩电荷，Ib 撤掉后要先把电荷"抽干"才能退出饱和——这是三极管做不了高频 PWM 功率开关的根本原因；
- 关断时序：Ib 拉低 → 存储 ts → Ic 下降 → Vce 上升。

### 达林顿（Darlington）

两只 NPN 级联（前管发射极接后管基极），等效 β ≈ β1×β2（数量级 1000~30000），驱动电流要求降低两个数量级；代价：

- Vce_sat ≈ Vbe + Vce_sat2 ≈ 0.9~1.2V（比单管高 4~5 倍，大电流时发热明显）；
- 存储时间更长，开关更慢；
- 典型芯片 ULN2003：7 路达林顿 + 每路内置续流二极管（COM 脚接 +12V），驱动继电器阵列的老朋友。

### 为什么 ECU 中逐渐被 MOS 取代

- 驱动方式：BJT 是"电流控制"（要持续给 Ib），MOS 是"电压控制"（栅极几乎不取电流）→ MCU 直驱更省事；
- 导通损耗：BJT 的 Vce_sat ≈ 0.2V（达林顿 ≈1V）是固定偏大的压降，MOS 的 Rds(on) 在大电流下损耗 I²R 更低（10mΩ 管 10A 才损 1W）；
- 速度：BJT 存储时间限制频率，MOS 无存储电荷问题，可做几百 kHz 开关；
- 集成度：智能高边开关把 MOS+诊断+保护封进一个芯片，BJT 方案做不到。

小电流、低成本、事件型开关（继电器/蜂鸣器/LED）BJT 仍存活；功率和高频场景全是 MOS。

## 计算与选型

完整算例：**3.3V GPIO 驱动 12V 继电器线圈**。

已知条件：

| 参数 | 值 | 来源 |
|---|---|---|
| 继电器线圈 | 12V / 线圈电阻 240Ω | 继电器手册 |
| 负载电流 Ic | 12V / 240Ω = 50mA | 欧姆定律 |
| 开关管 | MMBT3904，hFE_min = 100 | 器件手册 |
| GPIO 高电平 | 3.3V，引脚驱动能力 ≥ 4mA | MCU 数据手册 |

计算步骤：

1. 饱和所需最小基极电流：Ib_min = Ic / β = 50mA / 100 = 0.5mA；
2. 取 5 倍余量（深饱和，抵消 β 波动与低温）：Ib = 0.5 × 5 = 2.5mA；
3. 基极电阻：Rb = (3.3 − 0.7) / 2.5mA = 1.04kΩ → 取标称 **1kΩ**（实得 Ib = 2.6mA ✓）；
4. 验证 GPIO：2.6mA < 4mA ✓（若超标，换 β 更高的管子或达林顿，而不是硬扛）；
5. 验证管耗：饱和导通 P = Vce_sat × Ic ≈ 0.2V × 50mA = 10mW，封装无压力 ✓；
6. 感性负载：线圈两端反向并联续流二极管（见 [04-感性负载与续流](04-感性负载与续流.md)）。

选型检查表（三极管本体）：

| 检查项 | 经验准则 |
|---|---|
| Ic_max | ≥ 2× 负载电流 |
| Vceo | ≥ 2× 电源电压（感性负载再放宽，考虑反电动势） |
| β | 用 hFE_min 计算 |
| 功耗 P | = Vce_sat × Ic，对封装热阻核算 |
| 开关速度 | 手册 ts/tf，决定最高可用开关频率 |

## ECU 实例

- 车规小信号开关管：MMBT3904 / BC817 量级（Ic 额定 100~500mA，AEC-Q101 认证版本）；
- 车用继电器线圈 12V 下典型 30~70mA（线圈功率约 0.4~0.9W，以继电器手册为准）；
- 继电器触点响应时间：吸合/释放典型 5~20ms，机械寿命 10^5~10^7 次（以手册为准）；
- 蜂鸣器（有源，20~40mA）、按键背光 LED 组、指示灯等小电流负载；
- 多路继电器板卡常用 ULN2003 一片搞定 7 路；
- 喷油嘴、电机、DCDC 功率级等大电流/高频场合已全部由 MOS 方案接管。

## 与软件的关联

1. **GPIO 输出配置**：推挽输出、初值=低、建议使能内部下拉——MCU 复位期间引脚是高阻态，没有下拉的话基极悬空，继电器可能在复位窗口"半吸合"。
2. **开关频率限制**：三极管存储时间 μs 级 → 适合事件型开关（继电器控制、背光开关），**不要**把它配置成 20kHz PWM 功率开关，管子会长时间滞留放大区发热。
3. **继电器是机械开关**：电气寿命有限、响应 5~20ms、触点不允许抖动 → 软件控制周期应 ≥ 50ms 量级（以继电器手册为准），并且**严禁用 PWM 驱动继电器线圈**。
4. **上电默认态**：Port 初始化要早于应用逻辑，先把所有开关输出显式置为安全态（低），再交给应用控制，避免初始化窗口负载乱动。
5. **开关次数统计**：继电器触点有寿命，软件里对高频动作的继电器做次数统计/降频策略，是延长寿命的常见手段。

## 易错点与陷阱

- 用 β 典型值（如 300）算 Rb：低温或大批量下不饱和，管子停在放大区 → Vce 偏大、管子发烫、负载欠压。**必须用 hFE_min × 余量**。
- 忘记减 Vbe：Rb 上电压是 (3.3−0.7)V，不是 3.3V，直接差 20%。
- 基极无下拉电阻：复位期间 GPIO 高阻，基极悬空易受干扰半开通；加 10kΩ 基极-地下拉。
- 感性负载不加续流二极管：关断尖峰几十到上百伏，直接打穿三极管（详见 04 篇）。
- E/C 接反：反向 β 只有 1 左右，现象是"怎么加大 Ib 都不饱和、管子巨烫"。
- 达林顿当万能管用：Vce_sat ≈ 1V，50mA 也有 50mW，大电流场景发热被低估。
- 3.3V GPIO 直驱小信号三极管没问题，但直驱"标准电平 MOS"不行（见 02 篇）。

## 面试高频题

1. **Q：三极管开关为什么要工作在深度饱和？**
   A：饱和后 Vce = Vce_sat 最小，导通损耗 P=Vce_sat×Ic 最小；且 Ib 有余量能抵消 β 随温度/批次的波动，保证批量产品都可靠满开。若 Ib 不足，管子停在放大区，Vce 大 → 发热且负载电压不足。

2. **Q：什么是存储时间？它为什么限制开关频率？**
   A：三极管饱和时基区积累过剩少数载流子，Ib 撤除后必须先泄放这些电荷管子才能退出饱和，这段 Ic"赖着不降"的时间就是存储时间 ts（μs 级）。PWM 周期若与 ts 同量级，占空比严重失真、损耗剧增，所以 BJT 只能做低频开关。

3. **Q：3.3V MCU 怎么控制 12V 继电器？给出电路与 Rb 计算。**
   A：NPN 共射低边开关：线圈接 +12V 与集电极之间，发射极接地，基极经 Rb 接 GPIO，线圈两端反向并联续流二极管。Ic=50mA、β_min=100 → Ib=2.5mA（5 倍余量）→ Rb=(3.3−0.7)/2.5mA≈1kΩ。

4. **Q：达林顿结构的优缺点？**
   A：优点：β 相乘（10³~10⁴），驱动电流需求极低。缺点：Vce_sat≈1V 导通损耗大、存储时间更长、开关慢。适合低速小电流多路驱动（ULN2003），不适合功率开关。

5. **Q：为什么 ECU 里三极管开关越来越少、MOS 越来越多？**
   A：MOS 电压驱动几乎不取电流、无存储时间可高频开关、Rds(on) 损耗在大电流下更低、且易与诊断保护电路集成为智能高边开关；三极管只保留在低成本小电流事件开关里。
