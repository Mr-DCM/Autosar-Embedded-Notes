# 高边与低边驱动

> 一句话定位：开关放在负载的电源侧还是地侧，决定了断开后负载带不带电、能不能诊断、安不安全——这是看懂 ECU 输出驱动电路的第一道选择题。
> 等级：L2 ｜ 前置：[MOS管开关与驱动](02-MOS管开关与驱动.md)

## 原理

任何"电源—负载—开关—地"回路，开关只有两个位置可放：紧挨电源（高边，High-Side）或紧挨地（低边，Low-Side）。

```
   高边驱动（开关在电源侧）            低边驱动（开关在地侧）

     +12V (KL30)                        +12V (KL30)
        │                                  │
      [开关]                             [负载]
        │                                  │
      [负载]                             [开关]
        │                                  │
       GND                                GND

   断开后：负载不与电源相连            断开后：负载仍接在 +12V 上
   → 负载两端都不带电，安全            → 对地"悬空"但仍带电，碰地即导通
```

关键差异逐项对比：

| 对比项 | 高边驱动 | 低边驱动 |
|---|---|---|
| 断开后负载状态 | 两端都不带电，安全 | 负载上游仍接 +12V，**带电但对地悬空** |
| 测量陷阱 | 无 | 万用表测负载对地可能读到 12V（经负载串到电源），误判"有电/没断开" |
| 驱动实现 | PMOS 直接做，或 NMOS+电荷泵 | NMOS/NPN 直接做，最简单 |
| 对地短路故障 | 开关能切断，可保护 | 开关在短路点下游，**保护不了对地短路前的路径** |
| 诊断能力 | 易做开路/短路检测（测负载对地电压） | 开路时负载上游仍有电压，判别要靠电流 |
| 负载接地要求 | 负载一端必须固定接地（车身搭铁） | 负载一端固定接电源 |
| 典型器件 | 智能高边开关（HSS） | NMOS/NPN、低边驱动器 |

**低边断开后的带电陷阱（工程安全重点）**：低边开关"关断"只是切断了回路的接地路径，负载的上游依然连着 +12V。此时用万用表测负载下端对地，会通过负载读到接近 12V 的电压，极易误判为"开关没断开"；维修时以为断电去摸负载对地短接的线束，负载会立即通电。**"低边关断≠负载无电"**，断电检修必须断高边或拔保险。

### 智能高边开关（Smart High-Side Switch）

把 NMOS（+电荷泵驱动）、电流检测、温度检测、保护逻辑封装成一个芯片（如 BTS/VNQ 系列多通道产品，以器件手册为准），是当代 ECU 负载输出的主流：

```
        +12V (KL30)
           │
   ┌───────┴────────┐
   │  智能高边开关   │
   │  ┌──────────┐  │
   │  │ NMOS+泵  │──┼──→ OUT0 ──[负载]── GND
   │  │ 电流镜   │──┼──→ OUT1 ──[负载]── GND
   │  │ 过温/过流│  │
   │  │ 诊断逻辑 │  │
   │  └──────────┘  │
   └──┬───┬───┬─────┘
    IN0 IN1 诊断
   (GPIO/PWM) (CS 电流采样 / FAULT 故障报告)
```

接口概念（软件视角的三类引脚）：

- **IN（输入）**：每通道一个，接 GPIO 或 PWM，控制通断；
- **CS/Current Sense（电流采样）**：模拟输出，输出电压正比于负载电流，接 MCU ADC——开路（电流≈0）、过流的软件判据来源；
- **FAULT/ST（故障/状态）**：多为开漏输出（需上拉，见 [上拉下拉电阻](../../1-L1基础/上拉下拉电阻/README.md)），过流/过温/开路时拉低报警。

集成诊断能力：过流保护（限流或关断）、过温关断/自动重试、开路检测、负载突降耐压、感性负载钳位（主动钳位吸收反电动势，见 04 篇）。

## 计算与选型

### 选型决策表：什么时候用高边/低边

| 判断条件 | 倾向 |
|---|---|
| 断开后负载必须安全无电（灯、加热、用户可触及） | 高边 |
| 负载一端必须接车身地（结构搭铁，如燃油泵外壳接地） | 高边 |
| 需要对地短路保护和开路诊断 | 高边（智能开关） |
| 成本极敏感、小电流指示灯/信号 | 低边 |
| 负载一端固定接电源（部分电磁阀驱动拓扑） | 低边 |
| 需要与低边器件组半桥（电机 H 桥下管） | 低边 |
| 维修场景要求"关断即可拆" | 高边 |

### 智能高边开关选型参数清单

| 参数 | 要点 |
|---|---|
| 通道数与 Inom | 单/多通道；额定电流 ≥ 负载稳态电流（灯负载按冷丝冲击电流核） |
| Rds(on) | 决定导通损耗与压降：P=I²R，10A×30mΩ=3W 需铺铜散热 |
| 短路保护 | 限流值/关断策略（是否自动重试） |
| 感性负载能力 | 内部主动钳位能量指标（继电器/电磁阀必看） |
| 诊断精度 | CS 输出斜率（mA/mV）与开路检测门限，能否覆盖最小负载电流 |
| 供电范围与静态电流 | 睡眠模式下 IN 漏电流（睡眠预算，见 ../电源电路/03-功耗估算.md） |
| 认证 | AEC-Q100，工作温度 −40~125°C（以器件手册为准） |

### 算例：用 CS 读负载电流

手册标定 CS 输出 1mV/mA（以器件手册为准），ADC 基准 3.3V/12bit（LSB≈0.8mV）：

- 6A 额定 → CS 输出 6V？——注意多数器件 CS 满量程约 2~4V，配比是"电流×系数"，读手册换算；
- 开路判据：负载 200mA，开路时 CS 读数应 <10mA（对应电压按系数换算），软件阈值取 50mA 留裕量；
- 过流判据：负载稳态 2A，阈值设 3A（1.5 倍），去抖 10~50ms 防浪涌误报（灯冷丝冲击可达稳态 10 倍，去抖时间以负载特性为准）。

## ECU 实例

- 车身控制器（BCM）：车灯、喇叭、雨刮、门锁全部智能高边开关，每通道独立诊断；
- 座椅加热丝：高边开关 + PWM 调功 + 过温保护；
- 继电器/电磁阀线圈：高边开关需带感性钳位能力（或按 04 篇外加续流）；
- 历史方案：喷油嘴低边驱动（低边 NMOS + 专用峰值保持驱动芯片）；
- 组合仪表背光：低边 PWM 控制接地侧（LED 阳极共电源）；
- 经验数字：智能高边单通道 Inom 常见 0.5~10A，多通道芯片 2~8 路，Rds(on) 10~100mΩ（以器件手册为准）。

## 与软件的关联

**FAULT → GPIO 中断 → DTC 上报链路**（智能高边驱动的标准软件形态）：

1. 硬件 FAULT（开漏低有效）拉低 → GPIO 外部中断触发（或周期轮询去抖）；
2. ISR 里置事件标志，交由轮询任务处理，不在中断里做重活；
3. 读 CS/ADC 换算电流，判定故障类型（开路/过流/过温）；
4. 按 Dem 配置的事件位（去抖计数、愈合计数）上报/恢复 DTC，详见 [Dem配置](../../../06-诊断与标定/2-L2进阶/Dem配置/README.md)；
5. 故障处理策略：关通道→延时重试 N 次→锁定并报 DTC（具体策略以项目诊断规范为准）。

软件要点：

- **去抖/消抖**：灯冷丝冲击、容性负载浪涌都是瞬时"过流"，故障判定必须有软件时间窗，避免误报 DTC；
- **开路检测窗口**：感性负载关断后电流退磁需要时间（见 04 篇），在退磁完成前读 CS 会把"电流还没降到 0"误判为正常/故障，按手册 tDEMAG 等待；
- **上电默认态**：IN 引脚通常内部下拉（复位默认关断），但软件仍要在 Port 初始化时显式写 0，形成双保险；
- **PWM 调功**：需要调功率的负载（加热/背光）IN 接 PWM，注意器件的开关速度是否支持目标 PWM 频率（以器件手册为准）。

## 易错点与陷阱

- **低边关断后测到 12V 就以为开关坏了**：其实是负载上游带电、经负载串到测量点的正常现象；判通断要看"开关两端压差"或回路电流。
- **低边驱动保护不了负载对地短路之前的路径**：短路点在开关上游时，低边开关根本检测不到。
- FAULT 忘记上拉：开漏输出悬空，永远读不到低电平以外的状态（见 [上拉下拉电阻](../../1-L1基础/上拉下拉电阻/README.md)）。
- 开路误报：小电流负载（LED 指示）电流低于芯片开路检测门限 → 常态报开路，选型时核对最小可检测电流。
- 感性负载用了不带钳位的普通高边开关：关断反电动势打坏内部 MOS（见 [04-感性负载与续流](04-感性负载与续流.md)）。
- 中断里直接刷 EEPROM/报 DTC：FAULT 中断应只置标志，诊断动作放任务上下文。

## 面试高频题

1. **Q：高边和低边驱动的核心区别？**
   A：开关位置不同——高边在电源侧，断开后负载完全无电，安全、易诊断、能切对地短路；低边在地侧，实现最简单便宜，但断开后负载仍带电（对地悬空），且保护不了开关上游的对地短路。

2. **Q：低边驱动断开后，为什么万用表还能在负载上测到 12V？**
   A：负载上游仍连着 +12V，万用表内阻大，测负载下端对地时电压经负载串过来，读到接近电源电压。这不代表负载在工作，也正说明低边关断≠无电，检修有触点对地导通就使负载通电的风险。

3. **Q：智能高边开关的 IN/CS/FAULT 接口分别是什么？**
   A：IN 是每通道通断控制（接 GPIO/PWM）；CS 是正比负载电流的模拟采样输出（接 ADC，做开路/过流判据）；FAULT 是开漏故障报告输出（需上拉，接 GPIO 中断/轮询），过流/过温/开路时报警。

4. **Q：软件如何处理高边开关的 FAULT？**
   A：FAULT 低有效接 GPIO 中断；ISR 只置标志，任务里读 CS 换算电流判定故障类型，经软件去抖后按 Dem 事件上报 DTC，执行关断-重试-锁定策略，恢复时按愈合计数消除故障。

5. **Q：为什么灯负载的过流判据要做去抖？**
   A：冷灯丝电阻只有热态的 1/10 左右，开灯瞬间冲击电流可达稳态 10 倍量级，瞬时必然"过流"；软件必须设时间窗（几十 ms 量级，以负载特性为准）过滤浪涌，否则每次开灯都误报 DTC。
