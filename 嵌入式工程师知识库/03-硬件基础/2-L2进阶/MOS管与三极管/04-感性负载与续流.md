# 感性负载与续流

> 一句话定位：电感电流不能突变，关断瞬间 V=L·di/dt 产生高压尖峰——不加续流措施就炸管，加错了方向就短路，这是驱动继电器/电磁阀的第一条铁律。
> 等级：L2 ｜ 前置：[高边低边驱动](03-高边低边驱动.md)

## 原理

继电器线圈、电磁阀、电机绕组都是感性负载（Inductive Load）：等效为电感 L 串联电阻 R。

**电感电流不能突变**：电感以磁场储能 E = ½LI²，电流要变化就要改变储能，而能量不能瞬间转移。开关强行把电流回路切断时，di/dt 极大：

```
V_反电动势 = L × (di/dt)
直觉：电感为了维持电流不变，会产生任意高的电压给自己续命
     （回路断得越快，di/dt 越大，尖峰越高）
```

### 不加续流的后果

- **开关管过压击穿**：12V 系统里线圈关断尖峰轻松冲到几十~上百伏，超过 MOS 的 Vds（或 BJT 的 Vceo）→ 雪崩击穿，反复冲击后管子损坏；
- **地弹（Ground Bounce）**：尖峰电流流经地线电感，使本地地电位瞬间抬升，殃及同一块板上的 MCU/逻辑电路（复位、通信误码）；
- **EMC 辐射**：关断沿极陡的高压振铃是宽频干扰源，收音机杂音、CAN 误码常由此而来。

### 续流二极管（Freewheeling Diode）

给线圈电流一条"泄洪通道"：反向并联在线圈两端（阴极接电源正侧）。

```
              +12V (KL30)
                 │
        ┌────────┴────────┐
        │                 │
        │            D1   │
        │        ┌────|◄──┤   D1：阴极(|◄ 竖线侧)朝 +12V
   [线圈 L+R]     │       │        反向并联在线圈两端
        │        └────►───┘
        │                 │   续流通路：线圈下端 → D1 → 线圈上端
        └────────┬────────┘   （电流沿原方向继续流，经 D1 环流衰减）
                 │
                 C
   驱动(GPIO/高边开关)   ← 开关关断后，线圈电流改走 D1 续流
                 │
                GND
```

工作直觉：开关关断瞬间，线圈电流"惯性"保持原方向 → 线圈两端电压翻转，直到下端比上端高 0.7V（二极管导通）→ 电流在"线圈—二极管"环路里环流，按时间常数 τ=L/R 指数衰减 → 开关两端电压被钳位在 Vsupply+0.7V，安全。

**为什么接反就是短路**：二极管如果正向跨在线圈两端（阳极接 +12V 侧、阴极接开关侧），电源→二极管→开关→地形成低阻通路，开关闭合瞬间二极管直接把电源短路——烧管、烧电源。

### 尖峰有多高（量级直觉）

```
无钳位时的理论尖峰：V = L × di/dt
例：L=0.24H 的继电器线圈，电流 50mA 在 1μs 内被强制切断：
    V ≈ 0.24 × (0.05/1e-6) = 12000V → 现实中被寄生电容/雪崩钳位
    在几十~几百伏，仍远超开关管耐压
```

实际不会到理论值——线圈的寄生电容会与其形成 LC 振铃，把尖峰"限制"在几倍电源电压量级（几十~上百伏），但这依然足以击穿 40V/60V 耐压的器件。所以结论不是"可能过压"，而是"必然过压，只是高低问题"。

常见感性负载的储能量级（以器件手册为准）：

| 负载 | 电感量级 | 稳态电流量级 | 单次关断能量 |
|---|---|---|---|
| 小型信号继电器线圈 | 0.1~1H | 20~50mA | 0.1~1mJ |
| 功率继电器线圈 | 0.05~0.5H | 50~200mA | ~1mJ |
| 喷油嘴电磁阀 | 1~20mH | 0.5~20A（峰值） | 10~100mJ |
| 直流电机绕组 | μH~mH | A 级 | 大（桥臂体二极管续流） |

### RC 吸收（Snubber）概念

电阻+电容串联后并联在开关两端（或线圈两端）：电容在电压跳变瞬间提供低阻通路吸收尖峰，电阻消耗能量抑制振铃。适用场景：继电器触点灭火花、交流/不便用二极管的场合、与二极管配合加快电流衰减（RCD：二极管串电阻，牺牲钳位电压换退磁速度，喷油嘴驱动常用，典型 R 几欧~几十欧、C 0.01~0.1μF，以设计规范为准）。

## 计算与选型

### 算例：继电器线圈续流设计

已知：线圈 12V / 240Ω（I0 = 50mA），电感 L ≈ 0.24H（继电器手册典型值，以手册为准）。

1. **续流时间**：τ = L/R = 0.24/240 = 1ms，电流约在 3~5τ（3~5ms）内衰减到接近 0——继电器释放时间因此略被拖慢（磁通维持），若嫌慢用稳压管+二极管钳位（钳位电压高、衰减快）；
2. **二极管电流**：续流起始电流=稳态 50mA，平均电流 = I0×τ×开关频率（50Hz 动作时 <2.5mA），选额定 ≥ 线圈稳态电流（1N4148 的 200mA 足够此例；大电流电磁阀选 1A 级快恢复/肖特基）；
3. **二极管耐压**：≥ 2× 电源电压；汽车 12V 系统还要考虑负载突降（Load Dump，可到 40V+，钳位后以 ISO 16750/项目规范为准），常取 ≥ 60~80V；
4. **恢复速度**：开关频率高时选快恢复/肖特基（trr ns 级），低速继电器 1N4148 即可；
5. **能量核算**：E = ½LI² = 0.5×0.24×0.05² = 0.3mJ/次；动作频率 f 时二极管功耗 P ≈ E×f，50Hz 时 15mW，无压力。高频电磁阀（数百 Hz）必须认真算。

选型速查：

| 项目 | 经验准则 |
|---|---|
| 反向耐压 Vr | ≥ 2×Vsupply，且满足负载突降要求 |
| 电流额定 | ≥ 线圈稳态电流 |
| 恢复速度 | 高频开关选快恢复/肖特基 |
| 极性 | 阴极接电源正侧（万用表二极管档复核） |
| MOS 方案 | 选带主动钳位（Active Clamp）的智能开关，能量指标按手册核算 |

## ECU 实例

- 继电器线圈：最经典的续流场景，ULN2003 内置续流二极管（COM 脚必须接 +12V，否则白配）；
- 喷油嘴/电磁阀：峰值保持驱动，常用 RCD 或稳压管钳位，钳位电压越高退磁越快（高速开关必需）；
- 直流电机绕组：桥臂体二极管续流 + 死区配合（见 [02-MOS管开关与驱动](02-MOS管开关与驱动.md)）；
- 触点保护：继电器触点两端 RC 灭火花，延长触点寿命；
- 经验数字：继电器线圈储能 mJ 级，大电磁阀几十~上百 mJ；退磁时间 tDEMAG 手册给值，开路诊断窗口必须等它结束（见 [03-高边低边驱动](03-高边低边驱动.md)）。

## 与软件的关联

1. **开关频率限制**：感性负载电流按 τ=L/R 上升/衰减，周期太短电流根本到不了稳态（等效"关不断/开不满"）。PWM 周期应远大于 τ（>5~10 倍），或干脆只用通断控制。
2. **PWM 驱动继电器为什么禁止**：①机械触点响应 5~20ms，跟不上 PWM 会持续弹跳打弧烧触点；②线圈电流来不及建立，触点吸合不牢；③每次开关都产生续流尖峰，EMC 灾难。继电器只允许"慢速通断"。
3. **退磁时间与开路诊断**：智能高边开关关断感性负载后，须等 tDEMAG 再做开路判定，否则把衰减中的电流/电压读成异常——软件里开路检测要留延时窗口（以器件手册为准）。
4. **关断顺序**：下电流程先停 PWM/通断控制、等电流衰减，再断主电源轨（EcuM 下电序列），避免带电流硬切。
5. **高频电磁阀的 PWM 参数**：如喷油嘴的峰值/保持电流控制，PWM 频率与钳位电压共同决定退磁速度，参数由硬件特性定，软件只是执行配置。

## 易错点与陷阱

- **二极管接反 = 短路**：正向并联后开关闭合瞬间电源直接对地，立烧。装调时用万用表二极管档确认"线圈两端反向"。
- 只看耐压不看能量/平均功耗：高频动作场景二极管发热被低估（P≈E×f）。
- 信号二极管扛大电流：1N4148 额定 200mA 冲击可以，大电磁阀稳态安培级必须选功率管。
- 忘记 ULN2003 的 COM 接电源：续流二极管形同虚设，损坏芯片。
- 高频 PWM 场景用普通二极管续流：trr 慢 → 反向恢复尖峰叠加，改快恢复/肖特基或 RCD。
- 长线束（本身是电感）驱动的负载即使"阻性"也建议留缓冲措施；MCU 引脚出板的长线更要防感性耦合/ESD。
- MOS 过压击穿有时"延迟发作"：每次关断都雪崩一次，单次不坏、累计老化后批量失效——示波器看关断沿才是真相。

## 面试高频题

1. **Q：为什么感性负载关断会产生高压尖峰？**
   A：电感电流不能突变（磁场储能不能瞬间消失），开关切断回路时 di/dt 极大，V=L·di/dt 产生反电动势，回路断得越快尖峰越高，可达电源电压的十倍量级，超过开关管耐压就击穿。

2. **Q：续流二极管怎么接？怎么选？**
   A：反向并联在线圈两端（阴极接电源正侧），关断后电流经二极管环流、按 τ=L/R 衰减，把开关电压钳位在 Vsupply+0.7V。选型：反向耐压 ≥2× 电源电压并满足负载突降、电流 ≥ 线圈稳态电流、高频用快恢复/肖特基，最后按 P≈½LI²×f 核功耗。

3. **Q：续流二极管接反了会怎样？**
   A：变成正向并联，开关闭合瞬间电源经二极管直通到地形成短路，烧驱动管甚至电源。所以调试时必须先核对极性。

4. **Q：为什么禁止用 PWM 驱动继电器线圈？**
   A：继电器是机械开关：触点响应 5~20ms 跟不上 PWM 会持续弹跳打弧烧蚀触点；线圈电感使电流难以建立，吸合不牢；每次开关都有续流尖峰，EMC 恶化。继电器只能低速通断控制。

5. **Q：RC 吸收和续流二极管有什么区别？各用在什么地方？**
   A：二极管把电压钳位到约 0.7V，续流慢、退磁慢，适合低速继电器；RC/RCD 吸收能量并提高钳位电压，退磁快、抗振铃，适合高频电磁阀（喷油嘴）、继电器触点灭火花、交流场合。
