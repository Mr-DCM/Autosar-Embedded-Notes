## 原理

### 1. 晶体等效模型：BVD 电路（RLC 串联谐振）

石英晶体在电气上等效为"串联 RLC 支路 + 并联电容 Cp"，即 BVD（Butterworth-Van Dyke）模型：

```
   端子1 ●──┬───────────────────────┬──● 端子2
            │                       │
          ─┴┐ Cp                  ┌─┴─┐
          ─┬┘ 并联电容            │串 │
            │  (石英电极+支架      Rm  │  运动电阻 mΩ~百Ω
            │   寄生，pF 级)       Lm  │  运动电感 mH~百 mH ← 高 Q 的来源
            │                       Cm  │  运动电容 fF~几 pF
            │                       └─┬─┘
   端子1 ●──┴───────────────────────┴──● 端子2
```

关键结论：

- **串联谐振频率 fs**：由 Lm、Cm 决定，fs = 1/(2π√(Lm·Cm))，此时晶体呈纯阻（Rm）
- **并联谐振频率 fp**：Cp 参与后比 fs 略高，间距由 Cm/Cp 比值决定，典型为万分之几量级
- 皮尔斯电路实际振荡频率落在 fs 与 fp 之间，**外接负载电容 CL 决定确切落点**——这就是"CL 不对 → 频偏"的物理根源
- Q = 2πf·Lm/Rm 可达 10⁴~10⁶，远高于普通 LC 回路——这是晶振 ppm 级稳定度的来源

### 2. 基音 vs 泛音（一句话）

晶体可工作在基音（fundamental，几十 MHz 以下）或奇次泛音（overtone，3/5/7 次，用于 30~200 MHz 高频晶体，需额外 LC 选频回路抑制基音）；MCU 主时钟用的几乎都是基音晶体，泛音晶振多见于以太网 PHY 等高频场景。

### 3. 拉偏特性（Trim Sensitivity）

CL 偏离标称值 → 振荡频率移动，典型灵敏度每 pF 引起数 ppm 到十几 ppm（向上偏 CL → 频率向 fs 方向下移），具体曲线以晶体规格书为准。

## 计算与选型

### 1. CL 进阶算例（目标 CL = 12.5 pF）

设计步骤（含 Cstray 估计与取值校核）：

```
第 1 步：查晶体规格书，标称 CL = 12.5 pF
第 2 步：估计 Cstray（引脚寄生 + PCB 走线 + 焊盘）
        MCU OSC 引脚寄生：2~4 pF（查 DS）
        PCB 走线（<10mm，紧凑布局）：0.5~1.5 pF
        焊盘/过孔：约 0.5 pF
        → 取 Cstray ≈ 4 pF（保守可按 3~5 pF 区间）
第 3 步：反解外部电容串联值
        需要 (C1×C2)/(C1+C2) = 12.5 − 4 = 8.5 pF
第 4 步：取对称值 C1 = C2 = 2×8.5 = 17 pF → 取标称 18 pF
第 5 步：回代校核：18/2 + 4 = 13 pF，比目标大 0.5 pF
        → 若按 3 ppm/pF 灵敏度，约 −1.5 ppm，可接受
第 6 步：验电容规格：精度选 ±5%（C0G/NP0 温漂最小），
        别用 X7R——容值随温度/电压漂移会直接转化为频偏
```

对比入门篇的 12 pF 算例可见：**Cstray 每估错 1 pF，结论电容值就差 2 pF**——这是"抄别家板子电容值"频发的根因。

### 2. 频偏来源分解（各典型量级）

| 频偏来源 | 典型量级 | 说明 |
|---|---|---|
| 初始容差（工厂调整） | ±10~30 ppm | 25°C 标称条件下 |
| CL 失配（含 Cstray 估计误差） | 每 pF 数 ppm | 见上文算例 |
| 温度漂移（AT 切） | −40~125°C 内约 ±15~30 ppm | S 形曲线，切角决定形状；以规格书为准 |
| 老化 | 首年 ±1~3 ppm，之后递减 | 驱动功率超标会显著加速老化 |
| 驱动功率（Drive Level）过大 | 额外温漂+老化 | 串 Rs 限流保护；规格书典型 DL 100 μW 量级 |

### 3. 频偏的系统性危害量化：CAN 采样点漂移

直觉计算（以 500 kbit/s、时钟偏差 +0.5% 为例）：

```
1 位时间 = 1/500k = 2000 ns
0.5% 偏差 → 每位多走 10 ns
CAN 位填充保证边沿最疏间隔约 10 位（5 同值位 + 填充位）
→ 两次再同步之间误差累积可达 10 × 10 ns = 100 ns
相位缓冲段（Seg1+Seg2+SJW）预算通常只有几百 ns
→ 100 ns 已吃掉预算的相当比例；再叠加线上噪声/收发器延迟
→ 表现为偶发位错误、CRC 错误，高低温下批量复现
```

这正是 CAN 振荡器容差预算通常按 ±0.5% 量级设计的原因（精确公式以 CAN 规范位时序计算为准）。晶振总偏差（初始+温漂+老化）几十 ppm 远够；但**任何"拿 RC/内部振荡器凑合当 CAN 时钟"的决定都会直接烧穿这个预算**。

### 4. LIN 从机同步容忍度

LIN 从机无石英时靠起始位下降沿同步主机时钟。同步后从机时钟容差仍需保持在约 ±1.5%~2% 量级（数据段与校验段要求不同，以 LIN 规范为准）——所以 LIN 从机节点用内部 RC（±1~2% 出厂精度）**临界可行但高风险**（温漂叠加后超标），量产项目仍普遍用晶振。

### 5. TCXO 概念与何时需要

- TCXO（Temperature Compensated Crystal Oscillator，温补晶振）：内部用温度传感器 + 变容网络补偿温漂，全温区 ±0.5~2 ppm
- 何时需要：需要长期精确时基（如整车时钟、计量）、CAN-FD 更高的容差要求、宽温区下普通晶振预算吃紧时
- 大多数车身/底盘 ECU：普通无源晶体 + 正确的 CL 设计已足够

## ECU 实例

- 某车身控制器：20 MHz 晶体、CL=12 pF、C1/C2=16 pF/16 pF、C0G ±5%，量产实测频偏 ≤±30 ppm（含高低温），CAN 500 kbit/s 零容差问题（数字以该项目规格书/实测报告为准）
- 某网关：CAN-FD + 车载以太网，时钟预算紧，选 TCXO 供 PHY（以太网 50 ppm 要求但抖动指标紧）
- 排障案例：产线批量"偶发 CRC 错误"，最终定位 8 pF 与 12 pF 两卷晶体混料——CL 差 4 pF → 频偏十几 ppm，单节点没事，与另一批节点配对时采样点漂移超限

## 与软件的关联

1. **Mcu 时钟配置里的"外部晶振频率"必须与 CL 设计后的实际频率一致**——硬件换晶体型号，软件配置要同步改
2. CAN 位时序参数（Seg1/Seg2/SJW/采样点）由时钟频率推算，频偏预算是位时序设计输入之一
3. 时钟失效检测中断（CSS/时钟监测）需按安全策略处理：记录 DTC、切换备份时钟或复位
4. 低功耗进休眠停晶振，唤醒后等起振稳定（典型 ms 级）再开通讯，否则首帧就位错误

## 易错点与陷阱

- Cstray 按 0 估算 → CL 偏大 → 批量负频偏；按 10 pF 高估 → 频率偏高，同样错
- 用 X7R 介质做负载电容：容值温漂 → CL 随温度变 → 频偏随温度跑
- 只看常温频率不验高低温：温漂项在 85°C/−40°C 才暴露
- 驱动功率超标长期运行：老化加速，产线老化后频偏逐年劣化，售后才爆
- 两颗电容不对称取值（C2 大 C1 小）本身不必然错（有意调节 CL 或压摆），但抄设计不明就里容易错
- 示波器探头（约 10 pF）直接挂 XTAL 引脚测频率——测量本身把频率拉偏（详见信号完整性篇的探头负载效应）

## 面试高频题

**Q1：晶体等效模型是什么？为什么振荡频率由 CL 决定？**
A：BVD 模型——Rm/Lm/Cm 串联支路并 Cp。串联谐振 fs 由 Lm·Cm 决定，并联谐振 fp 略高；皮尔斯电路振荡在 fs 与 fp 之间，外接 CL 越大落点越向 fs 靠近（频率越低），所以 CL 决定确切频率。

**Q2：目标 CL=12.5 pF，Cstray 估 4 pF，C1/C2 怎么取？**
A：需外部串联 8.5 pF，对称取 C1=C2=17 pF → 标称 18 pF，回代 18/2+4=13 pF，偏差 0.5 pF（数 ppm 量级）可接受；电容选 C0G ±5%。

**Q3：频偏来源有哪些？各什么量级？**
A：初始容差 ±10~30 ppm；CL 失配每 pF 数 ppm；AT 切温漂 −40~125°C 约 ±15~30 ppm；老化首年 ±1~3 ppm，驱动功率超标会加速。总预算做最坏情况累加再对网络容差。

**Q4：0.5% 频偏对 CAN 采样点意味着什么？**
A：500 kbit/s 下每位 2000 ns，0.5% 即每位 10 ns；位填充保证约 10 位内必有边沿，两次再同步间累积可达 100 ns，与几百 ns 的相位缓冲预算同量级——叠加噪声即出现偶发位错误，所以 CAN 容差预算按 ±0.5% 量级设计。

**Q5：什么是 TCXO？什么时候必须上？**
A：温补晶振，用变容网络补偿温漂，全温区 ±0.5~2 ppm。需要长期精确时基、CAN-FD/以太网等容差或抖动指标紧、或宽温区下普通晶体预算不够时使用。
