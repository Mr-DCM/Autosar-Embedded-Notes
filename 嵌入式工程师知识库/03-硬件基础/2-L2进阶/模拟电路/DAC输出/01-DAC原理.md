# DAC 原理：从数字码到模拟电压

> 一句话定位：DAC（Digital-to-Analog Converter，数模转换器）用电阻网络把二进制码按权重叠加成电压/电流，MCU 内部 DAC 常用于给比较器供阈值、生成测试波形。
> 等级：L2 ｜ 前置：[采样与量化](../ADC采样原理/01-采样与量化.md)

## 原理

### R-2R 梯形网络

只用两种阻值（R 和 2R）搭出按 2 的幂加权的分压网络，每一位开关决定该位电流流向：

```
          2R        2R        2R        2R
Vref ──┬──[2R]──┬──[2R]──┬──[2R]──┬──[2R]──┐
       │        │        │        │        │
      [SW b3]  [SW b2]  [SW b1]  [SW b0]   │（末端 2R 到地）
       │        │        │        │       2R
       └─ R ────┴─ R ────┴─ R ────┴──→ Vout
              （每位开关接地=0，接 Vref=1）

4bit 输出：Vout = Vref × (b3/2 + b2/4 + b1/8 + b0/16)
```

好处：阻值只有两种，芯片内易做到高匹配度，温度跟踪一致。从 Vout 向左看的戴维南等效电阻恒为 R——这就是"输出阻抗=R"的由来，也是必须加缓冲的原因。

### 电压型 vs 电流型

- **电压型**（如 R-2R 电压模式）：输出电压，高输出阻抗，需运放缓冲——MCU 片上 DAC 多为此类。
- **电流型**：输出电流（常见 STEERING 电流舵结构），速度快，负载上并联精确电阻转电压，视频/通信常用。

### 建立时间（Settling Time）

定义：输入码跳变后，输出进入终值 ±½LSB 带内并保持所需时间。MCU 片上 DAC 典型几 µs 量级（含缓冲器，以器件手册为准）。**换码频率不能快于建立时间**，否则输出永远在追赶，波形幅度偏小。

### 输出缓冲器的必要性

R-2R 网络输出阻抗 ≈ R（内部电阻网络几十 kΩ 量级的芯片比比皆是），不缓冲直接带负载就是分压器：

```
不带缓冲：Vout' = Vout × RL / (RL + R)
```

### MCU 内部 DAC 兿型用法

1. **阈值基准**：DAC 输出接比较器同相端，软件实时改码值即改检测门限（过流检测门限随工况调整）。
2. **波形发生**：Timer 定时触发 + DMA 搬运查找表，输出正弦/斜坡做激励或自检信号。
3. **慢变控制量**：背光亮度、偏置电压等（配 RC 见 [02-输出缓冲与滤波.md](02-输出缓冲与滤波.md)）。

## 计算与选型

**算例 1：未缓冲直接带负载的错误**

3.3V 系统、12bit DAC，内部 R-2R 输出阻抗 Rout=10kΩ（典型量级，以 DS 为准）。写码 2048（半量程）：

```
空载：Vout = 2048 × 3.3/4096 = 1.650V
接 RL=10kΩ 负载：Vout' = 1.650 × 10k/(10k+10k) = 0.825V  ← 差了一半
```

即使接 100kΩ"高阻"负载：1.650 × 100/110 = 1.500V，仍差 9%。结论：**电压型 DAC 不带缓冲就没有直连负载的能力**。

**算例 2：码值与电压互转（12bit、Vref=3.3V）**

```
V = code × Vref / 2^N = code × 0.8057mV
要输出 1.000V：code = 1.000/0.0008057 ≈ 1241
```

**算例 3：PWM+RC 伪 DAC 与真 DAC 的选择**

| 维度 | 片上 DAC | PWM+低通（伪 DAC） |
|---|---|---|
| 成本 | 占用 DAC 外设 | 只要一个定时器通道+RC |
| 分辨率 | 硬件位数（12/8bit） | 占空比步数（Timer 周期决定，常用 8~10bit 有效） |
| 纹波 | 本征无开关纹波，仅噪声 | 由 RC 与 PWM 频率决定，永远存在 |
| 带宽 | 高（µs 级建立） | 极低（RC 要压纹波，通常 <100Hz） |
| 适用 | 波形发生、快速阈值 | 背光调节等慢变直流量 |

结论口诀：**要快、要干净用 DAC；只要一个慢直流电平且 DAC 口富余，PWM+RC 也够**。

## ECU 实例

- 过流检测门限：DAC 输出 0~3.3V 接比较器基准端，软件按工况在 0.5V~1.2V 间调门限，码值 621~1490。
- 传感器开路自检激励：DAC 经 10k 注入 100mV（码 124）偏置，看 ADC 回读判断断线。
- 背光亮度：8bit 模式足够（0~255 级），码值线性映射 0~3.3V 控制驱动芯片 ADJ 脚。
- 注意点：Vref 同样是 DAC 的"刻度尺"，Vref 抖 1% 输出抖 1%，去耦与基准选择同 [../ADC采样原理/02-参考电压与精度.md](../ADC采样原理/02-参考电压与精度.md)。

## 与软件的关联

- **MCAL/Dio 层**：DAC 通常不进 AUTOSAR 标准外设抽象（非 IO 语义），项目里多做成 CDD（Complex Device Driver）提供 `Dac_SetValue(channel, code)` 接口。
- **写码时序**：改码前确认上次输出的建立时间已过；做波形发生时用 Timer 触发 DMA 自动搬表，避免 CPU 抖动造成波形周期毛刺。
- **码值换算宏**：`#define DAC_MV_TO_CODE(mv) ((uint16)(((mv)*4096UL + 1650UL)/3300UL))` 四舍五入一次到位。
- **校准**：输出精度同样受 Vref 影响，高要求场合用 ADC 回读 DAC 输出做闭环校准。

## 易错点与陷阱

- 把 DAC 输出当"能驱动东西的电源"：输出阻抗 kΩ 级，直连 LED/低阻负载立即拉垮，必须缓冲（见算例 1）。
- 满码写 4096：12bit 最大码是 4095，写 4096 会截断/回绕（看硬件实现），校准表里最上面一格尤其容易踩。
- 高于建立时间连续换码：输出变成"追不上的斜坡"，波形幅度偏小，误判为 DAC 增益不足。
- 忽视码值抖动沿：DAC 码切换瞬间有尖峰毛刺（glitch energy），后级比较器可能误触发，必要时加小 RC。
- 单电源 DAC 想输出负压/双极性：需外部偏置电路或差分接法，软件码值映射要同步改，不是"写负数"就行。

## 面试高频题

**Q1：R-2R 网络为什么只用两种阻值就能实现二进制权重？**
答：每级 2R 与后级等效 R 的分压恒为 1/2，向输出每前进一级权重减半，位自然按 2 的幂叠加；两种阻值在工艺上易匹配。

**Q2：电压型 DAC 为什么必须加输出缓冲？**
答：内部电阻网络输出阻抗为 R（kΩ~几十 kΩ 级），任何负载都会与 R 分压造成增益误差；缓冲（跟随器）把输出阻抗降到 Ω 级，实现"所写即所得"。

**Q3：DAC 建立时间的定义是什么？为什么它限制了更新率？**
答：输出进入终值 ±½LSB 并保持的时间；更新周期短于建立时间时输出永远达不到终值，幅度与形状都失真。

**Q4：什么场景用 PWM+RC 替代 DAC 合理？**
答：慢变直流量（亮度、偏置）、带宽要求 <几十 Hz、允许一定纹波、且 DAC 资源紧张或没有时；反之要波形/低纹波/快建立就用真 DAC。
