# 输出缓冲与滤波：让 DAC "所写即所得"

> 一句话定位：DAC→运放缓冲→RC 滤波→负载是标准输出信号链，缓冲解决带载能力，RC 解决纹波与毛刺，两者参数都要在"纹波 vs 建立时间"之间做权衡。
> 等级：L2 ｜ 前置：[DAC原理](01-DAC原理.md)

## 原理

### 标准信号链

```
            R-2R 网络                缓冲(跟随器)         RC 低通
code ──→ [DAC Rout≈R(kΩ)] ──→ [运放 Gain=1] ──→ [R ──┬──] ──→ 负载
         阻抗高，不能带载      阻抗变换：kΩ→Ω 级      │
                                                    C（滤纹波/毛刺/噪声）
```

三个环节各司其职：

1. **DAC**：产生与码值成比例的电压，但输出阻抗 kΩ 级。
2. **缓冲（电压跟随器）**：输入端几乎不取电流、输出端阻抗极低，做"阻抗变换"，原理见 [../运放电路/01-理想运放与虚短虚断.md](../运放电路/01-理想运放与虚短虚断.md)。MCU 片上 DAC 通常已内置缓冲，注意有些器件可配置旁路（BYPASS）——旁路后就是裸 R-2R 输出，只能喂高阻负载。
3. **RC 低通**：把 DAC 换码毛刺、量化噪声和高频干扰压掉，让输出平滑。

### 纹波与建立时间的跷跷板

RC 越大（截止频率越低）→ 纹波越小，但阶跃建立越慢：

```
一阶 RC 阶跃：达到 90% 需 2.2τ，达到 99% 需 4.6τ
τ = RC
```

设计永远是折中：先定纹波指标算出 τ 下限，再验证建立时间是否满足应用节奏，两头打架就升 PWM 频率/加滤波阶数/换真 DAC。

## 计算与选型

**算例 1：PWM 伪 DAC 的纹波估算（背光调节）**

条件：3.3V MCU、PWM 20kHz（周期 T=50µs）、占空比 50% 时纹波最大。一阶 RC 在 τ >> T 时，锯齿纹波峰峰值近似：

```
Vripple ≈ Vcc × T / τ
```

目标纹波 <1%（33mV）：

```
τ > Vcc × T / Vripple = 3.3V × 50µs / 33mV = 5ms
取 R=10kΩ、C=1µF → τ = 10ms（留 2 倍余量）
fc = 1/(2πRC) = 1/(2π × 10k × 1µF) ≈ 15.9Hz
```

建立验证：亮度从 10%→90% 约 2.2τ = 22ms，人眼对背光渐变无感，可接受。若产品要求 5ms 内完成调光渐变，就得减小 τ 并放宽纹波，或提高 PWM 频率到 100kHz 重算。

**算例 2：真 DAC 要纹波 <1LSB 有多难（为什么别提这种指标）**

同上 20kHz 阶梯源（若用 PWM），12bit 1LSB=0.806mV：

```
τ > 3.3V × 50µs / 0.806mV ≈ 205ms
fc ≈ 0.78Hz，99% 建立 ≈ 4.6τ ≈ 0.94s
```

一个亮度调节要 1 秒才稳定——工程不可用。**结论**：① 真正需要 <1LSB 纹波时改用真 DAC（本征无开关纹波，RC 只需对付毛刺，τ 取 µs 级即可）；② 或提高开关频率 16 倍（纹波按 1/f 下降）再配 RC；③ 或上二阶 RC（同 τ 纹波再降一个量级）。

**算例 3：真 DAC 的 RC 只为压毛刺**

12bit DAC 换码毛刺 ns 级、信号带宽 <1kHz：取 R=100Ω、C=10nF → τ=1µs，fc=159kHz，对 1kHz 信号幅度几乎无衰减（-0.003dB），毛刺能量大的高频段被压 40dB 以上（以实测毛刺频谱为准）。**RC 别盲目加大**——先想清楚要滤的是什么频段。

### 慢变模拟量的工程做法（背光调节模板）

1. 优先片上 DAC（若有）：`code = brightness × 255 / 100`（8bit），缓冲直出，无纹波烦恼。
2. 没有 DAC：Timer PWM 20kHz+，RC 取 10k/1µF（fc≈16Hz），渐变用软件斜坡每 20ms 加 1 级。
3. 负载是驱动芯片 ADJ 脚（高阻）：缓冲可省；负载 <100kΩ 或引线长：一律加跟随器再出板。

## ECU 实例

| 应用 | 信号链 | 关键参数 |
|---|---|---|
| 背光调节 | MCU PWM 20kHz → RC 10k/1µF → 屏驱动 ADJ | 纹波 <1%，渐变 22ms |
| 传感器自检激励 | 片上 DAC → 跟随器 → 10k 注入电阻 | 码 124（100mV） |
| 比较器阈值 | 片上 DAC → 直连比较器同相端（高阻负载） | 免缓冲，注意毛刺加 100Ω+1nF |
| 音频提示音 | DAC + Timer 触发 DMA 查表 → 缓冲 → 二阶 RC | fc ≈ 30kHz，建立 µs 级 |

## 与软件的关联

- **渐变斜坡**：直接从码 0 跳到码 255 会让背光"啪"地亮；软件按固定节拍（如 10ms）步进 ±1，视觉平滑，也降低对 RC 建立时间的要求。
- **PWM 频率与分辨率联动**：提高 PWM 频率会减少定时器计数步数（分辨率下降），伪 DAC 要同时核对"频率上去了、占空比步数还够不够 8bit"。
- **DMA+Timer 波形发生**：RC 之后的建立时间要计入波形频率上限（周期 > 4.6τ 才能到 99% 幅度）。
- **毛刺规避**：对毛刺敏感的比较器阈值应用，软件避免在大电流负载开关动作的同一时刻改 DAC 码值，错开几 ms。

## 易错点与陷阱

- 把 RC 当万能平滑器而不管 τ：τ 太小纹波依旧，太大响应迟钝，必须带数字验算（见算例 1/2）。
- 缓冲运放选型只看"轨到轨输入"不看输出电流与容性负载稳定性：带长线/大电容会振铃甚至振荡，串 50~100Ω 隔离（以运放手册为准）。
- 旁路了片上 DAC 内置缓冲还直连负载：等效 R-2R 裸输出，负载分压把增益吃掉一半（见 [01-DAC原理.md](01-DAC原理.md) 算例 1）。
- PWM 伪 DAC 带负载后忘了输出阻抗：RC 的 R（如 10k）本身串在路径里，负载 10k 就再分压一半——重负载时 R 要减小、C 同比加大。
- 电容选型：1µF 用 X7R 陶瓷即可，但电压系数会损失容值（偏置下-20% 常见），精度要求高的场合以实测或薄膜电容为准。

## 面试高频题

**Q1：为什么 DAC 输出后要加跟随器？**
答：DAC 内部电阻网络输出阻抗 kΩ 级，负载会分压造成增益误差；跟随器输入高阻、输出低阻，隔离负载、保住满摆幅驱动能力。

**Q2：PWM+RC 做 DAC，纹波和响应速度怎么权衡？**
答：纹波 ∝ 1/(f_PWM × τ)，响应时间 ∝ τ：先按纹波指标算 τ 下限，再验证建立时间；矛盾时提高 PWM 频率、加二阶 RC 或改用真 DAC。

**Q3：一阶 RC 阶跃到 90% 要多久？**
答：t ≈ 2.2τ（τ=RC）；到 99% 约 4.6τ。这是估算所有"RC 之后多快能稳定"的速查数。

**Q4：给比较器供阈值的 DAC 要不要 RC？**
答：要小 RC（百 Ω+纳法级）：不为纹波，为压换码毛刺，避免毛刺瞬间误触发比较器。
