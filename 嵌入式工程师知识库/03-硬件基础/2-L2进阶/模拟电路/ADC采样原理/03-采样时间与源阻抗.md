# 采样时间与源阻抗：读数偏低的隐形元凶

> 一句话定位：ADC 内部保持电容要靠源阻抗充电，采样窗不够长电容充不满，读数就偏低且随通道顺序变化——软件上表现为"采样时间参数一改读数就变"。
> 等级：L2 ｜ 前置：[采样与量化](01-采样与量化.md)、[参考电压与精度](02-参考电压与精度.md)

## 原理

### 充电模型

从信号源看进 ADC 输入脚，等效电路是：

```
                 Ron（采样开关导通电阻，kΩ 级）
Vin ──[Rs 源阻抗]──[SW]──┬────→ ADC 比较器
  传感器/分压网络          │
                        Ch（保持电容，pF 级）
                         │
                        GND
时间常数 τ = (Rs + Ron) × Ch
```

采样窗内 SW 闭合，Ch 以指数曲线从当前残压冲向 Vin：

```
V_Ch(t) = Vin − (Vin − V_0) × e^(−t/τ)
```

### τ 直觉：3τ/5τ 工程法则

| 充电时间 | 充到目标 | 残余误差 |
|---|---|---|
| 1τ | 63.2% | 36.8% |
| 3τ | 95.0% | 5% |
| 5τ | 99.3% | 0.7% |

对 N bit ADC，要让充电残余误差 < ½LSB，需要：

```
t ≥ τ × ln(2^(N+1)) = τ × (N+1) × 0.693
12bit：t ≥ 13 × 0.693 ≈ 9τ
```

### 读数偏低与串扰

- **读数偏低**：Ch 没充满，采到的电压比 Vin 低，且**输入电压越高偏差越大**（从 0 冲向 3.3V 剩 5% 就是 165mV，从 0 冲向 1V 剩 5% 只有 50mV）。
- **多通道串扰**：切换通道后 Ch 上还挂着前一通道的残压。前一通道电压高、当前通道低时，当前读数被残压"抬高"；顺序反过来则被压低——表现为"读数与扫描顺序相关"。

采样窗充足（12 拍内充满）与不足的对比示意：

```wavedrom

  {name: '通道扫描', wave: '0.....1.....0.....1....', data: ['CH1 = 3.3V', 'CH2 = 1.0V']},

```

### 源阻抗上限

Rs 越大 τ 越大，需要的采样窗越长。具体上限取决于该 ADC 允许配置的最大采样时间：慢速 ADC（µs 级采样窗）可容忍几十 kΩ；高速 ADC（几十 ns 采样窗）只容忍几百 Ω~几 kΩ。**准确限值必须查器件手册的 ADC 输入网络参数表**（Ch、Ron、最大允许 Rin 三件套）。

### 高阻传感器的标准解法

分压网络电阻做大（省电）后源阻抗必然高，标准做法是加一级**电压跟随器**做阻抗变换（见 [../运放电路/README.md](../运放电路/README.md)），把几十 kΩ 变成几十 Ω 再喂 ADC。

## 计算与选型

**算例 1：10k 源阻抗 + 12bit，采样窗要多久**

设 Ron=1kΩ、Ch=10pF（典型量级，以器件手册为准）：

```
τ = (10k + 1k) × 10pF = 110ns
12bit 半 LSB 定居：9τ ≈ 0.99µs
```

若 ADC 时钟 10MHz、采样窗配 10 个时钟 = 1µs → 刚好压线（9.1τ）；配 20 个时钟 = 2µs（18τ）→ 误差 e^-18 ≈ 1.5e-8，远小于 ½LSB，稳妥。

**算例 2：高阻分压网络（470k 上 + 100k 下）踩坑与修复**

电池检测分压 R1=470k、R2=100k（静态电流仅 28µA@16V），等效源阻抗 = 470k∥100k ≈ 82.5kΩ：

```
不做跟随器：τ = (82.5k + 1k) × 10pF ≈ 0.84µs → 12bit 需要 9τ ≈ 7.5µs 采样窗
若采样窗只配 1µs → 仅 1.2τ → 只充到 1 − e^−1.2 ≈ 70%
16V 分压后 2.807V 本应读 3484 码 → 实读约 2440 码，偏低 30%
```

修复二选一：
1. 采样时间参数拉满到 ≥8µs（牺牲转换速率，通道多时组扫描周期变长）；
2. 分压后加电压跟随器（输出阻抗几十 Ω 量级），τ 掉到 ns 级，采样窗随便配，同时消除多通道串扰——**推荐**。

**串扰消除的工程手段**：同一扫描组内相邻通道电压差大时，可把"首通道重复放两次取第二次""组间加间隔"或"高电压通道排最后"当临时手段，根治仍靠降低源阻抗或加长采样窗。

## ECU 实例

- 板上 12V 检测：47k/10k 分压 → 源阻抗 8.2k，采样窗 2µs（ADC 10MHz、20 时钟），实测 12bit 下无可见偏差。
- NTC 温度通道：上拉 10k，NTC 阻值随温度在 1k~60k 变化，低温端最容易读数偏低——注意节点源阻抗是 10k∥NTC（恒 ≤10k，最坏 ≈10k∥60k≈8.6k），设计时按最坏值验算 τ。
- 多路传感器共用一个 ADC 组扫描：把"高阻低温通道"与"0V 检地通道"排相邻会放大串扰，排序时拉开或加跟随器。
- 硬件兜底：输入脚挂 10nF 对地电容，等效把 Ch 从 pF 抬到 nF 级、电荷重分配比例变小，同时兼作 RC 抗混叠（代价是 τ 由外部 RC 主导，仍需验算采样窗）。

## 与软件的关联

- **Adc MCAL 采样时间参数**：`AdcChannel` 级别通常可配采样时间（ADC 时钟数，如 3/15/63/255 周期档位）；高阻通道单独配长档，低阻通道配短档，组扫描周期才不至于整体拖慢。
- **转换速率核算**：采样窗 + N 拍比较 = 单通道转换时间；组内 m 通道 × 转换时间要小于 `AdcGroup` 周期触发间隔，否则丢帧。
- **判定技巧**：现场读数可疑时，把采样时间加倍重测——读数明显变化（>2LSB）即源阻抗/采样窗不足的铁证，与 Vref 问题（改采样时间不变）区分开。
- **滤波配合**：串扰类误差是确定性的（与顺序相关），均值滤不掉；先修硬件参数再谈滤波。

## 易错点与陷阱

- 只看 DS 的"最大外部输入阻抗"一栏就下结论：该值往往绑定特定采样时间档位，换档要重查曲线。
- 传感器开路/短路诊断电阻参与分压后源阻抗翻倍：故障态反而是最坏情况，验算别只算正常态。
- 以为加大输入对地电容万能：电容帮助有限且引入新的 τ（充电电流来自源阻抗），过大的电容让通道建立更慢。
- 温度通道 NTC 阻值在 -40℃ 可达 100kΩ+：常温调试正常、低温标定才发现偏低，是典型量产问题。
- 运放跟随器输出直接接 ADC 没查运放驱动能力：部分小电流运放驱动大容性负载会振荡，需串 50~100Ω 隔离电阻（以运放手册稳定性曲线为准）。

## 面试高频题

**Q1：ADC 读数偏低且随输入幅度变大而变大，什么原因？**
答：采样时间不足导致保持电容未充满，偏差正比于目标电压与残压差；加大采样时间或降低源阻抗（加跟随器）验证。

**Q2：多通道扫描时后一个通道读数受前一个影响，机理与对策？**
答：切换通道后 Ch 带前一通道残压，采样窗内未放/充到位。对策：加长采样时间、相邻通道排序错开、首通道丢弃重采、根治用跟随器降源阻抗。

**Q3：12bit ADC 充电到 ½LSB 内要几个 τ？**
答：t = τ·ln(2^(N+1)) ≈ 9τ（N=12）；工程留 2 倍余量取 15~20τ。

**Q4：为什么高阻分压网络后要加跟随器而不是减小分压电阻？**
答：减小电阻省不了功耗矛盾（静态电流随阻值反比上升）；跟随器既保住 µA 级耗电又把输出阻抗降到几十 Ω，还顺手解决串扰。
