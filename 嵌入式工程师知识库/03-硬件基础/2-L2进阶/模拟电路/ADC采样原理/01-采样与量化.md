# 采样与量化：ADC 的三步曲

> 一句话定位：ADC（Analog-to-Digital Converter，模数转换器）把连续电压变成数字码要经过采样保持→量化→编码三步，理解这三步就理解了"读数为什么抖、为什么差半个 LSB"。
> 等级：L1→L2 ｜ 前置：[从一块 ECU 板开始](../../../00-入门导读/01-从一块ECU板开始.md)、[欧姆定律与功率](../../../1-L1基础/电压电流与基本定律/01-欧姆定律与功率.md)

## 原理

### 三步流水线

```
Vin ──[SW 采样开关]──┬── Ch 保持电容 ──→ 量化比较 ──→ 二进制编码 ──→ N bit 结果
      (采样保持 S/H)  │    (保持)        (台阶化)       (寄存器锁存)
```

1. **采样保持（Sample & Hold，S/H）**：开关闭合期间，保持电容 `Ch` 跟随输入电压充电；开关断开后，`Ch` 上"冻结"断开瞬间的电压，给后级一个稳定的比较对象。`Ch` 通常只有几 pF 到十几 pF（具体值查器件手册的 ADC 输入网络参数）。
2. **量化（Quantization）**：把 0~Vref 的连续电压轴切成 2^N 个台阶，落入第 k 个台阶就记为 k。台阶宽度就是 LSB。
3. **编码（Encoding）**：把台阶序号 k 写成二进制数，这就是软件读到的 raw 值。

### 分辨率与 LSB

LSB（Least Significant Bit，最低有效位）= 一个台阶代表的电压：

```
LSB = Vref / 2^N
```

量化误差：量化是"四舍五入"到最近台阶，单次转换结果最多偏离真实值 **±½LSB**，这是原理性误差，无法通过更好的器件消除，只能靠过采样摊薄。

### 采样率与奈奎斯特

一句话：采样率 `fs` 必须 ≥ 2 倍信号最高频率（奈奎斯特 Nyquist 准则），否则高频分量折叠成低频假信号（混叠），工程上习惯取 10 倍以上。细节见 [../滤波器基础/02-抗混叠设计.md](../滤波器基础/02-抗混叠设计.md)。

### SAR 逐次逼近：二分猜数

SAR（Successive Approximation Register，逐次逼近寄存器）ADC 每一拍用 DAC 试探一个中间值，与保持电压比较一次，"大了就减、小了就保留"，N 拍出 N 位——本质是对电压轴做二分查找。

以 Vref=3.3V、Vin≈2.1V、4bit 为例的逐位判定：

```wavedrom
{signal: [
  {name: 'DAC 试探值', wave: 'x2..3..4..5..6..x', data: ['1.65V','2.475V','2.0625V','2.269V','2.0625V']},
  {name: 'Vin>DAC ?', wave: 'x.1..0..1..0..x..', data: ['保留','清0','保留','清0']},
  {name: 'SAR 寄存器', wave: 'x.2..3..4..5..6..', data: ['1xxx','10xx','101x','1010']}
], head: {text: 'SAR 逐位判定（4bit 示意：Vref=3.3V，Vin≈2.1V）'}}
```

结果码 1010（十进制 10）→ 还原电压 10 × 3.3/16 = 2.0625V，与真值 2.1V 差 37.5mV，正好在 4bit 的 ±½LSB（±103mV）之内。

### 三种架构一句话对比

| 架构 | 一句话 | 典型场景 |
|---|---|---|
| SAR | 中速中精度，速度/功耗/面积折中最好 | MCU 片上 ADC 主流（几十 kHz~几 Msps） |
| Σ-Δ（Sigma-Delta） | 过采样+噪声整形换超高分辨率，速度慢 | 24bit 秤重、温度、压力慢信号 |
| 流水线（Pipeline） | 多级并行换高速，精度中等 | 视频、通信中频采样 |

## 计算与选型

**算例 1：3.3V 系统、12bit 的 LSB**

```
LSB = 3.3V / 2^12 = 3.3V / 4096 ≈ 0.806mV
满码 = 4095（对应 4095×0.806mV ≈ 3.2992V，永远到不了 3.3V）
```

**算例 2：电压反推码值**

输入 1.65V：code = 1.65 / 0.000806 ≈ 2048；
输入 2.100V：code = 2.100 / 0.000806 ≈ 2606（四舍五入）。
若真实输入恰在 2606.5 个台阶边界上，读数就会在 2606/2607 之间跳——这就是 ±½LSB 抖动的来源之一。

**算例 3：选采样率**

- 电池电压（KL30 检测，接近直流，带宽 <10Hz）：fs=1kHz 绰绰有余，取 10ms 一组。
- 加速度传感器带宽 400Hz：奈奎斯特下限 800Hz，工程取 10× = 4kHz 以上。

## ECU 实例

典型节点控制器配置（数字以具体项目/器件手册为准）：

| 项 | 值 |
|---|---|
| MCU 片上 ADC | 12bit SAR，Vref=3.3V |
| LSB | ≈0.806mV |
| NTC 温度通道 | 分压后 0.15~3.1V，映射 -40~125℃ |
| 采样保持电容 | 约 5~15pF（查 DS 输入网络参数表） |
| 单次转换时间 | 采样窗 + 12 拍逐位比较，典型几 µs |

NTC 读数链：NTC 与上拉电阻分压 → ADC 采样 → 软件查 R-T 表插值出温度。码值每抖 1LSB 对应温度多少度，取决于分压点电压-温度斜率（灵敏度最差的中段 1LSB 可能对应 0.1℃ 以上），这是"要不要滤波"的判断依据。

## 与软件的关联

- **Adc MCAL**：`AdcGroup` 配转换模式（ONESHOT / CONTINUOUS）、触发源（软件/硬件 Timer/PWM 同步）；分辨率、架构是硬件属性，软件只决定"何时采、采多少"。
- **raw → 物理值**：`V = raw × Vref / 2^N`（或反向 `raw = V / LSB`），换算系数放编译期常量或运行期校准系数（见 [02-参考电压与精度.md](02-参考电压与精度.md) 的两点校准）。
- **滤波算法选择**：直流/慢变信号（电压、温度）→ 均值或一阶 IIR；交流信号不能无脑均值（会把有效幅度也滤掉），先想清楚信号带宽。
- **抖动排查顺序**：先看量化抖动（±1~2LSB 正常）→ 再查参考电压噪声 → 最后查源阻抗/采样时间（见 [03-采样时间与源阻抗.md](03-采样时间与源阻抗.md)）。

## 易错点与陷阱

- LSB 误算成 `Vref/(2^N −1)`（分母 4095）：差 0.02%，12bit 下长期累计会引入系统性偏差，标准写法是 4096。
- "满量程输入 3.3V 应该读到 4096"：不可能，满码是 4095；读到 4095 就意味着输入 ≥ 4095.5×LSB。
- 把量化误差记成 ±1LSB：正确是 ±½LSB（偏置误差另算）。
- 以为"多采几次求平均能消除一切误差"：平均只能压随机噪声，对 offset/gain/INL 这类系统性误差无效。
- 在中断里做浮点换算再比较阈值：先把 raw 与整数阈值比较，换算留给后台任务。

## 面试高频题

**Q1：3.3V 系统、12bit ADC 的 LSB 是多少？量化误差多大？**
答：LSB = 3.3V/4096 ≈ 0.806mV；量化误差 ±½LSB ≈ ±0.4mV，原理性存在。

**Q2：简述 SAR ADC 工作过程。**
答：采样保持后，SAR 逻辑从最高位开始逐位试探：内置 DAC 输出中间值与保持电压比较，大于则保留该位、小于则清零，N 拍二分逼近得到 N 位结果。速度中等、功耗低、面积小，是 MCU 片上主流。

**Q3：读数在相邻两个码之间来回跳，正常吗？**
答：若只跳 ±1~2LSB 且输入本身稳定，多半是量化边界+噪声，属正常，可用均值/迟滞处理；若跳动几十 LSB，查参考电压与地回路。

**Q4：为什么不用 Σ-Δ 做所有采样？**
答：Σ-Δ 靠大量过采样换分辨率，输出速率低（常几十 Hz~几 kHz）且群延迟大，不适合多通道快速扫描的通用 MCU 场景。
