# 参考电压与精度：Vref 是读数的天花板

> 一句话定位：ADC 输出码 = Vin/Vref × 2^N，Vref 错 1% 读数就整体错 1%——软件做任何滤波都救不回参考电压引入的系统性误差，这是模拟精度问题的第一嫌疑对象。
> 等级：L2 ｜ 前置：[采样与量化](01-采样与量化.md)

## 原理

### Vref 决定刻度尺

ADC 是一把刻度由 Vref 决定的尺子：

```
code = round( Vin / Vref × 2^N )
```

Vref 变大 → 同样 Vin 读出的码变小（读数偏低）；Vref 变小 → 读数偏高。Vref 的误差、噪声、温漂**原样按比例**传递给每一个读数。

Vref 与量化台阶的关系（以 3bit 为例，满量程分成 2^N=8 档，每档 1LSB = Vref/2^N）：

```
 Vref ─┬─────────────────────────── 111 (满量程附近)
       │ ▲7
       │ ├──── 1LSB = Vref/8 ────┐
       │ ▲6                      │ Vref 变大 → 台阶变宽
       │ ▲5                      │ → 同一 Vin 落入更低档
       │ ▲4                      │ → 读数偏低
       │ ▲3                      │
       │ ▲2                      │ Vref 变小 → 台阶变窄
       │ ▲1                      │ → 读数偏高
 0 ────┴─▲0──────────────────────┘
        0        Vin →        Vref

 例：Vin=1.65V（3.3V 满量程中点）
   Vref=3.300V → code = 1.65/3.3 × 4096 ≈ 2048
   Vref=3.366V(+2%) → code ≈ 2008（低约 40 码，整体性偏移，滤波救不回）
```

### Vref 的三种来源

| 来源 | 典型初始精度 | 说明 |
|---|---|---|
| MCU 内部带隙基准（Bandgap） | ±1%~±2%（以器件手册为准） | 免外围、省成本，精度一般、温漂 30~100ppm/℃ 量级 |
| 外部基准 IC（如 2.5V/3.0V） | ±0.05%~±0.5% | 高精度场合；注意其输入也要干净供电 |
| 直接拿 3.3V LDO 当 Vref/VDDA | 取决于 LDO（±1%~±3%） | 最常见也最偷懒；LDO 的纹波、负载调整率、上电斜率全部进读数 |

### 噪声→码抖动的传导链

```
Vref 抖 1mV（纹波/地弹）
  → 满量程刻度抖 1mV / 3.3V ≈ 0.03%
  → 12bit 下 0.03% × 4096 ≈ 1.2 LSB
  → 表现为读数整体 ±1~2 码同步抖动（所有通道一起抖）
```

判别技巧：**多个不相关通道同时同步抖动**，先怀疑 Vref/供电；只有单通道抖，先怀疑该通道的源阻抗与接线。

### 误差预算（Error Budget）

一次转换的总误差是多项误差的叠加，工程上先列预算表再动手（典型量级如下，具体以器件手册为准）：

| 误差项 | 含义 | 典型量级（12bit） |
|---|---|---|
| Offset 误差 | 输入为 0 时读数不为 0 | ±1~±5 LSB |
| Gain 误差 | 斜率偏差（多来自 Vref 与内部分压） | ±5~±80 LSB（Vref 用 3.3V LDO 时最大） |
| INL（积分非线性） | 实际转移曲线偏离直线的最大值 | ±1~±4 LSB |
| DNL（微分非线性） | 相邻台阶宽度不均 | ±0.5~±1 LSB（可能丢码） |
| 量化误差 | ±½LSB | ±0.5 LSB |
| Vref 噪声 | 见上节传导链 | 视供电质量 |

叠加方式：最坏情况直接相加（保守），随机不相关项按 RSS（方和根）合成。

## 计算与选型

**算例 1：Vref 精度直接换算成 LSB 误差**

3.3V LDO 初始精度 ±2%：

```
ΔVref = 3.3V × 2% = 66mV
等效码误差 = 66mV / 0.806mV ≈ 82 LSB（约 2% × 4096）
```

也就是说：**芯片手册写 12bit，但 Vref 用 ±2% 的 LDO，实际"绝对精度"只有约 5.6 bit 有效**（4096/82 ≈ 50:1 → log2(50) ≈ 5.6 bit）。想要真 12bit 绝对精度，必须外部基准+校准。 <!-- 数值修正：有效位=log2(4096/82)≈5.64，原"6.3 bit"误取 log2(82)=6.36 -->

**算例 2：均值滤波压噪声**

随机噪声标准差 σ=4 LSB，采 16 次平均：

```
σ_mean = 4 / √16 = 1 LSB   （噪声降 4 倍，代价：16 倍采样时间）
```

只对随机噪声有效，offset/gain 无效。

**算例 3：过采样（Oversampling）换分辨率**

常识换算：每提高 1bit 分辨率需要 4 倍采样数——**+2bit 需 16 次采样求和后右移 2 位；+4bit 则需 256 次**。前提：输入端存在 ≥1LSB 幅度的白噪声（噪声成了"抖动信号"），且被测信号本身在过采样期间近似不变。

```
例：3.3V/12bit，要 14bit：采 16 次求和 → 右移 2 位
新 LSB = 0.806mV / 4 ≈ 0.2mV（仅压随机噪声，绝对精度不变）
```

**算例 4：两点校准（软件修 offset/gain）**

产线用可调电源给 ADC 输入端加两个已知电压，记录读数：

- 加 0.500V → raw=635
- 加 2.500V → raw=3122

求 `V = (raw − b) / k`：

```
k = (3122 − 635) / (2500 − 500) mV = 2487 / 2000 = 1.2435 LSB/mV
b = 635 − 1.2435 × 500 = 13.25 LSB
校准后斜率：1/1.2435 = 0.8042 mV/LSB（理想 0.8057，偏差来自 Vref 偏低） <!-- 技术性修正：0.8042<0.8057 反推 Vref=0.8042×4096≈3294mV<3300mV，方向应为偏低 -->
```

C 片段（系数由产线写入 NVM）：

```c
/* 两点校准：0.5V→635 码，2.5V→3122 码 */
#define CAL_X1_MV 500.0f
#define CAL_X2_MV 2500.0f
#define CAL_Y1    635.0f
#define CAL_Y2    3122.0f

static float k_lsb_per_mv, b_lsb;

void AdcCal_Init(void)
{
    k_lsb_per_mv = (CAL_Y2 - CAL_Y1) / (CAL_X2_MV - CAL_X1); /* 1.2435 */
    b_lsb        = CAL_Y1 - k_lsb_per_mv * CAL_X1;           /* 13.25 */
}

uint16_t AdcCal_RawToMv(uint16_t raw)
{
    return (uint16_t)((raw - b_lsb) / k_lsb_per_mv + 0.5f);
}
```

校准点选取：两点尽量拉开（如满量程 10% 与 90% 位置），中间段的 INL 剩余误差无法用两点法消除。

## ECU 实例

- 电池电压检测（要求 ±2%）：Vref 用内部基准+软件两点校准即可达标，省一颗外部基准 IC。
- NTC 温度（要求 ±2℃）：温度精度由 NTC 本身（±1%）主导，ADC 侧 82LSB 的 gain 误差在分压中段折算 <1℃，可以不校。
- 精密踏板位置（双通道冗余，要求 ±0.5%）：必须外部 2.5V 基准 + 产线两点校准 + 上电自检（测已知基准通道比对）。
- 硬件配套：Vref/VDDA 引脚就近 1µF+100nF 去耦，模拟地与数字地单点连接（参考 ../电路基础/电源电路/04-纹波与去耦.md 的布局做法）。

## 与软件的关联

- **Adc MCAL**：`AdcHwUnit` 的参考源选择（内部/外部）是配置项；开内部基准时注意其使能后需要稳定时间（典型几十 µs，以 DS 为准）再启动首组转换。
- **采样时间参数**：过采样若在软件做（`AdcGroup` 配 16 次连续转换或用 DMA 攒缓冲），要确认总时间不违反信号带宽。
- **滤波算法选择**：随机噪声 → 均值/滑动窗口；系统性偏差 → 校准系数，滤波无效；两者都要时先校准后滤波。
- **自检策略**：定期采一个内部基准通道（很多 MCU 提供 Vrefint/温度通道），读数漂移超过阈值上报 DTC，作为 Vref 异常的在线监控。

## 易错点与陷阱

- 把 Vdda 和 Vref 混用：Vdda 带数字噪声，Vref 要单独去耦，能分则分。
- 校准点取 0V 和满量程附近：0V 附近可能落在 ADC 线性区之外（轨附近 50~100mV 不可信，以 DS 为准）。
- 过采样想 +4bit 却只采 16 次：16 倍只值 +2bit，右移位数与采样数不匹配会引入比例错误。
- 温漂被忽略：常温校准 +2% 的 LDO，-40℃ 下可能漂到 +4%；温度跨度大的产品校准系数需分温区。
- 上电立即读 ADC：内部基准/采样电容未稳定，首几帧读数偏低，应丢弃或延迟启动。

## 面试高频题

**Q1：ADC 读数整体偏差 3%，软件怎么排查？**
答：先判断是随机还是系统性：均值后仍稳定偏差 → 系统性，查 Vref 精度与 gain 误差，用两点校准修；均值能收敛 → 随机噪声，查供电与地。

**Q2：过采样为什么能提高分辨率？代价是什么？**
答：输入噪声幅度 ≥1LSB 且近似白噪声时，多次采样的"抖动"使量化误差去相关，求和平均后等效台阶变细；每 +1bit 需 4 倍样本，代价是带宽/时间，且绝对精度（offset/gain）不变。

**Q3：两点校准能消掉 INL 吗？**
答：不能。两点校准只拟一条直线（修 offset+gain），INL 是直线外的弯曲部分，只能靠更高等级器件或分段查表修正。

**Q4：Vref 上有 10mV 的开关纹波，读数会怎样？**
答：满量程刻度被 10mV/3.3V≈0.3% 调制，12bit 下约 ±12 LSB 同步抖动，且与开关频率相关；应加 RC/LC 滤波或换低噪基准。
