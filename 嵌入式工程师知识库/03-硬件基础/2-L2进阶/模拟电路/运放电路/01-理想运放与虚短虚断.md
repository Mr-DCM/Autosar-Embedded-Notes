# 理想运放与虚短虚断：模拟电路的两把万能钥匙

> 一句话定位：把运放（Operational Amplifier，运算放大器）当成"增益无穷大、不取电流"的黑盒，负反馈下用"虚短+虚断"两条规则，几乎所有运放电路都能两条 KCL 方程推出来。
> 等级：L2 ｜ 前置：[基尔霍夫定律](../../../1-L1基础/电压电流与基本定律/02-基尔霍夫定律.md)

## 原理

### 理想模型

```
              ┌──────────────┐
   V+ ───────┤+             │
              │   Av → ∞     ├───── Vout = Av × (V+ − V−)
   V− ───────┤−             │      （Av 典型 10^5~10^7）
              └──────────────┘
   输入电阻 Rin → ∞（输入电流 ≈ 0）
   输出电阻 Rout → 0（带负载不掉压）
```

三句话记住理想运放：差分输入、单端输出、开环增益无穷大。真实器件的非理想（offset、GBW、轨到轨限制）都是在这个骨架上打补丁。

### 负反馈逼出"虚短"

开环增益 Av→∞ 时，只要输出还在线性区（没顶到电源轨），必有：

```
Vout = Av × (V+ − V−)  且  |Vout| < Vcc
→ (V+ − V−) = Vout/Av ≈ 3V / 10^5 ≈ 30µV ≈ 0
```

**虚短：负反馈闭环、运放工作在线性区时，V+ ≈ V−（像短接但没真的短）。**

### 输入电阻无穷大逼出"虚断"

**虚断：两个输入端都不取电流（≈0），流入 V+、V− 的电流忽略。**

注意适用边界：虚短只对**负反馈+线性区**成立；开环使用（如比较器接法）V+ 与 V− 可以差任意大，虚短失效——这正是运放不能当比较器用的根源之一（详见 [03-比较器.md](03-比较器.md)）。

### 两大法宝的使用套路

对 V− 节点（或 V+ 节点）写一条 KCL（虚断保证电流全部走已知支路），代入 V−=V+（虚短），解出 Vout/Vin——完事。

## 计算与选型

### 同相放大器：Gain = 1 + Rf/Rg

```
              Rf
        ┌────[Rf]────┐
        │            │
Vin ──┬─┤+      ┌────┴──── Vout
      │ └─┤−    │
      │   └─[Rg]─┴─ GND?   （Rg 接地，V− 节点 = Vout 分压点）
```

推导：虚短 → V− = V+ = Vin；虚断 → Rg、Rf 上电流相等：

```
(Vout − Vin)/Rf = Vin/Rg
→ Vout = Vin × (1 + Rf/Rg)
```

**算例 1**：Rf=10k、Rg=1k → 增益 11 倍；输入 0.30V → 输出 3.30V（正好把 0~0.3V 传感器信号抬到 3.3V 满量程）。

### 反相放大器：Gain = −Rf/Rg

```
            Rf
Vin ──[Rg]──┬───[Rf]───┬──── Vout
            │          │
            └──┤−  ┤+ ─┴─ Vbias（=GND 或虚地）
```

推导：虚短 → V− = V+ = 0V（"虚地"）；虚断 → Vin/Rg 全部流入 Rf：

```
Vout = −Vin × Rf/Rg
```

**算例 2**：Rf=Rg=10k → 增益 −1（0.500V → −0.500V）。注意输出是**负压**——单电源系统必须先给 V+ 提供偏置（见下节），否则输出直接削底。

### 单电源运放的"地"问题

- 单电源（如 0/5V）供电时，输出摆不到 0V，输入接近 0V 时可能反相/死区。
- **轨到轨（Rail-to-Rail，R2R）**：输入/输出摆幅接近电源轨的器件，缓解但不能完全消除端头问题。
- **虚地偏置**一句话：把 V+ 增益网络的中点抬到 Vcc/2（用分压+电容），交流信号绕着"新地"摆动，输出再用电容隔直还原。

### 运放 vs 比较器

| 维度 | 运放（闭环用） | 比较器（开环用） |
|---|---|---|
| 设计目标 | 线性度、稳定（内部有补偿电容） | 翻转速度（无补偿） |
| 传播延迟 | 慢（输出摆率受限，µs 级可能） | 快（数十~数百 ns） |
| 过驱动恢复 | 差：深度饱和后"醒来"很慢 | 专为反复翻转设计 |
| 输出级 | 推挽模拟电平 | 常为开漏/开集，方便接逻辑电平与线与 |

结论：**普通运放不当高速比较器用**——响应慢、饱和恢复慢、输出电平不标准；真要低成本慢速比较（ms 级阈值检测），需确认器件允许开环且输出摆幅兼容 MCU。

## ECU 实例

- 轮速传感器（磁电，±差分信号）：差分运放放大后整形进 MCU，虚短虚断同样适用于差分接法分析。
- 踏板位置双通道：各自跟随器进 ADC（见 [02-跟随器与放大.md](02-跟随器与放大.md)）。
- 供电：单电源 5V，轨到轨输入输出（RRIO）型号，保证 0~3.3V 信号不走端头死区。
- 电阻取值习惯：Rf/Rg 在 1k~100k 之间取值——太小费电、太大引入噪声与偏置误差（输入偏置电流 × 大电阻 = 额外 offset）。

## 与软件的关联

- 理解信号链增益才能写对**换算公式**：`V_phys = raw × LSB / Gain`，硬件增益改了软件系数必须同步改（ECU 标定表的"通道增益"项）。
- 输出被削顶（运放饱和）时 ADC 读数钉在满量程附近：软件应把"raw 连续贴顶/贴底"识别为传感器/运放饱和故障，而不是当正常值滤波。
- 虚地偏置电路的偏置电压不准会造成整体 offset——正好用 [../ADC采样原理/02-参考电压与精度.md](../ADC采样原理/02-参考电压与精度.md) 的两点校准吸收。

## 易错点与陷阱

- 对开环接法（比较器用法）套虚短：虚短仅在负反馈线性区成立，开环时 V+≠V−。
- 反相放大忘了输出极性翻转：软件把"增大"方向搞反，标定时会发现负斜率。
- 单电源跑双极性电路没加偏置：负半周全部削底，波形只剩一半。
- 增益电阻用到 MΩ 级：输入偏置电流（nA~pA 级）乘大电阻产生可观 offset，还易拾取干扰。
- 以为轨到轨=真到轨：端头仍差几十~几百 mV，信号链别贴着 0V/3.3V 极限设计（以器件手册输出摆幅曲线为准）。

## 面试高频题

**Q1：什么是虚短、虚断？成立条件？**
答：虚短：负反馈线性区下 V+≈V−；虚断：输入端电流≈0（Rin→∞）。条件是闭环负反馈、输出未饱和。

**Q2：推导同相放大器增益。**
答：虚短 V−=Vin，虚断使 Rf/Rg 电流相等：(Vout−Vin)/Rf=Vin/Rg → Gain=1+Rf/Rg。

**Q3：为什么不能用普通运放当比较器？**
答：运放内部按线性闭环稳定设计（补偿电容限速、输出推挽慢），深度饱和后恢复慢，传播延迟 µs 级；比较器无补偿、传播延迟 ns 级、常带开漏输出适配逻辑电平。

**Q4：单电源系统如何处理双极性小信号？**
答：轨到轨器件+虚地偏置（Vcc/2），或先用电平移位把信号抬进 0~Vcc 共模范围，输出端再隔直/软件去偏置。
