# 比较器：阈值的守门员

> 一句话定位：比较器（Comparator）是开环工作的"一位 ADC"，比较两个输入大小直接翻输出；不加迟滞时噪声会让输出在阈值附近抖动，把 MCU 中断打成风暴。
> 等级：L2 ｜ 前置：[理想运放与虚短虚断](01-理想运放与虚短虚断.md)

## 原理

### 基本行为

```
        ┌────────────┐
 V+ ────┤+           │
        │  开环，无反馈 ├──── Vout
 V− ────┤−           │
        └────────────┘
V+ > V− → Vout = VOH（高）
V+ < V− → Vout = VOL（低，开漏输出时由上拉决定）
```

两个关键参数（典型量级，以器件手册为准）：

- **传播延迟（Propagation Delay）**：输入过阈到输出翻转的时间，专用比较器数十~数百 ns；
- **迟滞（Hysteresis）**：上行/下行翻转阈值之差，可外接正反馈自行设置。

### 为什么必须加迟滞

输入信号缓慢爬过阈值且叠加噪声时，输出在 VOH/VOL 之间高频抖动：

```
Vin ──────╱╲──╱╲────────── 穿越阈值（带噪声）
          ╲╱──╲╱
         ──────阈值──────
Vout ─┐  ┌┐ ┌┐ ┌┐  ┌───
      └──┘└─┘└─┘└──┘
      ←多路窄脉冲：EXTI 中断风暴、DTC 反复置位/恢复→
```

对软件的杀伤：中断风暴占满 CPU、故障状态高频翻转导致 DTC 抖动、计数型逻辑出错。**迟滞把"一个阈值"变成"上下两个阈值"**，噪声幅度小于迟滞宽度时输出稳定单次翻转。

### 迟滞比较器：正反馈接法

输入经 R1 进 V+，输出经 R2 也接 V+（**正反馈**），基准 Vref 接 V−：

```
              R2
        ┌────[R2]────┐
        │            │
Vin ──[R1]──┬── V+   │
            │     ┌──┴──┐
            │     │比较器├── Vout
        Vref ─── V−┘└────┘
```

翻转条件是 V+ 穿过 Vref，叠加输出状态得到两个阈值（推导用叠加定理求 V+）：

```
V_TH（上行阈值，Vout=VOL 时）= [Vref×(R1+R2) − VOL×R1] / R2
V_TL（下行阈值，Vout=VOH 时）= [Vref×(R1+R2) − VOH×R1] / R2
迟滞宽度 ΔV = V_TH − V_TL = (VOH − VOL) × R1 / R2
```

注意与运放负反馈放大器的区别：这里反馈到**同相端**是正反馈，虚短不成立（开环/正反馈，两输入端可以差任意大）。

### 开漏输出与线与（Wired-AND）

比较器输出级常为开漏（Open-Drain）：内部只有下拉管，高电平靠外部上拉电阻提供，上拉到哪个电压域输出就是哪个电平（5V 器件直接驱动 3.3V MCU 输入，省电平转换）。多个开漏输出直接并联，任一拉低总线就为低——"线与"，正好做多路故障信号汇总（原理详见 [../../../1-L1基础/上拉下拉电阻/03-OC-OD门与线与.md](../../../1-L1基础/上拉下拉电阻/03-OC-OD门与线与.md)）。

### 窗口比较器（Window Comparator）

两个比较器 + 一个逻辑门：上限比较器与下限比较器的输出组合判断"输入是否在 [V_L, V_H] 窗口内"，用于供电窗口监视（欠压+过压一起判）。

## 计算与选型

**算例 1：过压检测迟滞设计（完整数字）**

条件：Vref=2.500V（外部基准）、供电 3.3V（VOH=3.3V、VOL=0V）、R1=10k、R2=100k：

```
V_TH = (2.5 × 110k − 0 × 10k) / 100k = 2.750V   （上行：超过 2.75V 判过压）
V_TL = (2.5 × 110k − 3.3 × 10k) / 100k = 2.420V （下行：回落到 2.42V 才解除）
ΔV = 3.3 × 10k/100k = 0.330V
```

设计校核：分压链噪声与纹波叠加 <100mV 时，0.33V 迟滞留 3 倍余量 ✓。
对应物理量（分压比 0.17544 的 KL30 链）：2.75V/0.17544 ≈ 15.7V 报过压、2.42V/0.17544 ≈ 13.8V 解除——若目标阈值不同，按 V_TH 反解 R1/R2 重配。

**算例 2：迟滞宽度按噪声定**

输入噪声峰峰 50mV → 迟滞 ≥ 3×50mV = 150mV；VOH−VOL≈3.3V → R1/R2 ≥ 150m/3.3V = 1/22 → 取 R1=4.7k、R2=100k（ΔV=155mV）。R2 别取太大：上拉后与输入电容形成 RC，拖慢翻转沿。

**算例 3：线与故障总线**

3 路开漏比较器输出并联 + 10k 上拉到 3.3V：

```
任一路过流 → 总线拉低 → MCU 单个 EXTI
静态电流：仅上拉 3.3V/10k = 330µA（全高时）
恢复：3 路全部回到窗口内 → 总线回高
```

比"每路一根中断线"省 2 个 MCU 引脚，代价是失哪一路要软件读各自的 status 脚分辨。

## ECU 实例

- **过压检测**：KL30 经分压进比较器，过 18V 立即翻低触发硬件保护（不需要等软件轮询 ADC），迟滞 0.33V 防抖。
- **故障上报**：过流比较器开漏输出并入线与总线，进 MCU EXTI + 唤醒源（休眠下也能报故障）。
- **窗口监视**：5V 传感器供电窗口 4.75~5.25V，双比较器 + 二极管线与，窗口外置位故障锁存（RS 触发器），MCU 复位前不清除。
- **磁电轮速整形**：比较器 + 迟滞把正弦波变方波，阈值随幅值自适应（幅值检测 DAC 提供动态 Vref，见 [../DAC输出/01-DAC原理.md](../DAC输出/01-DAC原理.md) 的阈值基准用法）。

## 与软件的关联

- **EXTI/中断配置**：比较器输出接 MCU 外部中断，边沿触发 + 软件去抖时间窗（如 100µs 内多次触发只记一次），迟滞是硬件第一道、去抖是软件第二道。
- **故障 Debounce 计数**：DTC 置位要求故障持续 N 个周期（如 50ms），恢复要求连续 M 个周期正常——与硬件迟滞双保险，防止 DTC 抖动。
- **唤醒源**：休眠模式下比较器保持供电，输出跳变唤醒 MCU——软件要核对低功耗模式下该引脚的唤醒极性配置。
- **采样配合**：ADC 轮询慢、比较器快：保护类判据走比较器硬中断，趋势类监测走 ADC 软件阈值（软件阈值同样要加迟滞，思想一致）。

## 易错点与陷阱

- 不加迟滞直接用：阈值附近噪声必抖，中断风暴是经典量产事故；哪怕芯片内置 5~10mV 迟滞，多数场景也不够。
- 把比较器两个阈值公式与同相放大增益公式混着记：一个是正反馈叠加定理，一个是负反馈分压，推导各写一遍就不会混。
- 上拉电阻过大（>100k）：上升沿被输入电容拖成斜坡，EXTI 误触发多次；常用 4.7k~47k。
- 开漏输出忘了上拉：输出永远只有低电平，"高电平丢失"排查半天。
- 比较器电源与被比较信号共模范围不匹配：输入超出共模范围输出可能反相——必须查器件手册共模电压范围表。
- 用运放当高速比较器：饱和恢复慢、传播延迟 µs 级，详见 [01-理想运放与虚短虚断.md](01-理想运放与虚短虚断.md) 对比表。

## 面试高频题

**Q1：比较器为什么必须加迟滞？怎么加？**
答：缓慢信号+噪声在单一阈值附近反复穿越，输出抖动造成中断风暴/DTC 抖动；输出经电阻反馈到**同相端**形成正反馈，使上/下行阈值分开，噪声幅度小于迟滞宽度即稳定。

**Q2：写出迟滞比较器上下阈值公式。**
答：V_TH=[Vref(R1+R2)−VOL·R1]/R2，V_TL=[Vref(R1+R2)−VOH·R1]/R2，迟滞宽度 ΔV=(VOH−VOL)·R1/R2。

**Q3：开漏输出比较器有什么好处？**
答：输出电平由上拉决定，天然做电平转换；多个输出并联即线与，多路故障共用一根中断线。

**Q4：比较器输出接 MCU 中断，软件还要做什么防抖？**
答：硬件迟滞之外再加：边沿触发+时间窗去抖、DTC 置位/恢复分别 debounce 计数，避免单次毛刺进故障管理。
