# 跟随器与放大：阻抗变换与信号链增益

> 一句话定位：电压跟随器增益为 1 却最有用——把高阻信号源变成低阻输出喂 ADC；配上同相/反相放大和 GBW 校核，就是 ECU 里"传感器→运放→ADC"的标准信号链。
> 等级：L2 ｜ 前置：[理想运放与虚短虚断](01-理想运放与虚短虚断.md)

## 原理

### 电压跟随器（Voltage Follower / Buffer）

```
            ┌────────────┐
   Vin ─────┤+           │
            │   Gain=1   ├──── Vout = Vin
      ┌─────┤−           │
      │     └────────────┘
      └────────┴── 输出直接接回反相端（100% 负反馈）
```

推导只要两条法则：虚短 V−=V+=Vin，而 V− 又被输出线短接 → **Vout = Vin，增益恰为 1**。

价值不在增益在阻抗：输入端 Rin→∞（不取电流），输出端 Rout→0（可驱动 ADC 采样电容与引线电容）。一句话：**跟随器是"阻抗变换器"**——高阻传感器 100kΩ 进，低阻输出几十 Ω 出，直接化解 [../ADC采样原理/03-采样时间与源阻抗.md](../ADC采样原理/03-采样时间与源阻抗.md) 里"源阻抗过大读数偏低"的问题。

### 同相/反相放大回顾

- 同相：Gain = 1 + Rf/Rg，输入阻抗极高（直接进 V+）；
- 反相：Gain = −Rf/Rg，输入阻抗 = Rg（由外接电阻决定），虚地结构。

推导见 [01-理想运放与虚短虚断.md](01-理想运放与虚短虚断.md)。

### 增益带宽积（GBW，Gain-Bandwidth Product）

运放开环增益随频率以 −20dB/dec 下降，乘积近似常数：

```
GBW ≈ Gain × f_signal
```

工程约束：**信号频率 × 闭环增益 < GBW / 10**（留 10 倍余量保证相位裕度与增益精度，以器件手册波特图为准）。

## 计算与选型

**算例 1：跟随器（增益 1）**

NTC 分压点（源阻抗最坏 60kΩ）→ 跟随器 → ADC。输出≈输入（差 <1mV，含 offset），源阻抗降为运放输出阻抗（几十 Ω 量级）→ ADC 采样窗按最短档配也够。

**算例 2：同相放大（0~1.1V → 0~3.3V）**

要求增益 3，取 Rf=20k、Rg=10k：

```
Gain = 1 + 20k/10k = 3
1.10V → 3.30V（满量程）  0.55V → 1.65V
```

电阻误差注意：1% 电阻最坏组合增益误差 ±1.4%，与 ADC 增益误差同量级——高精度场合要么用 0.1% 电阻，要么靠软件校准吸收。 <!-- 数值修正：G=1+Rf/Rg，最坏 1+20×1.01/(10×0.99)≈3.04，即 +1.35%，原"±3%"偏大 -->

**算例 3：反相放大（±信号、单电源）**

Rf=Rg=10k、V+ 偏置 Vbias=1.65V：

```
Vout = Vbias − Vin
Vin=+0.5V → 1.15V；Vin=−0.5V → 2.15V（都在 0~3.3V 内）
软件还原：Vin = 1.65V − Vout
```

**算例 4：GBW 校核**

信号带宽 10kHz、闭环增益 11：

```
需要 GBW > 10kHz × 11 × 10（余量） = 1.1MHz
选 GBW=1MHz 的通用运放 → 不够；选 GBW≥3MHz → 通过
```

**算例 5（重头戏）：KL30 电池电压检测全链路**

需求：9~16V 工作范围，耐 18V 不超量程，静态电流 <50µA，3.3V/12bit ADC。

① 分压设计（比例留 18V 裕量）：

```
上 R1=470k，下 R2=100k → 分压比 k = 100/570 = 0.17544
9V  → 1.579V（码 1960）
16V → 2.807V（码 3484）
18V → 3.158V（码 3920，未顶满 4095 ✓） <!-- 数值修正：18×100/570/3.3×4096≈3919.6，四舍五入 3920，原"3918" -->
静态电流：16V / 570k ≈ 28µA ✓
```

② 源阻抗验算：Rs = 470k∥100k ≈ 82.5kΩ，直接进 ADC 需要 ≈7.5µs 采样窗（见 [../ADC采样原理/03-采样时间与源阻抗.md](../ADC采样原理/03-采样时间与源阻抗.md) 算例 2），且多通道扫描有串扰 → **加跟随器**，采样窗按默认短档即可。 <!-- 数值修正：470k×100k/570k=82.46kΩ，原"82.7k" -->

③ 读数还原（整数运算，避免浮点）：

```
Vbat_mv = raw × 3300 × 57 / (4096 × 10) = raw × 4.5923mV（近似）
验证：raw=3484 → 3484 × 188100 / 40960 = 16000mV ✓
```

```c
/* KL30 电池电压还原：R1=470k / R2=100k，Vref=3.3V，12bit */
#define BAT_DIV_NUM   57UL     /* R1+R2 = 570k */
#define BAT_DIV_DEN   10UL     /* R2 = 100k */
#define VREF_MV       3300UL
#define ADC_FULL      4096UL

uint16_t Bat_GetVoltageMv(uint16_t raw)
{
    uint32_t mv = (uint32_t)raw * VREF_MV * BAT_DIV_NUM;
    mv = (mv + ADC_FULL * BAT_DIV_DEN / 2UL) / (ADC_FULL * BAT_DIV_DEN);
    return (uint16_t)mv;   /* 溢出校核：4095×3300×57 = 770M < 2^32 ✓ */
}
```

④ 软件侧：10ms 采一次，16 点滑动均值（噪声 ÷4），低于 9V 置欠压标志、18V 以上报过压 DTC（阈值判据加迟滞，思想同 [03-比较器.md](03-比较器.md)）。

## ECU 实例

| 信号 | 信号链 | 关键数字 |
|---|---|---|
| KL30 电池电压 | 470k/100k 分压→跟随→ADC | 28µA 静态，2.807V@16V |
| NTC 水温 | 10k 上拉→跟随→ADC | 源阻抗最坏 60k，靠跟随化解 |
| 踏板位置 0~1.1V | 同相 ×3 →ADC | 增益 1% 电阻，软件校准吸收 |
| 磁电轮速 | 差分放大→比较器 | GBW/压摆率按最高轮频选型 |

## 与软件的关联

- **Adc MCAL**：跟随器之后的通道采样时间可配最短档，`AdcGroup` 扫描周期得以做小；无跟随的高阻通道必须单独配长档。
- **标定**：分压比、运放增益进通道换算系数；产线两点校准把电阻误差+Vref 误差一并吸收（做法见 [../ADC采样原理/02-参考电压与精度.md](../ADC采样原理/02-参考电压与精度.md)）。
- **饱和检测**：raw 贴近 0/4095 持续出现 → 判传感器短路/开路或运放饱和，先报故障再滤波。
- **滤波选择**：跟随器只改阻抗不改噪声，滤波策略照旧按信号带宽选（均值/IIR 见 [../滤波器基础/01-RC滤波.md](../滤波器基础/01-RC滤波.md)）。

## 易错点与陷阱

- 分压电阻求省电做到 MΩ 级：漏电流（PCB 污染/ESD 器件漏电，µA 级）与电阻可比，低温高湿环境下读数漂移，570k 量级已是常规上限。
- 跟随器输出直接挂长电缆/大电容：容性负载易振铃，串 50~100Ω 电阻隔离（以运放手册容载稳定性曲线为准）。
- 增益电阻精度与 ADC 精度不匹配：12bit 系统（0.02%）配 5% 电阻，增益误差吃掉近 8 个 bit 的绝对精度。 <!-- 数值修正：5%×4096≈205LSB≈2^7.7，原"6 个 bit"低估 -->
- GBW 只按基波算：方波/梯形信号的 5~9 次谐波也要在带宽内，否则沿变缓、幅度失真。
- 反相端虚地网络旁路电容省略：偏置点被噪声调制，全通道跟着抖。

## 面试高频题

**Q1：电压跟随器增益为 1，为什么还要用它？**
答：做阻抗变换：输入高阻不取流、输出低阻能驱动，保护高阻信号源并为 ADC 提供快速充电通路；隔离前后级负载效应。

**Q2：GBW 是什么？怎么校核？**
答：开环增益与频率的乘积近似常数；要求"信号最高频率 × 闭环增益 × 10 < GBW"留相位裕度，高速信号还要另查压摆率 SR。

**Q3：KL30 检测链怎么设计？**
答：高阻分压（百 kΩ 级控制静态电流）→ 跟随器（化解源阻抗）→ ADC → 整数换算还原（乘分压比倒数），再叠加均值滤波与迟滞阈值判断。

**Q4：运放输出接 ADC，中间还要什么？**
答：必要时小 RC（如 100Ω+10nF）限流抗混叠；注意 RC 引入的 τ 与采样窗的配合，别把 [../ADC采样原理/03-采样时间与源阻抗.md](../ADC采样原理/03-采样时间与源阻抗.md) 的问题又请回来。
