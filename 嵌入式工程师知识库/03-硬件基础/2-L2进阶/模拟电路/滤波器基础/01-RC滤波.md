# RC 滤波：一阶低通/高通的万能积木

> 一句话定位：一个电阻一个电容构成的一阶 RC 低通，截止频率 fc=1/(2πRC)，是抗混叠、去耦、输入滤波的通用积木，也是理解"硬件滤波 vs 软件滤波怎么分工"的起点。
> 等级：L2 ｜ 前置：[电阻电容电感](../../../1-L1基础/原理图阅读/常用元器件符号与封装/01-电阻电容电感.md)

## 原理

### 一阶 RC 低通

```
                 R
Vin ────────[R]──────┬────→ Vout
                      │
                     ┌┴┐
                     │C│
                     └┬┘
                      │
                     GND
高通时 R、C 位置对调：C 串在路径上、R 接地（隔直通交）
```

低通的频域行为由电容阻抗随频率下降决定：频率越高，C 分走的越多，Vout 越小。

```
fc = 1 / (2πRC)          （-3dB 截止频率，幅度降到 0.707 倍）
通带外：-20dB/dec 滚降    （频率 ×10，幅度 ×1/10）
|H(f)| = 1 / √(1 + (f/fc)²)
```

- **-3dB 的含义**：幅度降到 70.7%（功率减半）的点，即"通带与阻带的分界线"，不是"信号从此没了"。
- **-20dB/dec**：一阶滤波器斜率固定，每 10 倍频程衰减 20dB；要更陡就串多阶（二阶 -40dB/dec）。
- **高通一句话**：R、C 对调后隔直通交，典型用途是去掉直流偏置、耦合交流信号；隔直电容+对地电阻构成"高通"，fc 公式相同。

### 阶跃响应：τ 的另一面

RC 在时域是指数充放电（时间常数 τ=RC）：

```
Vout(t) = Vfinal × (1 − e^(−t/τ))
从 10% 到 90% 上升时间 t_r ≈ 2.2τ
到 50% 约 0.69τ，到 99% 约 4.6τ
```

fc 与 τ 是一件事的两面：fc = 1/(2πτ)。**频域滤波越狠（fc 低），时域反应越慢**。

## 计算与选型

**算例 1：fc 算例（1kΩ + 100nF）**

```
τ = 1k × 100nF = 100µs
fc = 1/(2π × 1k × 100nF) = 1/(2π × 100µs) ≈ 1.59kHz
```

**算例 2：指定频率处衰减量**

上例滤波器对 15.9kHz 干扰（10 倍 fc）：

```
|H| = 1/√(1+10²) ≈ 0.0995 → 约 -20dB，干扰只剩 1/10
对 159kHz（100 倍 fc）：1/√(1+100²) ≈ 0.01 → -40dB，剩 1/100
```

**算例 3：开关量输入的滤波延迟估算**

数字输入脚前挂 10k+10nF RC（τ=100µs）整形毛刺：输入阶跃后，

```
过 50% 阈值（多数输入脚阈值在 0.5×Vcc 附近）：0.69τ ≈ 69µs
10%→90%：2.2τ = 220µs
```

即这个硬件滤波天然带来约 70µs 的检测延迟——对按键/开关信号无感，对 µs 级 PWM 捕获就是灾难（会把沿变成斜坡，边沿时刻漂移）。

**算例 4：数字滤波替代（一阶 IIR）**

```c
/* 一阶 IIR 低通：alpha = 1/16，等效截止 fc ≈ fs/(2π×16) */
static uint16_t y;

uint16_t IirFilter_Update(uint16_t x)
{
    y += (int16_t)(x - y) / 16;   /* 每 step 修 1/16 误差 */
    return y;
}
```

fs=1kHz 时等效 fc ≈ 1000/(2π×16) ≈ 10Hz，阶跃到 99% 约 4.6×16≈74 个采样周期（与硬件 τ 类似的规律）。改用 8 点均值：延迟 4 个周期、噪声 ÷√8≈2.8，适合纹波型噪声；IIR 内存 1 个变量、均值要缓冲区。

### 硬件 RC vs 软件滤波取舍表

| 维度 | 硬件 RC | 软件滤波（均值/IIR） |
|---|---|---|
| 抗混叠能力 | **有**（在 ADC 之前拦住高频） | **无**（混叠发生在采样瞬间，事后无法恢复） |
| CPU/RAM 开销 | 零 | 每周期计算+缓冲 |
| 参数可调性 | 改电阻电容/换料 | 一行系数，随时 OTA |
| 非线性/大幅值毛刺 | 无削波问题 | ADC 削顶后滤波无效 |
| 适用 | ADC 前抗混叠、EMI、毛刺 | 量化噪声、慢漂、趋势平滑 |

口诀：**ADC 之前的问题（混叠、EMI）交硬件 RC，ADC 之后的问题（量化抖动、偶发坏点）交软件**。

## ECU 实例

- 每路模拟输入：10k+10nF 对地（fc≈1.6kHz）+ TVS/串阻保护，兼顾 EMI 与 ADC 采样（注意外部电容与源阻抗的 τ 配合，见 [../ADC采样原理/03-采样时间与源阻抗.md](../ADC采样原理/03-采样时间与源阻抗.md)）。
- 开关量输入：10k+10nF 抗毛刺（延迟 70µs 可忽略），软件再加 3 次一致采样（20ms 周期）防触点抖动。
- CAN 收发器供电：磁珠+RC/π 型滤波压共模噪声（频率规划避开通信频段）。
- 电池检测：1k+100nF（fc≈1.6kHz）压发电机纹波（数百 Hz~数 kHz），再由 16 点均值收尾。

## 与软件的关联

- **滤波参数联动**：硬件 fc 决定了软件还能看到什么——fc=1.6kHz 时想用软件分析 5kHz 分量是徒劳的；采样率按"fc 以内 10 倍"配即可。
- **IIR 系数与采样率绑定**：`/16` 这类系数在 fs 变化时等效 fc 同比变化，改采样周期必须复核滤波带宽。
- **坏点剔除**：先做限幅（偏差 > 阈值丢弃重采）再做均值，否则单次 EMI 尖峰会污染整个均值窗口。
- **诊断配合**：滤波后值用于控制、滤波前原始值用于诊断（原始值贴顶=硬件饱和，见 [../运放电路/02-跟随器与放大.md](../运放电路/02-跟随器与放大.md)）。

## 易错点与陷阱

- fc 算例里把 2π 忘掉，差 6.28 倍：养成 `fc=1/(2πRC)` 整体代入的习惯。
- 用大 RC 抗混叠却不看源阻抗：外部 C 与信号源内阻构成新 τ，采样窗不够照样读偏（两篇要合起来看）。
- 把 -3dB 点当"通带内无损"：0.707 倍即 -29% 幅度，精密测量时 fc 应远高于信号频率（信号在 fc/10 处才衰减 <0.5%）。
- 软件均值窗口过长掩盖真实变化：1s 均值的温度通道对快速温漂天然迟钝，动态需求要先算窗口延迟。
- 数字输入 RC 后直接接边沿中断：沿被拉缓，多次误触发——要么施密特输入缓冲，要么电平轮询+去抖。

## 面试高频题

**Q1：1kΩ 和 100nF 组成的一阶 RC 低通，fc 是多少？**
答：fc=1/(2πRC)=1/(2π×1k×100n)≈1.59kHz，τ=100µs，二者互为倒数关系（fc=1/2πτ）。

**Q2：-3dB 和 -20dB/dec 是什么意思？**
答：-3dB 即幅度 0.707（功率减半）的截止点；-20dB/dec 是一阶滚降斜率，频率每 ×10 幅度 ÷10。

**Q3：RC 阶跃后到 90% 要多久？开关量检测延迟怎么估？**
答：t≈2.2τ；过 50% 阈值约 0.69τ。10k+10nF（τ=100µs）的输入滤波 ≈70µs 固有延迟。

**Q4：软件滤波能替代 ADC 前的抗混叠 RC 吗？**
答：不能。混叠在采样瞬间把高频折叠成低频假信号，软件只能处理采样后的数据，折叠信息已不可逆；抗混叠必须在模拟域完成。
