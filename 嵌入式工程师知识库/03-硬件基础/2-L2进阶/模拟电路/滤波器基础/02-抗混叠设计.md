# 抗混叠设计：别让高频假信号混进读数

> 一句话定位：采样率不够时，高于 fs/2 的干扰会"折叠"成低频假信号叠加在读数上，且采样之后软件永远无法把它分离出去——抗混叠滤波必须在 ADC 之前的模拟域完成。
> 等级：L2 ｜ 前置：[RC滤波](01-RC滤波.md)、[采样与量化](../ADC采样原理/01-采样与量化.md)

## 原理

### 频谱折叠直觉

采样相当于频谱以 fs 为周期做"镜像复制"：凡是高于 fs/2（奈奎斯特频率）的分量，都会以 fs/2 为镜子折回到低频段：

```
 采样前的频谱（fs = 1kHz）          采样后的频谱（折叠叠加）

 f↑ 信号 10Hz                        f↑
 │ ▌                                 │ ▌ 10Hz（真）
 │        ▌干扰 800Hz                │      ▌ 200Hz ← 1000−800 折回（假！）
 │             ▌干扰 1010Hz          │ ▌ 990Hz? ← 1010−1000=10Hz，正好砸在信号上（假）
 └──────────────→ f                  └──────────────→ f
      0    500（fs/2）                     0    500
           ↑折叠镜子在这
```

致命点：折叠不是"变成另一个可辨识的干扰"，而是**叠加到某个低频位置冒充真实信号**——800Hz 干扰折回 200Hz，1010Hz 干扰折回 10Hz 直接骑在 10Hz 真信号上。示波器看 ADC 前波形正常，读数却"无规律漂移"，多半是它。

### 奈奎斯特与工程余量

- 理论下限：fs ≥ 2 × f_max；
- 工程经验：**fs ≥ 10 × 信号带宽**——理由有三：①一阶 RC 在 fs/2 处衰减有限，余量给滤波器留滚降空间；②采样点重建相位/幅度更准；③避开干扰正好落在信号带宽内的坏运气（如上例 1010Hz）。

### 抗混叠滤波器的位置与形态

```
传感器 → [RC 低通（抗混叠）] → [跟随器(可选)] → ADC → 软件
              ↑ 必须在采样之前          之后全是数字域，救不了混叠
```

## 计算与选型

**算例 1：1kHz 采样系统的 RC 设计**

信号带宽 50Hz，采样率 fs=1kHz：

```
设计目标：fc 落在"信号带宽"与"fs/2"之间，取 fc ≈ 100~200Hz
选 R=10k、C=100nF：
τ = 10k × 100nF = 1ms
fc = 1/(2πRC) = 1/(2π × 1ms) ≈ 159Hz ✓
```

校核 50Hz 信号衰减：50/159=0.314 → |H|=1/√(1+0.099)≈0.952，即 -0.43dB——精密场合嫌大，可把 fc 提到 300Hz（C 换 47nF）或软件端做增益补偿。

**算例 2：算一算干扰压得够不够（设计迭代）**

板上有 800Hz 开关噪声耦合进信号，幅度 100mV。算例 1 的 RC 对 800Hz：

```
800/159 = 5.03
|H| = 1/√(1 + 5.03²) ≈ 0.195 → -14.2dB
残余 100mV × 0.195 ≈ 19.5mV → 折回 200Hz，仍比 12bit 的 0.806mV 大 24 倍
```

不够，三选一迭代：
1. **加一阶**（两个 RC 级联）：-28dB → 残余 4mV，仍偏大但可配软件陷波；
2. **提采样率**：fs=10kHz 时 800Hz 处于带内（不折叠），改由软件滤除——把干扰"请出混叠区"也是解法；
3. **源头治理**：800Hz 走线远离/加磁珠，比任何滤波器便宜。

结论模板：先列"信号带宽 / 采样率 / 已知干扰频点"三要素，再验算每个干扰的折回位置与残余量，**别只算 fc 不算干扰**。

**算例 3：判断现场读数是不是混叠**

现象：KL30 检测读数在 13.98~14.05V 间无规律缓慢摆动，示波器看分压点平稳；把采样率从 1kHz 改成 977Hz（故意错开），摆动周期跟着变——**读数随采样率变化 = 混叠实锤**（真实低频分量不会理会 fs），随后查到发电机纹波 950Hz 折回 50Hz。

## ECU 实例

| 通道 | fs | 信号带宽 | 抗混叠 RC | 备注 |
|---|---|---|---|---|
| KL30 电池电压 | 1kHz | <10Hz | 1k+100n（fc≈1.6k）+软件均值 | 干扰主要是发电机纹波数百 Hz~kHz |
| NTC 水温 | 100Hz | <1Hz | 10k+100n（fc≈159Hz） | 慢信号，余量充足 |
| 加速度 | 4kHz | 400Hz | 二阶 RC，fc≈800Hz | 一阶滚降不够才上二阶 |
| 轮速方波 | — | — | 比较器整形，不走 ADC | 数字量无混叠概念 |

设计顺序口诀：**先定信号带宽 → 定 fs（≥10×）→ 定 fc（带宽与 fs/2 之间偏带宽侧）→ 验算已知干扰折回量 → 不够再迭代**。

## 与软件的关联

- **Adc MCAL 采样率配置**：`AdcGroup` 的触发周期决定 fs，改周期时同步复核抗混叠 fc 是否仍覆盖（fs 降低会把原本无害的干扰折叠进来）。
- **软件滤波的边界**：均值/IIR 只能处理采样后留在带内的噪声；折回的假信号频率若与信号重叠，任何数字滤波都无解——这是"软件修不了混叠"的准确含义。
- **诊断策略**：读数异常时先做"变采样率实验"（fs 微调看现象是否跟随）；把高频干扰诊断写进产线测试（注入已知干扰验证衰减量）。
- **降采样（Decimation）也要抗混叠**：先软件低通再抽取点，不能直接隔点取样——否则原始 fs 下的带外噪声折叠进新 fs，等于自己制造混叠。

## 易错点与陷阱

- 认为"软件均值 16 次就抗混叠了"：均值发生在采样之后，折叠早已发生，只能压带内噪声。
- fc 取太靠近 fs/2：一阶 RC 在 fs/2 处仅 -3dB 起步，fs/2 附近的干扰几乎全数折回；fc 必须明显低于 fs/2。
- 降采样直接抽点、FFT 直接截段：都是"自己制造混叠"的经典操作，先滤波再抽取/加窗。
- 慢信号就掉以轻心：温度通道带宽 1Hz，但板上的 MHz 级数字噪声照样折回 0.1Hz 变成"缓慢漂移"——每个 ADC 输入都要有 RC。
- RC 前面忘了想源阻抗：10k 的 R 与传感器内阻叠加改变实际 fc 与 τ（联动 [01-RC滤波.md](01-RC滤波.md) 与 [../ADC采样原理/03-采样时间与源阻抗.md](../ADC采样原理/03-采样时间与源阻抗.md)）。

## 面试高频题

**Q1：什么是混叠？为什么软件无法修复？**
答：高于 fs/2 的分量折叠成低频假信号叠加到带内；采样瞬间信息已按错误频率登记，折叠分量与真信号在数字域不可分离，只能在 ADC 前模拟滤波。

**Q2：抗混叠滤波器的 fc 怎么定？**
答：落在信号带宽与 fs/2 之间（偏带宽侧）：保证信号衰减可接受，同时把 fs/2 以上压到足够小；再按已知干扰频点逐一验算残余。

**Q3：为什么工程上取 fs≥10×带宽而不是 2×？**
答：2× 只是数学下限；留余量是为了滤波器滚降空间、采样重建精度，并避免干扰折回点正好落进信号带内。

**Q4：读数缓慢漂移但示波器看输入很稳，怎么排查？**
答：怀疑混叠：微调采样率观察现象是否跟随（跟随=混叠）；再查板上有无与 fs 有特定关系的开环节拍，加强输入 RC 或调整 fs/治理源头。
