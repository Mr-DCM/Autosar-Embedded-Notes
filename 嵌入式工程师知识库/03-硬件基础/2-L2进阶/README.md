# 2-L2进阶

> 上级目录：[03-硬件基础](../README.md)

## 定位

主等级 **L2**：排障与评审够用——MOS 与电源电路、模拟电路（ADC/DAC/运放/滤波）、时钟电路、ECU 硬件常识。读完本带，你能在硬件评审会上提出有效问题，在"软件诡异现象"里识别出板级因素，与硬件工程师高效分工排障。

> 提示：[ADC采样原理/01-采样与量化](模拟电路/ADC采样原理/01-采样与量化.md) 为【L1→L2】篇——只依赖分压/量程概念，L1 阶段即可提前读。

## 坡道说明

- **何时进入**：L1 带三站（电压电流 → 上下拉 → 原理图阅读）读完即可进入；按工作内容选入口（做供电相关先进电源电路，做采集相关先读 ADC 采样原理，做驱动/诊断先进 MOS 与 ECU 硬件常识）。
- **何时离开**：能独立走完"原理图 → 引脚 → 软件配置 → 换算验证"一条链路、能看懂硬件评审清单上的每一条——即按需查阅本带，不必强读 [L3 带](../3-L3高级/README.md)。
