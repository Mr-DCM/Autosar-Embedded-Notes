# DCDC 原理（Buck 降压为主）

> 一句话定位：开关电源 = 高频斩波 + LC 滤波取平均值——效率高（90%+）、发热小，但纹波/EMC 复杂，是 ECU 里 12V→5V/3.3V 主功率轨的承担者。
> 等级：L2 ｜ 前置：[LDO原理与选型](01-LDO原理与选型.md)

## 原理

线性电源（LDO）把多余电压"烫"成热，开关电源（Switch-Mode Power Supply，SMPS）换个思路：让开关节点只有"全通"和"全断"两种状态（损耗都极小），用电感电容把斩波后的方波"平均"成直流。

### Buck 降压拓扑

```
   Vin(12V) ──[S1 高边MOS]──┬──[L 电感]──┬──────── +Vout(5V)
                 ①开关      │            │
                           │           C1 ─| |--   ③输出电容滤波
                  ②续流    │            │
              [S2 同步MOS   │           [负载]
               或 -->| 二极管]           │
                           │            │
                          GND ─────────GND
```

两个阶段循环（周期 T = 1/fsw，占空比 D = t_on/T）：

1. **导通阶段（t_on）**：S1 闭合、S2 断开 → Vin 加在电感上，电感电流线性上升（储能）；
2. **关断阶段（t_off）**：S1 断开 → 电感电流不能突变，经 S2（或续流二极管）续流，电流线性下降（释能）；
3. LC 滤波把开关节点（S1/S2 中点）的方波平均成平直的 Vout。

稳态下伏秒平衡（导通升的电流=关断降的电流）：

```
Vout = D × Vin     （CCM 连续电流模式，忽略损耗）
```

### 同步整流（Synchronous Rectification）

用第二只 MOS（S2）替代肖特基续流二极管：二极管压降固定 ~0.4V，MOS 导通压降 I×Rds(on) 在大电流下小得多 → 效率提升 3~5 个百分点。代价：需要控制芯片精确互补驱动 + 死区（防上下管直通），轻载时可能反而损耗大（有些芯片轻载自动回退到二极管仿真/PFM 模式）。

### 损耗来源（概念）

| 损耗 | 来源 | 与频率关系 |
|---|---|---|
| 导通损耗 | I²×（Rds(on) 高管+低管+电感 DCR） | 与频率无关 |
| 开关损耗 | 每次开关的电压电流交叠 + MOS 结电容充放电 | **正比于 fsw** |
| 磁芯/驱动损耗 | 电感磁芯、栅极驱动 | 随频率上升 |

fsw 越高：电感电容越小（体积成本降）但开关损耗越大、EMC 越恶劣——选频率是折中。

### 开关频率与汽车 EMC

- **避开 AM 频段**：调幅广播 150kHz~1.8MHz（LW/MW/SW）。DCDC 基波/谐波落在其中会直接灌进车载收音机 → 常见选择：低于 150kHz 或 2MHz 以上（400kHz 档用于对 EMC 不敏感场合，以项目 EMC 规范为准）；
- **扩频（Spread Spectrum）**：让 fsw 在小范围内伪随机抖动，把窄带尖峰能量摊宽、峰值降低几 dB~十几 dB——芯片使能脚/寄存器配置，EMC 对策的常用手段。

### 电感/电容选型（一句话版）

- 电感：饱和电流 > Iout + ΔIL/2（留 20~30%），DCR 低；感值决定纹波电流；
- 输出电容：容量按纹波 ΔV = ΔIL/(8×fsw×C) 核，ESR 低（MLCC），注意直流偏压效应（见 [04-纹波与去耦](04-纹波与去耦.md)）。

## 计算与选型

### 算例 1：占空比

12V → 5V：D = 5/12 ≈ 0.42（导通 42% 周期）。fsw=400kHz 时 t_on ≈ 1.04μs。

### 算例 2：电感纹波电流

```
ΔIL = (Vin − Vout) × D / (L × fsw)
    = (12−5) × 0.417 / (10μH × 400kHz)
    = 2.92 / 4 ≈ 0.73A（峰峰）
```

设计惯例 ΔIL 取 Iout 的 30~40%：Iout=1A 想要 ~0.35A → L 加大到 22μH（ΔIL≈0.33A ✓）。纹波电流大 → 输出纹波大、电感发热、进入 DCM 早；太小 → 动态响应慢。

### 算例 3：效率对比

12V→5V/1A：LDO 损耗 7W（η=42%）；Buck 整体损耗 ~0.4W（导通+开关+磁件，以实测为准）→ η≈93%。这就是主功率轨必须用 DCDC 的原因。

### DCDC vs LDO 决策表

| 维度 | DCDC（Buck） | LDO |
|---|---|---|
| 效率 | 高（85~95%） | 低（≈Vout/Vin） |
| 发热 | 小 | 大（压差×电流全变热） |
| 输出纹波 | 大（mV~几十 mV） | 极小（μV 级） |
| EMC | 差（开关噪声需对策） | 好（无开关噪声，还有 PSRR） |
| 成本/复杂度 | 高（电感+布局讲究） | 低（一颗芯片） |
| 大压差/大电流 | ✓ 首选 | ✗ 热扛不住 |
| 给 ADC/PLL 供电 | 需后级滤波/LDO | ✓ 首选 |
| 典型位置 | 12V→5V 主轨 | 5V→3.3V/2.5V 模拟轨 |

### 典型 ECU 电源树

```
KL30(+12V) ─[防反接/TVS]─┬─→ [DCDC Buck] ─ 5V ─┬─→ [LDO] ─ 3.3V ─ MCU IO / 收发器
                         │                     ├─→ [LDO] ─ 1.2V ─ 内核（小电流场景）
                         │                     └─→ 传感器 5V
                         └─→ [SBC 常电 LDO] ─ 3.3V_std ─ 唤醒电路/RTC
注：大电流内核轨（数百 mA）常由独立 Buck 供，以实际原理图为准
```

架构逻辑：DCDC 干粗活（大压差大电流要效率），LDO 干细活（低噪声轨保精度），常电轨独立（睡眠不断）。

## ECU 实例

- 主轨：KL30 → Buck 5V/3.3V（MCU+外设，0.5~2A）；
- AURIX TC3xx 外置 DCDC：内核 1.2V 轨电流大，用专用 Buck（可通过 SPI 配置使能/监控）；
- 多轨 PMIC：一路芯片集成多路 Buck+LDO+监控+看门狗（SBC）；
- 经验数字：车规 Buck fsw 常见 400kHz / 2MHz / 2.2MHz 档位；轻载 PFM 模式纹波增大会恶化 ADC（以器件手册为准）。

## 与软件的关联

1. **EN/FS 引脚**：使能与频率选择由硬件电阻/引脚电平定，软件改不了——但要知道板上 fsw 是多少，因为它是 EMC 排障与 ADC 采样同步的基准。
2. **可配置 DCDC（SPI/寄存器）**：使能、时序、轻载模式切换（强制 CCM 保纹波 vs 自动 PFM 省电）是软件配置项，配置错误直接影响 ADC 噪声与睡眠电流。
3. **上电时序**：多轨电源的建立顺序（内核→IO 或反之）由电源树硬件决定，软件的 EcuM/启动代码要配合：先等 PG/稳定，再初始化需要特定电压顺序的外设（如 QSPI/PLL）。
4. **ADC 与 fsw 的纠缠**：DCDC 纹波会耦合进 ADC 读数（见 [04-纹波与去耦](04-纹波与去耦.md)），软件可用"采样时刻避开开关沿 + 多次平均"缓解。
5. **睡眠功耗**：主 Buck 常在睡眠时关断（EN 拉低），只留常电 LDO 轨——睡眠电流预算的关键开关项（见 [03-功耗估算](03-功耗估算.md)）。

## 易错点与陷阱

- **fsw 落进 AM 频段**：收音机测试才发现杂音，改版困难——选型时先对 EMC 规范。
- 轻载进 PFM：纹波突增，ADC/PLL 噪声"偶尔变差"的典型原因，可强制 CCM（费电）或加后级滤波。
- 电感饱和电流不足：大负载时电感饱和 → 纹波暴涨+啸叫+过热，按 Iout+ΔIL/2+裕量选。
- 续流二极管用慢管：反向恢复损耗巨大，异步 Buck 必须肖特基。
- 布局不讲环路：开关节点环路面积大 = EMC 灾难（硬件问题，但表现为软件通信误码/复位，排查时别只盯代码）。
- 输出电容忽略直流偏压：MLCC 标 10μF 实际剩一半，纹波翻倍（见 [04-纹波与去耦](04-纹波与去耦.md)）。
- 12V 下跌（曲轴起动）时 Buck 占空比顶到最大仍撑不住 → 后级轨跌落，软件表现为"冷起动复位"。

## 面试高频题

1. **Q：Buck 为什么 Vout = D×Vin？**
   A：稳态下电感伏秒平衡：导通期 (Vin−Vout)×D×T 与关断期 Vout×(1−D)×T 相等（同步整流近似），解得 Vout = D×Vin。直觉：输出是斩波方波（幅值 Vin、占空比 D）的平均值，LC 滤波取出这个平均。

2. **Q：同步整流为什么提升效率？**
   A：用 MOS 的 I×Rds(on)（毫欧级，压降几十 mV）替代续流二极管的固定 ~0.4V 压降，大电流时导通损耗大幅下降，典型提升 3~5 个百分点；代价是驱动复杂与轻载效率可能劣化。

3. **Q：车载 DCDC 为什么避开 AM 频段？什么是扩频？**
   A：开关基波及谐波落在 150kHz~1.8MHz 会耦合进线束和天线，收音机里出现啸叫；所以选 <150kHz 或 >1.8MHz。扩频是让开关频率小范围抖动，把集中的窄带干扰摊成宽谱低峰值，降低 EMC 峰值几 dB~十几 dB。

4. **Q：DCDC 和 LDO 怎么选？**
   A：大压差/大电流要效率选 DCDC（但纹波与 EMC 差）；小压差/小电流/对噪声敏感（ADC、PLL、射频）选 LDO；典型架构是 DCDC 粗降压 + LDO 精稳压两级。

5. **Q：DCDC 的损耗有哪些？为什么频率不能无限提高？**
   A：导通损耗（I²R）、开关损耗（交叠+结电容充放电，正比 fsw）、磁芯与驱动损耗。频率高电感电容可小型化，但开关损耗线性增长、EMC 恶化，故是折中而非越高越好。
