# LDO 原理与选型

> 一句话定位：线性稳压器（LDO）= 一个被误差放大器实时调节的"可变电阻"，把高压"烫"成低压——简单、干净、安静，但效率低、发热大，是 MCU/收发器 3.3V 这"最后一厘米"的经典选择。
> 等级：L2 ｜ 前置：[欧姆定律与功率](../../1-L1基础/电压电流与基本定律/01-欧姆定律与功率.md)

## 原理

LDO（Low Dropout Regulator，低压差线性稳压器）的核心是负反馈：误差放大器（Error Amplifier）比较输出分压与内部基准 Vref，动态调整串联调整管（Pass Transistor，PMOS/NMOS/PNP）的导通程度，使 Vout 恒定。

```
      Vin(KL30 或前级 5V)
        │
   ┌────┴────┐
   │ 调整管   │ ←── 误差放大器输出控制（等效"可变电阻"）
   └────┬────┘
        ├─────────────┬────── Vout（稳定）
        │             │
      [R1 上分压]      │ 输出电容 --| |-- → GND
        │             │
        ├── FB 反馈脚  │
        │             │
      [R2 下分压]   [负载]
        │             │
       GND           GND
   基准 Vref ──→ 误差放大器 ⊕/⊖ ──→ 调整管
```

直觉：把调整管想成"串联在电源上的可变电阻"——负载电流变大 Vout 想跌，放大器就让电阻变小补回压降；Vin 波动、负载变化都在反馈环内被吸收。代价是"多余的电压×电流"全部变成热。

关键参数（每个都直接影响你的软件行为）：

| 参数            | 含义                                                      | 软件工程师为什么要在意                                      |
| --------------- | --------------------------------------------------------- | ----------------------------------------------------------- |
| Dropout（压差） | 维持稳压所需的最小 Vin−Vout（典型 0.1~0.6V，以手册为准） | 压差不够 → Vout 跟随 Vin 跌 → MCU 欠压复位/时钟异常       |
| 效率 η         | ≈ Vout/Vin（忽略 Iq）                                    | 决定发热量与热设计                                          |
| Iq（静态电流）  | 空载时自身消耗的地电流（μA~mA 级）                       | **睡眠功耗的关键项**，整车静态电流指标                |
| PSRR            | 电源电压抑制比：对输入纹波的衰减（dB）                    | 前级 DCDC 纹波经 LDO 抑制后给 ADC/PLL（高频段会跌，看曲线） |
| 负载瞬态响应    | 负载电流突跳时 Vout 的跌落/恢复                           | MCU 从睡眠唤醒瞬间电流突增，可能瞬间跌压                    |
| EN/PG           | 使能输入 / Power Good 输出                                | 上电时序控制与电压监测的软件接口                            |

## 计算与选型

### 算例 1：效率与损耗

12V 直接降到 3.3V 给 MCU（负载 100mA）：

- 损耗 P = (Vin−Vout)×Iout = (12−3.3)×0.1 = 0.87W；
- 效率 η ≈ Vout/Vin = 3.3/12 = 27.5%——四分之三的功率变成热；
- 若前级先 DCDC 到 5V 再 LDO 到 3.3V：LDO 损耗 = (5−3.3)×0.1 = 0.17W，η = 66%，发热降到五分之一。**这就是"DCDC 粗降压 + LDO 精稳压"两级架构的由来**（见 [02-DCDC原理](02-DCDC原理.md)）。

### 算例 2：热计算（完整流程）

条件：SOT-223 封装 LDO，θja ≈ 60°C/W（以器件手册为准），P = 0.87W，环境温度 Ta = 85°C（发动机舱边界）：

```
Tj = Ta + P × θja
   = 85 + 0.87 × 60
   = 85 + 52.2
   = 137.2°C  > 125°C（车规结温上限，以器件手册/项目规范为准）→ 不合格！
```

整改选项：①降到 5V 输入（P=0.17W → Tj=85+10.2=95°C ✓）；②换封装/加铺铜降 θja；③直接改用 DCDC。热计算不合格的 LDO 不是"可能坏"，是"夏天必坏"。

### 算例 3：睡眠功耗

系统睡眠时只剩 LDO 自身：Iq = 50μA（典型，以手册为准）→ 12V 下功耗 0.6mW，睡眠预算里的固定项（详见 [03-功耗估算](03-功耗估算.md)）。

### 算例 4：Dropout 校验（冷起动工况）

条件：曲轴起动时 KL30 可跌到 6V（以 ISO 16750/项目规范为准），5V 轨由前级 DCDC 保持，LDO 5V→3.3V：

- 可用压差 = 5 − 3.3 = 1.7V；手册 dropout@100mA 典型 0.3V、最坏 0.6V（以手册曲线为准）；
- 判定：1.7V > 0.6V ✓，且留 1.1V 余量覆盖低温与负载瞬态；
- 若是 3.45V→3.3V 这类"贴地飞行"设计，dropout 必须选 <100mV 的超低压差型号，否则冷起动直接跌轨。

补充两个选型时容易漏看的细节：

- **软启动（Soft-Start）**：上电时输出电压按斜坡建立，避免浪涌电流打垮前级；多轨系统中软启动时间还决定上电时序（配合 EN 使用）；
- **输出放电（Discharge）功能**：关断时主动把输出电容放掉，保证重新上电时序干净——对要求"快速循环上电"的诊断场景（如 KL30 快速断通）很关键（以器件手册为准）。

| 参数     | 车规要点                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------- |
| 输入耐压 | **≥ 45V**：12V 系统需扛负载突降（Load Dump，ISO 16750，以项目规范为准）；普通 6.5V 消费级 LDO 接 KL30 必坏 |
| Dropout  | 最坏 Vin（冷启动 6V 以下曲轴工况）− Vout − 余量 > dropout                                                       |

| PSRR     | 看 100kHz~1MHz 曲线（DCDC 开关频率处），不是只看 DC                                                               |

| 认证     | AEC-Q100，−40~125°C                                                                                             |

## ECU 实例

- 汽车应用链路：KL30（12V 常电）→ 前级 DCDC/SBC 降到 5V → LDO 5V→3.3V 供 MCU IO 与 CAN/LIN 收发器；
- 传感器供电（5V/3.3V，100mA 内）：LDO 是标配——低纹波保住 ADC 精度；
- 通信收发器供电：PSRR 隔离数字噪声；
- SBC（System Basis Chip）把 LDO+看门狗+收发器集成，是小型 ECU 的主流方案；
- 经验数字：MCU 3.3V 轨 50~300mA，传感器轨 10~100mA，Iq 车规 LDO 1~50μA（以器件手册为准）。

## 与软件的关联

1. **欠压时 MCU 行为**：Vin 跌破 dropout → Vout 跟跌 → MCU 触发 BOR（欠压复位）或时钟异常。软件要区分"看门狗复位"与"欠压复位"：读复位原因寄存器分别处理、分别报 DTC。
2. **EcuM 电压监控**：EcuM 的 RUN/POST_RUN 阶段配置电压监控阈值，欠压事件触发受控下电（NvM 写回、外设安全态），而不是被硬复位打断（详见 [EcuM 上下电时序](../../../07-AUTOSAR架构/2-L2进阶/系统服务栈/EcuM/02-上下电时序.md)）。
3. **PG（Power Good）引脚**：接 GPIO 轮询或中断，电源异常早期预警；也可作为 MCU 正常运行的硬件监视输入。
4. **EN 引脚时序**：多电源轨上电顺序由 EN 控制（硬件延时或软件 GPIO 拉高），顺序错了可能闩锁或总线争用。
5. **睡眠策略**：系统睡眠时通过 EN 关断非必要 LDO 轨（传感器轨、通信轨），只留常电轨——睡眠电流预算的重要开关项（见 [03-功耗估算](03-功耗估算.md)）。

## 易错点与陷阱

- **忽略负载突降耐压**：普通 LDO（6.5V/10V 耐压）接 KL30，抛负载瞬间 40V+ 直接击穿——车规第一坑。
- Dropout 只看典型值：手册 dropout 是特定电流/温度下的，大电流低温下成倍恶化，要按曲线取最坏值。
- Iq 用典型值做睡眠预算：全温最大值可能大一个数量级，预算失真。
- 热设计只算"平均功耗"：环境温度 85°C + 大压差 = 悄悄超结温，寿命加速衰减。
- MLCC 输出电容导致振荡：部分 LDO 要求 ESR 窗口，全陶瓷电容布局要在手册稳定性图上确认（以器件手册为准）。
- PSRR 只看 DC 值：DCDC 开关频率处的 PSRR 可能已跌到 20dB 以下，纹波照样穿过来（见 [04-纹波与去耦](04-纹波与去耦.md)）。

## 面试高频题

1. **Q：LDO 的工作原理？**
   A：误差放大器将输出分压与内部基准比较，动态调节串联调整管的导通程度（等效可变电阻），负反馈使 Vout 恒定。多余电压×负载电流全部转为热量，所以效率 ≈ Vout/Vin。
2. **Q：LDO 效率怎么算？12V 转 3.3V 带 100mA 发热多少？**
   A：η ≈ Vout/Vin = 27.5%；P = (12−3.3)×0.1 = 0.87W。若封装 θja=60°C/W，85°C 环境下结温 137°C 超限——要么前级 DCDC 降到 5V，要么改用开关电源。
3. **Q：Dropout 压差是什么？不够会怎样？**
   A：维持稳压所需最小 Vin−Vout。不足时调整管完全导通也补不回，Vout 跟随 Vin 下跌，下游 MCU 欠压复位、时钟漂移；冷启动曲轴工况（KL30 跌到 6V 以下）是典型考验点。
4. **Q：为什么睡眠电流设计要盯 LDO 的 Iq？**
   A：系统睡眠时负载几乎为零，LDO 自身地电流成为常电轨的主要耗电项（μA~mA 级），直接决定整车静态电流指标是否达标；选型要看全温最大值并善用 EN 关断非必要轨。
5. **Q：车规 LDO 输入耐压为什么常要 40V 以上？**
   A：12V 系统存在负载突降（发电机抛负载瞬间电压尖峰，钳位后仍可达 40V 左右，以 ISO 16750/项目规范为准），耐压不足的 LDO 一击即坏。
