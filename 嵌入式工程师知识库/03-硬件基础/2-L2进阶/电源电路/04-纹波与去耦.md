# 纹波与去耦

> 一句话定位：IC 需要的不是"平均电压"而是"每一纳秒都够用的电压"——瞬态电流乘以电源阻抗就是压降，去耦电容就是放在芯片嘴边的"随身水壶"；MCU 无故复位，十有八九先查这里。
> 等级：L2 ｜ 前置：[DCDC原理](02-DCDC原理.md)

## 原理

### 为什么需要去耦（Decoupling）

电源走线有电阻和电感（nH 级），响应不了纳秒级的负载电流跳变：

```
压降 = ΔI × Z_电源路径
Z 随频率上升（走线电感 ωL），频率越高阻抗越大
```

MCU 内核时钟门控打开的一瞬间、IO 成排翻转的一瞬间，电流在 ns~百 ns 内跳变几十~几百 mA。此时若电源阻抗高，电压瞬间塌陷 → 低于复位/BOR 阈值 → **复位；没塌到复位但时钟/PLL 受扰 → 周期异常、ADC 跳码**。对策：把低阻抗的"就地储能池"（去耦电容）放到芯片电源脚旁边。

### 去耦电容组合策略（工程常识）

| 电容 | 作用 | 位置 |
|---|---|---|
| 100nF × 每个电源脚 | 高频第一响应（低 ESL 的 0402/0603 MLCC） | 紧贴引脚，回路最小 |
| 4.7~10μF × 每电源域/每组 | 中频补给、覆盖 100nF 与大电容之间的缺口 | 电源入口附近 |
| 100μF 级电解/大容量 | 低频储能，扛慢波动 | 电源入口 |

只用大电容不行（高频阻抗高），只用小电容不行（能量不够）——**组合**才形成宽频低阻抗。

频段-电容分工（横轴频率示意，SRF = 自谐振频率）：

```
 |Z|                              每颗电容：低于 SRF 呈容性↓，高于 SRF 呈感性↑
  │╲
  │ ╲        100μF          4.7~10μF        100nF×N(0402 紧贴引脚)
  │  ╲      ╱╲  SRF低      ╱╲   SRF中      ╱╲   SRF高
  │   ╲    ╱   ╲___       ╱   ╲______    ╱    ╲_____
  │    ╲__╱        ╲_____╱           ╲__╱
  └──────┬──────────┬──────────────────┬──────────────────→ f
       ~kHz        ~百kHz~MHz          ~十~百MHz
      低频储能      中频补给            高频第一响应
   (扛DCDC慢波动)  (补大小电容缺口)    (ns 级 ΔI 就地供给)
        │ 覆盖缺口 → 组合拼出"宽频低阻抗"，单打独斗都不行
```

### 电容的非理想性

理想电容不存在，实际是 C + ESR（等效串联电阻）+ ESL（等效串联电感）：

- 自谐振频率（SRF）：低于它呈容性（阻抗随频率下降），高于它呈感性（阻抗回升）——大电容 SRF 低、小电容 SRF 高，组合覆盖宽频；
- ESR 提供阻尼，全无 ESR 的 MLCC 阵与电源电感易形成振铃；
- **MLCC 直流偏压效应（一句话）**：陶瓷电容上加直流电压后有效容量下降，X5R 10μF/16V 在 12V 偏压下可能只剩 3~5μF——标称值不是有效值（以器件手册曲线为准）。

### 布局就近原则

高频电流回路面积决定寄生电感：电容离电源脚 1cm，回路电感就可能让 100nF 在 100MHz 处完全失效——**去耦电容的有效性由布局决定，远放等于没放**。BGA 类芯片在 PCB 内层再埋电容就是这个道理。

### 模拟电源隔离

MCU 的 VDDA（模拟电源）/PLL 电源对噪声敏感，常用"磁珠（Ferrite Bead）+ 电容"做一级隔离：磁珠在 MHz 频段呈电阻性，把数字侧高频噪声变成热耗掉，后级 RC/LC 平滑，给 ADC 基准、PLL 一个安静电源。

### 纹波 → ADC 精度劣化链条

```
DCDC 开关纹波 → (PSRR 有限/耦合) → VDDA/基准波动
→ ADC 参考电压随纹波抖动 → 转换结果叠加开关频率的周期性误差
→ 表现：ADC 低位跳动、按 fsw 相关周期出现规律性噪声
```
详见 [模拟电路](../模拟电路/README.md) 的 ADC 采样专题。

## 计算与选型

### 算例：瞬态压降与电容组合

场景：MCU 内核轨 3.3V，负载电流 100ns 内从 20mA 跳到 220mA（ΔI=200mA），本地只有远处 10μF（假设供电流全靠它）：

```
ΔV = ΔI × Δt / C = 0.2 × 100e-9 / 10e-6 = 2mV（理想电容足够）
```

但实际 10μF 在 100MHz 等效频率处是感性（|Z| 可能 >1Ω）：

```
ΔV = ΔI × |Z| = 0.2 × 1 = 200mV → 塌陷！
```

加 4 颗紧贴的 100nF（该频段 |Z| ≈ 0.1~0.3Ω/颗，并联更低）：

```
ΔV ≈ 0.2 × 0.05~0.08 ≈ 10~16mV ✓（低于 BOR/时钟余量）
```

结论：**数量与位置比单颗容值更重要**。

### MLCC 偏压核算

12V 轨需要有效 10μF：选 25V 耐压 X7R 10μF（偏压下剩 ~60%）≈ 6μF，两颗并联达标；若选 16V 同容值可能只剩 30~40%（以所选型号手册 DC-bias 曲线为准）。

### 排障工具与手法

- 示波器 AC 耦合、20MHz 带宽限制、探头用**地弹簧**（短地线）贴测电源脚；
- 看纹波频率是否等于 DCDC fsw（定位到电源）还是随任务/IO 活动（定位到负载瞬态）。

排障速查表：

| 现象 | 首查 |
|---|---|
| MCU 无故复位 | 电源脚纹波/塌陷（先于查代码） |
| ADC 低位规律跳动 | VDDA 隔离、基准滤波、采样时刻 vs fsw |
| PLL 偶发失锁 | PLL 电源滤波电容是否漏贴/虚焊 |

## ECU 实例

- MCU：每对电源脚 100nF（0402 紧贴）+ 每域 4.7μF + 入口 47μF，VDDA 磁珠+1μF+100nF，PLL 电源独立 RC（以参考设计为准）；
- CAN 收发器：VCC 100nF+4.7μF 紧贴，否则收发瞬间压降造成误码；
- 车规要求：去耦电容 AEC-Q200 认证，X7R/X5R 温稳介质优先（Y5V 慎用，容值随温度剧变）；
- DCDC 输出：大容量 MLCC 组 + 必要时聚合物电容提供阻尼（见 [02-DCDC原理](02-DCDC原理.md)）。

原理图评审时的去耦检查清单（软件工程师也能对照看）：

| 检查项 | 合格判据 |
|---|---|
| 每电源脚 100nF | 数量=电源脚对数，0402/0603 紧贴 |
| 每域 μF 级 | 4.7~10μF 至少每域一颗 |
| VDDA 隔离 | 磁珠+两级电容，不与 VDD 直连 |
| 电容介质/耐压 | X7R/X5R；偏压后有效容值达标 |
| 大电流器件 | 收发器/驱动器本地独立去耦 |
| 布局 | 电容与电源脚同面就近，回路最短（PCB 评审项） |

## 与软件的关联

1. **ADC 采样时序避开开关噪声**：采样时刻与 DCDC 开关沿同步错开（或过采样平均），能显著压噪——知道板上 fsw 才能设计这个时序（见 [02-DCDC原理](02-DCDC原理.md)）。
2. **软件滤波不背硬件的锅**：纹波引起的规律性跳码应先修硬件（加去耦/隔离），软件均值只是掩盖；判据：噪声是否与 fsw/IO 活动锁相。
3. **复位原因分析**：读复位源寄存器，BOR/欠压复位频繁出现 → 立即怀疑电源塌陷而不是代码；记录并上报 DTC 辅助产线与售后定位。
4. **低功耗切换瞬间的电源冲击**：进/出睡眠时外设成批开关，电流跳变大，若布局薄弱会出现"睡眠唤醒偶发复位"——软件可分批使能外设时钟缓解。
5. **调试配合**：写一段"负载跳变测试代码"（周期性开关外设/翻转 IO），配合示波器就是最便宜的电源完整性测试。

## 易错点与陷阱

- 电容全选同值：宽频低阻抗靠组合，10 颗 100nF 不如 100nF×4+10μF×2；
- 电容摆得远："有电容"不等于"有去耦"，高频下 1cm 走线就毁掉 100nF 的作用；
- 只看标称容值：MLCC 偏压下容量减半是常态，按 DC-bias 曲线选耐压；
- 示波器探头地线夹长线：测出来全是探头自激振铃，用地弹簧+带宽限制；
- 忘了 AC 耦合/带宽限制设置：看不到 mV 级纹波，误判电源干净；
- VDDA 与 VDD 直接短接省事：ADC 精度永久劣化，跳码查不到"软件 bug"；
- Y5V 介质电容用在电源位置：温度一高容值掉 80%，低温下产品批量异常。

## 面试高频题

1. **Q：为什么每个电源脚都要 100nF，还要加 4.7μF？**
   A：IC 瞬态电流频率高，100nF 低 ESL 就近提供高频电流通路；但容量小撑不住中频需求，μF 级电容补能量。两者自谐振点不同，组合形成宽频低阻抗，单打独斗都不行。

2. **Q：MLCC 的直流偏压效应是什么？**
   A：陶瓷电容上加直流偏压后有效容值下降（与介质材料/耐压相关），10μF/16V 在 12V 下可能只剩三四成。设计要按手册 DC-bias 曲线取有效值，或选更高耐压档。

3. **Q：磁珠在电源隔离里起什么作用？**
   A：磁珠在低频呈低阻、在 MHz 频段呈电阻性，串在 VDDA 供电路径上把数字侧高频噪声衰减为热，配合电容组成低通，给 ADC/PLL 一个安静电源。

4. **Q：MCU 无故复位，为什么先查电源纹波？**
   A：欠压/纹波塌陷是最常见的"软性"复位源：BOR 阈值被瞬态压降触发，复位原因寄存器也未必能区分细微欠压。AC 耦合+地弹簧测电源脚纹波，比先怀疑代码快得多。

5. **Q：去耦电容的布局为什么必须就近？**
   A：电容到电源脚的回路（含过孔与内层走线）存在电感，频率越高感抗越大；距离远回路面积大、电感大，电容在高频处失效。去耦有效性=电容参数×布局，后者常常是决定项。
