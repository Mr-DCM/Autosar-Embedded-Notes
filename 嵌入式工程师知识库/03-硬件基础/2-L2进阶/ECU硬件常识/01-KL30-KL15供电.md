# KL30/KL15 供电架构

> 一句话定位：车载 ECU 的电源不是"插上就有的 12V"，而是从蓄电池经 KL30 常电、KL15 点火、防反接、TVS、DCDC/LDO 一路驯化成芯片电压——电压范围 9~16V 只是常态，冷启 6V、抛负载 60V+ 才是设计难点。
> 等级：L2 ｜ 前置：[汽车电路实例](../../1-L1基础/电压电流与基本定律/03-汽车电路实例.md)

## 原理

### 1. 汽车电源网络：从蓄电池到 ECU

```
发电机(Alternator) ──┐
                    ├──▶ 蓄电池 12V ──▶ 熔丝盒 ──▶ 各 ECU
       ▲            │
   由发动机拖动      └── 全车电气地（车身/ chassis 地）

ECU 侧三根关键线：
  KL30  常火（蓄电池正极直供，不受点火开关控制）→ 供睡眠/唤醒电路、常记存储
  KL15  点火（ignition，钥匙/启动按钮控制）      → "用户要用车了"的信号
  KL31  地（蓄电池负极/车身地）
  KL50  起动机控制线（cranking，起动瞬间接入）    → 冷启动电压跌落的肇事者
```

### 2. 端子电压范围（以 ISO 16750-2 与项目规范为准）

| 工况 | 电压量级 | 说明 |
|---|---|---|
| 常态运行（12V 系统） | 约 9~16 V | 发电机调节器决定上限（14.x V 常态） |
| 冷启动（cranking） | 跌到 6 V 量级 | 起动机大电流拉低电池电压，数百 ms~秒级 |
| 起动脉冲/缓升缓降 | 各类曲线 | 详见 ISO 16750-2 各 profile |
| 抛负载（load dump） | 60 V 以上尖峰 | 断电池瞬间发电机磁场能量释放，详见[负载突变保护](03-负载突变保护.md) |
| 反接 | −12 V 或 −24 V（跳线） | 防反接电路的地狱测试 |
| 静态漏电流 | 整车 mA 级预算 | 睡眠设计约束，见[唤醒电路](02-唤醒电路.md) |

（精确限值以 ISO 16750-2 版本与主机厂企标为准；24V 商用车系统数值加倍量级。）

### 3. ECU 内部供电架构全图

```
KL30 ──▶ 熔丝 ──▶ [防反接] ──▶ [TVS 钳位] ──▶ [前端 LC 滤波]
                      │            │
                      │        抛负载/瞬态被钳到这里
                      ▼
              ┌───────────────┐
              │  DCDC(buck)   │ 12V→5V（大电流域：MCU IO、CAN 收发器）
              └──────┬────────┘
                     ├──▶ [LDO 5V→3.3V]（数字域：外设、接口）
                     ├──▶ [LDO 5V→1.3V类]（内核域，大电流内核也有独立 buck）
                     └──▶ [传感器供电 5V]（独立 LDO/带诊断，供外部传感器）
KL31 ──────────────▶ ECU 地（单点汇接，见地平面篇）
KL15 ──▶ [分压/滤波] ──▶ MCU 输入捕获（高有效数字输入）
```

每一环的详细电路见[电源电路目录](../电源电路/README.md)：[DCDC 原理](../电源电路/02-DCDC原理.md)、[LDO 原理与选型](../电源电路/01-LDO原理与选型.md)、TVS 见[二极管与 TVS](../../1-L1基础/原理图阅读/常用元器件符号与封装/02-二极管与TVS.md)。

### 4. 防反接方案对比

| 方案 | 压降/损耗 | 成本 | 一句话 |
|---|---|---|---|
| 串联二极管 | ~0.5~0.7 V（数百 mA 时百 mW 级损耗发热） | 最低 | 简单可靠但损耗大，小电流 ECU 可用 |
| 桥式整流 | 2×二极管压降 | 低 | 正反都能工作但损耗加倍，仪表类偶用 |
| Ideal Diode（MOS 防反接） | mV 级（MOS 导通内阻） | 中 | 高边 PMOS/NMOS+控制器，正向近零损耗，大电流主流（MOS 开关细节见 [MOS 管开关](../MOS管与三极管/02-MOS管开关与驱动.md)） |

  {name: 'RSTn(复位释放)', wave: '0...10......', node: '....d'},

关键约束：**复位释放必须在电源稳定之后**（POR 电路+外部复位电容保证），**外设初始化必须在时钟切换之后**——顺序错了就是"偶发初始化失败"（见[RC 时钟](../时钟电路/02-RC时钟.md)）。

## 计算与选型

### 设计步骤：供电架构检查单

```
第 1 步：列出所有电源域与电流（MCU 内核/IO/收发器/传感器供电/驱动）
        （功耗估算方法见功耗估算篇）
第 2 步：按电流量级选拓扑：大电流域 buck、小电流/洁净域 LDO
第 3 步：前端防护三件套确认：防反接(MOS) + TVS(选钳位电压/功率，
        见负载突变保护篇) + 前端 LC
第 4 步：校核最坏输入：冷启 6V 时 DCDC 是否还能维持输出（占空比极限/压差）
第 5 步：欠压检测阈值设计：9V 附近预警、6V 紧急动作（写入数据/复位）
```

### 算例：冷启动跌落预算

```
冷启动时输入跌至 6 V（典型量级，以 ISO 16750-2 曲线与实测为准）：
  buck 5V 输出：需占空比 D = 5/6 ≈ 83% → 芯片最大占空比（多数 buck 90%+）内，OK
  若还有 5V→3.3V LDO：压差 1.7 V >> LDO 裕量，OK
  注：算例未计防反接/TVS 压降与 DCDC buck 最小关断（导通）时间约束，
      实车冷启动余量须按整机原理图复核
  风险点：6 V 跌落斜率快于 buck 环路响应时输出瞬间跌落 →
          欠压中断/复位电路动作，软件需按"下电-上电"全流程处理
```

## ECU 实例

- 某车身 ECU：KL30 8 A 熔丝 → ideal diode（PMOS，压降 <50 mV）→ TVS（抛负载钳位，见[负载突变保护](03-负载突变保护.md)）→ buck 12→5 V/1 A → LDO 5→3.3 V（MCU 外设）+ 独立传感器 5 V 供电带断路诊断（架构以该项目原理图为准）
- 冷启动测试案例：−30°C 冷启动时 KL30 跌至 5.8 V、持续 400 ms——buck 维持但传感器 5V 域纹波超标，软件欠压中断记录事件并延迟非关键任务，通过
- 排障案例：产线偶发"上电不启动"——复位电容容值偏差+电源上升斜率慢，复位释放在电源到阈值之前；硬件增大复位常数后消除（时序细节见[复位电路](../../1-L1基础/原理图阅读/MCU最小系统/02-复位电路.md)）

## 与软件的关联

1. **欠压行为设计**：欠压中断里做什么（停非关键负载/记录 DTC/准备下电）必须分级——9V 预警、6V 紧急，策略以项目规范为准
2. **EcuM 下电时序**：KL15 掉电 → EcuM RUN→POST_RUN→SHUTDOWN 序列 → NvM 写入 → 断外设 → 进 SLEEP；总时长要小于主继电器保持时间（若有），详见 [系统服务栈/EcuM](../../../07-AUTOSAR架构/2-L2进阶/系统服务栈/EcuM/README.md)
3. **紧急 NvM 写入**：掉电检测到复位之间只有 ms~s 级窗口——"关键数据先写、非关键数据丢弃/延后"的写入策略要在设计期定好（NvM immediate write 概念，见[系统服务栈](../../../07-AUTOSAR架构/2-L2进阶/系统服务栈/README.md)）
4. **复位原因区分**：上电首件事读复位源寄存器（POR/外部复位/看门狗/欠压），落 DTC——冷启动与真故障的区分依据
5. **KL15 软件解读**：去抖+电平变化中断；KL15 有效是唤醒与"保持唤醒"的条件之一（与网络唤醒的仲裁见[唤醒电路](02-唤醒电路.md)）

## 易错点与陷阱

- 只按 12V 标称设计：冷启 6V、抛负载 60V+、反接 −12V 全没考虑，实车一打火就翻车
- 复位释放早于电源稳定：偶发上电不启动，低温（电源上升慢）才暴露
- 串联二极管扛大电流：损耗发热在高温车厢叠加，二极管烧毁后反接保护失效
- 欠压中断里做"重活"：中断里跑长流程，电压继续跌穿→复位打断→数据写一半（NvM 页损坏）
- 传感器供电与 MCU 供电共一个 LDO：传感器短路/过载拉垮 MCU 电源
- KL15 去抖不够：点火抖动被当成多次开关，EcuM 上下电反复横跳
- 传感器 5V 供电不做断路诊断：外部短路要能检测并关断（视安全等级），否则一颗短路的传感器拖垮整个 ECU（供电诊断策略以项目规范为准）

## 面试高频题

**Q1：KL30/KL15/KL31/KL50 分别是什么？**
A：KL30 蓄电池常火（不受钥匙控制，供睡眠与常记电路）；KL15 点火开关输出（"要用车"信号）；KL31 电源地/车身地；KL50 起动机控制线（起动时接入，冷启动压降的元凶）。

**Q2：车载 12V 系统正常电压与极端电压范围？**
A：常态约 9~16 V；冷启动可跌到 6 V 量级（数百 ms）；抛负载瞬态 60 V 以上；还有反接、缓升缓降等 profile——精确限值以 ISO 16750-2 与项目规范为准。

**Q3：画 ECU 内部供电架构链。**
A：KL30→熔丝→防反接（ideal diode MOS）→TVS 钳位→前端 LC→DCDC buck（12V→5V）→分路 LDO（3.3V 数字域/内核域/传感器独立供电）；KL31 单点接地；KL15 经分压滤波进 MCU 输入。

**Q4：防反接两种主流方案对比？**
A：串联二极管——简单但 0.5~0.7V 压降、大电流发热大，小电流场合用；ideal diode（MOS 方案）——导通压降 mV 级近零损耗，大电流 ECU 主流，成本与驱动稍复杂。

**Q5：掉电时软件该做什么？EcuM 怎么参与？**
A：分级欠压处理：预警级停非关键负载并记录；紧急级触发 NvM 立即写关键数据。EcuM 走 RUN→POST_RUN→SHUTDOWN 下电序列，总时长受主继电器保持时间约束；写入只保关键数据，非关键延后丢弃，防写一半损坏。
