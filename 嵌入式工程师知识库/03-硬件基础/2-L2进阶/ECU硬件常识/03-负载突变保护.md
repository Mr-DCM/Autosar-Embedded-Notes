# 负载突变保护（Load Dump 与电源瞬态）

> 一句话定位：行车中断开蓄电池的一瞬间，发电机磁场能量无处泄放，全车电压冲到 60V+ 并持续百 ms 级——这就是抛负载（load dump），加上感性负载瞬态与地偏移，构成了 ECU 电源端"活着回来"要闯的三关。
> 等级：L2 ｜ 前置：[KL30-KL15供电](01-KL30-KL15供电.md)、[二极管与TVS](../../1-L1基础/原理图阅读/常用元器件符号与封装/02-二极管与TVS.md)

## 原理

### 1. 抛负载：断电池瞬间的电压尖峰

发电机给蓄电池充电的同时励磁绕组储存磁场能量。**蓄电池在位时它是个大电容+大钳位池**，把全车电压按住；行车中断电池（端子松动、保险丝断、维修误操作）：

```
发电机 ──磁场能量(励磁电感 Wf)──▶ 无处可去！

  带电池在位：电压被电池钳在 ~14V          ┌─ 抛负载尖峰
  断电池瞬间：能量经整流管涌入电网          │  60V~100V+（未抑制）
                                           │  持续几十~几百 ms
  时间轴： ─────────────────────────────▶  └─▄▄▄▄▄▄▄▄▄▄▄▄▄
  12~14V ═══════════╳断开                  ↑ 缓慢衰减的指数形浪涌

危害：能量大（J 级）、时间长（百 ms 级）——普通小功率 TVS 扛不住，
必须专用的抛负载抑制 TVS（或发电机内置中央抑制，整车方案以项目规范为准）
```

### 2. ISO 7637-2 脉冲概念表（各一句话，精确参数以标准版本/项目规范为准）

| 脉冲 | 一句话描述 | 特征量级 |
|---|---|---|
| Pulse 1 | 电源线断开后感性负载（线束电感）上的负瞬态 | −100V 量级、ms 级、低能量 |
| Pulse 2a | 与被测装置并联的负载突然断开引起的正瞬态 | +50~100V 量级、μs 级 |
| Pulse 2b | 点火关闭瞬间点火电路感性负载注入的正缓脉冲 | +10~20V 量级、几十 ms |
| Pulse 3a/3b | 开关过程（继电器触点弹跳）产生的高频负/正尖峰群 | ±几十~百 V、ns~μs 级、高频振荡 |
| Pulse 4 | 起动机大电流拉低电压（电压跌落） | 跌至 ~5V、百 ms 级（冷启动相关） |
| Pulse 5a/5b | 抛负载浪涌（5b 为带中央抑制钳位的版本） | +60~100V+、几十~几百 ms、能量最大 |

软件相关直觉：Pulse 4 与冷启动类似，考验欠压处理；Pulse 5 考验前端钳位；3a/3b 高频毛刺考验滤波与输入去抖（呼应[唤醒电路](02-唤醒电路.md)假醒）。

### 3. 防护链：TVS + 压敏电阻 + LC

```
KL30 ──▶ [压敏电阻 MOV] ──▶ [TVS 抛负载抑制] ──▶ [前端 LC 滤波] ──▶ 后级
          │                   │                    │
          高能粗钳            精细钳位              高频毛刺滤除
          (先扛大能量)        (快响应钳到安全值)    (3a/3b 类高频)
          └──────────── 三级递进：先粗后细 ────────────┘
```

- **TVS**（Transient Voltage Suppressor，瞬态抑制二极管）：反向击穿钳位，响应 ps~ns 级，选型看钳位电压/峰值脉冲功率——符号、特性曲线与选型见[二极管与 TVS](../../1-L1基础/原理图阅读/常用元器件符号与封装/02-二极管与TVS.md)
- **压敏电阻（MOV）**：电压敏电阻，钳位电压随能量变化、响应慢于 TVS 但耐大能量，做第一级粗保护
- **LC 滤波**：滤除高频毛刺兼 EMI 双向抑制（见 [EMC 入门](../../3-L3高级/PCB常识/04-EMC入门.md)）
- 层级思想：**每一级削掉一层威胁**（能量→电压→频率），不能指望单个器件包打天下

### 4. 感性负载切换瞬态

继电器/电机/电磁阀断电瞬间，绕组电感电流不能突变，产生高压反电动势——这就是续流二极管存在的原因（续流电路详见[感性负载与续流](../MOS管与三极管/04-感性负载与续流.md)）：

- 驱动侧没续流：尖峰打回电源网络，污染全板（典型症状：继电器一断，MCU 复位或 ADC 跳动）
- 电源侧对策即上面的 LC+TVS 链；根源治理在驱动电路自身（续流/RC 吸收）

### 5. 地偏移（Ground Offset）

大电流负载（电机、加热器）工作时，其回流电流流经地路径阻抗产生压降：

```
负载大电流 I=10A 流过地线阻抗 Rg=20mΩ
   → 负载地相对 ECU 参考地偏移 ΔV = I×Rg = 200 mV！
   → ADC 采集精度典型 ±10mV 级 → 200mV 偏移直接淹没精度
症状：电机一转，传感器读数整体漂移；远端传感器单端采集最惨
对策：差分采集/传感器就近参考/单点星形接地（见[地平面与回流](../../3-L3高级/PCB常识/02-地平面与回流.md)）
```

## 计算与选型

### 设计步骤：前端防护检查单

```
第 1 步：确认项目引用的 ISO 7637 等级与 pulse 清单（企标常加严）
第 2 步：按 Pulse 5a 能量选抛负载 TVS（峰值脉冲功率 ≥ 脉冲能量折算，
        钳位电压 < 后级 DCDC 耐压，留温度降额）
第 3 步：TVS 前串功率电阻/保险丝限流分能（常见组合，以设计规范为准）
第 4 步：LC 参数按 3a/3b 高频毛刺与 DCDC 开关频率交叉设计
第 5 步：软件侧对照下表补齐约束清单
```

### 算例：TVS 能量直觉（量级示意）

```
Pulse 5a（概念）：Us≈65V、td≈40ms、源内阻 Rs≈0.5~4Ω（以标准版本为准）
TVS 钳位 Vc≈35V 量级 → 压差主要落在 Rs 上
→ 冲击电流 I ≈ (65−35)/2Ω ≈ 15 A，持续 40ms
→ TVS 吸收能量量级 ≈ Vc × I × td ≈ 35 × 15 × 40ms ≈ 21 J
→ 选抛负载级 TVS（1500W~5000W 系列按等效波形折算，以规格书曲线为准）
（本算例仅示范量级直觉，选型必须按标准波形与器件 datasheet 计算）
```

## ECU 实例

- 某车身 ECU 前端：MOV（粗钳）+ 专用抛负载 TVS（钳位 ~36V）+ 保险丝 + LC → 后级 buck 耐压 42V，ISO 7637-2 全 pulse 通过（等级与判级以该项目测试报告为准）
- 排障案例：直流电机驱动板继电器断开瞬间 MCU 偶发复位——驱动侧续流二极管虚焊，感性尖峰直接打上电源轨；补焊后消失（链条：感性负载瞬态→电源污染→复位，对应地弹/复位链条见[地平面与回流](../../3-L3高级/PCB常识/02-地平面与回流.md)）
- 地偏移案例：鼓风机高速档时某温度采集偏低 3%——采集回路与风机共地路径，大电流地偏移 180mV；改差分采集+就近参考后归零（以该项目问题报告为准）
- 台架复现案例：用可编程电源+瞬态发生器在台架复现 Pulse 5a，配合 DTC 记录验证软件约束清单（复位原因/写保护）全部生效后才送第三方实验室——省一轮实测排期

## 与软件的关联

对软件的约束清单（瞬态全过完，软件要"活下来且说得清"）：

1. **复位原因记录**：上电读复位源寄存器（POR/外部/看门狗/欠压/BOR），落 DTC——区分"用户断电"与"瞬态打挂"，售后分析的根基（见 [Dem 配置](../../../06-诊断与标定/2-L2进阶/Dem配置/README.md)）
2. **关键数据写保护**：瞬态打穿电源的瞬间若正在写 Flash/EEP，会出现半写页——NvM 层用 CRC+双页/写完成标志机制保证可恢复（见[系统服务栈](../../../07-AUTOSAR架构/2-L2进阶/系统服务栈/README.md)）
3. **上电自检与 DTC 上报**：复位后校验存储完整性、外设自检，异常上报 DTC——瞬态损伤（Flash 页损坏/外设状态错乱）要能被发现
4. **欠压瞬态行为**：Pulse 4 类跌落期间是"硬撑"还是"有序下电"由策略决定；硬撑期禁写 Flash（欠压写 Flash 是数据损坏高发原因）
5. **去抖与滤波**：3a/3b 高频毛刺会打到数字输入/唤醒脚——输入去抖、假醒对策（见[唤醒电路](02-唤醒电路.md)）就是软件级的最后一道滤波
6. **测试配合**：ISO 7637 实验室逐 pulse 打，被测件判级（A/B/C/D）依赖软件恢复机制与 DTC 状态输出——测试软件要能上报"我挂过、我恢复了"

## 易错点与陷阱

- 拿小信号 TVS 扛抛负载：能量不够瞬间烧毁，还以为"有 TVS 就安全"
- 只做电源防护不做驱动侧续流：感性尖峰从驱动电路内部打上电源轨，前端防护鞭长莫及
- 忽视 Pulse 4（跌落）只防"高压"：跌落期间欠压写 Flash 造成的损坏比高压更隐蔽
- 地偏移当"ADC 精度问题"查：换高精度 ADC 没用，先看大电流地路径
- 复位后不查复位源：瞬态复位被当普通上电，DTC 丢失关键线索
- 抛负载参数按记忆写测试计划：不同标准版本/系统电压（12V/24V）差异大，以 ISO 7637-2 版本与企标为准
- 测试判级不看失效可恢复性：C 类（需人工干预）在部分功能上可能可接受，D 类（损坏）绝不可接受——判级矩阵要在测试计划里逐功能定义（以项目规范为准）
- 防护链只仿真不实测：TVS 布局走线过长，引线电感让钳位"到不了"后级——layout 距离就是防护性能

## 面试高频题

**Q1：什么是抛负载（load dump）？怎么防护？**
A：行车中断开蓄电池，发电机励磁电感磁场能量无处泄放，全车电压冲到 60V+、持续几十~几百 ms。防护：MOV 粗钳+专用抛负载 TVS 精钳+保险丝限流+LC 滤波的分级链；选型按脉冲能量与钳位电压计算。

**Q2：ISO 7637-2 各 pulse 一句话。**
A：P1 负瞬态（感性负载断开）、P2a/2b 正瞬态/点火关断缓脉冲、P3a/3b 开关弹跳高频毛刺群、P4 起动电压跌落、P5a/5b 抛负载浪涌（5b 为带中央抑制）。精确波形参数以标准版本与项目规范为准。

**Q3：TVS 和压敏电阻怎么分工？**
A：压敏电阻耐大能量但响应慢、钳位电压随电流漂，做第一级粗保护；TVS 响应 ps~ns 级、钳位精确，做精细钳位；再加 LC 滤高频。三级递进各削一层威胁（能量→电压→频率）。

**Q4：什么是地偏移？对采集精度什么影响？**
A：大电流负载回流流经地路径阻抗产生压降，负载/传感器地相对 ECU 参考地偏移（如 10A×20mΩ=200mV），远超 ADC 精度预算造成系统性误差。对策：差分采集、就近参考、星形单点接地。

**Q5：瞬态对软件的约束有哪些？**
A：①复位原因记录落 DTC；②关键数据写保护（CRC/双页/完成标志）防半写；③上电自检并上报损伤；④欠压期间禁写 Flash；⑤输入去抖与假醒对策；⑥测试软件支撑判级（可报告失效与自恢复）。

**Q6：为什么抛负载能量最大、最难防？**
A：发电机励磁电感储能 J 级、浪涌持续几十~几百 ms（其他 pulse 是 μs~ms 级），远超普通 TVS 的峰值脉冲能力；必须用专用抛负载抑制 TVS（大功率）+MOV 粗钳+保险丝分流的组合，且后级 DCDC 耐压要覆盖钳位电压余量（以标准波形计算为准）。
