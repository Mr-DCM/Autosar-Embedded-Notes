# OC/OD 门与线与

> 一句话定位：开集（OC, Open-Collector）/开漏（OD, Open-Drain）输出只有一只下拉管，"只能拉低、不能拉高"——高电平靠上拉电阻补上，多输出并联天然构成线与（Wired-AND），I2C 与电平转换都源于此。
> 等级：L1 ｜ 前置：[原理与作用](01-原理与作用.md)

## 原理

### 结构：输出级只有下拉管

推挽（Push-Pull）输出有上、下两只管子，能主动输出高和低；开漏输出**砍掉上面那只 PMOS**，漏极（drain）直接引出：

```
   推挽输出                     开漏输出
     +3V3                       +3V3
      │                           │
   ───┴───                      [Rpu 上拉]
   │PMOS │                        │
   └──┬──┘                        │ ← 无上管，输出"1"
      ● ●──────── Y              ● ──────── Y（漏极开路）
   ┌──┴──┴┐                     ┌──┴──┐
   │NMOS │          vs           │NMOS │
   ───┬───                       ───┬───
      │                             │
      ⏚                             ⏚
```

行为表（带外部上拉时）：

- 控制端使 NMOS **导通** → Y 被拉到 GND → 输出 **0**（主动、强驱动、下降沿陡）；
- 控制端使 NMOS **截止** → Y 呈高阻（Hi-Z）→ 由上拉电阻慢充到 VDD → 输出 **1**（被动、弱驱动、RC 指数上升沿）。

**没有上拉电阻时，输出 1 = 悬空高阻，读不到任何确定电平——这就是"开漏必须上拉"的电气本质。**

### 线与（Wired-AND）：多个 OD 输出并联

两个 OD 输出接同一条线（整线只需一只上拉）：

```
   输出A（OD）        输出B（OD）
      │                  │
      ●──────────────────●────[Rpu]──── +3V3
                     │
                     Y = A AND B
```

真值算例：

| A 输出 | B 输出 | 线上结果 | 说明 |
|---|---|---|---|
| 1（截止） | 1（截止） | **1** | 没人拉低，上拉胜出 |
| 1（截止） | 0（导通） | **0** | B 拉低，A"随大流" |
| 0（导通） | 1（截止） | **0** | 对称情形 |
| 0（导通） | 0（导通） | **0** | 都拉低 |

线上电平 = A AND B → **线与**（负逻辑视角下等效线或 Wired-OR）。关键性质：**任何器件都能把线拉低且互不冲突**——没人主动输出高，不存在推挽对推挽"一个输出 1 一个输出 0"的电源到地短路大战。

### 电平转换：3.3V ↔ 5V

OD 输出的"高电平"由**上拉电源**决定，与器件自身供电无关：

- 3.3V MCU 的 OD 脚上拉到 5V → 供 5V 器件读取（前提：该脚为 5V 容忍 FT 脚，以数据手册为准）；
- 5V 器件的 OD/OC 输出上拉到 3.3V → 3.3V MCU 安全读取（常用：5V 传感器开漏输出直连）；
- 这也是 I2C 跨电压总线（各挂各的上拉或 TXS/PCA95xx 等专用转换芯片）的基础。

## 计算与选型

- **上拉阻值**：与普通上拉同一套四步法（见 [02-阻值选择计算](02-阻值选择计算.md)）；线与总线要把**所有挂载器件的电容与泄漏累加**后代入；
- **低电平电流归属**：线上只有一个器件导通时，它独自承担全部灌电流（V/Rpu）——每个器件的 IOL 都要单独核对"独自拉低"场景；
- **上升时间预算**：t_r ≈ 2.2 × Rpu × Cbus；I2C 400kHz、50pF → Rpu ≤ 2.7k（完整算例见下一篇）。

## ECU 实例

- I2C 的 SDA/SCL 是 OD + 上拉的标准线与总线（见 [04-I2C为何必须上拉](04-I2C为何必须上拉.md)）；
- 多 ECU 共享信号线：如多控制器共用的"急停/互锁"状态线，各方 OD 输出并联，任一拉低 = 急停——线与天然实现"任一触发"；
- 5V 传感器开漏输出（车速/位置开关类）上拉到 3.3V 直连 MCU，省一颗电平转换芯片；
- nRESET/nINT 类低有效信号：看门狗 + 电源监控 + 调试器多源共用一条复位线，任一拉低即复位。

## 与软件的关联

- **Port/GPIO 输出模式配置**：Port MCAL 输出模式选开漏（如 S32K Port 的开漏配置位、STM32 GPIO 的 OTYPE=OD）；**把共享线上的脚配成推挽 = 与其他器件短路冲突，烧管子级错误**；
- **输出"1"的语义变了**：开漏模式下写 1 = 释放总线（高阻），写 0 = 拉低；I2C 驱动依赖"写 1 后回读"做仲裁与 ACK 检测，全靠这个语义；
- **写 1 读回的值不等于自己的输出**：开漏模式下读回的是"上拉 + 其他器件共同作用"后的总线真实电平，不能用于输出自检（自检应看方向/输出寄存器）；
- **调试经验**：某 OD 引脚"输出 1 但量出来是 0" → 先查有没有上拉、是否被别人拉低，再怀疑芯片。

## 易错点与陷阱

- **开漏忘上拉**：输出 1 永远高阻、读回随机——原理图评审第一眼查这个；
- **开漏当推挽驱动负载**：高电平靠 4.7k 上拉只有 <1mA 拉电流，驱动 LED/继电器必须推挽或外加三极管/MOS；
- **推挽并联到线与总线**：一输出高、一输出低 = 电源到地短路，瞬时大电流损坏 IO；
- **上拉电源域搞错**：上拉到 5V 但引脚非 FT → 过压；睡眠时上拉电源被切断，常电域器件读到漂移电平；
- **把上升沿缓当故障**：OD 总线"上升慢（RC）、下降快（强驱动）"的不对称是正常特征。

## 面试高频题

1. **问：OD 输出为什么必须上拉？**
   答：输出级只有下拉 NMOS，截止时引脚高阻，必须靠上拉电阻把电平抬到高；否则输出 1 无定义。

2. **问：什么是线与？举一个应用。**
   答：多个 OD 输出并联，任一拉低则线为低，逻辑等效 AND；典型应用：I2C 的 SDA/SCL、多源共享 nRESET、多 ECU 急停互锁线。

3. **问：OD 输出和推挽输出的差异？**
   答：推挽上下双管、双向强驱动、速度快但不能并联；开漏只有下管、高电平弱（RC 上升）、可并联线与、可换上拉电压做电平转换。

4. **问：3.3V MCU 怎么安全读 5V 信号？**
   答：若 5V 侧是 OD/OC 输出，上拉到 3.3V 即可直连；若 5V 侧是推挽，需电平转换器，或 MCU 引脚为 5V 容忍（FT）时直连（以数据手册为准）。
