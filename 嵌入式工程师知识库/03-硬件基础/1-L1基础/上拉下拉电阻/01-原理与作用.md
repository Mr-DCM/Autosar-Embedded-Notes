# 上拉下拉电阻：原理与作用

> 一句话定位：给"没人驱动"的输入一个确定的默认电平——上拉（pull-up）默认高、下拉（pull-down）默认低；选哪个、放多大，全是失效安全与功耗/速度的权衡。
> 等级：L1 ｜ 前置：[欧姆定律与功率](../电压电流与基本定律/01-欧姆定律与功率.md)

## 原理

### 浮空输入的风险

CMOS 输入阻抗极高（GΩ 级），引脚不接任何驱动源时称为**浮空（floating）**，两个后果：

- **噪声翻转**：引脚像一根天线，耦合线束/开关噪声，读值在 0/1 之间乱跳；
- **直通电流（shoot-through / crowbar current）**：输入级是 PMOS+NMOS 互补对，输入电平在 VDD/2 附近摆动时**两只管子同时半开**，VDD→GND 出现额外电流，芯片发热、功耗异常。

```
         +3V3
          │
       ───┴───
       │PMOS │ ← 输入悬空时栅极电平不定，
       └──┬──┘   两管工作在半开区，
          ●       VDD~GND 之间漏电流
       ┌──┴──┐
       │NMOS │
       ───┬───
          │
          ⏚
```

> 表现到软件：未初始化的输入口读值随机、休眠电流莫名偏大、外部中断随机触发——第一嫌疑就是浮空。

### 上拉 vs 下拉：选择逻辑

| 问题 | 答案决定选型 |
|---|---|
| 空闲/默认时该读什么电平？ | 默认高 → 上拉；默认低 → 下拉 |
| 断线（开路）时失效成什么态？ | 失效安全（fail-safe）：断线后落到"安全"的那个默认态 |
| 驱动器件是什么结构？ | 按键接地 → 上拉；按键接电源 → 下拉；OD/OC 输出 → 必须上拉 |

汽车惯例：**开关量输入默认拉高、闭合接地（低有效）**——断线读高 = 未激活（安全态），详见 [汽车电路实例](../电压电流与基本定律/03-汽车电路实例.md)。

### 阻值权衡三角

```
              弱上拉（阻值大，如 100k）
              /                    \
      功耗小、省电               速度慢（RC 大）
      泄漏敏感、电平软           上升沿缓、易受扰
              \                    /
              强上拉（阻值小，如 1k）
       功耗大、灌电流大、速度快、驱动硬
```

三个角：**驱动电流/功耗 ↔ 速度（RC）↔ 电平精度（泄漏压降）**。阻值只能在三角形内部取舍，没有全优解；定量计算见下一篇的四步法。

### MCU 内部上拉/下拉 vs 外部

MCU 引脚普遍内置可配置上拉/下拉（典型 20~50kΩ，离散 ±30~50%，以数据手册为准），在 Port 配置里选 `PULL_UP` / `PULL_DOWN` / 无。

| 维度 | 内部上拉 | 外部上拉 |
|---|---|---|
| 阻值 | 固定区间、离散大 | 精确可选 |
| 成本/布板 | 免费 | 每脚一只电阻 |
| 适用场景 | 按键、非关键输入、调试 | I2C、复位、关键信号、量产输入通道 |
| 休眠一致性 | 受引脚休眠配置影响 | 硬件常在、与软件状态无关 |

原则：**协议总线（I2C）、可靠性关键信号（nRESET、唤醒脚）一律外部电阻**；内部只用于临时/低成本场景。

## 计算与选型（速览）

- 按键类：10k 上拉，按下灌入 0.33mA，功耗与速度都宽裕（算例见 [欧姆定律与功率](../电压电流与基本定律/01-欧姆定律与功率.md)）；
- I2C：2.2k~4.7k，由上升时间与总线电容反推（详见 [02-阻值选择计算](02-阻值选择计算.md)）；
- 复位脚 nRESET：10k 上拉 + 100nF 到地，保证上电时复位可靠释放。

定量四步法（灌电流上限 → RC → 功耗 → 泄漏压降）整篇展开在下一篇；本篇只建立"为什么必须有这四步"的直觉。

## ECU 实例

- 汽车开关量输入通道默认拉高（低有效）是行业默认约定，断线诊断策略依赖它；
- CAN 收发器的 nSTB/EN 等控制脚上/下拉决定收发器上电默认模式，配错 = 总线莫名进待机；
- 未使用 GPIO：数据手册通常要求接确定电平（内部上/下拉或外部），不许浮空——EMC 辐射发射测试不过时，悬浮脚是常见根因；
- 唤醒脚（如 CAN wake）的上拉电源域必须是常电域，否则睡眠中唤醒信号被"连坐"断电。

## 与软件的关联

- **Port 配置必须与原理图对齐**：硬件有外部上拉 → 内部配无；硬件没配 → 按需内部上/下拉。内部上拉误开（如 50k 与外部 13k 分压下臂并联）会改变分压比，读值整体偏移。
- **休眠脚位表**：进睡前每个 IO 的输出值/上下拉状态要成组规划（Init/DeInit 镜像配置），否则内部上拉与外部电平打架产生 mA 级漏电。
- **复位脚**：看门狗/上电复位行为与 nRESET 上拉相关；软件复位（如 Mcu_Reset）不改变该硬件默认态。
- **输入抖动与去抖**：上拉值与开关/线束电容构成 RC，影响抖动波形宽度，间接决定去抖窗口下限。

## 易错点与陷阱

- **"输入不用配"**：输入不配上下拉又不接信号 = 浮空，读值随机；
- **内部上拉当 I2C 上拉用**：50kΩ 对几百 pF 总线 τ 达 µs 级，400kHz 必失败；
- **上拉下拉同时开**：形成 VDD→GND 分压通路，电平卡中间、功耗还大；
- **外部已有强上拉还开内部下拉**：电平被拉低，VIH 不达标；
- **把低有效当高有效处理**：软件语义全反，且断线诊断一并失效。

## 面试高频题

1. **问：为什么输入引脚不能悬空？**
   答：CMOS 输入高阻，悬空电平由噪声决定，读值乱跳；且输入级可能两管同导通产生直通电流，功耗与 EMC 都恶化。

2. **问：上拉下拉怎么选？**
   答：由默认电平与失效安全决定：断线时要落到安全态；按键接地就上拉、接电源就下拉；OD/OC 器件输出必须上拉。

3. **问：MCU 内部上拉一般多大？能替代外部吗？**
   答：典型 20~50kΩ、离散大；按键与非关键输入可以，I2C、复位、需要精度与一致性的场合必须外部电阻。

4. **问：上拉电阻取值的三方权衡？**
   答：驱动电流/功耗（小阻值差）、速度（RC，大阻值差）、电平精度（泄漏压降，大阻值差），按信号类型在三角形内取折中。
