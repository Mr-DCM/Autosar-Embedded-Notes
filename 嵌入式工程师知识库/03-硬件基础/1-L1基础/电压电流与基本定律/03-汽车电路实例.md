# 汽车电路实例

> 一句话定位：把 KL30/KL15/KL31/KL50 的定义、高低有效约定，落到一个真实的"开关量输入从 12V 开关到 MCU GPIO"采集电路——软件里那一行 Dio 读值的完整来路。
> 等级：L1 ｜ 前置：[欧姆定律与功率](01-欧姆定律与功率.md)

## 原理

### 汽车电气信号定义（KL 端子）

KL 源自德语 Klemme（端子），是车身电气接点的通用编号：

| 端子 | 名称 | 含义 | 软件视角 |
|---|---|---|---|
| KL30 | 常电（battery positive） | 蓄电池正极直连，任何时候有电 | 睡眠时的唯一供电来源 |
| KL15 | 点火（ignition） | 钥匙 ON 档接通 | 常作唤醒源/上电信号 |
| KL31 | 接地（ground，搭铁） | 蓄电池负极，接车身 | 所有电压的参考点 |
| KL50 | 启动（crank） | 启动机工作档 | 冷启动低压工况的来源 |

扩展端子如 KL30C（经保险丝常电）等以 OEM 原理图标注为准。

### 高低有效约定（high-active / low-active）

两层概念必须分开记：

- **电路电平**：引脚上是高还是低（Dio 读到的 0/1）；
- **逻辑语义**：什么状态算"激活/按下/触发"。

汽车开关量输入的行业惯例：**默认拉高、开关闭合接地 → 低有效（Active-Low）**。理由：

1. 断线时读高，与"未激活"同态——失效安全（fail-safe）；
2. 对地短路是最常见故障，表现为"常激活"，与正常操作可区分，诊断可查；
3. 车身就是搭铁（chassis ground），开关回路就近回地最省线。

⚠ 软件工程师必查信号定义表/ICD（Interface Control Document）：Dio 读 0 到底代表"按下"还是"松开"，别想当然"1 = 闭合"。

### 负载类型一句话

- **阻性（resistive）**：灯丝/加热丝，电流随电压稳定，欧姆定律直接算；
- **感性（inductive）**：继电器线圈/电机/电磁阀，断电瞬间反电动势（EMF）上冲，必须配续流（freewheeling）二极管或 MOS 吸收；
- **容性（capacitive）**：DCDC 输入/长线束，上电瞬间浪涌电流，需要缓启动/限流。

## 计算与选型

### 完整实例：开关量输入采集电路（KL15 → MCU GPIO）

```
                R1 47k      A       R3 1k     B
KL15 ──o o────────[R1]──────●──────[R3]─────●────→ MCU GPIO
（触点开关）                 │               │
                           R2 13k          C1 10nF
                             │               │
                             ⏚               ⏚
```

- R1/R2 构成分压，把 12V 摆幅压进 3.3V GPIO 安全区；
- R3 串联限流，保护引脚内部 ESD 二极管；
- C1 靠近 MCU，滤除 µs 级毛刺。

**分压比**：k = R2/(R1+R2) = 13/(47+13) ≈ 0.217。逐工况计算（3.3V 系统，VIH ≈ 2.31V、VIL ≈ 0.99V，以手册为准）：

| 工况 | 开关输入 | 节点 A 电压 | 判定 |
|---|---|---|---|
| 触点断开 | 0V | 0V | 读 0（未激活态） |
| 触点闭合 @12V | 12V | 12 × 0.217 ≈ **2.60V** | 读 1 ✓（> 2.31V，裕量 0.29V） |
| 触点闭合 @16V | 16V | 16 × 0.217 ≈ **3.47V** | 读 1，但逼近 VDD+0.3V 极限 ⚠ |
| 触点闭合 @冷启 6V | 6V | 6 × 0.217 ≈ 1.30V | 落入不定区 ⚠ |

工程结论：

- 3.47V 贴着引脚上限，量产设计会再加钳位二极管到 3.3V 轨或齐纳管（以 ISO 16750/项目规范为准）；
- 冷启动期间电平可能进灰区，软件应**冻结采样/沿用上次有效值**直到电压恢复——这正是欠压处理策略的一部分。

**滤波时间常数**：节点 A 等效阻抗 = R1∥R2 = 47k×13k/60k ≈ 10.2k：

```
τ = 10.2kΩ × 10nF ≈ 102µs
```

µs 级干扰（大负载切换经线束耦合的毛刺）被滤掉；机械触点 ms 级抖动滤不掉，交给软件。

**泄漏校验**：GPIO 输入泄漏 ±1µA 流经 R1，额外压降 ≈ 1µA × 47k = 47mV，可忽略。

```wavedrom
  {name: '20ms软件去抖后', wave: '1..................0......'}
], head: {text: '机械开关闭合瞬间的弹跳（µs~ms 级）与 20ms 软件去抖', tick: 0}}
```

软件侧做法：周期采样（如 5ms）+ 连续 N 次一致才更新状态（N × 5ms ≈ 15~25ms），或时间戳法。AUTOSAR 分层里去抖通常落在 IOC/EAL 或应用层——MCAL 的 Dio 只给瞬时电平，不做去抖。

### 输入引脚读不到预期电平的排障思路

按信号流向从外到内：

1. **量源头**：开关前端有 12V 吗？（KL15 供电、保险丝、触点本身）
2. **量节点 A**：闭合时 ≈ 2.6V？
   - 0V → R1 断、开关未接通、或该点对地短路；
   - ≈12V → R2 断/虚焊（下臂失效，分压变直通）⚠ 此时 GPIO 可能过压，比"读不到"更危险；
3. **量节点 B**：与 A 差异过大 → R3 虚焊或 C1 短路；
4. **查 GPIO 配置**：方向是否输入？是否误开内部上拉（典型 50k 并入 R2 会改变分压比）？是否误配成输出与外部电平"打架"？
5. **核对语义**：低有效还是高有效？软件比较方向写反是"最像硬件问题的软件 bug"；
6. **上示波器**：抖动、毛刺、缓慢边沿（RC 参数变化）一眼可见。

## ECU 实例

- 开关量输入通道常态 8~32 路，前端统一为：分压 + RC + TVS/钳位；高密度/需诊断的输入用专用开关检测芯片（自带开路/短路诊断）；
- 输出侧的高边驱动（high-side）/低边驱动（low-side）与感性负载续流见 [MOS管与三极管](../../2-L2进阶/MOS管与三极管/README.md)；
- 全库反复出现的工程常识数字：CAN 差分端接 120Ω、I2C 上拉 2.2k~4.7k、去耦 100nF/电源脚——出处与计算见对应笔记。

## 与软件的关联

- **Dio/Port 配置**：方向、上下拉、施密特触发（Schmitt Trigger）选项都影响实测电平；Port MCAL 的 pull 配置必须与原理图的外部分压/上拉匹配，不能"软件随手开"。
- **去抖窗口**：102µs 硬件滤波 + 20ms 软件去抖两层配合，决定最快可响应的开关事件——急停类信号要单独评估响应时间预算。
- **唤醒与睡眠**：KL15 掉沿是典型休眠触发；冷启灰区电平要求状态机加滞回，避免电压抖动导致反复上下电。
- **DTC 语义**：开关"卡滞/断线"诊断依赖低有效电路的特征电平（断线 = 常高），软件超时判定逻辑与硬件特征配套设计。

## 易错点与陷阱

- **12V 直接接 3.3V GPIO**：必坏；必须分压 + 钳位。
- **漏算 16V 上限**：常态上限 16V 下节点 3.47V 贴着极限，量产必须钳位（以 ISO 16750/项目规范为准）。
- **R2 虚焊时节点 A ≈ 12V**：不是"读不到"，而是"过压 + 恒读 1"，既伤引脚又误判，比 R1 断更危险。
- **低有效语义想当然**：读 0 当"未按"，与电路约定相反，功能全反。
- **用 IO 内部下拉替代 R2**：内部下拉阻值离散大（±50%）、休眠配置变化时漂移，量产输入通道一律用外部电阻。

## 面试高频题

1. **问：KL30、KL15、KL31、KL50 分别是什么？**
   答：蓄电池常电正极、点火开关电、蓄电池负极（搭铁）、启动档信号；KL 源自德语 Klemme（端子）。

2. **问：为什么汽车开关量输入普遍低有效（默认拉高）？**
   答：断线失效安全（读高 = 未激活同态）、对地短路故障表现恒激活可诊断、车身搭铁天然是就近回地点。

3. **问：12V 开关信号进 3.3V MCU，前端电路怎么设计？**
   答：电阻分压把 12V/16V 压入 GPIO 安全区，串联限流电阻 + 对地滤波电容，量产再加钳位（二极管/TVS/齐纳）；校验 VIH 裕量与 RC 时间常数。

4. **问：输入引脚读不到预期电平，排障顺序？**
   答：从源头到引脚分段量电压：开关前端 12V → 分压节点 A → MCU 脚 B；再查 GPIO 配置（方向/上下拉/输出冲突）与高低有效语义；最后上示波器看抖动与边沿。

5. **问：硬件 RC 滤波能去掉开关抖动吗？**
   答：τ≈100µs 只能滤 µs 级毛刺；机械弹跳持续 ms 级，必须软件去抖（采样一致法或时间戳法）。
