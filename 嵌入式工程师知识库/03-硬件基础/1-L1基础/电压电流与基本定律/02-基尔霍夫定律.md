# 基尔霍夫定律

> 一句话定位：KCL 管节点（流进 = 流出）、KVL 管回路（压降之和 = 电源电压），把零散的欧姆定律算例串成一张完整的供电树/采集网络——ECU 功耗预算与 ADC 换算的底层工具。
> 等级：L1 ｜ 前置：[欧姆定律与功率](01-欧姆定律与功率.md)

## 原理

**KCL（Kirchhoff's Current Law，基尔霍夫电流定律）**：任一节点，流入电流之和 = 流出电流之和。

直觉：电荷在节点不会堆积，像水管三通——进多少出多少。

**KVL（Kirchhoff's Voltage Law，基尔霍夫电压定律）**：任一回路，各元件压降之和 = 电源电动势（绕回路一圈，电位升降相抵）。

直觉：从电路某点出发绕一圈回到原点，电位必然回到原值。

两者与欧姆定律的分工：**KCL/KVL 告诉你电流怎么分、电压怎么分（结构约束），欧姆定律算出每个元件上的具体数值（元件约束）**。

ECU 典型供电树（本篇主算例的载体）：

```
KL30 ──→ [DCDC 12V→5V] ──┬──→ CAN 收发器
              │           ├──→ 传感器供电
              │           └──→ [LDO 5V→3.3V] ──→ MCU/外设
              ⏚（电流经 KL31 返回电池负极）
```

## 计算与选型

### 应用一：ECU 供电树电流守恒估算（KCL + 功率守恒）

已知条件（示例值，实际以器件手册/项目功耗表为准）：

- DCDC 效率 η = 90%，输出 5V；
- 5V 支路一：CAN 收发器常态 50mA；
- 5V 支路二：传感器供电 30mA；
- LDO（线性，5V→3.3V）：输出 MCU+外设合计 120mA，自身地脚电流 1mA。

**第一步：LDO 输入电流（KCL 在 LDO 节点）**

线性稳压器输入电流 ≈ 输出电流 + 自身消耗：

```
I_LDO_in = 120mA + 1mA = 121mA
```

**第二步：DCDC 输出电流（KCL 在 5V 节点）**

```
I_5V = 50 + 30 + 121 = 201mA
```

**第三步：KL30 输入电流（功率守恒）**

```
P_out = 5V × 0.201A = 1.005W
P_in  = P_out / η = 1.005 / 0.9 ≈ 1.117W
I_KL30 = 1.117W / 12V ≈ 93mA
```

注意：**DCDC 是功率转换器而非电流直通**，跨电压级要用功率守恒，同级电源轨内部才用 KCL 直接加电流；LDO 效率 ≈ Vout/Vin（本例 3.3/5 = 66%），压差全部变成热。

**第四步：节点电流表（KCL 的工程化模板）**

| 节点 | 流入 | 流出 | 校验 |
|---|---|---|---|
| KL30 入口 | 93mA（电池） | 93mA（DCDC） | ✓ |
| 5V 节点 | 201mA（DCDC） | 50+30+121 = 201mA | ✓ |
| 3.3V 节点 | 121mA（LDO） | 120mA（负载）+ 1mA（GND） | ✓ |

把每个电源域做成这张表，就是 ECU **功耗预算（power budget）** 的雏形——评审一张新板，先要这张表。

### 应用二：传感器分压→ADC 的 KVL 分析

电位计式位置传感器接 5V 供电：上臂固定电阻 R1 = 10k，下臂为传感器内阻 R2 = 4.7k（某转角位置），中间节点进 ADC。

```
+5V ──[R1 10k]──●──[R2 4.7k]── ⏚
                │
                └──→ V_ADC
```

**KVL 列回路方程**：`5V = I × (R1 + R2)`

```
I = 5V / (10k + 4.7k) = 340µA
V_ADC = I × R2 = 340µA × 4.7k ≈ 1.60V
```

KVL 验算：V_R1 + V_R2 = 3.40 + 1.60 = 5.00V ✓

软件换算：12 位 ADC（3.3V 满量程）码值 ≈ 1.60/3.3 × 4095 ≈ **1987**。反算物理量（角度/位置）时，别忘了这层分压关系与传感器阻值-物理量曲线。

### 睡眠态预算（同一张表的夜间版）

睡眠时 3.3V 只剩 MCU 待机 2mA + 域外设 1mA = 3mA，CAN 收发器待机 15µA：

- P_3.3V ≈ 3.3V × 3mA ≈ 9.9mW；LDO 输入电流 ≈ 3.1mA；
- DCDC 若可切轻载/直通模式，KL30 总静态电流可压到几百 µA 级（以器件手册为准）；
- 整车静态电流预算通常对每个 ECU 限定 mA 级贡献，具体指标以项目规范为准。

## ECU 实例

- 供电树三层结构是当前主流：KL30 → DCDC（5V 或直接 3.3V）→ LDO（给模拟/通信单独的 3.3V/5V 域），见 [电源电路](../../2-L2进阶/电源电路/README.md)。
- 睡眠策略与功耗预算绑定：CAN 收发器待机 15µA 与常态 50mA 差三个数量级——是否进待机、何时进待机由 ECUM/BswM 状态机决定，依据就是上面这张电流表。
- 每个电源域分别配 100nF 去耦（decoupling）+ 若干 µF 级储能，保证瞬态电流（如 CAN 发射瞬间）不把轨拉塌——瞬态下 KCL 依然成立，只是电容成了"流出项"。

## 与软件的关联

- **功耗预算决定睡眠策略**：哪条支路能关（外设时钟、收发器待机、DCDC 模式切换）、必须留哪条（唤醒源），取决于各支路 mA 级电流数据；软件配置直接改写表中数字。
- **IO 休眠漏电**：睡眠时 IO 输出电平若与外部上/下拉相反，会持续漏电（如输出 0 而外部 10k 上拉到 3.3V → 每脚 0.33mA）。进睡前逐脚设置安全态，是 Port DeInit/初始化镜像要管的事。
- **ADC 换算链**：物理量 → 传感器 → 分压（KVL）→ ADC 码值 → 软件物理值，每层系数都要对上，漏掉一层就是系统性偏差。
- **欠压行为分级**：电压跌落时先降级（关闭大负载支路）再复位——关谁留谁的顺序，来自功耗表中各支路的可裁剪性。

## 易错点与陷阱

- **跨 DCDC 直接加电流**：93mA ≠ 201mA，输入输出之间用功率守恒换算，别把两边电流混在一张表里直接相加。
- **LDO 的压差是热**：5V→3.3V 带 120mA 时 LDO 自身耗散 ≈ 1.7V × 121mA ≈ 0.2W，小封装会发烫。
- **忘记自身消耗**：LDO/收发器的 1mA 级静态电流在睡眠预算里是大头，不能忽略。
- **KVL 方程正负号**：绕行方向要统一，遇电源取负、遇压降取正；符号错是初学者最常见的翻车点。
- **单位混乱**：mA 与 µA 混写导致数量级错误，建议整表统一为 mA。

## 面试高频题

1. **问：KCL 和 KVL 一句话表述？**
   答：KCL——任一节点流入流出电流守恒（电荷不堆积）；KVL——任一回路电压升降守恒（绕一圈电位回到原值）。

2. **问：KL30 测得 93mA，DCDC 5V 输出却有 201mA，矛盾吗？**
   答：不矛盾。DCDC 是功率转换器：1.117W 进、1.005W 出（η=90%），5V/201mA 折算回 12V 侧约 93mA——跨级用功率守恒，不用电流守恒。

3. **问：怎么估算 ECU 的睡眠电流？**
   答：列各电源域支路电流表：睡眠保留项（MCU 待机、唤醒电路、收发器待机）逐项相加，再按各级效率折算回 KL30，与整车静态电流预算比对。

4. **问：分压网络算 ADC 电压用 KVL 还是 KCL？**
   答：串联支路电流唯一，先用 KVL 求回路电流 I = Vin/(R1+R2)，再用欧姆定律算节点电压；两条定律配合完成。
