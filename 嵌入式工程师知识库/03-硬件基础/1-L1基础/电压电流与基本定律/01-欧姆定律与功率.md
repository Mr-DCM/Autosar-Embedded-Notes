# 欧姆定律与功率

> 一句话定位：`V = I × R`、`P = V × I` 加上分压/分流，是软件工程师算"引脚上到底有多少伏"的第一把钥匙——软件读到的 0/1、ADC 码值，全部由这三条公式反推出来。
> 等级：L1 ｜ 前置：[从一块 ECU 板开始](../../00-入门导读/01-从一块ECU板开始.md)

## 原理

**欧姆定律（Ohm's Law）**：电阻两端电压 V、流过的电流 I、电阻 R 满足 `V = I × R`。

直觉：电压是"推力"，电阻是"阻力"，电流是被推出来的"结果"。

心算速记：**1kΩ 电阻上流过 1mA，压降就是 1V**——记住这一组，其余按比例缩放。

两个最常用的变形：

- `I = V / R`：已知电压和电阻求电流（算支路电流）。
- `R = V / I`：已知压降和电流反推电阻（选电阻值）。

**功率（Power）**：`P = V × I`，代入欧姆定律得到 `P = I² × R = V² / R`。电阻把电能变成热，超过额定功率就烧毁——选型时**功耗比阻值更容易被忽视**。

**分压（Voltage Divider）**：串联电阻按阻值比例分走总电压：

```
+5V ──[R1 10k]──●──[R2 4.7k]── ⏚
                │
                └──→ Vout = 5V × R2/(R1+R2) ≈ 1.6V
```

`Vout = Vin × R2 / (R1 + R2)`。这是软件工程师最常打交道的电路：电源检测、NTC 测温、传感器调理，全是它把大电压缩进 ADC 量程。

**分流（Current Divider）**：并联电阻按阻值反比分走电流，`I1 = Itotal × R2/(R1+R2)`——两支路中阻值小的那路电流大。

## 计算与选型

### 算例 1：上拉电阻的压降（默认高电平够不够高）

3.3V 系统的按键电路：GPIO 经 10k 上拉（pull-up）电阻到 3.3V，按键另一端接地。

- **按键松开**：输入泄漏电流（leakage current）典型 ±1µA，电阻上压降 = 1µA × 10k = **10mV**，引脚电压 3.29V，远高于 VIH（典型 0.7 × VDD = 2.31V）→ 读 1 稳定。
- **按键按下**：电流 = 3.3V / 10k = **0.33mA**，由 GPIO 灌入（sink）。对照手册 IOL 规格（见算例 2 的 8mA），0.33mA 余量充足 → 低电平可靠。

结论：10k 上拉对数字输入绰绰有余；泄漏引起的 10mV 对逻辑电平无感，但对 ADC 是另一回事（见 [上拉下拉电阻/02](../上拉下拉电阻/02-阻值选择计算.md)）。

### 算例 2：IO 灌电流超规格，低电平被"抬起来"

数据手册典型规格：VOL(max) = 0.4V @ IOL = 8mA（示例值，以具体手册为准）。把输出级导通内阻近似为线性：

```
Ron ≈ VOL / IOL = 0.4V / 8mA = 50Ω
```

假设某引脚同时承担两件事：外部 1k 上拉到 5V（错误设计）+ 直驱 LED 拉电流 8mA：

- 上拉灌入电流 = 5V / 1k = **5mA**（还叠加引脚耐压问题，见易错点）；
- 总灌电流 = 5 + 8 = **13mA > 8mA 规格**；
- 线性外推 VOL ≈ 50Ω × 13mA ≈ **0.65V**。若下一级 VIL(max) = 0.8V，裕量只剩 0.15V——温漂与批次差异下可能误判。

教训：**把一个 IO 上所有灌入电流加总，再对照 IOL 规格**；VOL 不是常数，是随电流抬升的。

### 算例 3：电阻功耗与封装选型——2 倍余量法则

ECU 内部 KL30 对地一只 4.7k 放电/防漏电阻，常年带电。汽车常态电压上限按 16V 算（见下节）：

```
P = V² / R = 16² / 4.7k ≈ 54.5mW
```

逐级核对封装额定功率：

| 封装 | 额定功率 | 2 倍余量要求（≥2×54.5mW=109mW） | 判定 |
|---|---|---|---|
| 0402 | 1/16W = 62.5mW | 62.5 < 109 | ✗ |
| 0603 | 1/10W = 100mW | 100 < 109 | ✗ |
| 0805 | 1/8W = 125mW | 125 ≥ 109 | ✓ 选它 |

**2 倍余量法则**：`P_rated ≥ 2 × P_actual`，覆盖高温降额、脉冲冲击与老化。车规项目还需按 AEC-Q200 降额曲线执行，以项目规范为准。

## ECU 实例

汽车 12V 系统标称 12V，实际波动极大（以 ISO 16750 / 项目规范为准）：

| 工况 | 典型范围 | 对硬件/软件的含义 |
|---|---|---|
| 常态运行 | 9 ~ 16V | KL30 相关电阻按 16V 算功耗与耐压 |
| 冷启动（crank） | 可跌至 6V 级，持续数十 ms | DCDC 需宽输入；软件需处理欠压复位与 DTC |
| 抛负载（load dump） | 瞬态上冲数十伏 | 前端 TVS/钳位保护，MCU 不可直接承受 |
| 静态漏电 | 整车预算通常 mA 级分摊 | 决定 ECU 睡眠功耗预算（见下一篇） |

工程常识：KL30 上的电阻功耗按 16V 常态上限算，瞬态由钳位器件另行校核；具体限值以 ISO 16750 与 OEM 规范为准。

## 与软件的关联

- **GPIO 驱动能力决定外部上拉的下限**：IO 能灌/拉多少 mA，直接限制上拉电阻最小值（R ≥ VDD / IOL）与能否直驱 LED；继电器线圈几乎必须经三极管/MOS 驱动（见 [MOS管与三极管](../../2-L2进阶/MOS管与三极管/README.md)）。
- **低电平语义依赖 VOL**：Dio 读到的 0 对应"VOL + 电流抬升"。外部灌入电流超标时出现"毛刺性误判"，这类问题软件调不掉，只能回推硬件。
- **ADC 读电压先想分压**：测 KL30 必须经分压 + RC，软件换算公式里的分压系数错一位，码值就是系统性偏差。
- **欠压/过压监控阈值**来自上表：如低于 9V 报欠压类 DTC、先降级后复位，阈值由硬件检测电路与软件标定共同决定。

## 易错点与陷阱

- **VOL/VOH 不是 0V/VDD**：随电流变化，算电平裕量必须用规格值 + 实际电流。
- **功耗用最坏电压算**：12V 系统按 16V 算 `P=V²/R`，不要用标称 12V。
- **3.3V IO 上拉到 5V/12V**：除非引脚标注 5V 容忍（FT, 5V-tolerant），否则不只是电流问题，还有耐压问题。
- **分压电阻不是越大越好**：阻值大省电但源阻抗高，ADC 采样读数会漂（详见 [上拉下拉电阻/02](../上拉下拉电阻/02-阻值选择计算.md)）。
- **并联支路电流相加**：多个负载挂同一输出时电流是加法，不是"各自独立"。

## 面试高频题

1. **问：按键上拉电阻取 1k 和 100k 各有什么问题？**
   答：1k——按下时灌入 3.3mA 接近 IO 规格，功耗大；100k——RC 大、电平建立慢，泄漏与噪声下高电平裕量不足。常规取 4.7k~47k。

2. **问：为什么 GPIO 输出低电平实测是 0.6V 而不是 0V？**
   答：输出级导通内阻 × 灌电流形成压降，VOL 随电流增大而抬升；0.6V 说明灌电流可能超规格，需核对 IOL。

3. **问：12V 系统的电阻功耗按多少伏算？**
   答：常态按上限 16V（ISO 16750 范围，以项目规范为准），瞬态由 TVS 钳位后另行校核；封装按 2 倍余量选。

4. **问：P=V²/R 和 P=I²R 分别什么时候用？**
   答：电压已知且固定（电阻挂电源）用 V²/R；电流已知且固定（串联支路）用 I²R——串联电路电流处处相同，后者更方便。
