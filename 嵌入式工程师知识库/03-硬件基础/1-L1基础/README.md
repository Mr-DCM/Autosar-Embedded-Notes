# 1-L1基础

> 上级目录：[03-硬件基础](../README.md)

## 定位

主等级 **L1**：看懂板子的最小集——电路定律、上下拉电阻、原理图阅读。读完本带，你能在原理图上认出元器件、找到 MCU 最小系统、顺着网络标号追一条信号，并算出引脚上的电压大概是多少。

## 坡道说明

- **何时进入**：零基础从 [00-入门导读](../00-入门导读/README.md) 逛完板子地图后即可进入；有一定电路概念的可直接进入。
- **何时离开**：能独立回答"I2C 为什么必须上拉""KL30 检测通道的分压电阻怎么算""复位引脚上那几个元件是干嘛的"——即进入 [L2 带](../2-L2进阶/README.md)；不要在 L1 追求深度，够用就走。
