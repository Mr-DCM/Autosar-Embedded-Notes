# 封装与功率：从丝印反查元件与热设计入门

> 一句话定位：看到封装名（0402/SOT-23/SOIC/QFP/QFN/BGA）能反应出尺寸量级与功率能力，会用 θja 估算结温判断芯片会不会过热，并能从 PCB 丝印反查回原理图位号。
> 等级：L1 ｜ 前置：[电阻电容电感](01-电阻电容电感.md)

## 原理

### 1. 封装命名体系（尺寸量级表）

**贴片阻容感（英制四位数字 = 长×宽，单位 1/100 英寸）**：

| 英制 | 公制(mm) | 实际尺寸 | 备注 |
|---|---|---|---|
| 0402 | 1005 | 1.0×0.5 | 高密度数字电路主力 |
| 0603 | 1608 | 1.6×0.8 | 通用 |
| 0805 | 2012 | 2.0×1.25 | 通用 |
| 1206 | 3216 | 3.2×1.6 | 功率电阻/大容值 |
| 1210/2512 | 3225/6332 | 最大 6.3×3.2 | 大电流 |

注意英制/公制数字极易混用（0402 英制 = 1005 公制），BOM 与贴片程序核对时要统一口径。

**晶体管/IC 封装（引脚数+节距是关键量级）**：

| 封装 | 引脚量级 | 节距 | 典型器件 |
|---|---|---|---|
| SOT-23 | 3~6 | 0.95 mm | 小信号三极管、LDO、ESD 管 |
| SOT-223 | 4（含散热翼） | 2.3 mm | 中功率 LDO |
| SOIC-8 | 8 | 1.27 mm | 收发器、EEPROM、运放 |
| TSSOP/SSOP | 8~56 | 0.65/0.5 mm | 中规模 IC |
| LQFP | 32~144 | 0.8/0.5/0.4 mm | S32K1xx 系列 MCU |
| QFN/DFN | 8~100+ | 0.4~0.65 mm | 底部有裸露散热盘（Thermal Pad） |
| BGA | 数百 | 0.5~1.0 mm 球阵 | 高端 SoC/TC3xx 部分型号（以 DS 为准） |

**功率与封装的关系**：封装越小，散热面积与引脚载流越小，功率能力越低。同一颗芯片 die，QFN（带裸盘）的功率能力显著优于同尺寸 QFP——因为热量主要靠裸盘焊盘导走。

### 2. 热设计入门

三个核心量：

- **Tj（结温，Junction Temperature）**：芯片内部有源区温度，必须低于 DS 上限（车规常按 125℃ 或 150℃ 设计）
- **θja（结到环境热阻）**：RθJA，°C/W，含板条件的影响，**依赖 PCB 铺铜面积，不同 DS 间不可直接对比**
- **θjc（结到壳热阻）**：RθJC，°C/W，配合散热器/裸盘用

基本公式：

```
Tj = Ta + P × θja        （Ta=环境温度，P=芯片功耗）

例：LDO SOT-23 封装，θja≈350℃/W（DS 典型，视板条件）
    输入 5V→输出 3.3V，负载 100 mA
    P = (5-3.3)V × 0.1A = 0.17 W
    ΔT = 0.17 × 350 = 59.5℃
    舱内环境 85℃ 时 Tj ≈ 144℃ → 超过 125℃ 上限，不可用！

    换 SOT-223（θja≈125℃/W，DS 典型）：
    ΔT = 0.17 × 125 ≈ 21℃ → Tj ≈ 106℃ < 125℃，可行
```

**铺铜散热算例**：θja 与铺铜强相关——1 oz 铜皮从几乎不铺到铺满 2×2 英寸，θja 可能下降一半左右（量级概念，具体曲线以器件 DS 的热性能图为准）。大电流走线/裸盘要打过孔阵列导到内层/底层散热。

### 3. 车规标识（概念）

- **AEC-Q100**：车规集成电路（有源器件）认证标准，按温度分 Grade 0（-40~150℃）/1（-40~125℃）/2（-40~105℃）/3（-40~85℃）
- **AEC-Q200**：车规无源元件（阻容感/磁珠/晶振等）认证标准
- 选型时看 DS 首页是否声明 AEC-Q100/Q200 认证及温度等级——动力域/热区件必须 Grade 1/0

### 4. 从 PCB 丝印反查元件（实操方法）

拿到一块实物板要定位元件：

1. 读板上**位号丝印**（如 R123、U7、FB3）——丝印带前缀：R=电阻、C=电容、L=电感、FB=磁珠、D/VD=二极管、Q/T=三极管、U=IC、Y/X=晶振
2. 在原理图 PDF 里**全文搜索该位号**，找到所属网络与参数
3. IC 类看**封装顶面丝印代码**（如 SOT-23 上印 "1AM"），用丝印反查工具/厂商对照表定位具体型号
4. 无源件用万用表在路测（断电测阻值、二极管档测单向性），注意并联路径影响读数
5. 交叉验证：BOM 表的位号-型号-封装三列对齐，防止改版后原理图与实物板版本不一致

### 5. 常见 SOT-23 丝印代码与 QFN 热路径

SOT-23 顶面丝印是缩写代码而非完整型号（同一代码可能对应多家不同器件，务必用"封装+丝印"双条件反查）：

| 丝印代码(举例) | 可能对应 | 说明 |
|---|---|---|
| `1AM` | BC847 类小信号 NPN | 三极管 |
| `t7` / `1P` 等 | 各厂 MOS/ESD/LDO | 只能查对照表确认 |
| `LM3480` 等完整印字 | 少数厂家印全型号 | 直接读 |

QFN 裸盘热路径 ASCII：

```
        芯片 die
      ┌────────┐
      │ QFN 塑封 │
      └─┬────┬─┘
        │裸盘│ ← 焊锡层（虚焊=热阻暴增）
     ┌──┴────┴──┐
     │ PCB 焊盘 │ ← 大面积铜皮
     └──┬──┬──┬─┘
        过孔阵列 ↓ ↓ ↓ → 内层大地铜 / 底层散热铜
```
## 计算与选型（识别步骤清单）

- [ ] 看到封装名先估尺寸与节距（决定返修难度，QFN/BGA 返修难）
- [ ] 功率器件先算 P，再套 θja 验算 Tj，留 20~30℃ 余量
- [ ] 比较不同器件热阻时确认测试板条件（JEDEC 标准板 vs 实际铺铜）
- [ ] 车规项目核对 AEC-Q100 温度等级/Q200 认证
- [ ] 大电流路径核对封装载流上限（如 2512 比 0402 强一个量级）

## ECU 实例

- 车窗/雨刮等驱动：DPAK/DSO 封装 MOSFET 或高边驱动芯片，裸盘过孔阵列到大地铜
- MCU：LQFP100/LQFP144（S32K1xx 常见）或 QFP/BGA（TC3xx，以项目为准）
- 5V→3.3V 小电流：SOT-23 LDO（功耗许可时）；3.3V 大电流域：SOT-223/DFN DCDC
- 温度/压力传感器小信号调理：SOIC-8/TSSOP 运放

## 与软件的关联

1. **过温保护阈值来自热设计**：软件里风扇控制/降功率/过温 DTC 的阈值，本质是 Tj=Ta+P×θja 反推——硬件热阻估错，软件阈值全错。
2. **降额策略**：接近热限时的 PWM 限流/降频策略要和硬件工程师对齐同一套 Tj 假设。
3. **QFN 裸盘虚焊**→热阻剧增→正常运行过温误报：软件报"过温 DTC"但板子摸着不烫时，让硬件查散热焊盘。
4. **故障注入测试**：过温 DTC 的台架复现（热风枪/加热台）要按封装热时间常数设定加热速率，否则 DTC 来不及置位。

## 易错点与陷阱

- 英制/公制封装数字混用导致 BOM 错件（0402 vs 1005 实为同一物；0603 英制 ≠ 0603 公制）
- 拿 A 厂 DS 的 θja 与 B 厂直接对比（板条件不同，不可比）
- θja 是"自然对流+标准板"下的参考值，密封壳/无风舱内环境要再打折
- 只算常温功耗忘了最恶劣工况（最大负载+最高环温+最差电源电压同时出现）
- QFN 裸盘没接地/虚焊，热与 EMC 双双出问题
- 车规等级只看温度范围数字、没核对 AEC 认证状态

## 面试高频题

**Q1：Tj、Ta、θja 之间的关系？**
A：Tj = Ta + P×θja。结温等于环境温度加上功耗乘以结到环境热阻；θja 受 PCB 铺铜与气流影响，设计时要按实际板条件取值并留余量。

**Q2：AEC-Q100 和 AEC-Q200 的区别？**
A：AEC-Q100 面向集成电路等有源器件，按工作温度分 Grade 0/1/2/3；AEC-Q200 面向电阻电容电感等无源元件的车规可靠性认证。

**Q3：同一颗 LDO，SOT-23 和 SOT-223 封装能承受的功耗差多少？为什么？**
A：典型差约 2~3 倍（如 0.17W 的例子中 SOT-23 已超温而 SOT-223 可行），因为 SOT-223 有更大的散热翼和更低的热阻，热量能更快导到 PCB 铜皮。

**Q4：怎么从一块实物板反查某个元件是什么？**
A：读位号丝印→原理图搜位号定位网络与参数→IC 按封装丝印代码查对照表→无源件断电在路测量→最后与 BOM 交叉验证，同时确认原理图版本与实物板版本一致。

**Q5：芯片 DS 里 θja 和 θjc 各用于什么场合？**
A：θja 用于自然散热（把 PCB 当散热器）时估算结温；θjc 用于外加散热器或强制冷（裸盘贴散热结构）时，配合壳温测量推结温，两者不可混用。
