# MCU 电源与去耦：审图先看这几组引脚

> 一句话定位：拿到 MCU 原理图第一件事是核对电源域——VDD/VSS、VDDA/VSSA、内核电压各自是否接对、去耦是否齐全、上电先后是否满足要求，这决定了芯片能否稳定跑起来。
> 等级：L1 ｜ 前置：[电阻电容电感](../常用元器件符号与封装/01-电阻电容电感.md)

## 原理

### 1. MCU 电源引脚分类

| 引脚组 | 名称含义 | 作用 | 软件工程师关注点 |
|---|---|---|---|
| VDD/VSS | 数字电源/地 | 数字逻辑与 IO 供电 | 数量多，每组都要有去耦 |
| VDDA/VSSA | 模拟电源/地 | ADC、PLL 等模拟电路供电 | 决定 ADC 精度与噪声 |
| VDD_CORE / VCAP | 内核电压 | CPU 核心低压供电（现代 MCU 多为 1.2~1.3V 量级） | 有的芯片由内部 LDO 产生、只外接电容（如 S32K1xx 的 VDDF?以 DS 为准），有的需外部供电 |
| VBAT | 备份电池域 | RTC/备份寄存器 | 掉电保持策略 |
| VDDPLL | PLL 电源 | 时锁相环供电 | 噪声直接影响时钟抖动 |

概念：S32K1xx 单电源域器件（VDD 与 VDDA 同电平、内部集成稳压），TC3xx（AURIX）内部集成 EVR（Embedded Voltage Regulator，嵌入式稳压器）由外部 5V 产生内核电压——**每颗芯片有几个电源域、谁先谁后，以该芯片 DS 为准**。

### 2. 去耦（Decoupling）标准电路

每个电源引脚就近放一颗 100 nF（0402/X7R），每个电源域再配一颗 4.7~10 μF 大容量储能（常识值，DS 供电章节的推荐值优先）：

```
VDD ────┬────┬────┬────┬────── 每个电源脚
        │    │    │    │
      100nF 100nF 100nF 100nF      ← 就近（<几 mm）
        │    │    │    │
        ┴────┴────┴────┴
       GND（地平面）
VDD ──┬──[4.7~10μF]──┤ 整域储能一颗
```

去耦电容的作用：MCU 内部门电路翻转时的瞬态电流由就近电容供给，避免电流回路拉长引起电源塌陷与 EMI。

### 3. VDDA 滤波（磁珠+电容）

```
VDD ──[磁珠 600Ω@100MHz]──┬── VDDA
                           ├─[10nF]──┐
                           ├─[1μF]───┤
                           │        GND(A)
                        （VSSA 通常单点接数字地，画法以 DS 评估板为准）
```

目的：把数字域的高频噪声挡在磁珠之前，给 ADC/PLL 一个干净电源。**磁珠后≠磁珠前**，测噪声要测对位置。

### 4. 上电时序要求（概念）

多电源域器件常有先后/斜率要求：例如模拟域与数字域的建立先后、内核电压与 IO 电压的上电顺序、各域达到阈值的时间差——违反时轻则外设初始化异常，重则总线挂死。DS 会有"Power sequencing"一节，给出最小/最大间隔。


### 5. LVD 欠压检测（概念）

LVD（Low Voltage Detector，欠压检测）/BOR（Brown-Out Reset，掉电复位）监测电源：低于阈值时先产生中断（阈值配置在复位阈值之上）让软件收尾，再低则强制复位。S32K 的 LVD/PMC、TC3xx 的 EVR 监控都属此类，阈值与迟滞以 DS 为准。

### 6. 电源树审图 ASCII（一页图看懂供电来龙去脉）

```
KL30(12V 常电)
  │  [TVS+防反接+π滤波]（防护，见二极管与TVS篇）
  ▼
buck DCDC ──→ 5V 域 ──┬─→ MCU VDD（若为 5V 器件，如 S32K1xx 常见）
  │                    ├─→ CAN/LIN 收发器 VCC
  │                    └─→ 传感器供电
  ▼
LDO ──→ 3.3V 域 ──→ 外设芯片
  │
  └─→ 休眠域：常电 LDO(小电流) → MCU standby + 唤醒电路
```

审图时沿这棵树自上而下核对：每级的耐压（抛负载残压 vs 器件耐压）、电流（总负载×余量）、时序（使能脚由谁控制）。

### 7. 去耦电容数量与布局经验

- 数量按 DS "Power supply" 章节的推荐连接图为准，宁多勿少（成本 vs 稳定性）
- 布局优先级：VDDA/VSSA > PLL 电源 > VDD 常规脚 > 储能大电容
- 大电容离芯片可稍远（它管低频），小电容必须贴脚
- 双面布局时，去耦过孔要紧贴焊盘（每 mm 寄生电感都在吃掉高频性能）

- [ ] 测点（test point）是否预留：各电源域电压、地、复位、BOOT 引脚？
- [ ] 休眠唤醒源（KL30 常电 vs 12V 唤醒）在原理图哪里切换？

### 8. 电源器件类型一览

| 类型 | 特点 | ECU 里的位置 |
|---|---|---|
| buck（降压 DCDC） | 效率高、有开关噪声 | 12V→5V 主降压 |
| LDO（线性稳压） | 干净、简单、发热大 | 5V→3.3V、模拟小电流域 |
| boost（升压） | — | 少数场景（如驱动背光） |
| SBC（系统基础芯片） | 集成 DCDC+LDO+CAN 收发器+看门狗 | 中小型 ECU 高集成方案 |
## ECU 实例

- 典型电源树：KL30(12V) → 防13V/TVS/滤波 → buck(5V) → LDO(3.3V/1.8V?以项目为准) → MCU
- 车规 MCU 电源入口常加共模电感+大电容储能，应对冷启动电压跌落
- 休眠 ECU：MCU 由 KL30 常电域 LDO 小电流供电，唤醒后使能主电源——软件 EcuM 的 sleep/ wakeup 状态机与硬件电源开关一一对应（以项目原理图为准）

## 与软件的关联

1. **上电时序错 → 外设初始化偶发异常**：现象是"偶尔上电后 CAN 发不出/ADC 读数飞"，先怀疑电源域先后与去耦，再怀疑代码。
2. **LVD 中断是"最后遗言"**：在 LVD 中断里做关键数据落盘/复位源记录，能区分"正常下电"与"异常掉电"。
3. **去耦不良 → PLL 抖动 → CAN 位错误**：软件看到间歇性 Bus Off 别只查收发器，让硬件用示波器看 VDD 纹波。
4. **EcuM 上下电流程**：硬件电源保持（hold）引脚、唤醒源列表，都要在原理图上找到对应网络再写驱动。

## 易错点与陷阱

- VDDA 漏接磁珠/电容 → ADC 噪声大、LIN 波形异常，一整批标定返工
- 大容量电容全堆在入口 → 上电浪涌电流过大，电源芯片打嗝或保险误动
- 把磁珠前后当同一域测量/调试
- 5V 容忍 IO ≠ 芯片 VDD 能接 5V（引脚级特性与电源域是两回事）
- DS 的上电间隔要求被忽略：一批板子在低温下"随机"起不来，常是时序余量不足
- 去耦电容离引脚太远（布局问题）等效于没接

## 面试高频题

**Q1：MCU 每个电源脚放 100nF 的作用是什么？为什么还要再并一颗大电容？**
A：100nF 就近供给门电路翻转的瞬态高频电流，把电流回路缩到最短；大电容（4.7~10μF）提供较长时间尺度的储能，应对负载突变引起的电源跌落，两者作用频段不同、缺一不可。

**Q2：VDDA 为什么要用磁珠隔离？**
A：数字域电源上叠加高频开关噪声，直接进 VDDA 会恶化 ADC 精度与 PLL 抖动；磁珠对高频呈高阻抗并耗散能量，让模拟域拿到干净电源，同时直流压降极小。

**Q3：什么是 LVD/BOR？软件该怎么利用？**
A：欠压检测/掉电复位电路监测电源电压，低于阈值产生复位；很多芯片支持在复位阈值之上的可配中断，软件用它做关键数据保存、复位源记录，实现"掉电前收尾"。

**Q4：上电时序不满足会有什么现象？**
A：典型症状是上电偶发外设异常、总线挂死或时钟不稳，低温下更明显；因为各电源域未按 DS 要求先后建立时，内部逻辑/IO 可能处于未定义状态。排查要对照 DS 的 Power sequencing 表。

**Q5：去耦电容不足时软件侧会看到什么？**
A：常见的有 PLL 抖动导致的通讯位错误、ADC 读数跳变、大负载开关时 MCU 复位——这些"软件怪象"的根源常在电源完整性。
