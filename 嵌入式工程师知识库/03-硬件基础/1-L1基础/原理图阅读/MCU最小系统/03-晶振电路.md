# MCU 晶振电路：皮尔斯振荡与负载电容

> 一句话定位：晶振给全芯片提供时间基准——认得皮尔斯振荡电路的三件套（晶体/负载电容/反馈电阻），会算负载电容 CL，理解频偏对 CAN/LIN 通讯的量化影响，是"时钟出问题先想到硬件"的基础。
> 等级：L1 ｜ 前置：[电源与去耦](01-电源与去耦.md)

## 原理

### 1. 石英晶体：压电谐振（一句话）

石英晶体（Quartz Crystal）具有压电效应（Piezoelectric Effect）：施加电场产生机械形变，机械振动又产生电场，在固有机械谐振频率上等效为一个高 Q 值的谐振回路，振荡频率极其稳定（ppm 级）。

### 2. 皮尔斯振荡电路（Pierce Oscillator）

MCU 内部集成了反相放大器，外部只需晶体 + 两颗负载电容 +（片内或外置的）反馈电阻：

```
                Rf(反馈电阻,1MΩ 量级,常在片内)
          ┌────────────┤├──────────────┐
          │                                  │
 MCU ──XTAL_IN───┬───────────────┬─── XTAL_OUT── MCU
                 │                │
               [CL1]           [CL2]     ← 负载电容
                 │                │
                GND              GND
                 └───[石英晶体]───┘
                        X1

说明：反相器在片内（OSC 电路）；Rf 使反相器偏置在线性放大区；
      CL1/CL2 与晶体共同决定振荡频率；串阻 Rs(可选)限制驱动功率。
```

### 3. 负载电容计算（完整算例）

晶体规格书给定的 CL（如 12 pF）是**厂家标定频率时的外部等效负载电容**，需满足：

```
CL = (CL1 × CL2) / (CL1 + CL2) + Cstray

其中 Cstray = 引脚寄生 + PCB 走线杂散电容，典型按 3~5 pF 估
```

算例：晶体标 CL = 12 pF，PCB 杂散估 4 pF：

```
要求 (CL1×CL2)/(CL1+CL2) = 12 - 4 = 8 pF
取 CL1 = CL2 = 16 pF → 串联 8 pF ✓ → 实际 CL = 12 pF，频率准

常见错误：无脑抄 22 pF → 串联 11 pF + 4 pF = 15 pF
          → 负载电容偏大 → 振荡频率偏低（负频偏）
```

### 4. 负载电容错 → 频偏 → 通讯受影响（概念量化）

- 频偏方向：CL 偏大 → 频率偏低；CL 偏小 → 频率偏高。灵敏度典型为每偏差 1 pF 引起几 ppm 量级频偏（以晶体规格书的负载曲线为准）
- **CAN**：位时序由位速率与采样点决定，收发双方时钟差异计入振荡器容差预算；高速 CAN 的时钟容差设计通常要求 ±0.5% 量级（含温漂、老化、初始偏差，具体以位时序计算与网络规范为准）——晶振 ppm 级频偏本身远够，但**内部 RC 或频偏大的替代时钟就会吃光预算**，表现为间歇性位错误
- **LIN**：从机靠起始位的下降沿同步，同步后从机时钟容差要求约 ±2%（以 LIN 规范版本为准）；频偏过大 → 采样点漂移 → 校验和错误偶发
- 工程直觉：通讯偶发错误查不出来时，示波器测晶振实际频率（或测 MCU 输出的总线位宽）是低成本高收益的一步

### 5. 起振时间与起振失败

- 起振时间（Startup Time）：从上电到幅度/频率稳定，典型 ms 级（几百 μs~十几 ms，与晶体、CL、放大器增益有关，以实测/DS 为准）
- 起振失败现象：MCU 不跑或时钟异常、看门狗复位、串口乱码——低温下更易发生（放大器增益下降）
- 时钟安全机制兜底：许多 MCU 带时钟失效检测（如 S32K 的时钟监控、TC3xx 的 CCU/OSCS 相关安全机制，名称以 RM 为准）——外部时钟异常时切换到内部备份时钟并触发报警/复位，软件应处理该故障中断

### 6. 晶振 vs 内部 RC：选型选择表

| 时钟源 | 精度(典型) | 成本 | 适用 |
|---|---|---|---|
| 外部石英晶体+皮尔斯 | ±10~50 ppm | 晶体+两电容+布板面积 | CAN/LIN 通讯、需要精确时基的 ECU |
| 外部有源晶振（OSC 供时钟） | ppm 级，单器件 | 稍贵 | 多器件共享同一时钟、布局受限 |
| 内部 RC 振荡器 | ±1%~几%（温漂大） | 零外部件 | 无精确通讯/时基要求的低成本场景 |

S32K1xx：片内 IRC（内部 RC）+FLL/PLL 可跑，但 CAN 通讯项目几乎都外接晶振驱动 PLL；TC3xx：典型外接 20 MHz 晶振驱动 PLL 到额定主频，内部 RC 作备份/安全兜底——**具体时钟树以芯片 RM/项目原理图为准**。

### 7. 布局：就近一句话

晶体与 CL1/CL2 必须紧贴 MCU 的 XTAL 引脚（走线越短杂散越可控），下方铺净地、远离高频开关线——布局细节见 [PCB 常识](../../../3-L3高级/PCB常识/README.md)。

### 8. 无源晶体 vs 有源晶振（OSC）

| 对比项 | 无源晶体（Xtal） | 有源晶振（Oscillator） |
|---|---|---|
| 内部结构 | 只有谐振片，需 MCU 片内振荡电路 | 自带振荡电路，上电即输出方波 |
| 引脚 | 2 脚（+负载电容） | 4 脚（VCC/GND/OUT/EN） |
| 精度/稳定度 | ppm 级 | ppm 级（集成温补后更高） |
| 成本/面积 | 低 | 稍高 |
| 适用 | MCU 主时钟（主流方案） | 时钟要分给多器件、MCU 无振荡电路、要求快速启动 |

### 9. 时钟树审图步骤

1. 找到晶振/OSC 位号（Y/X 前缀），确认频率标称值（丝印或 BOM）
2. 找到 MCU 的 XTAL_IN/XTAL_OUT（或 EXTAL/CLKIN）引脚与负载电容 CL1/CL2
3. 核对 CL1/CL2 是否按晶体规格书 CL 计算取值
4. 追时钟去向：晶振只进 MCU？还是分给 CAN 控制器/以太网 PHY 等其他器件？
5. 核对软件时钟配置的输入频率与原理图一致（最高频的"抄板错误"来源）
### 10. 常见晶体频率与工程用途（印象表）

| 频率 | 典型用途 | 备注 |
|---|---|---|
| 8 MHz | STM32 系经典、S32K 项目常见 | 倍频到内核主频 |
| 16/20 MHz | S32K/TC3xx 常见 | TC3xx 典型 20 MHz 驱动 PLL |
| 40 MHz | 高速 MCU/PHY | 输入 PLL 或直接跑总线时钟 |
| 32.768 kHz | RTC/低功耗域 | 2^15 分频恰好 1Hz |

同型号芯片在不同项目用不同频点很常见——所以"看软件配置先看板上晶振"，以项目原理图为准。
## ECU 实例

- S32K1xx + 8~40 MHz 晶体（常见 8 MHz/16 MHz 档驱动内部 PLL，以项目为准）
- TC3xx + 20 MHz 晶体（典型值，以项目原理图为准）
- 无通讯小节点：纯内部 RC 也能过功能测试，但产线发现批量 CAN 错误帧时第一件事就是核对时钟方案
- 晶振停振的典型工艺原因：裸盘/晶体焊点应力开裂（车震环境）、助焊剂污染漏电

## 与软件的关联

1. **时钟初始化代码对应原理图时钟源**：PLL 倍频公式里的输入频率必须与板上晶振一致——抄别的板子的时钟配置到自己的板子上，输入频率不同则全错
2. **CAN 位时序参数由时钟频率推**：时钟变了，波特率与采样点全变，用上位机算的参数要重算
3. **起振失败 → 卡在时钟等待**：软件等待时钟稳定标志（如 PLL Lock）应有超时与故障分支，而不是死等
4. **时钟安全中断处理**：检测到外部时钟失效时按安全策略切换/复位，并记录 DTC
5. 低功耗策略：进休眠停晶振省电，唤醒后要等起振稳定再通讯（连接 LIN/CAN 前的等待时间余量）

## 易错点与陷阱

- CL1/CL2 抄别家板子的值而不算 Cstray → 批量频偏 → 多节点网络偶发位错误
- 把 CL1/CL2 焊成一样大但晶体 CL 规格不同（8 pF vs 12 pF 晶体混料）
- 用内部 RC 上 CAN：常温测试通过，高低温批量失败（RC 温漂吃光容差）
- 晶振走线绕远/跨分割 → 杂散大、起振慢、抗扰差
- 软件死等 PLL Lock 无超时 → 起振失败的板子"假死"
- 示波器探头直接压在 XTAL 引脚上（探头电容几 pF，直接把频率拉偏甚至停振）——测量要轻触或用低容探头

## 面试高频题

**Q1：皮尔斯振荡电路由什么组成？各元件作用？**
A：片内反相放大器（放大）、石英晶体（选频谐振）、负载电容 CL1/CL2（与晶体共同决定振荡频率）、反馈电阻 Rf（把反相器偏置在线性放大区）。外部有时还串 Rs 限幅保护晶体。

**Q2：负载电容 CL 怎么算？CL 偏大会怎样？**
A：CL=(CL1×CL2)/(CL1+CL2)+Cstray，等于晶体规格书标称值时频率才准。CL 偏大振荡频率偏低（负频偏），偏小则偏高；典型每偏差 1 pF 引起几 ppm 频偏。

**Q3：为什么 CAN 通讯的 ECU 基本都用外部晶振而不用内部 RC？**
A：CAN 位时序要求收发双方时钟容差在约 ±0.5% 量级（含温漂老化），内部 RC ±1%~几%的温漂会吃光容差导致位错误；晶振 ppm 级精度才能稳定满足预算。

**Q4：晶振起振失败会有什么现象？软件怎么兜底？**
A：现象是 MCU 不启动、看门狗反复复位或时钟异常。软件要配置时钟安全/失效检测机制，外部时钟异常时切到内部备份时钟并报警复位，等待时钟稳定的代码必须有超时分支。

**Q5：示波器测晶振要注意什么？**
A：探头电容（约 10 pF 量级）会直接并到振荡回路，把频率拉偏甚至造成停振；应用低输入电容探头或轻触测量，必要时测 MCU 输出的时钟分频/总线位宽间接判断。
