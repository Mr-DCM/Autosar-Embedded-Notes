# 3-L3高级

> 上级目录：[03-硬件基础](../README.md)

## 定位

主等级 **L3**：**点到即止**——PCB 常识只写概念 + 评审清单 + 延伸指针，布线、EMC 的深入设计靠硬件团队与工程实践，不在本区展开。软件工程师读到这里的目标是：Layout 评审时能听懂、能提出软件侧需求（测试点/调试口/关键走线），而不是自己会画板。

## 坡道说明

- **何时进入**：L2 带读完（至少电源电路与 ECU 硬件常识）且工作涉及 Layout 评审、EMC 整改或板级排障协作时再读；赶项目时可只读各篇"太长不看"。
- **何时离开**：读完概念与清单即止——往下是硬件工程师的专业领域，需要时与硬件团队结对深入，而不是继续自学布线。
