# PCB 布局布线基础

> 一句话定位：软件工程师不需要会画板子，但需要看得懂板子——功能分区、去耦就近、CAN 差分、电源路径这四个词是与硬件同事排障协作的通用语言。
> 等级：L3 ｜ 前置：[从一块 ECU 板开始](../../00-入门导读/01-从一块ECU板开始.md)

## 太长不看

> - 人话直觉：布局就是"谁挨着谁"——功能分区不串味、去耦贴着芯片、晶振贴着 MCU、防护堵在连接器口；布线记住电源粗、信号短、差分成对、地平面完整。
> - 本篇解决：不学画板，但能看懂布局布线评审意见，跟硬件同事用同一套语言把"软件诡异现象"定位回板级原因。
> - 赶时间记住：①布局四原则：功能分区/去耦就近/晶体就近/防护靠边；②1oz 铜箔约 0.3mm 线宽≈1A（1mm≈2.5~3A，经验量级，精确按 IPC-2150）；③评审时替软件说话：测试点、调试口、Boot 电阻可达性。

## 原理

### 1. 软件工程师为什么需要懂布局布线

不是要你画板，而是排障协作的接口语言：

- "CAN 偶发错误" → 定位是软件位时序问题还是走线/端接问题，需要能问出"CAN 走线多长、参考层是哪层"
- "ADC 抖动" → 需要知道采样走线离功率电感多远、参考地怎么接
- "EMC 超标" → 整改涉及降边沿、加磁珠、挪器件，软件要配合改 slew rate / 开关频率（见 [EMC 入门](04-EMC入门.md)）
- 评审原理图/PCB 时能提出与软件相关的要求：测试点位置、调试口预留、Boot 电阻可达性

一句话：**板级问题经常以"软件诡异现象"的形式出现**，不懂板子就只能背锅或瞎猜。

### 2. 布局四大原则

| 原则 | 内容 | 违反后果 |
|---|---|---|
| 功能分区 | 按电源/数字/模拟/接口分块，信号流单向不交叉 | 各区噪声互相串 |
| 去耦就近 | 去耦电容紧贴芯片电源脚（mm 级） | 电容引线电感吃掉高频去耦效果，详见[纹波与去耦](../../2-L2进阶/电源电路/04-纹波与去耦.md) |
| 晶体就近 | 晶振离 MCU 引脚尽量短（典型 <10 mm），下方不走线 | 走线长→易受扰/频偏/停振，见[晶振原理](../../2-L2进阶/时钟电路/01-晶振原理与负载电容计算.md) |
| 接口防护靠边 | TVS/共模电感/ESD 器件放连接器入口，防护在前、滤波在后 | 干扰进了板内才防护，为时已晚 |

### 3. 布线常识速查

**线宽与电流的量级**（1 oz 铜箔，10~20°C 温升，经验值，精确按 IPC-2150/项目规范）：

| 线宽 | 载流量级（外层） | 典型用途 |
|---|---|---|
| 0.15 mm (6 mil) | ~0.5 A | 普通信号线 |
| 0.3 mm (12 mil) | ~1 A | 弱电源、CAN |
| 1 mm (40 mil) | ~2.5~3 A | 中等功率电源 |
| ≥2 mm / 铺铜 / 加锡 | 5 A+ | KL30 主电源、电机相线（大电流常开窗加锡或多层并联） |

**其他布线常识**：

- **CAN 差分走线**：CANH/CANL 平行等长伴行，目标特性阻抗（characteristic impedance）差分 120 Ω——线宽/线距/参考层间距决定阻抗，布线软件可算；阻抗不匹配会引起反射（见[信号完整性](03-信号完整性入门.md)）
- **避免锐角/直角**：走线拐弯用 45° 或圆弧——直角尖端阻抗不连续且电场集中，是辐射/反射源
- **关键信号包地**（一句话）：晶振、复位、CAN 等关键线两侧用地线包围隔离，配合完整参考层降低串扰与骚扰耦合
- **等长**：高速并行总线（SPI 高速、存储器接口）要求组内等长，否则采样窗口错开

### 4. 电源路径与"回流最小环"

电流永远走回路：信号线出去，回流从参考层/地线回来，去+回构成一个环路（loop）：

```
   芯片 ──────信号线──────▶ 器件
    ▲                        │
    │   回流走正下方的地平面  │
    └────────────────────────┘
         ← 环路面积 = 信号线×回流路径围出的面积

环路面积越小 → 天线效应越弱 → EMI 辐射越小、抗扰越强
布局纪律：信号线短、回流紧贴其正下方走 → 环路天然最小
```

电源路径同理：KL30 入口 → 防护 → DCDC → 各域负载，主电源走线粗短直接，不绕板（详见[KL30 供电](../../2-L2进阶/ECU硬件常识/01-KL30-KL15供电.md)）。

### 5. 典型 ECU 板功能分区（ASCII 全景图）

```
┌──────────────────────────────────────────────────────────┐
│  连接器区（板边）                                          │
│  ┌─────────┐  ┌──────────┐  ┌──────────┐                 │
│  │ 电源入口 │  │ CAN/LIN  │  │ 高边驱动  │   ← 接口防护    │
│  │ KL30/31 │  │ 接口     │  │ 输出     │     器件靠边     │
│  └────┬────┘  └────┬─────┘  └────┬─────┘                 │
│       │            │             │                        │
│  ┌────▼────┐  ┌────▼─────────────▼─────┐                 │
│  │ 电源区  │  │      功率/驱动区        │                 │
│  │ 防反接  │  │  DCDC·继电器·电机驱动   │                 │
│  │ TVS     │  │（发热大、噪声大，独占一角）│                 │
│  │ DCDC/LDO│  └───────────┬────────────┘                 │
│  └────┬────┘              │ 隔离带/单点地                  │
│       │  ┌────────────────▼─────┐                        │
│       └─▶│      数字区          │                        │
│          │  MCU·存储·晶振(就近)  │                        │
│          │  ┌────┐ ┌──┐ ┌────┐ │                        │
│          │  │MCU │ │晶│ │去耦│  │  ← 去耦电容贴 MCU 脚下   │
│          │  └────┘ └──┘ └────┘ │                        │
│          │  ┌────────────┐     │                        │
```

分区逻辑一句话：**脏的（功率/接口）靠边角，安静的（模拟）远离脏的，MCU 居中统领，晶振和去耦贴身**。

## 计算与选型

### 设计步骤：软件工程师参与的布线检查单

```
第 1 步：找到每个连接器的功能（电源/CAN/LIN/驱动输出/传感器输入）
第 2 步：确认防护器件（TVS/共模电感）在连接器与板内电路之间
第 3 步：找 MCU——晶体是否贴脚？去耦电容是否成排贴在电源脚旁？
第 4 步：找 CAN 收发器——CANH/CANL 是否等长伴行、端接电阻位置
第 5 步：找 DCDC 电感——ADC 采样线/晶振是否远离其开关噪声辐射区
第 6 步：确认测试点/调试口是否引出（软件调试刚需）
```

### 线宽估算速算（量级判断）

```
需要载流 I（A），按 1 oz 铜、温升约 10°C 查经验表：
  I ≤ 0.5 A → 0.15 mm 即可
  I ≈ 1 A   → ≥0.3 mm
  I ≈ 3 A   → ≥1 mm 或铺铜
  I > 5 A   → 开窗加锡/多层并联/加铜条
（经验值仅供量级判断，量产按 IPC-2150 计算与温升试验验证，以项目规范为准）
```

## ECU 实例

- 某车身控制器（6 层板）：连接器全在板一边，电源入口 TVS+共模电感紧贴连接器；MCU 居中，20 MHz 晶体距引脚 8 mm，去耦 100 nF×16 贴脚排布；CAN 两路差分等长走背层完整参考面；DCDC 电感布置在远离 ADC 区的对角（布局以该项目 PCB 评审报告为准）
- 排障协作案例：产线 CAN 偶发 CRC 错误，软件位时序参数反复调整无效；硬件按检查单第 4 步复查发现某路 CAN 端接电阻被 Layout 挪到了支路末端（非总线端点）导致反射——端接位置修正后消失
- 某低成本单层板 ECU：去耦电容为省面积拉长走线到 2 cm，高频去耦失效，MCU 在继电器动作时偶发复位（见[地平面与回流](02-地平面与回流.md)地弹链条）

## 与软件的关联

1. **排障分工**：偶发通讯错误先分"软件时序 / 走线信号质量"两条线并行查，能读板子才能配合硬件复现试验
2. **测试点需求反向提给硬件**：调试需要的信号（复位、Boot 电平、CAN RXD、唤醒输入）在 Layout 前提出，打样后再加就难了
3. **EMC 整改配合**：板级整改（磁珠/挪件）与软件整改（slew rate/扩频）经常同步做，软件要知道硬件在改什么（见 [EMC 入门](04-EMC入门.md)）
4. **软件补偿物理缺陷**：走线偏长导致的边沿变缓，可用 IO 驱动强度寄存器补偿（有条件场合）

## 易错点与陷阱

- 只看原理图不看 Layout：原理图正确≠板子正确，端接、去耦位置、走线参考层都是 Layout 层面的事
- 去耦电容"有"但"远"：数量够但走线拉长，高频段形同虚设
- 晶振走线绕远/下方过线：频偏与停振隐患，高低温才暴露
- CAN 差分不等长/跨分割：反射与共模辐射双杀（详见[信号完整性](03-信号完整性入门.md)、[地平面与回流](02-地平面与回流.md)）
- 高电流走线按信号线宽画：温升超标、压降吃掉余量，负载突增时复位
- 测试点没提需求：量产排障时飞线，破坏量产一致性

## 面试高频题

**Q1：布局的四大原则是什么？**
A：功能分区（电源/数字/模拟/接口分块、信号流单向）、去耦就近（电容 mm 级贴电源脚）、晶体就近（<10 mm 且下方不走线）、接口防护靠边（TVS/共模电感放连接器入口、防护在前滤波在后）。

**Q2：为什么去耦电容必须紧贴芯片？**
A：电容到引脚之间的走线存在电感，距离越远感抗越大，高频下"电容+引线电感"的谐振点上阻抗飙升，去耦失效。去耦的本质是就近提供高频电流，物理位置就是电气性能。

**Q3：CAN 差分走线要注意什么？120 Ω 是什么阻抗？**
A：CANH/CANL 平行等长伴行、同层同参考面、少打孔；120 Ω 是差分特性阻抗（与总线端接电阻匹配），由线宽/线距/到参考层距离决定。阻抗不匹配→信号反射→位边沿畸变。

**Q4：什么是"回流最小环"？**
A：信号电流去程走信号线、回程走参考面/地，围成环路；环路面积越小天线效应越弱，EMC 越好。布局纪律是让回流紧贴信号线正下方（完整参考层），所以走线不跨分割。

**Q5：软件工程师为什么懂 PCB？**
A：板级问题常以软件诡异现象出现（偶发复位/通讯错误/ADC 抖动）；排障要与硬件协作，需要能看懂功能分区、端接位置、去耦布局，并在 Layout 前提出测试点等软件需求。
