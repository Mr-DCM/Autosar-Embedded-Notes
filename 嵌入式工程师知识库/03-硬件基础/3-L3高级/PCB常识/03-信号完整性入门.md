# 信号完整性入门

> 一句话定位：信号完整性（Signal Integrity，SI）讲的是"波形到达接收端还是不是它出发时的样子"——决定 SI 的不是频率高低，而是边沿有多快；边沿越快，传输线效应、反射、串扰越明显。
> 等级：L3 ｜ 前置：[布局布线基础](01-布局布线基础.md)、[地平面与回流](02-地平面与回流.md)

## 太长不看

> - 人话直觉：SI 看"波形到接收端还是不是出发时的样子"，决定它的不是频率而是边沿快慢——边沿越快，传输线效应、反射、串扰越明显，1 ns 边沿的低频信号照样振铃。
> - 本篇解决：会用"走线长度 > 上升沿空间长度（tr×15 cm/ns）的 1/6"判据判断要不要管阻抗与端接，能跟硬件讨论反射/串扰/振铃以及 SPI、CAN 走线整改。
> - 赶时间记住：①判据看边沿不看频率：走线 > L_edge/6 即按传输线处理；②反射源于阻抗突变，端接让 Γ→0（CAN 两端 120Ω 并联端接、SPI 源端串阻 22~33Ω 量级）；③串扰靠 3W 间距法则压量级，过冲超 VDD 有闩锁风险，探头电容会把边沿"量好看"。

## 原理

### 1. 什么时候 SI 变重要：看边沿速率，不是频率

```
SI 严重的判据（经验法则）：走线长度 > 信号上升沿长度的 1/6

上升沿在走线上的空间长度：
  L_edge = 上升时间 tr × 信号传播速度 v
  （PCB 上 v ≈ 光速/2 ≈ 15 cm/ns）

例 1：CAN 500k，tr ≈ 50 ns  → L_edge ≈ 750 cm → 板级走线全都是"短线"，慢
例 2：SPI 10 MHz，tr ≈ 5 ns  → L_edge ≈ 75 cm  → 一般板级尚可
例 3：MCU IO 最快档 tr ≈ 1 ns → L_edge ≈ 15 cm → 10 cm 走线已是传输线！
```

结论：**1 kHz 信号用 1 ns 边沿驱动，SI 问题比 100 MHz 正弦波严重**——判据永远是 tr，不是重复频率。这也是为什么 IO 的 slew rate/驱动强度寄存器（见 [EMC 入门](04-EMC入门.md)）默认不该无脑开最快档。

### 2. 反射：阻抗突变

信号沿传输线传播，遇到阻抗不连续处（线宽变化、过孔、分支、端接缺失）部分能量被反射回来，与入射波叠加造成过冲/振铃：

```
驱动 ──Z0=50Ω──╦══════════════╦══════> 接收端（高阻输入）
               ║              ║
              开路/高阻 → 反射系数 Γ≈+1 → 全反射 → 2×入射幅度过冲

端接（一句话）：在接收端或驱动端加电阻把阻抗"续上"（串联端接/并联端接），
使 Γ→0，反射消失——CAN 总线两端 120Ω 就是并联端接的教科书案例
```

### 3. 串扰：平行线耦合

相邻走线通过互容/互感耦合，一根线上的边沿在邻线感应出噪声脉冲（近端/远端串扰）：

- 平行长度越长、间距越近、边沿越快，串扰越强
- **3W 间距法则**（常识）：线间距 ≥ 3 倍线宽时，串扰降到可接受量级（经验法则，非精确保证）
- 带完整参考面的内层走线串扰天然小于表层微带线

### 4. 振铃/过冲对数字输入的危害：闩锁效应

过冲振铃超过 VDD（或低于 GND）时，芯片 ESD 保护二极管正向导通，注入电流：

```
振铃尖峰 > VDD + 二极管压降
   → ESD 保护寄生二极管导通 → 电流注入芯片衬底
   → 寄生可控硅（SCR）结构被触发 → VDD-GND 低阻通路
   → 闩锁效应（latch-up）：大电流、芯片发热，轻则功能错乱重则烧毁
   （现代 MCU 有一定抗闩锁设计，但注入电流限值必须查 DS 绝对最大额定值）
```

即使不到闩锁程度，超限注入电流也会退化器件寿命——振铃不该被当作"能用就行"。

### 5. SPI 高速时钟线 / CAN 走线注意

- **SPI**：时钟线 SCK 是最敏感线（时钟边沿被反射/串扰污染→数据错位采样）；CS 到 SCK 首边沿的建立时间预算吃走线延迟；高速 SPI（≥10 MHz）要求短走线、少过孔、组内等长、串阻（源端 22~33 Ω 量级常见）抑制振铃
- **CAN**：差分对等长伴行、120 Ω 差分阻抗（见[布局布线基础](01-布局布线基础.md)）；分支（stub）要短——分支是阻抗突变点，长分支的反射直接毁掉位边沿；端接只在总线两端物理端点

### 6. 示波器探头负载效应：测量本身改变信号

```
探头 = 衰减电阻 + 寄生电容（10:1 探头典型 ~10 pF，1:1 探头可达 100 pF）

被测点 ──R源──┬──→ 原边沿（陡）
              │
           C探头 10pF ← 与源阻抗构成 RC 低通
              │
             GND

R源=50Ω、C=10pF → 时间常数 0.5ns，边沿明显拉缓
R源=1kΩ、C=10pF → 时间常数 10ns，几十 MHz 信号直接"看不见"了
```

- 结论：**测得缓的边沿可能本来是陡的**——探头电容拉缓了它；测晶振引脚还会拉偏频率（见[晶振原理篇](../../2-L2进阶/时钟电路/01-晶振原理与负载电容计算.md)易错点）
- 实操：能用 10:1 不用 1:1（输入电容小）；高频测量用低容探头；记得补偿校准

## 计算与选型

### 设计步骤：SI 快筛清单

```
第 1 步：列出全板最快边沿信号（SPI 时钟、MCU 高速 IO、CAN、晶振）
第 2 步：对每根算 L_edge = tr × 15 cm/ns，与走线长度比较
        走线 > L_edge/6 → 传输线，需管阻抗与端接
第 3 步：查串扰风险：关键线间距是否 ≥3W？平行段是否长？
第 4 步：查端接：CAN 两端 120Ω？SPI 源端串阻？分支长度？
第 5 步：量测验证：用 10:1 探头在接收端量边沿与振铃，
        过冲幅度对照 DS 绝对最大额定值（VDD+0.3V 量级，以 DS 为准）
```

### 量级速算例

```
SPI 时钟 20 MHz，IO 最快档 tr = 2 ns：
  L_edge = 2ns × 15cm/ns = 30 cm → L_edge/6 = 5 cm
  板上走线 8 cm > 5 cm → 必须按传输线处理：控阻抗+源端串阻
串阻值直觉：源阻抗 ~20-30Ω 内阻，目标 50Ω 走线 → 串 22-33Ω
（数值以具体 IO 驱动特性与 DS 为准）
```

## ECU 实例

- 某域控 ECU：外部 Flash 的 QSPI 跑 40 MHz，初版 Layout 走线 9 cm 无串阻，示波器量 SCK 接收端振铃过冲 1.2 V（超 VDD+0.5V）——读取偶发位错；加 33 Ω 源端串阻后过冲降至 0.3 V 以内，问题消失（数值以该项目实测报告为准）
- 某网关：CAN 分支 stub 长 8 cm（非端点节点引出），2 Mbit/s CAN-FD 位错误率超标——反射叠加；整改缩短 stub 至 3 cm 内后通过
- 排障协作案例：软件报 SPI 偶发 CRC 错误，硬件用 10:1 探头测得波形良好——但换低容探头后发现实际边沿有振铃，10 pF 探头把它"抹平"了（探头负载效应的反向利用：测量误判）

## 与软件的关联

1. **降速是软件侧 SI 整改**：SPI 时钟频率、IO slew rate、驱动强度寄存器都可软件调整——先降速保功能，再等硬件改板（与 [EMC 入门](04-EMC入门.md)共用手段）
2. **SPI 通信参数与 SI 相关**：时钟极性/相位（CPOL/CPHA）决定了采样边沿落在振铃后还是振铃中——换模式偶尔能"绕开"振铃窗口（治标手段）
3. **错误统计定位**：SPI/CAN 错误计数器、CRC 统计的分布（偶发 vs 温度相关 vs 负载相关）是判断 SI 问题的证据来源
4. **测量配合**：复现 SI 问题需要特定触发条件（特定数据图案、特定温度），软件要能构造最坏图案（如 0101 交替的最高翻转率序列）
5. **输入毛噪过滤**：部分 MCU 输入有数字滤波器可配置，对受扰输入做脉宽过滤

## 易错点与陷阱

- "频率不高不用管 SI"：判据是边沿速率，1 ns 边沿的低频信号照样振铃
- IO 无脑开最快 slew rate：边沿更快=SI 与 EMC 双恶化，够用就好
- 1:1 探头量高频信号：探头电容直接把波形量"好看"了——测量造假
- 振铃当"能用就行"：超过绝对最大额定值的注入电流在累积损伤，量产批次高温老化后集中爆
- 忽略 stub：CAN 支线/测试点引出的短分支在高边沿速率下是反射源
- 换探头不补偿校准：方波补偿未调，幅度与边沿全失真

## 面试高频题

**Q1：SI 什么时候变重要？为什么不是看频率？**
A：看边沿速率：走线长度超过上升沿空间长度（tr×15 cm/ns）的约 1/6 时，走线是传输线，反射/串扰显现。低频信号配快边沿（如 1 ns IO）照样有 SI 问题，判据是 tr 不是重复频率。

**Q2：反射怎么产生？怎么消除？**
A：信号遇到阻抗不连续（线宽变化/过孔/分支/开路），反射系数 Γ=(Z2−Z1)/(Z2+Z1)，部分能量反射与入射叠加成过冲振铃。消除：端接使阻抗连续——CAN 两端 120Ω 并联端接、SPI 源端串阻，让 Γ→0。

**Q3：什么是 3W 法则？**
A：相邻走线间距 ≥3 倍线宽时，耦合的串扰降到经验上可接受的量级。间距越大/平行越短/有完整参考面，串扰越小。是经验法则不是精确保证。

**Q4：过冲为什么危险？什么是闩锁？**
A：过冲超 VDD 使 ESD 保护寄生二极管导通、电流注入衬底，可能触发寄生 SCR 结构形成 VDD-GND 低阻通路——闩锁效应（latch-up），大电流发热烧芯片。即使不闩锁，超注入电流限值也累积损伤。幅度限值查 DS 绝对最大额定值。

**Q5：示波器探头如何影响被测信号？**
A：探头有输入电容（10:1 约 10 pF），与被测点源阻抗构成 RC 低通，拉缓边沿、衰减高频分量——测得的波形比真实"温和"。高频测量用 10:1 或低容探头；测晶振还会拉偏频率。
