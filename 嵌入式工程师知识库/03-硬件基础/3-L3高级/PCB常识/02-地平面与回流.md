# 地平面与回流

> 一句话定位：地（GND）不是"0V 的一个点"，而是所有信号的回流路径——地平面被开槽/分割破坏时，回流被迫绕行，环路变大变天线，EMC 辐射、串扰、地弹全找上门。
> 等级：L3 ｜ 前置：[布局布线基础](01-布局布线基础.md)

## 太长不看

> - 人话直觉：地是所有信号的回流路径，高频回流自动紧贴信号线正下方走；地平面一被开槽/分割，回流被迫绕行，环路变大变天线——辐射、串扰、地弹全找上门。
> - 本篇解决：看懂"走线不能跨分割"的物理原因，排查偶发复位/ADC 跳动时先问"地"，记住分割地单点连接原则与示波器地线夹的烧板红线。
> - 赶时间记住：①回流走信号正下方，跨槽=绕行=环路天线；②地弹 ΔV=Lg·di/dt（10nH×50mA/ns≈0.5V，足以打穿复位阈值）；③数字/模拟/功率地要分就单点连接，多点乱连等于没分；④示波器地线夹接市电保护地，不共地先共地或用差分探头。

## 原理

### 1. 地平面的双重角色

高速/高频电流选择阻抗最小路径回流。频率升高后，回流不再走几何最短直线，而是**紧贴信号线正下方的地平面**（感抗最小）：

```
信号层走线 ────────────────────────▶
                ↕ 分布耦合
地平面回流 ◀────────────────────────  ← 回流自动聚在信号线正下方

地平面角色：
① 回流路径（Return Path）—— 每根信号线都需要
② 参考平面（Reference Plane）—— 决定走线特性阻抗 Z0 与屏蔽
```

破坏地平面 = 同时破坏回流路径与阻抗基准，这是地平面问题的总根源。

### 2. 地平面开槽的危害：绕行 → 环路天线

```
【完整地平面】                【地平面被开槽（如一条长通孔带/挖槽）】

 信号线 ════════════════       信号线 ════════════════
          ↓ 回流                      ↓        ↓
 ────────████████────       ────████┌─────────┐████────
          ↑ 直行                     │ 回流绕槽 │
 ─────────████████────       ────████└─────────┘████────
                                    ↑ 环路面积暴涨

环路面积 A × 电流变化 di/dt = 磁通量 → 等效环路天线 → 辐射发射（EMI）
同时：绕行段回流与信号线不再紧贴 → 耦合减弱、串扰与抗扰双恶化
```

开槽的常见来源：过孔阵列（连接器/接插件排孔）、地平面挖空散热、不合理的分割线。**信号线跨过开槽 = 强制回流绕行**——这就是"走线不能跨分割区"规则的原因：不是玄学，是环路天线定律。

### 3. 分割地策略：数字/模拟/功率地单点连接

不分割全平面最好（一块完整地）；确实要分（如大功率驱动噪声大）时用**单点连接**：

```
┌────────────────────────────────────────────┐
│  数字地 GND_D          模拟地 GND_A         │
│  ┌──────────┐         ┌──────────┐         │
│  │ MCU/CAN  │         │ ADC/Vref │         │
│  └────┬─────┘         └────┬─────┘         │
│       │                    │               │
│  ═════╪════════════════════╪═════ ← 磁珠/0Ω│
│       └───────┐    ┌───────┘      单点桥    │
│             ┌─▼────▼─┐                     │
│             │ 功率地  │  DCDC/驱动          │
│             │ GND_P  │  （大电流噪声源）     │
│             └───┬────┘                     │
└─────────────────┼──────────────────────────┘
                  ▼ 板边一点汇到电源地/整车地
```

- 单点连接：各域噪声电流只能通过一个窄桥，不互相灌入对方地
- 数字地与模拟地之间常放磁珠或 0 Ω 电阻（直流通、高频阻），选型见[电阻电容电感](../../1-L1基础/原理图阅读/常用元器件符号与封装/01-电阻电容电感.md)
- 反面教材：多点乱连 = 分了个寂寞，噪声到处流

### 4. 地弹（Ground Bounce）：大电流 IO 翻转的链条

```
大电流 IO 翻转（如驱动继电器/多脚并驱动）
   → 瞬间 di/dt 流过地路径电感 Lg
   → 地噪声 ΔV = Lg × di/dt （芯片地相对板地"弹"起来）
   → 后果链条：
       ├─ 复位脚阈值被瞬时噪声击穿 → 偶发复位
       ├─ ADC 参考地抖动 → 采样值跳动
       └─ 数字输入毛刺 → 外部中断误触发/按键误判
```

对策：缩短地路径（减小 Lg）、大电流器件去耦就近、驱动分散翻转时刻（软件可配合错峰）、关键输入加 RC 滤波。

### 5. 多板共地与仪器接地安全（实操警告）

⚠️ **示波器地线夹的烧板风险**：

- 标准示波器探头地线夹通过电源插头地接到市电保护地——**它就是一根接大地的线**
- 车载 ECU 调试常用台架电源（浮地）或整车蓄电池：若把探头地线夹夹到"看似是地"的点位上，而该点与真实大地之间存在电位差/短路路径（如夹到了 KL30、或跨接了不同系统地），瞬间大电流流过探头地线——**轻则跳闸，重则烧板烧探头**
- 规矩：①夹之前用万用表确认夹点与台架地的电位关系；②两块板不共地时先共地或用隔离通道/差分探头；③禁止把地线夹当"随便找个金属点"
- 同理：两台仪器（示波器+电源）+被测板三方，任何一方接地关系搞错都会形成地环路（ground loop）烧器件

## 计算与选型

### 设计步骤：地平面检查单

```
第 1 步：确认每层地平面完整性——哪些层是完整 GND？哪里被挖槽？
第 2 步：把所有高速/关键信号线（CAN、晶振、高速 SPI）叠在平面图上，
        逐条检查是否跨越开槽或分割线
第 3 步：检查连接器过孔排是否在地平面切出长槽（缝），必要时跨槽桥接电容/短走线
第 4 步：检查单点连接位置——是否在干净区域、是否只此一点
第 5 步：大电流回路（DCDC 输入/输出环路）面积目测最小化
```

### 地噪声估算（量级直觉）

```
地路径电感 Lg ≈ 10 nH 量级（几 cm 走线/引线）
驱动电流翻转 di/dt ≈ 50 mA/ns（多脚并驱动典型）
→ ΔV = Lg × di/dt = 10nH × 50mA/ns ≈ 0.5 V 地弹尖峰
→ 与复位阈值（施密特典型 1V 级以下裕量）同量级 → 足以偶发复位
（量级直觉用，精确值以实测与项目规范为准）
```

## ECU 实例

- 某车身 ECU：6 层板第 2/5 层完整地平面，CAN 与晶振走线全部不跨槽；连接器过孔排在第 2 层切出 15 mm 长缝——Layout 在缝上加了两处桥接过孔修复，CISPR 25 辐射余量提升数 dB（以该项目 EMC 报告为准）
- 排障案例：某节点继电器动作瞬间 MCU 偶发复位——地弹链条：继电器驱动电流回路与 MCU 地共用一段细走线，di/dt 地噪声击穿复位阈值；硬件改单点地+驱动去耦，软件配合把多路输出错峰 1 ms 翻转后解决
- 实操事故案例：调试台架用可调电源（接地型），示波器地线夹夹到"传感器屏蔽层"，而屏蔽层在该台架上接 KL30——上电瞬间探头地线冒烟（典型共地错误，真实风险，引以为戒）

## 与软件的关联

1. **偶发复位先问地**：大电流负载动作与复位时间相关性强 → 怀疑地弹，软件可记录复位原因寄存器配合定位（见[负载突变保护](../../2-L2进阶/ECU硬件常识/03-负载突变保护.md)）
2. **ADC 跳动排查**：采样值随继电器/电机动作跳动 → 参考地被扰动，软件可做触发式多通道连采取证
3. **外部中断误触发**：地噪声/串扰毛刺打进去——软件可加消抖/短脉宽过滤（滤波也算软件兜底）
4. **错峰驱动**：多路大电流 IO 的翻转时刻在软件里人为错开，降低叠加 di/dt（地弹治理的软件贡献）
5. **复位原因记录**：上电后第一件事读复位源寄存器并落 DTC，是区分"真复位"与"地弹毛刺"的证据链（见 [Dem 事件与DTC](../../../06-诊断与标定/2-L2进阶/Dem配置/01-事件与DTC.md)）

## 易错点与陷阱

- "地就是地，随便接"：地的本质是回流路径，接错点=给噪声开高速路
- 信号线跨分割区：环路天线+阻抗突变双杀，高频下必出问题（规则原因见上文开槽分析）
- 分割地多点连接：以为分了就干净，实际噪声互相串
- 示波器地线夹乱夹：不同系统地不共地时直接短路烧板（实操第一警告）
- 大电流回路绕远：环路面积大，EMI 与地弹双高
- 只测信号不测地：排障时量信号线电平"正常"，但芯片地本身在弹——要测芯片地相对板地的噪声

## 面试高频题

**Q1：地平面的两个作用是什么？**
A：①回流路径——高频回流紧贴信号线正下方走，环路最小；②参考平面——决定走线特性阻抗并提供屏蔽。破坏地平面同时破坏这两点。

**Q2：为什么走线不能跨越地平面分割区？**
A：跨分割时回流无法从信号线正下方通过，被迫绕行分割边缘，环路面积暴涨→等效环路天线→EMC 辐射与串扰恶化，且阻抗突变引起反射。物理本质是回流路径连续性。

**Q3：什么是地弹？怎么治理？**
A：大电流 IO 翻转的 di/dt 流过地路径电感，芯片地电位相对板地瞬时抬升（ΔV=Lg·di/dt），可击穿复位/输入阈值造成偶发复位、ADC 抖动。治理：缩短地路径、驱动去耦就近、关键输入 RC 滤波、软件错峰翻转。

**Q4：数字地/模拟地/功率地怎么处理？**
A：优先一块完整地；确需分割时单点连接（窄桥/磁珠/0Ω），各域噪声电流只能过一点，不互窜。多点连接等于没分。

**Q5：示波器地线夹为什么有烧板风险？**
A：探头地线夹接市电保护地。被测系统（台架电源/整车）若与大地存在电位差或不共地，夹到错误点位瞬间形成大电流回路，烧探头/烧板。规矩：夹前确认共地关系，不共地先共地或用差分探头。
