# EMC 入门

> 一句话定位：EMC（Electromagnetic Compatibility，电磁兼容）= 自己不骚扰别人（EMI 发射）+ 不被别人骚扰（EMS 抗扰）——汽车上由 CISPR 25 / ISO 11452 系列标准考试，软件工程师要懂概念、会配合测试、知道软件能帮什么。
> 等级：L3 ｜ 前置：[布局布线基础](01-布局布线基础.md)、[信号完整性入门](03-信号完整性入门.md)

## 太长不看

> - 人话直觉：EMC 就是"自己不吵别人、也不被别人吵"的考试；吵不吵看三件事——源头（边沿/开关频率）、路径（传导/辐射）、受体（扛不扛得住），整改就从这三处下刀。
> - 本篇解决：能看懂 EMC 测试项目与整改单，知道 slew rate、时钟扩频、开关频率规划、抗扰恢复这些软件手段该在什么时候顶上去。
> - 赶时间记住：①CISPR 25 管发射（EMI）、ISO 11452 系列管抗扰（EMS），限值以项目规范为准；②整改优先级：先源头（软件可先行：降边沿/扩频/频率规划）再路径（滤波/屏蔽/接地）；③EMS 判 B 类（自恢复）全靠看门狗/重试/重初始化这些软件机制撑着，测试版软件要开满负载。

## 原理

### 1. 汽车 EMC 标准概念（概念级）

| 标准 | 管什么 | 一句话内容 |
|---|---|---|
| CISPR 25 | 整车/零部件**发射**（EMI） | 传导发射（150 kHz~108 MHz，电压/电流法）+ 辐射发射（到 GHz 级，天线法），按等级给限值线（以标准版本与项目适用等级为准） |
| ISO 11452 系列 | 零部件**抗扰**（EMS） | 大电流注入 BCI、电波暗室法、带状线法等，各频段注入干扰验证功能状态 |
| ISO 7637-2 | 电源线瞬态抗扰 | 沿电源线的脉冲抗扰（详见[负载突变保护](../../2-L2进阶/ECU硬件常识/03-负载突变保护.md)） |
| ISO 16750-2 | 电源环境 | 电压范围/缓升缓降/起动特性等（详见 [KL30 供电](../../2-L2进阶/ECU硬件常识/01-KL30-KL15供电.md)） |

项目通常引用主机厂企标（在上述国际标准上加严），**测试项目与限值以项目 EMC 规范为准**。

### 2. EMC 三要素：干扰源—耦合路径—敏感体

```
┌──────────┐    耦合路径            ┌──────────┐
│ 干扰源    │ ──────────────────▶  │ 敏感体    │
│ DCDC开关  │  ①传导（电源线/线束） │ MCU/ADC/ │
│ IO 边沿   │  ②辐射（空间电磁场）  │ 收发器   │
│ 晶振/时钟 │  ③感性/容性耦合       │ 复位电路 │
└──────────┘                      └──────────┘
整改思路 = 三选一（或组合）：压源头 / 断路径 / 提敏感度
```

耦合路径细看（EMC 整改的"下刀处"）：

- **传导**：干扰电流沿电源线/信号线束流出 ECU——用车载电源网络当"天线"把能量辐射出去；对策在"入口"：LC 滤波、共模电感、去耦（详见[布局布线基础](01-布局布线基础.md)）
- **辐射**：板级环路（信号+回流围出的面积，见[地平面与回流](02-地平面与回流.md)）与线束本身就是辐射天线；对策在"缩小天线"：环路最小化、屏蔽、地平面完整
- **近场耦合**：板上器件/走线之间感性（磁场）与容性（电场）互串——DCDC 电感干扰相邻 ADC 走线是典型；对策在"拉开距离+包地"

### 3. 整改手段分类表

| 类别 | 手段 | 针对要素 | 典型例子 |
|---|---|---|---|
| 滤波 | LC/π 滤波、共模电感、去耦电容、磁珠 | 路径（传导） | 电源入口 LC、CAN 共模电感 |
| 屏蔽 | 金属外壳、屏蔽线缆、屏蔽罩 | 路径（辐射） | 屏蔽双绞线束、ECU 铝壳接地 |
| 接地 | 地平面完整、单点地、外壳接地 | 路径+源头 | 见[地平面与回流](02-地平面与回流.md) |
| 降边沿 | slew rate 控制、串阻 | 源头 | IO 边沿放缓（见[信号完整性](03-信号完整性入门.md)） |
| 扩频 | 时钟/开关频率扩频（SSC） | 源头 | 峰值能量摊到频带，限值线下降数 dB |
| 频率规划 | 开关频率避开敏感频段 | 源头 | DCDC 避开 AM 频段（下文） |
| 软件加固 | 错误恢复/看门狗/重试 | 敏感体 | 抗扰失败自动恢复（下文） |

### 4. 软件能帮什么

- **IO slew rate 控制**：多数 MCU IO 可配边沿速率/驱动强度档位——非必要不开最快档，边沿放缓=高次谐波能量直降（SI 与 EMC 双收益）
- **时钟扩频（Spread Spectrum Clocking，SSC）概念**：让主时钟在中心频率附近低频抖动（如 ±0.5%~2%），能量从尖峰摊开成包络，窄带辐射峰值可降数 dB；代价是频率抖动进入位时序预算，CAN 等通讯时钟慎用
- **开关频率避开 AM 频段**：DCDC 开关频率及其谐波落在 150 kHz~30 MHz 时极易撞 CISPR 25 限值——选频时避开 AM 广播频段及敏感频点，思路详见 [DCDC 原理](../../2-L2进阶/电源电路/02-DCDC原理.md)；软件可调（数字控制电源）时更要规划
- **抗扰失败恢复**：EMS 测试允许"功能降级但可自恢复"的状态等级（以项目规范定义的 Function Status Class 为准）——看门狗、通讯重试、外设重新初始化等软件机制直接决定测试判级

## 计算与选型

### EMC 三步定位法（debug 流程）

```
第 1 步：看超标频谱——尖峰在哪个频点/频段？
        尖窄单峰 → 时钟/晶振/开关频率及其谐波（对号入座查源头）
        宽带抬升 → 边沿/随机噪声/多个源叠加
第 2 步：定位源头——关掉可疑功能分项测试（停 CAN / 停 DCDC / 降主频）
        峰消失/下降 → 源头锁定
第 3 步：按分类表选整改——先源头（软件可先行的 slew rate/扩频/频率），
        再路径（滤波/屏蔽/接地），最后敏感体
```

### debug 案例：CAN 辐射超标（概念性）

```
现象：CISPR 25 辐射发射在某频段超限值线数 dB，频点与 500 kbit/s CAN
     位速率谐波对号入座
分析链（三要素套用）：
  源头：CAN 差分边沿 + 收发器共模噪声
  路径：线束共模辐射（差分转共模的失衡）→ 天线效应
  敏感：无（本案例是"自己是源"）
整改阶梯（从软到硬，先易后难）：
  ① CAN 收发器 slope/引脚 slew rate 放缓（软件/寄存器级）——边沿谐波下降
  ② 共模电感 + 端接复核（120Ω 在端点、stub 最短）——断共模路径
  ③ 屏蔽/接地整改（外壳接地、线束屏蔽层 360° 环接）——断辐射路径
  每步整改后复测频谱，锁定有效手段组合
```

### 量级速算：为什么先管环路

```
辐射直觉（量级示意，非精确公式，工程判断用）：
  差模辐射 ∝ (电流 × 环路面积 × 频率²)
  → 频率翻倍 = 辐射 +12 dB（平方律），环路面积减半 = −6 dB
  → 同样的整改力度花在"缩小环路/降边沿（压高频分量）"上收益最大
  共模辐射 ∝ (共模电流 × 线束长度 × 频率)
  → 共模电流仅 μA 级就能超标——这就是共模电感/屏蔽优先级高的原因
（量级直觉仅供排序整改优先级，合规判定以测试为准）
```

## ECU 实例

- 某车身 ECU：DCDC 默认开关频率谐波正落 AM 频段，传导发射临界超标——改 DCDC 频率（避开 AM 整段）+ 输入 LC 后余量达 6 dB 以上（以该项目 EMC 测试报告为准）
- 某网关：时钟 300 MHz 谐波在辐射扫描中超标——改用带 SSC 的时钟方案后单峰摊开回落限值线下（通讯时钟经位时序预算验证后采用）
- 测试协作案例：BCI（大电流注入）测试中 CAN 通讯中断不恢复——软件加"通讯超时→控制器/收发器复位重初始化"恢复链路后，判级从"功能失效"升为"自恢复"，通过
- 某低成本节点：传导发射在 DCDC 基频处超限——输入端共模电感+X 电容组合整改后达标，全程未改板（只改 BOM 器件位置预留位，以该项目报告为准）

## 与软件的关联

1. **测试版本的软件配置**：EMC 测试用的软件版本要开典型负载（CAN 满发、PWM 满占空比、DCDC 满载）——"安静"的软件测出来的结果不代表量产状态
2. **DVT/EMC 测试流程协作**：EMC 实验室按频段逐项测（发射/BCI/辐射抗扰/瞬态），每轮数天——软件要提前准备：可配测试模式、可远程切负载状态、带错误计数统计上报（方便现场判断是否"受扰失效"）
3. **判级与软件相关**：EMS 的 Function Status Class（如 A=正常/B=自恢复/C=需干预/D=损坏）中 B 类全靠软件恢复机制支撑——看门狗/重试/重初始化是"过测试"的一部分
4. **整改项里有软件**：slew rate、扩频、开关频率、错误恢复策略都在软件/配置域，硬件改板周期长，软件整改先上
5. **DTC 与 EMC 排障联动**：现场 EMC 类问题（偶发复位/通讯中断）靠 DTC 时间戳与环境记录回溯（见 [Dem 冻结帧](../../../06-诊断与标定/2-L2进阶/Dem配置/02-冻结帧.md)）

## 易错点与陷阱

- 拿"最安静"的软件配置去测 EMC：量产满负载状态才是真实最坏情况，测完换软件版本要复测
- 只想硬件整改：slew rate/扩频/频率规划等软件手段成本低见效快，应先筛
- 扩频滥用在通讯时钟上：频率抖动吃位时序容差预算，CAN 上乱开 SSC 可能从 EMC 问题变成通讯问题
- 端接/共模电感堆料不看源头：源头是边沿太陡时，先降边沿
- BCI 测试不准备恢复机制：硬件本来扛得住的等级被软件"不恢复"判成失败
- 忽略线束状态：EMC 结果与线束长度/摆放强相关，复测要同条件（以测试规范布置为准）
- 测试排期不当回事：EMC 整改常要 2~3 轮迭代（测→改→复测），最后一轮压到项目末期没有改板窗口——首次送测就该留整改余量
- 只盯限值线不看余量：卡线通过的量产一致性风险大，主流做法要求留数 dB 余量（以项目规范为准）

## 面试高频题

**Q1：CISPR 25 和 ISO 11452 分别管什么？**
A：CISPR 25 管发射（EMI）：零部件/整车的传导发射与辐射发射限值；ISO 11452 系列管抗扰（EMS）：BCI、暗室、带状线等方法向零部件注入干扰。项目实测引用的版本与等级以主机厂规范为准。

**Q2：EMC 三要素是什么？整改思路？**
A：干扰源（DCDC/IO 边沿/时钟）、耦合路径（传导/辐射/近场耦合）、敏感体（MCU/ADC/收发器）。整改三选一或组合：压源头（降边沿/扩频/频率规划）、断路径（滤波/屏蔽/接地）、提敏感度（滤波/软件恢复）。

**Q3：软件在 EMC 里能做什么？**
A：①IO slew rate/驱动强度控制——放缓边沿降谐波；②时钟扩频（SSC）摊窄带峰值；③DCDC 开关频率规划避开 AM 频段；④抗扰恢复机制（看门狗/重试/重初始化）支撑 EMS 判 B 类自恢复。

**Q4：什么是扩频时钟？有什么代价？**
A：让时钟频率在中心值附近低幅抖动，把尖峰能量摊成包络，辐射峰值降数 dB。代价是频率抖动计入位时序/频率容差预算——CAN 等通讯时钟使用前必须验证容差。

**Q5：CAN 辐射超标怎么整改？**
A：先定位（频点与位速率谐波对号）；整改阶梯：①放缓收发器 slope/边沿（源头）；②共模电感+端接复核（断共模路径）；③屏蔽与接地整改（断辐射路径）。每步复测验证有效性。

**Q6：传导和辐射两条耦合路径分别怎么管？**
A：传导在"入口"管——电源线/线束上加 LC 滤波、共模电感、去耦，把干扰电流拦在 ECU 内；辐射在"天线"管——缩小信号回流环路面积、保持地平面完整、线束屏蔽与外壳接地。近场耦合再靠布局拉开距离与包地。
