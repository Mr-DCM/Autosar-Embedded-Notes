# 00-入门导读

> 上级目录：[03-硬件基础](../README.md)

## 定位

给硬件零基础（或久疏）的软件工程师的**一小时入门**：不求深、不求全，目标是逛完一块 ECU 板后建立"板子直觉"——知道电从哪来、信号到哪去、软件读到的数字对应板上哪个角落。

## 篇目

| 篇目 | 等级 | 一句话 |
|---|---|---|
| [从一块 ECU 板开始](01-从一块ECU板开始.md) | 【L1】 | 分区导览 → 电源树 → 打通 KL30 电压检测链路，一小时的硬件第一课 |

## 读完去向

- 顺着导读末尾"下一步读什么"进入 [L1 基础带](../1-L1基础/README.md)：电压电流 → 上下拉 → 原理图阅读；
- 若你已有基本电路概念，可直接跳过导读进 L1 带，不必强读。
