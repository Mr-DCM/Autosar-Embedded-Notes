# 02-芯片与体系结构

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

体系结构通用原理 + Cortex-M/TriCore 双架构 + S32K/TC377 双平台 + 芯片行业版图（六大类横向认知），按 L1~L3 分带组织：先用 ARM 通用课和 S32K 平台打底，再进 TC377 平台与体系结构通用，行业版图随时按选型/认知需要跳读，最后按需深查 TriCore/异常/多核深水区。

## 入门坡道

1. L1 导读一天：把 [00-入门导读](00-入门导读/README.md) 四篇当" MCU 是什么"的速览，不求深只求有地图；
2. [1-L1基础](1-L1基础/README.md) 一周：ARM 通用课 + 所在平台的资源清单，读完能看懂寄存器手册的章节结构；
3. [2-L2进阶](2-L2进阶/README.md) 按平台主线走：做哪个平台读哪条主线，体系结构通用五篇穿插补原理；
4. [3-L3高级](3-L3高级/README.md) 按需深查：遇到 trap 定位、CSA 排查、多核踩踏再进，点到即止。
