# 1-L1基础

> 上级目录：[02-芯片与体系结构](../README.md)

## 定位

**架构通用课 + 首个平台落地。** ARM Cortex-M 五篇是不分平台的通用架构课（编程模型、NVIC、向量表、MPU、位带），S32K 平台八篇把通用课落到一颗真实芯片上（选型对比、外设清单、Flash 机制、时钟配置）。

- 主标签：**【L1】**（多数篇目零平台前置，读完导读即可进）
- 何时进：读完 [00-入门导读](../00-入门导读/README.md)，手里有芯片地图、想开始看寄存器手册；
- 何时离开：能独立翻 Cortex-M 编程模型手册章节、能说清 S32K 的外设/Flash/时钟三大资源版图，就该进 [2-L2进阶](../2-L2进阶/README.md) 了。
