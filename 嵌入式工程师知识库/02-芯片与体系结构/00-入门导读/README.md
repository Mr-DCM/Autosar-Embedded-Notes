# 00-入门导读

> 上级目录：[02-芯片与体系结构](../README.md)

## 定位

**一天入门芯片视角。** 四篇导读用大白话把"MCU 是什么、地址是什么、中断是什么、启动是什么"讲清楚——少公式、多直觉、每篇一张图。读完后你手里有了一张芯片地图，再进 L1 带就不会在术语里迷路。

- 主等级：**L1**（前置：无，可从零直接读）
- 何时进：新接触嵌入式/新接触本库/换平台想快速建立地图感；
- 何时离开：能不查资料说出"四要素、门牌号、轮询与中断、复位到 main 四步"，就该进 1-L1基础 动手深挖了——导读讲直觉，不讲寄存器。
