# 2-L2进阶

> 上级目录：[02-芯片与体系结构](../README.md)

## 定位

**平台深水 + 原理加固 + 行业横向。** TC377 平台把 L1 的通用课升级成 AURIX 工程视野（中断路由、存储器映射、时钟树、iLLD 生态、GTM），体系结构通用五篇补齐跨架构的原理底座（寄存器模型、流水线、Cache/MPU、总线/DMA、存储层次），启动流程三篇打通双平台从复位到 main 的全链路，芯片行业版图七篇把视野从双平台扩到六大类行业全景（MCU 五阵营/SoC/收发器/SBC/模拟驱动/AFE）。

- 主标签：**【L2】**（前置：1-L1基础 的 ARM 通用课；TC377 线建议先过 S32K 平台建立"平台"概念）
- 何时进：L1 带读完、开始接触真实工程代码（MCAL/iLLD/启动文件）；
- 何时离开：能独立看懂 TC377 的中断/时钟/存储配置与 map 文件、能读懂启动文件三件事，剩下的深水区（GTM、TriCore 内核、多核）按需进 [3-L3高级](../3-L3高级/README.md)。
