# 芯片行业版图

> 上级目录：[2-L2进阶](../README.md)

## 定位

从"双平台"扩到"行业版图"：把汽车上的芯片按**六大类**横向铺开——MCU/实时处理器、SoC/域控智驾、收发器/物理层、SBC/PMIC、模拟电源与驱动、AFE 与专用传感器，每类一篇，给"代表型号 × 用在哪个域 × 工程师哪里会遇到 × 与本库哪些笔记互链"。TC377/S32K 平台笔记管"纵向打穿"，本目录管"横向知道行业里有什么"。

## 使用方式

- **选型/行业认知/面试"你了解行业芯片吗"** → 从 [00-六大类总览](00-六大类总览.md) 进，按类跳读；
- **接手新平台**（如 RH850/SPC5/AM263x）→ 直读 [01-MCU与实时处理器](01-MCU与实时处理器.md)，再回 [TC377平台](../TC377平台/README.md)、[S32K平台](../../1-L1基础/S32K平台/README.md) 笔记补机制；
- **排障**：睡不醒/复位/喂狗类问题 → [04-SBC与PMIC](04-SBC与PMIC.md)；总线物理层问题 → [03-收发器与物理层](03-收发器与物理层.md)；供电与驱动链路 → [05-模拟电源与驱动](05-模拟电源与驱动.md)；
- **三电/传感器方向求职** → [06-AFE与专用传感器](06-AFE与专用传感器.md) + [14 区行业观察](../../../14-面试与成长/2-L2进阶/职业发展/04-行业观察-新能源与域控.md)。
