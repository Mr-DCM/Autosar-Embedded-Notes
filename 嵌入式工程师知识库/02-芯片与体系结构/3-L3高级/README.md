# 3-L3高级

> 上级目录：[02-芯片与体系结构](../README.md)

## 定位

**深水区参考层。** TriCore 架构五篇讲 AURIX 内核机制（TC1.6P、CSA、trap 与中断、DSPR/PSPR、lockstep），异常与 Trap 三篇是双平台异常定位的实操手册，多核架构三篇覆盖主从核启动、锁步核使用、核间通讯与共享资源保护。

- 主标签：**【L3】**（前置：2-L2进阶 对应平台主线；TriCore/01 是本带入口，标【L2→L3】）
- 何时进：不是"读完 L2 才准进"——遇到具体问题随时进来查对应篇；
- 何时离开：没有"离开"——本带按问题驱动使用，读完即走。

## 点到即止声明

本带是**深水区参考层，不要求按序通读**。正确用法：遇到具体工程问题（trap 现场定位、CSA 耗尽排查、多核数据踩踏、锁步安全评审）时，按需直读对应篇，**每个主题读到工程够用即止**——机制细节以 UM 章节为准，笔记目标是帮你快速定位与决策，不是替你背手册。没有对应问题时，本带可长期搁置。
