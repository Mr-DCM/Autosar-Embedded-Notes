# 00-入门导读

> 上级目录：[08-操作系统](../README.md)

## 定位

**半天入门操作系统视角。** 一篇导读让一个 LED 程序进化三次——前后台大循环、时间片轮询加事件驱动状态机、RTOS 多任务——每进化一次多出一份"OS 才会给你的东西"；再用一张"裸机痛点 vs RTOS 给了什么"对照表，把调度、同步、中断这内核三大件讲成三句排队直觉（排队上 CPU、排队拿钥匙、打断与让位），最后钉死 OSEK/AUTOSAR OS 在全景中的位置——少术语、多直觉。读完后你有了本区地图，知道每个子目录在回答哪个问题。

- 主等级：**L1**（前置：无，可从零直接读；若已读过 [02 区导读](../../02-芯片与体系结构/00-入门导读/README.md) 更佳——中断与 NVIC 是本文的硬件侧背景）；
- 何时进：分不清裸机和 RTOS 的边界、只调过 API 不理解调度/同步在排什么队、不知道为什么汽车 ECU 用 OSEK 而 IoT 设备用 FreeRTOS——都从这里起步；
- 何时离开：能画出三次进化的结构差异、说出内核三大件各在排什么队、解释"任务/互斥锁/延迟处理"分别解决了裸机的哪个痛点，就该进 [1-L1基础](../1-L1基础/README.md) 了——导读讲直觉，不讲逐个 API。
