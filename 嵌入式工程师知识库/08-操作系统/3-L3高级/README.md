## 定位

**跨界进阶，点到即止。** 嵌入式 Linux 是 RTOS 之外的另一个世界——从"单二进制裸跑"跨到"内核+根文件系统+驱动模型"。**本带声明：点到即止**——对 TC377/S32K BSW/CDD 方向的汽车工程师，Linux 是拓宽视野的跨界进阶方向而非主业，笔记以概念讲解 + 清单速查为主（设备树是什么、字符设备框架长什么样、Buildroot/Yocto 认门牌），不深挖内核源码与系统移植细节。

- 主标签：**【L2→L3】**（前置：RTOS通用原理的概念已通；对"OS 管什么"有答案之后，看 Linux 才是对照而非新学问）
- 何时进：RTOS 主线已走完，想理解座舱/网关类 Linux 平台的驱动与设备树，或为职业面拓宽备货；
- 何时离开：能读懂一个设备树节点、说清字符设备 file_operations 框架、知道 Buildroot 与 Yocto 的分工——即达标，不必恋战。
