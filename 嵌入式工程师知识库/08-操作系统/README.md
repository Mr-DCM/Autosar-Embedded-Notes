# 08-操作系统

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

通用 RTOS 原理（中断/调度/同步/内存）+ FreeRTOS 等实现 + 嵌入式 Linux，按 L1~L3 分带组织——先用一个 LED 程序的三次进化建立"为什么需要 OS"的直觉，L1 带吃透裸机三板斧与内核三大件，L2 带落回汽车主业（OSEK 内核本质）并用 FreeRTOS 对照验证，VxWorks/嵌入式 Linux 等跨界方向点到即止。

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：LED 程序三次进化，先建"为什么需要 OS"的全景直觉；
2. [1-L1基础/裸机与状态机编程](1-L1基础/裸机与状态机编程/README.md)：前后台系统起手，看清没有 OS 的世界长什么样、痛在哪；
3. [1-L1基础/RTOS通用原理/任务调度原理](1-L1基础/RTOS通用原理/任务调度原理/README.md)：内核三大件之"排队上 CPU"——任务状态机与调度策略，本区原理主阵地的第一站；
4. [2-L2进阶/OSEK与AUTOSAR-OS](2-L2进阶/OSEK与AUTOSAR-OS/README.md)：落到汽车项目实际用的 OS，看 OSEK 内核本质与商业实现对比，对照 [07-AUTOSAR架构/系统服务栈](../07-AUTOSAR架构/2-L2进阶/系统服务栈/README.md) 看集成配置与启动流；
5. [2-L2进阶/FreeRTOS](2-L2进阶/FreeRTOS/README.md)：用开源实现对照验证三大件——学完 OSEK 再看 FreeRTOS 的动态任务/heap 方案，两相对照理解最深。
