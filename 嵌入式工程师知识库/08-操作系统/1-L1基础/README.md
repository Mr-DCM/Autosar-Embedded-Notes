# 1-L1基础

> 上级目录：[08-操作系统](../README.md)

## 定位

**裸机世界与原理主阵地。** 裸机与状态机编程先看清没有 OS 的世界——前后台、时间片轮询、事件驱动状态机三板斧，知道痛在哪，"为什么需要 OS"才有落点；RTOS通用原理是本区概念主阵地，调度/同步/中断/内存/死锁五大主题讲成"排队"直觉，通吃所有 OS——之后学 FreeRTOS、OSEK、VxWorks 都是在认这套概念的实现方言；RTX 一篇概览顺带读。

- 主标签：**【L1→L2】**（前置：无；读过 [00-入门导读](../00-入门导读/README.md) 更佳，三大件直觉已在导读建立）
- 何时进：能写裸机大循环但不了解状态机、调过 RTOS API 但说不清调度在排什么队；
- 何时离开：能画出任务状态机与上下文切换、解释优先级反转成因、独立设计一个事件驱动状态机，即可进 [2-L2进阶](../2-L2进阶/README.md) 落主业。
