# 00-入门导读

> 上级目录：[05-汽车网络通讯](../README.md)

## 定位

**半天入门车载网络视角。** 一篇导读跟着一帧 CAN 报文从信号打包走到对端解包，把全链路分层（Com→PduR→CanIf→CanDrv）变成一张时序图，并用一张对比表摆正 CAN/LIN/FlexRay/车载以太网的位置——少公式、多直觉。读完后你有了本区地图与"会配置→懂原理→能排障"三级标尺，再进 L1 带就不会在术语里迷路。

- 主等级：**L1**（前置：无，可从零直接读）
- 何时进：新入车载行业、只配过工具没见过全链路、分不清 CanIf 与 CanDrv——都从这里起步；
- 何时离开：能不查资料说出"一帧报文从应用到总线经过哪四层、四种总线各自的定位、通讯数据库是什么"，就该进 1-L1基础 深挖了——导读讲直觉，不讲位时序计算。
