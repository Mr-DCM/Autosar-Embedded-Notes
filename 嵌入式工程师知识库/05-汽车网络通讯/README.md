# 05-汽车网络通讯

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

主业深挖：CAN/CAN-FD/LIN 原理与排障、网络管理、传输层、通讯数据库，按 L1~L3 分带组织——先用一帧报文的旅程建全网地图，再在 L1 带打牢 CAN/LIN 地基，L2 带爬传输层与网络管理，FlexRay/车载以太网深水区点到即止。

| 带 | 定位 |
|---|---|
| [00-入门导读](00-入门导读/README.md) | 半天入门地图：一帧 CAN 报文的一生 + 四总线对比表 + 三级成长标尺。 |
| [1-L1基础](1-L1基础/README.md) | 主业地基：CAN 全家桶（协议原理/收发器为 L1 地基）、LIN（协议原理起坡）、通讯数据库。 |

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：一帧报文从信号到总线的全链路 + 四总线定位，先建地图；
2. [1-L1基础/CAN/协议原理](1-L1基础/CAN/协议原理/README.md)：主业地基——帧格式、位时序、仲裁与填充、错误帧；
3. [1-L1基础/CAN/收发器与物理层](1-L1基础/CAN/收发器与物理层/README.md)：从报文走到波形，理解终端电阻与拓扑；
4. [2-L2进阶/传输层](2-L2进阶/传输层/README.md)：CanTp 分段与排障，衔接 06 区诊断；
5. [2-L2进阶/网络管理](2-L2进阶/网络管理/README.md)：睡眠与假醒，整车功耗问题的主战场；[1-L1基础/LIN/协议原理](1-L1基础/LIN/协议原理/README.md)可穿插，以 CAN 的底子快速拿下 LIN，配合 [09-调试与测试/总线工具](../09-调试与测试/2-L2进阶/总线工具/README.md) 用 CANoe 实操。
