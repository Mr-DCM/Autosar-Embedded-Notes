# 1-L1基础

> 上级目录：[05-汽车网络通讯](../README.md)

## 定位

**主业地基。** CAN 是全区的第一主线（协议原理与收发器为 L1 地基，总线错误与恢复为【L2】深水），LIN 以 CAN 底子快速拿下（协议原理起坡，LDF 与配置/排障为【L2】），通讯数据库（DBC/LDF/通讯矩阵 ARXML）是全车"时刻表"——配栈之前先会读库。

- 主标签：**【L1→L2】**（前置：读完 [00-入门导读](../00-入门导读/README.md) 即可进；CAN/LIN 内个别子目录为【L2】，归带从主、篇级头部行为准）
- 何时进：读完导读、开始接触总线报文与 DBC；
- 何时离开：能徒手画经典 CAN 帧格式、说清仲裁与位时序、看懂 DBC 里一条报文的信号布局，就该进 [2-L2进阶](../2-L2进阶/README.md) 爬传输层与网络管理了。
