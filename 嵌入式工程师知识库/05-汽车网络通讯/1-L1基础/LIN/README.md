## 定位

LIN 总线：以 CAN 的底子快速拿下的低速低成本网——协议原理起坡（L1），LDF 与配置、排障为【L2】——归带从主，整目录在 1-L1基础 带内，个别子目录以主等级标注为准。

## 子目录（带内索引）

| 目录 | 主等级 | 定位 |
|---|---|---|
| [协议原理](协议原理/README.md) | 【L1】 | 主从与调度表、帧结构、波特率与同步。（L1 起坡，起读入口） |
| [LDF与配置](LDF与配置/README.md) | 【L2】 | LDF 结构与信号映射。（篇级标【L2】） |

推荐序：协议原理 → LDF与配置（对照 [通讯数据库](../通讯数据库/README.md) 的 LDF 篇）→ 排障。
