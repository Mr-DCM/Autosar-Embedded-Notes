# 02-位时序与采样点

> 一句话定位：一个"位"不是瞬间，而是被切成同步段/传播段/相位缓冲段 1/2 四段的可调时间片——采样点定在哪，决定了长总线能不能用、不同节点会不会互相制造 CRC 错；CanControllerPropSeg 那堆参数全在这一篇落地。
> 等级：L1→L2 ｜ 前置：[01-帧格式](01-帧格式.md)

## 原理

位速率的倒数是**位时间**（如 500 kbps → 2 µs）。控制器内部把位时间切成若干**时间份额 Tq**，再分成四段：

```wavedrom
{signal: [
  {name: '总线电平', wave: '0....1....'},
  {name: '位内分段', wave: 'x3456x3456', data: ['同步段','传播段','相位缓冲段1','相位缓冲段2']}
], head: {text: '位四段划分（采样点=相位缓冲段1末尾=相位缓冲段2起点）', tick: 0}}
```

| 位段 | 长度（CAN 2.0） | 作用 |
|---|---|---|
| 同步段 SYNC_SEG | 固定 1 Tq | 位边沿应落在这里；边沿落在段外→相位误差 e |
| 传播段 PROP_SEG | 1~8 Tq | 给信号往返传播时间（总线+收发器延迟）留预算 |
| 相位缓冲段 1 PHASE_SEG1 | 1~8 Tq | 吸收**正**相位误差（可被重同步拉长） |
| 相位缓冲段 2 PHASE_SEG2 | 2~8 Tq | 吸收**负**相位误差（可被重同步缩短）；末尾即下一位起点 |

- **采样点**：PHASE_SEG1 结束的瞬间，控制器一次性采电平定这一位是 0 还是 1。位置用百分比表示：
  `采样点 = (1 + PROP + PHASE1) / (1 + PROP + PHASE1 + PHASE2)`
- **为什么要留传播段**：发送方在第 n 位驱动总线，最远节点要经过线缆+两级收发器延迟才看到；仲裁要求最远节点的回传电平在**发送方采样前**到达——所以 `2×单程延迟 + 收发器延迟 < 传播段 + PHASE1`，这就是**总线越长传播段预算越大、速率上限越低**的根源（量化见 [收发器/03-终端电阻与拓扑](../收发器与物理层/03-终端电阻与拓扑.md)）。

## 详解：重同步、SJW 与参数表

### 硬同步与重同步

| 机制 | 触发 | 动作 |
|---|---|---|
| 硬同步 | 总线空闲后第一个显性边沿（SOF） | 位时间计数器直接对齐边沿 |
| 重同步 | 帧内**每个隐性→显性边沿** | 边沿落在同步段之前→拉长 PHASE1；落在之后→缩短 PHASE2 |
| SJW（同步跳转宽度） | 上述调整的幅度上限 | 一次最多调 SJW 个 Tq（1~4，且 ≤ min(PHASE1, PHASE2)） |

SJW 太小：晶振偏差+噪声下追不上相位差，采样点漂移；SJW 太大：一次纠正过头、来回振荡。工程常取 SJW=PHASE2（或 1/4 位时间量级）。帧内没有足够边沿的长隐性串（靠填充位缓解，见 [03-仲裁与填充](03-仲裁与填充.md)）正是重同步的软肋——这也是填充位存在的物理原因之一。

### 典型参数组合（500 kbps，采样点 75%，总线 20 Tq）

| 参数 | 值 | 说明 |
|---|---|---|
| Tq | 100 ns | BRP 分频后（如 40 MHz / 2 / 20） |
| SYNC_SEG | 1 Tq | 固定 |
| PROP_SEG | 7 Tq | 传播预算 700 ns ≈ 单程 300 ns+收发器 2×255 ns 量级 |
| PHASE_SEG1 | 7 Tq | 采样点 = 15/20 = **75%** |
| PHASE_SEG2 | 5 Tq | ≥ SJW |
| SJW | 4 Tq | 上限 |

工程惯例：采样点两大主流 **75%**（多数 OEM 高速网）与 **87.5%**（CiA/J1939 血统，利于长总线传播预算）。位时间工程推荐 8~25 Tq；Tq 太多→分频细但重同步粒度细，太少→采样点难以凑准。

### 计算示例：500 kbps / 75% / 20 Tq 的完整推导

| 步骤 | 计算 | 结果 |
|---|---|---|
| 定 Tq | 位时间 2 µs ÷ 20 Tq | 100 ns |
| 定 BRP | CAN 时钟 40 MHz，要得到 100 ns Tq → 分频 4 | CAN 时钟÷4 = 10 MHz（Tq=100 ns） |
| 凑采样点 | 目标 75% → 采样前 15 Tq = 1 SYNC + PROP + PHASE1 | PROP=7、PHASE1=7 |
| 剩余段 | 20 − 15 | PHASE2=5 |
| 验 SJW | SJW ≤ min(7,5)，取 | 4 |
| 验传播预算 | 传播段+PHASE1 = 14 Tq = 1.4 µs > 2×单程线缆+收发器延迟 | 通过（线长 <50 m 量级） |

同样的位速率可以有多组解（20 Tq/75% 与 16 Tq/87.5% 都合法）——**全网用哪组由 OEM 规范统一指定**，节点各自最优解拼在一起就是事故。

## 配置层/工程关联

- AUTOSAR Can 驱动位时序参数：**CanControllerPropSeg / CanControllerSeg1 / CanControllerSeg2 / CanControllerSyncJumpWidth**，挂在 CanControllerBaudrateConfig（含 CanControllerBaudRate、CanControllerSamplePoint 百分比）下——工具按你给的"波特率+采样点"反解 Tq 分配，也可手调 Tq 分配；
- TC377 M_CAN 对应 NBTP 寄存器（NTSEG1/NBRP/NSJW…），S32K FlexCAN 对应 CBT 寄存器——改配置先确认落到哪个寄存器，再对 CANoe 实测；
- **同一条总线所有节点采样点必须一致**（OEM 一般给统一值±小公差）；CAN-FD 数据段另有一套采样点（惯例 80% 上下），两套独立配置，见 [CAN-FD/01-FD帧与BRS](../CAN-FD/01-FD帧与BRS.md)；
- 晶振：理论容差上限约 0.5%~1.58%（与位时序配置有关），项目实践按 **≤0.5%（100 ppm 量级晶振）** 选型，给重同步留裕量。

## 易错点与陷阱

1. **采样点不一致=偶发 CRC 错（经典案例）**：现象是产线偶发误码、CANoe 错误帧零星、两节点单独自环都好。原因：新节点采样点 60%，全网 75%，短线掩盖、温度/波特率微偏时爆雷。对策：逐节点读回采样点配置统一；把"采样点核对"写进节点准入 checklist。
2. **波特率对了采样点错了**：CANoe 能收到大部分帧不代表时序健康——误码率随传播延迟浮动。对策：验收用示波器量实际采样点或跑长时间误码统计。
3. **传播段给太小硬拉长总线**：现象是加长试验线缆后错误帧暴增。原因：回传信号晚于发送方采样点到达。对策：降速率或后移采样点，把线长算进传播段预算。
4. **SJW 忘了 ≤ min(PHASE1, PHASE2)**：配置工具一般会拦，手写寄存器代码（iLLD 直接设 M_CAN）容易越界，导致同步行为异常。
5. **Tq 分配凑不出目标采样点**：位时间取 10 Tq 想要 87.5% 无解（需 8.75 Tq）。对策：换 Tq 总数（如 16/20/24 Tq），先定采样点再定分频。
6. **拿 FD 数据段参数去配仲裁段**：两套位时序相互独立，抄配置时张冠李戴是最常见的"低级但致命"错误。

## 面试高频题

**Q1：位时间分哪四段，各干什么？**
答：同步段（1 Tq，边沿基准）、传播段（容纳信号往返+收发器延迟）、相位缓冲段 1/2（吸收晶振偏差与相位抖动，可被重同步增减）。采样点在 PHASE1 末尾。

**Q2：采样点为什么典型取 75%/87.5%？**
答：前移留传播预算（长总线/大延迟）、后移提高抗抖动能力。75% 是高速短网主流，87.5% 出自 CiA/J1939 体系；核心要求是**全网一致**，不一致直接制造偶发 CRC 错。

**Q3：SJW 是什么？设大设小各有什么问题？**
答：单次重同步最大调整量（1~4 Tq，≤min(PHASE1,PHASE2)）。太小追不上相位误差，太大一次纠正过头引起振荡。

**Q4：为什么总线越长速率越低？**
答：仲裁要求信号在最远节点与发送方之间一个位时间内往返可判，位时间必须 ≥ 2×单程传播+收发器延迟+采样裕量——传播段预算决定位时间下限，速率自然受限。
