# CAN

> 上级目录：[1-L1基础](../../README.md)
> 主等级：L1→L2

## 定位

CAN 总线全家桶，全区第一主线：协议原理与收发器是主业地基（L1），CAN-FD 与总线错误与恢复为【L2】深水——归带从主，整目录在 1-L1基础 带内，个别子目录以主等级标注为准。

## 子目录（带内索引）

| 目录 | 主等级 | 定位 |
|---|---|---|
| [协议原理](协议原理/README.md) | 【L1→L2】 | 帧格式、位时序与采样点、仲裁与填充、错误帧。（L1 地基，起读入口） |
| [收发器与物理层](收发器与物理层/README.md) | 【L2】 | TJA1145 等收发器、唤醒休眠、终端电阻与拓扑。 |
| [CAN-FD](CAN-FD/README.md) | 【L2】 | FD 帧、BRS、与经典 CAN 共存、收发器要求。 |
| [总线错误与恢复](总线错误与恢复/README.md) | 【L2→L3】 | 错误计数器、busoff 恢复策略、排障实录。（篇级标【L2】，排障实录可至 L3） |

推荐序：协议原理 → 收发器与物理层 → CAN-FD → 总线错误与恢复（配合 [2-L2进阶/传输层](../../2-L2进阶/传输层/README.md) 与 [09-调试与测试/总线工具](../../../09-调试与测试/2-L2进阶/总线工具/README.md) 实操）。
