# 01-收发器选型TJA1145

> 一句话定位：MCU 的 CAN 控制器只认 TXD/RXD 逻辑电平，把差分双绞线扛起来的是收发器——本篇以 NXP TJA1145（局部网络收发器）为样本，讲清它在链路中的位置、四种工作模式、选型参数表与典型应用电路要点。
> 等级：L1→L2 ｜ 前置：[01-帧格式](../协议原理/01-帧格式.md)

## 原理

收发器夹在控制器与总线之间，做**单端逻辑 ↔ 差分电平**的双向翻译：

```
        MCU 内部                         收发器                        总线
 ┌──────────────┐   TXD(0=发显性)  ┌─────────────────┐  CANH ────●———●———●——— (终端120Ω)
 │ CAN 控制器    │────────────────▶│ 发送驱动器       │            │
 │ (MCAN/FlexCAN)│   RXD(0=显性)   │ 接收比较器       │  CANL ────●———●———●——— (终端120Ω)
 └──────────────┘◀────────────────│ 模式管理/唤醒检测 │            ...
                                  │ 电源管理(INH)     │  BAT ◀── KL30 常电
                                  └─────────────────┘  VIO ◀── MCU IO 电源(3.3V)
```

- 发送：TXD=0 → 收发器在 CANH/CANL 上打出约 2 V 差分（显性）；TXD=1 → 释放总线，靠两端终端电阻回到约 2.5 V/2.5 V（隐性）；
- 接收：差分比较器把 V(CANH)−V(CANL) 还原成 RXD 电平（显性约 2 V → RXD=0）；
- 电源角色：**BAT 接 KL30 常电**（休眠时唯一带电的脚），VCC 供内部 5V 电路，VIO 跟随 MCU IO 电压（3.3V/5V 自适配，省掉电平转换）。

### TJA1145 的定位与亮点

TJA1145 不是"又一个 1050"，它是 **ISO 11898-2:2016 局部网络（Partial Networking）收发器**：

| 亮点 | 说明 | 工程意义 |
|---|---|---|
| 超低待机/休眠电流 | Sleep/Standby 下电池侧电流降到 µA 量级 | 满足整车静态电流预算 |
| 整节点断电（INH） | Sleep 时 INH 变高阻，关断外部稳压器，MCU 可完全下电 | 休眠电流省到底 |
| 总线唤醒+局部唤醒 | 标准 CAN 唤醒图案（显-隐-显）/选择性唤醒帧 + WAKE 引脚边沿 | 支持整车网络唤醒策略 |
| 选择性唤醒（PN） | 按 ID/掩码过滤唤醒帧，50k~1M 支持选择性唤醒 | 本 ECU 可在网段活跃时继续睡 |
| FD-passive（/FD 后缀） | 等待唤醒时忽略 CAN-FD 帧，不误醒不报错 | 经典网向 FD 混跑平滑过渡（见 [CAN-FD/02](../CAN-FD/02-与经典CAN共存.md)） |
| FD 快相时序 | 2 Mbit/s 数据段时序保证 | 500k+2M 主流组合可用（5M 需换 TJA1462/TCAN4550 类，见 [CAN-FD/03](../CAN-FD/03-收发器要求.md)） |
| SPI 控制 | 16/24/32 位 SPI 做模式控制/诊断/状态回读 | 模式不再是简单 STB 引脚 |

## 详解：模式表与选型参数

### 工作模式表（TJA1145 口径）

| 模式 | 进入方式 | 收发能力 | 电流水平 | 唤醒能力 |
|---|---|---|---|---|
| Normal | SPI 命令 | 全双工收发 | 正常（mA 级） | — |
| Standby | SPI 命令/上电默认 | 不发不收，监测总线唤醒图案 | 低（µA~百µA 级） | 总线图案/本地 WAKE/SPI |
| Sleep | SPI 命令 | 同 Standby，且 INH 高阻→外部稳压器关闭 | 最低（µA 级） | 总线图案/本地 WAKE（SPI 需 VIO 在位） |
| Off/掉电 | BAT 移除或 VIO/VCC 掉电 | 总线引脚真正浮空，不拖累总线 | — | 仅冷启动 |

注意与"简单收发器"（如 TJA1051，STB 引脚两态）的差异：TJA1145 的模式迁移、唤醒源使能、诊断（TXD 显性超时、欠压/过温、唤醒原因）全走 SPI 寄存器——驱动上多一层 CanTrcv 逻辑（见配置层）。

### 选型参数速查表（横向对比用）

| 参数 | 为什么重要 | TJA1145 取值口径 |
|---|---|---|
| FD 数据段速率 | 决定 2M/5M 可用性 | 时序保证到 2 Mbit/s |
| 休眠电流（BAT） | 整车静态电流预算 | Sleep 下 µA 级（具体见数据手册速查表） |
| 唤醒源 | 匹配整车唤醒策略（网管/PN/硬线） | 总线图案+选择性唤醒帧+WAKE 引脚 |
| 环路延迟及其对称性 | 高速率下位失真 | FD 收发器关键指标（详见 [CAN-FD/03](../CAN-FD/03-收发器要求.md)） |
| 总线耐压/抗扰 | 12V/24V 系统、抛负载、ISO 7637-3 | 总线脚耐 ±58 V，通过瞬态脉冲测试 |
| VIO 范围 | 3.3V MCU 直连 | 2.85~5.5 V |
| 封装/温度 | 布板与布置 | SO14/HVSON14，AEC-Q100 |

### 引脚与典型应用电路要点

- **BAT 前端**：串接反接保护+滤波，BAT 是休眠时唯一带电支路——这颗的前端漏流直接吃掉整车预算；
- **INH 用法**：驱动外部稳压器使能；Sleep=高阻断电，唤醒后 INH 拉高→稳压器上电→MCU 启动→SPI 把收发器置 Normal——**上电时序要留稳压器爬升时间**；
- **WAKE 引脚**：接 KL15 或专用唤醒线，边沿触发；滤波电容对抗毛刺（防假醒，见 [02-唤醒与休眠](02-唤醒与休眠.md)）；
- **TXD/RXD**：走 MCU 的 CAN 模块引脚，VIO 决定电平；TXD 显性超时保护是收发器对"MCU 卡死拉低 TXD"的自卫；
- **总线侧**：CANH/CANL 到连接器的走线按差分对待（等长、少过孔），TVS/共模电感按 03 区规范（见 [二极管与TVS](../../../../03-硬件基础/1-L1基础/原理图阅读/常用元器件符号与封装/02-二极管与TVS.md)、[EMC入门](../../../../03-硬件基础/3-L3高级/PCB常识/04-EMC入门.md)）；
- 原理图评审先看三件事：BAT 支路保护、INH 所控稳压器、VIO 是否真接 MCU IO 电源。

## 配置层/工程关联

- AUTOSAR 的收发器抽象：**CanTrcv 模块**（CanTrcv_SetOpMode：NORMAL/STANDBY/SLEEP），CanIf 经 CanIfTrcvRef 调用它；MCAL 侧 TC377/S32K 的 CanDrv 只管控制器，收发器模式切换由 CanTrcv/Trcv_9x 层实现（TJA1145 即 SPI 版驱动）；
- 模式联动：CanSM 在启动/停网时发起 CanTrcv_SetOpMode(NORMAL/SLEEP)，与网络管理的睡眠节奏配合（见 [网络管理](../../../2-L2进阶/网络管理/README.md)）；
- 诊断可用性：TJA1145 的唤醒原因/欠压/过温状态可经 CanTrcv 上报 Dem——排查"偶发掉线"时先读收发器状态寄存器再怀疑总线；
- 唤醒源裁剪：不需要的功能（如选择性唤醒）关闭可再降休眠电流，但要与整车网络架构确认。

## 易错点与陷阱

1. **把 TJA1145 当 TJA1051 用（只接 TXD/RXD/STB）**：它没有 STB 模式引脚，模式走 SPI——原理图画成"上电即 Normal"的接法，实际默认进 Standby，现象是"收发器完全不工作"。对策：走完整 SPI 初始化。
2. **VIO 忘接或接 5V 而 MCU 是 3.3V**：RXD 输出电平超 MCU IO 耐压/或 SPI 电平不匹配。对策：VIO 与 MCU IO 电源同网。
3. **INH 控制的稳压器启动慢**：唤醒后 MCU 复位释放前收发器还没被 SPI 置 Normal，第一帧网络管理报文发不出去。对策：初始化顺序先 Trcv 再 Can，留稳压器爬升时间。
4. **休眠电流超标**：BAT 支路分压/指示灯/上拉把 µA 级 Sleep 拖成 mA 级。对策：休眠电流测试从 BAT 支路逐项断开排查。
5. **FD 速率误配**：TJA1145 时序保证到 2 Mbit/s，项目要 5M 数据段则选型错误。对策：按数据段速率选型，见 [CAN-FD/03-收发器要求](../CAN-FD/03-收发器要求.md)。
6. **经典网用非 /FD 后缀还混跑 FD**：等待唤醒时收到 FD 帧可能误醒。对策：混跑网段选 /FD 后缀（FD-passive）。

## 面试高频题

**Q1：收发器在 CAN 链路里做什么？没有它会怎样？**
答：做单端逻辑（TXD/RXD）与差分总线电平（CANH/CANL）的双向转换，并承担驱动能力、终端偏置、待机/唤醒与总线保护；没有它控制器无法驱动双绞线，也无法在共模干扰下可靠鉴别 0/1。

**Q2：TJA1145 相比普通高速收发器的核心差异？**
答：超低功耗 Standby/Sleep + INH 整节点断电 + 总线/本地双路唤醒 + 选择性唤醒（局部网络），控制接口从 STB 引脚升级为 SPI（模式/诊断/唤醒原因可编程）；FD 变体支持 FD-passive 与 2 Mbit/s 数据段。

**Q3：Normal/Standby/Sleep 三个模式怎么分工？**
答：Normal 全功能收发；Standby 只监听总线唤醒图案（低功耗）；Sleep 在 Standby 基础上 INH 高阻、外部稳压器断电（电流最低）。唤醒后先进 Standby 再由 MCU 经 SPI 置 Normal。

**Q4：选 CAN 收发器主要看哪些参数？**
答：数据段速率上限（FD）、休眠电流与唤醒源、环路延迟及对称性、总线耐压与抗瞬态（ISO 7637）、VIO 是否匹配 MCU、封装温度与 AEC 认证。
