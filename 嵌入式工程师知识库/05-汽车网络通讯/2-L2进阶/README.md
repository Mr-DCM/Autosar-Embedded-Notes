# 2-L2进阶

> 上级目录：[05-汽车网络通讯](../README.md)

## 定位

**上层栈与整车级问题。** 传输层讲 CanTp 分段（ISO 15765-2）与 LinTp——大报文怎么拆着过 8 字节的车；网络管理讲 OSEK NM vs AUTOSAR NM 状态机、睡眠与假醒、部分网络——整车功耗问题的主战场。两个子目录都是"配得出 + 排得掉"的工程级内容。

- 主标签：**【L2】**（前置：1-L1基础 的 CAN 协议原理；传输层另衔接 06 区诊断基础）
- 何时进：CAN/LIN 地基扎实、开始配诊断或追睡眠电流问题；
- 何时离开：能独立配出一条 CanTp 通道并排查多帧丢帧、能沿着 NM 状态机定位假醒原因，即算出师——之后按问题回查本带。
