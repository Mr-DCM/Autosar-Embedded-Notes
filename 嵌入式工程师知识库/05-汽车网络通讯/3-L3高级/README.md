# 3-L3高级

> 上级目录：[05-汽车网络通讯](../README.md)

## 定位

**深水区参考层。** FlexRay 仅 1 篇概览——本库平台与主业都用不到，属于"知道它在哪、面试不哑火"的了解级，是"点到即止"的典型；车载以太网三篇（100BASE-T1、SOME/IP、DoIP）面向智驾数据与诊断刷写的下一代骨干网，按项目需要选读。

- 主标签：**【L2→L3】**（前置：1-L1基础 的 CAN 地基；FlexRay 无工程前置）
- 何时进：不是"读完 L2 才准进"——遇到以太网刷写、SOME/IP 服务设计等具体场景时随时进来查；
- 何时离开：没有"离开"——按问题驱动使用，读完即走。

## 点到即止声明

本带是**深水区参考层，不要求按序通读**。正确用法：**概念 + 排障清单 + 延伸指针，深入靠工程实践**——FlexRay 读一篇概览即可（概念：静态/动态段、双通道冗余；用到时再查协议规范）；车载以太网按场景直读对应篇（刷写查 DoIP、服务化查 SOME/IP），机制细节以规范文档为准，笔记目标是帮你建立选型与排障的判断框架，不是替你读协议。没有对应问题时，本带可长期搁置。
