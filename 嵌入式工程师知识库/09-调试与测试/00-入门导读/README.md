# 00-入门导读

> 上级目录：[09-调试与测试](../README.md)

## 定位

**半天建立调试全景视角。** 一篇导读跟着一个"报文丢了"的 bug 从接到问题走到关闭（复现→假设→工具三件套→定位→复盘），把四件工具（调试器/总线工具/方法论/案例库）各管哪摊摆成一张地图，并给出三种典型故障域的先看哪里直觉——少术语、多直觉。读完后你有了本区地图与"先复现、再分治、只改一个变量"的三原则，再进 L1 带就不会在工具海洋里迷路。

- 主等级：**L1**（前置：无，可从零直接读）
- 何时进：第一次接手 bug、只会 printf 不知道 TRACE32/CANoe 分工、遇到问题不知从哪下手——都从这里起步；
- 何时离开：能不查资料说出"四件工具各管什么、三种故障域各先看什么、调试三原则是什么"，就该进 1-L1基础 学工具了——导读讲直觉，不讲工具操作细节。
