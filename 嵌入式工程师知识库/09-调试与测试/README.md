# 09-调试与测试

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

主业深挖：TRACE32/CANoe 等工具 + 调试方法论 + 踩坑案例库，按 L1~L3 分带组织——先用一个 bug 的完整旅程建全景地图，再在 L1 带拿下调试器三件套（TRACE32/JTAG/日志），L2 带爬总线工具与单元测试、开始攒案例库，方法论套路化打法归入 L3 带但不设门槛（主业排障必读，随时可提前读）。

## 四带结构

| 带 | 定位 |
|---|---|
| [00-入门导读](00-入门导读/README.md) | 半天入门地图：一个"报文丢了"bug 的完整旅程 + 工具箱地图 + 三种故障域直觉。 |
| [1-L1基础](1-L1基础/README.md) | 工具入门：调试器三件套（TRACE32、DAP/JTAG/SWD、串口与 RTT 日志）——先能打断点、看变量、读日志。 |
| [2-L2进阶](2-L2进阶/README.md) | 工程级工具与资产沉淀：总线工具（CANoe/CAPL/CANape/CANdela 与 ODX）、单元测试与自动化（Unity/CppUTest/Tessy）、踩坑案例库（一坑一档）。 |
| [3-L3高级](3-L3高级/README.md) | 套路总结层：调试方法论（复位溯源、Trap/HardFault、busoff、睡眠电流假醒、NvM 失效）——套路化打法可提前读，主业排障必读。 |

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：一个 bug 从接到问题到关闭的完整旅程，四件工具各管哪摊；
2. [1-L1基础/调试器](1-L1基础/调试器/README.md)：工具入门第一站——[01-TRACE32](1-L1基础/调试器/README.md) 先能打断点、看变量、读日志，再补 DAP/JTAG/SWD 与串口/RTT；
3. [2-L2进阶/总线工具](2-L2进阶/总线工具/README.md)：[01-CANoe](2-L2进阶/总线工具/README.md) 建第一个仿真工程，学会发报文/看 trace，之后按需爬 CAPL/CANape/CANdela；
4. [3-L3高级/调试方法论](3-L3高级/调试方法论/README.md)：套路化打法可提前读——[01-复位溯源](3-L3高级/调试方法论/README.md) 起步，主业排障必读；
5. [2-L2进阶/踩坑案例库](2-L2进阶/踩坑案例库/README.md)：[00-一坑一档模板](2-L2进阶/踩坑案例库/README.md)——从此每个 bug 都变成资产；单元测试（[单元测试与自动化](2-L2进阶/单元测试与自动化/README.md)）结合 01 区 C 功底给核心函数补测试。
