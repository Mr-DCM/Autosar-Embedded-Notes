# 2-L2进阶

> 上级目录：[09-调试与测试](../README.md)

## 定位

**工程级工具与资产沉淀。** 总线工具把"看报文"升级成"玩总线"——CANoe 建仿真工程、CAPL 写自动化、CANape 标定测量、CANdela 与 ODX 管诊断数据库；单元测试与自动化在 bug 出生前掐死它（Unity/CppUTest/Tessy）；踩坑案例库让每个修完的 bug 变成资产——一坑一档：现象→定位→根因→预防。

- 主标签：**【L2】**（前置：1-L1基础 的调试器入门；总线工具衔接 05 区 CAN 地基，单元测试衔接 01 区 C 功底）
- 何时进：调试器已上手、开始独立排障或需要给核心函数补测试；
- 何时离开：能用 CANoe 独立完成"建工程→发报文→看 trace→过滤/触发"，能搭起一个 Unity 单测骨架，每个修完的 bug 都落一档——即算出师，之后按问题回查本带。
