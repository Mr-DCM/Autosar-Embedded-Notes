# 1-L1基础

> 上级目录：[09-调试与测试](../README.md)

## 定位

**工具入门。** 调试器三件套——TRACE32（连接、断点、变量观察）、DAP/JTAG/SWD（调试口与连接原理）、串口与 RTT 日志（最朴素也最常用的"飞行记录仪"）。目标是先能用：能连上板子、能打断点、能看到变量的值、能读日志——这是本区所有后续内容的手上功夫。

- 主标签：**【L1→L2】**（前置：读完 [00-入门导读](../00-入门导读/README.md) 即可进；串口/RTT 与 JTAG 深入篇可达【L2】）
- 何时进：读完导读、第一次接手 bug 或第一次要连调试器；
- 何时离开：能独立连接 TRACE32 并完成"打断点→看变量→单步跟一次调用"，能串口打印带时间戳的日志——就该进 [2-L2进阶](../2-L2进阶/README.md) 学总线工具了。
