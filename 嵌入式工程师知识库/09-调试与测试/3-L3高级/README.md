# 3-L3高级

> 上级目录：[09-调试与测试](../README.md)

## 定位

**套路总结层。** 调试方法论把散落的现场经验收成检查单——复位溯源（谁把板子重启了）、Trap/HardFault（跑飞后从哪里查起）、busoff（总线断了怎么救）、睡眠电流假醒（车不睡谁干的）、NvM 失效（数据为什么丢了）。这一带是本区最贴近"主业排障"的内容。

- 主标签：**【L2→L3】**（前置：1-L1基础 调试器上手；复位溯源/busoff 等篇以【L2】直觉为主，复杂 Trap 链分析可达【L3】）
- 何时进：不是"读完 L2 才准进"——接到复位/Trap/busoff/假醒/NvM 问题时随时进来翻；
- 何时离开：没有"离开"——按问题驱动使用，套路内化后本带变成速查手册。

## 点到即止声明

本带是**套路总结层，不要求按序通读，也不设等级门槛**。方法论是套路总结，几篇都可直接提前读——主业排障必读，接到对应问题就按篇索骥；深水区（如复杂 Trap 链分析）以工程实践为主，笔记给的是决策树与延伸指针，不是替你跑完每一次现场。
