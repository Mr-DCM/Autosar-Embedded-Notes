# 00-入门导读

> 上级目录：[07-AUTOSAR架构](../README.md)

## 定位

**半天入门 AUTOSAR 视角。** 一篇导读把分层架构讲成一座城的分区图——应用层是商户、RTE 是统一服务窗口、BSW 是市政系统、MCAL 是地基管网，再顺着"一帧信号从 SWC 到总线"的旅程给四大栈各归一句职责，最后建立"ARXML 图纸→生成代码"的配置驱动直觉——少公式、多直觉。读完后你有了本区地图与四层坐标，再进任何子目录都知道自己在哪一层。

- 主等级：**L1**（前置：无，可从零直接读；若已读过 [05 区导读](../../05-汽车网络通讯/00-入门导读/README.md) 更佳——报文之旅的下半程在本区）
- 何时进：刚接触 AUTOSAR 缩写体系、只见配置工具没见过分层全貌、分不清 RTE 与 BSW/MCAL 边界——都从这里起步；
- 何时离开：能不查资料画出四层结构、说出 BSW 四个栈各管什么、解释"换芯片为什么不用改应用"，就该进 [1-L1基础](../1-L1基础/README.md) 读分层架构详解了——导读讲直觉，不讲逐模块配置。
