## 定位

**分层图与规范工具。** 架构总览是入门第一课——把导读里的"城市分区图"落成正式分层图，知道每层管什么、层间边界在哪；SWS阅读法是方法论工具——学会查 AUTOSAR 规范原文（SWS），之后读任何模块笔记都能回到规范自证。两者是进入 L2 带四大栈之前的地基与"字典"。

- 主标签：**【L1→L2】**（前置：读完 [00-入门导读](../00-入门导读/README.md) 即可进）
- 何时进：读完导读、准备系统性进入 AUTOSAR 世界；
- 何时离开：能画出四层结构并说清层间边界、能在 SWS 里定位一个模块的某个规定，就该进 [2-L2进阶](../2-L2进阶/README.md) 爬四大栈主线了。
