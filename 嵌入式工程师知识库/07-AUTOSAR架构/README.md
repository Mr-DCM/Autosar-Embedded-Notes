# 07-AUTOSAR架构

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

核心区：分层架构、RTE、系统服务栈、通讯栈、内存栈与多核集成，按 L1~L3 分带组织——先用一座城的分区图建分层直觉，再在 L1 带入脑分层图与 SWS 查法，L2 带爬四大栈主线，RTE/加密/多核深水区点到即止。

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：一座城的分区图 + 四栈各表 + 本区地图，先建分层直觉；
2. [1-L1基础/架构总览](1-L1基础/架构总览/README.md)：从 01-分层架构起读，把导读里的城市图落成正式分层图；
3. [1-L1基础/SWS阅读法](1-L1基础/SWS阅读法/README.md)：学会查 AUTOSAR 规范原文，之后所有模块笔记都能自证；
4. [2-L2进阶/IO栈](2-L2进阶/IO栈/README.md)：从最薄的 IoHwAb 看 MCAL 与 ASW 如何接线；
5. [2-L2进阶/系统服务栈](2-L2进阶/系统服务栈/README.md)：以 EcuM 上下电时序为主线串起服务模块，再进 [2-L2进阶/方法论与ARXML](2-L2进阶/方法论与ARXML/README.md) 学手读配置图纸。
