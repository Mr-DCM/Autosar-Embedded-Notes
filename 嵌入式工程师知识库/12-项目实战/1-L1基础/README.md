# 1-L1基础

> 上级目录：[12-项目实战](../README.md)

## 定位

**第一次动手的主阵地。** 练手项目按难度递增四篇：MCAL 点灯（跑通第一个 AUTOSAR 工程的喜悦）→ PWM+ADC（模拟量进出+任务调度）→ CAN 裸驱收发（不经完整通讯栈直连 CanDrv，体会驱动契约）→ LIN 节点（主从调度表节奏）。每篇都是"目标→步骤→验收→回链深水区"的最小闭环，对应导读时间线上的"站 4~站 6"缩微版——配置、编码、上板验证一气呵成。

- 主标签：**【L1→L2】**（前置：[00-入门导读](../00-入门导读/README.md) 已读，知道项目长什么样；MCAL 概念看 [04 区导读](../../04-MCAL与外设驱动/00-入门导读/01-MCAL第一课-从点灯到分层驱动.md) 更顺）
- 何时进：看过 AUTOSAR 分层图但从没烧过板子、想在真实工具链（EB tresos/S32DS）里走一遍"配置→生成→编译→调试"；
- 何时离开：四篇都能独立复现并在板子上看到现象、说清每一步生成的代码落在哪一层——即达标。
