# 12-项目实战

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

全库收官区：把 01~11 区的知识按"项目时间线"串成叙事——双平台（TC377/S32K）工程模板、按难度递增的练手项目、项目复盘方法论。先用一篇导读从 RFQ 走到 SOP，看清一个 ECU 项目三段八站里软件工程师干什么、交付什么、每一步回链哪个区；再在 L1 带亲手跑通 MCAL 点灯→PWM+ADC→CAN 裸驱→LIN 节点的递增阶梯；L2 带把散件组织成可交付的工程骨架（Tresos/DaVinci 配置流程、目录结构、Git 分支与样件交付节奏）；L3 带用复盘模板把项目产出沉淀为可复用的配置与 CDD 资产。本区讲"怎么把知识组织成工程"；单项知识深度在 01~11 区，两区互链成网。

1. [00-入门导读](00-入门导读/README.md)（1 篇）：RFQ→SOP 全景走一遍，知道每站在干嘛、交付什么；
2. [练手项目](1-L1基础/练手项目/README.md)：从 [01-MCAL点灯](1-L1基础/练手项目/01-MCAL点灯.md) 到 [04-LIN节点](1-L1基础/练手项目/04-LIN节点.md)，四篇递增把最小闭环跑通；
3. [S32K工程模板](2-L2进阶/S32K工程模板/README.md)：把练手散件组织成 S32K 工程骨架（生态最熟，先走这条）；
4. [TC377工程模板](2-L2进阶/TC377工程模板/README.md)：换平台再走一遍，体会可移植部分与平台差异；
5. [项目复盘](3-L3高级/项目复盘/README.md)：用复盘模板把 A/B 样件交付与问题单闭环沉淀成个人资产，完成收官。
