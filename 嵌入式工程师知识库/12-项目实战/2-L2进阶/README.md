# 2-L2进阶

> 上级目录：[12-项目实战](../README.md)

## 定位

**工程骨架主阵地：一个"像样"的工程长什么样。** S32K 与 TC377 双模板各一篇，讲同一套骨架在不同平台的落地：目录分层（MCAL/BSW/CDD/应用/配置脚本各自安家）、Tresos/DaVinci/S32DS/AURIX Dev Studio 的配置-生成-集成流程、Git 分支策略与 A/B 样件交付节奏（release 分支打 tag、软件包可追溯）、以及"从练手散件到工程骨架"要补的规矩（MemMap 分区、Det 开发期开关、命名规范）。读完你拿到新项目就知道第一周该建什么目录、迁什么基线。

- 主标签：**【L2】**（前置：[1-L1基础/练手项目](../1-L1基础/练手项目/README.md) 已跑通至少点灯与 CAN 两篇；工具用法见 [10 区](../../10-工具链与工程化/README.md)）
- 何时进：能在板上跑通功能但工程目录一团乱、没打过 release tag、说不清配置工具生成物和手写代码怎么混合编译；
- 何时离开：能白板画出双平台任一的工程目录树、说清一次 A 样件交付从代码冻结到出包的完整步骤——即达标。
