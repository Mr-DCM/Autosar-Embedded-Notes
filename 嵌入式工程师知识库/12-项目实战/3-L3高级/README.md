# 3-L3高级

> 上级目录：[12-项目实战](../README.md)

## 定位

**收官沉淀带：项目做完，留下了什么？** 一个复盘模板，把项目周期里的关键产出——需求追溯链、配置基线（Tresos/DaVinci 工程快照）、自研 CDD、问题单库——分门别类沉淀成可复用资产，下次新项目直接站在上次的肩膀上。这一带不引入新技术点，它考验的是"工程资产化"的意识和纪律：哪些配置值得抽成模板、哪些坑值得进个人踩坑库、哪些 CDD 可以平移到下一个项目——对应导读时间线"站 8"之后的个人成长曲线。

- 主标签：**【L2→L3】**（前置：[2-L2进阶](../2-L2进阶/README.md) 双工程模板已读，且最好亲身跑完过 [练手项目](../1-L1基础/练手项目/README.md) 四篇的完整闭环）
- 何时进：项目交付过至少一个样件版本、问题单闭环过两只手数不过来的数量、开始觉得"下次还要从头再来一遍"很痛；
- 何时离开：能拿复盘模板对刚做完的项目填出一份完整档案、列出三件可直接复用的资产——即达标。
