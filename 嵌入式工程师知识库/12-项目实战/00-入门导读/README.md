# 00-入门导读

> 上级目录：[12-项目实战](../README.md)

## 定位

**半天建立"项目全景"的收官地图。** 一篇导读把一个 ECU 项目从 RFQ 询价到 SOP 量产按时间线完整走一遍——概念（需求/架构）、开发（BSW 配置/CDD/测试）、验证量产（联调/问题单闭环/SOP）三段各自的主旋律，八个站点工程师在干什么、交付什么，每一步回链 01~11 区对应深水笔记；再用一张"问题单的一生"流程图体会项目日常的工作流单位——少细节、多坐标。读完后你拿着任何项目的排期表都能对号入座，也知道本区三个带各自在练什么。

- 主等级：**L1**（前置：无，可从零直接读；若已读过 [07 区导读](../../07-AUTOSAR架构/00-入门导读/README.md) 与 [09 区导读](../../09-调试与测试/00-入门导读/README.md) 更佳——本文会把那边的知识钉到项目时间线上）；
- 何时进：写过代码但没见过完整项目、分不清 A/B/C 样件节奏、不知道 DOORS/Jira/问题单在项目里怎么流转、说不清 RFQ 到 SOP 之间软件工程师都干嘛——都从这里起步；
- 何时离开：能复述三段八站的主线、说出每站的交付物、把问题单闭环流程画出来，就该进 [1-L1基础](../1-L1基础/README.md) 动手了——导读讲坐标，不展开任何一站的实操细节。
