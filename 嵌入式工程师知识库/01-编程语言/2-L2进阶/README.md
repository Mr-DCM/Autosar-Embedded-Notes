# 2-L2进阶

> 上级目录：[01-编程语言](../README.md)

## 本带定位

从"会写"到"写得对、写得规范"：数据结构、内存管理、寄存器编程、MISRA 四大主干必修；Cpp、汇编基础、辅助脚本三支按项目平台选修。内容贴近 AUTOSAR 工程（TC377 + S32K 双平台举例）。

**主等级声明**：本带主等级【L2】；含 3 篇【L2→L3】碎片（AUTOSAR MemMap、读写时序与屏障、trap 入口代码），它们同时收录在 [3-L3高级索引](../3-L3高级/README.md)。

## 坡道说明

- **何时进本带**：[1-L1基础](../1-L1基础/README.md) 三目录过关——代码能独立复现、指针笔试题七成正确。
- **何时离开去下一带**：能读懂一段 BSW/CDD 代码并按 MISRA 条目改写合规；对内存布局（map 文件）能说清来龙去脉。此后不再有整目录的 L3——深入方向见 [3-L3高级](../3-L3高级/README.md)，靠工程实践推进。
- **建议顺序**：数据结构与算法 → 内存管理 → 寄存器编程 → 代码规范与MISRA-C；Cpp / 汇编基础 / 辅助脚本按需穿插。
