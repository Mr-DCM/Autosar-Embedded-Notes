# 01-编程语言

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

C 语言精通主线：指针、内存、位操作、寄存器编程四大功底 + 数据结构与 MISRA（核心中的核心），叠加 AUTOSAR MemMap 与 MISRA-C 定制内容；辅以嵌入式受限 C++、双架构（TriCore/ARM）汇编与提效脚本。按 L1~L3 分带组织：L1 打地基、L2 练工程、L3 碎片点到即止。
