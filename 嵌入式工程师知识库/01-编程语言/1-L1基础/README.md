# 1-L1基础

> 上级目录：[01-编程语言](../README.md)

## 本带定位

把 C 的地基打牢：语法、位操作、指针三块按序推进，目标是"能看懂别人的代码、能独立写对课后代码"。不追新术语，多用直觉与最小例子。

**主等级声明**：本带主等级【L1】；其中指针专题整体为【L1→L2】过渡带，读完即具备进 L2 的资格。

## 坡道说明

- **何时进本带**：[入门导读自检](../00-入门导读/01-C功底自检与爬坡图.md) 有任何一条勾不上；或刚接触嵌入式 C，需要系统补地基。
- **何时离开去下一带**：三个目录的代码都能脱离笔记独立复现，且 [指针专题常见笔试题](指针专题/05-常见笔试题.md) 能当场做对七成以上——即可进 [2-L2进阶](../2-L2进阶/README.md)。
- **建议顺序**：基础语法巩固 → 位操作 → 指针专题，倒着读会处处卡。
