# 01 掩码与置位清零

> 一句话定位：位操作的四件套——置位/清零/翻转/测试，加上掩码提取与组装，是 CAN ID 寄存器、DTC 字节拼装、外设控制位一切操作的地基；写错一个 `1UL` 或漏一对括号，TC377/S32K 上就是丢位、误清标志、甚至 Trap。
> 等级：L1 ｜ 前置：无

## 原理

### 1. 四件套公式

对寄存器 `R` 的第 `n` 位（最低位为 0），用掩码 `BIT(n) = 1UL << n` 做四种基本操作：

| 操作 | 公式 | 直觉 |
|---|---|---|
| 置位（set） | `R \|= BIT(n)` | "或 1 强制为 1"，其余位或 0 不变 |
| 清零（clear） | `R &= ~BIT(n)` | "与 0 强制为 0"，掩码先取反再与 |
| 翻转（toggle） | `R ^= BIT(n)` | "异或 1 翻转"，0→1、1→0 |
| 测试（test） | `(R & BIT(n)) != 0u` | "与掩码相与，非零即置位" |

记忆要点：清零是**先取反再与**（`R & BIT(n)` 只是测试，不是清零）；测试结果要和 `0u` 比，**不要和 `1u` 比**——位测试结果是 0 或 `BIT(n)`，不是 0 或 1。

### 2. 提取与组装位段

单个位用 `BIT(n)`，连续位段 `[n, n+w)` 用宽度掩码：

- 提取：`(R >> n) & ((1UL << w) - 1u)` —— 先右移到最低位，再用 `w` 个 1 的掩码截取；
- 组装：先把旧值位段清零（`& ~(mask << n)`），再或上新值（`| (val << n)`），其中 `mask = (1UL << w) - 1u`。

汽车场景两例：

1. **CAN 扩展帧 ID 寄存器**：TC377 的 MCAN TX Buffer ID 寄存器把 IDE（此处叫 XTD）、RTR、29 位 ID 塞进同一个 32 位字，发一帧就要"组装位段"。
2. **UDS DTC 三字节拼装**：DTC 是 24 位整型，总线上按大端拆成 3 字节，这就是"按位移提取/组装"的典型。

### 3. BIT(n) / MASK(n,w) 宏的安全写法

三条铁律：

1. **必须用 `1UL` 而非 `1`**：`1 << 31` 在 `int` 为 32 位的平台是对**有符号数左移溢出**，标准规定为未定义行为（UB, Undefined Behavior）；`1UL << 31` 才安全。这触犯 MISRA C:2012 规则 1.3（不得出现未定义行为）。
2. **每个参数都要加括号**：宏是纯文本替换，`BIT(n+1)` 若写成 `1UL << n+1` 会展开成 `(1UL<<n)+1`，全错；正确是 `1UL << (n)`。MISRA 规则 12.1 也要求运算符优先级显式化。
3. **移位计数必须落在位宽内**：`1UL << 32` 在 32 位平台上同样是 UB（移位计数等于或大于位宽），触犯 MISRA 规则 12.2（移位右操作数须在 `[0, 位宽-1]`）。

## 代码示例

### 场景 1：四件套与位段宏

```c
#include "Std_Types.h"

/* BIT(n)：第 n 位掩码。1UL 保证无符号移位，括号防优先级坑 */
#define BIT(n)                  (1UL << (n))
/* MASK(n, w)：[n, n+w) 位段的掩码 */
#define MASK(n, w)              (((1UL << (w)) - 1UL) << (n))
/* 提取 [n, n+w) 位段 */
#define FIELD_GET(reg, n, w)    (((reg) >> (n)) & ((1UL << (w)) - 1UL))
/* 把 val 写入 [n, n+w) 位段，其余位保持（先清零位段再或新值） */
#define FIELD_SET(reg, n, w, val)                                          \
    do {                                                                    \
        uint32 m_mask_ = MASK((n), (w));                                    \
        (reg) = ((reg) & ~m_mask_) | (((uint32)(val) << (n)) & m_mask_);    \
    } while (0)

void BitOps_Demo(volatile uint32 *reg)
{
    *reg |=  BIT(3);                 /* 置位第 3 位 */
    *reg &= ~BIT(3);                 /* 清零第 3 位（先取反再与） */
    *reg ^=  BIT(3);                 /* 翻转第 3 位 */
    if ((*reg & BIT(3)) != 0u)       /* 测试第 3 位：与 0u 比，别与 1u 比 */
    {
        /* 已置位 */
    }
}
```

### 场景 2：CAN 扩展帧 ID 寄存器组装

```c
/* TC377 MCAN TX Buffer ID 寄存器（IFX_MCAN_TXBUF_ID，Bosch M_CAN 布局）位定义：
 * bit29: XTD  1=扩展帧(29位ID) 0=标准帧(11位ID)   ← 即 IDE
 * bit30: RTR  1=远程帧 0=数据帧
 * bit28..0: ID（标准帧时低 11 位有效，扩展帧时低 29 位有效）
 * 注：位号以所用版本的 UM / iLLD 头文件为准
 */
#define CAN_ID_XTD         (1u << 29)
#define CAN_ID_RTR         (1u << 30)
#define CAN_STD_ID_MASK    (0x000007FFu)   /* 11 位标准 ID */
#define CAN_EXT_ID_MASK    (0x1FFFFFFFu)   /* 29 位扩展 ID */

/* 组装 ID 寄存器：先把 IDE/RTR 位置出来，再用掩码截断 ID，避免越界污染高位 */
uint32 Can_BuildIdReg(boolean isExt, boolean isRtr, uint32 canId)
{
    uint32 reg;

    if (isExt == TRUE)
    {
        reg = CAN_ID_XTD | (canId & CAN_EXT_ID_MASK);   /* 扩展帧置 XTD，截 29 位 */
    }
    else
    {
        reg = canId & CAN_STD_ID_MASK;                  /* 标准帧只取低 11 位 */
    }
    if (isRtr == TRUE)
    {
        reg |= CAN_ID_RTR;                              /* 远程帧再或上 RTR */
    }
    return reg;
}

/* 反向：从 ID 寄存器拆出各字段（位段提取） */
void Can_ParseIdReg(uint32 reg, boolean *isExt, boolean *isRtr, uint32 *canId)
{
    *isExt = ((reg & CAN_ID_XTD) != 0u) ? TRUE : FALSE;
    *isRtr = ((reg & CAN_ID_RTR) != 0u) ? TRUE : FALSE;
    *canId = (*isExt == TRUE) ? (reg & CAN_EXT_ID_MASK)
                              : (reg & CAN_STD_ID_MASK);
}
```

### 场景 3：UDS DTC 三字节拼装

```c
/* UDS DTC 为 3 字节(24 位)，按 ISO 14229 在 CAN 总线上大端传输：
 * byte0=高8位  byte1=中8位  byte2=低8位
 * 注：高字节的高 2 位是格式标识(ISO14229=0b00)，故有效故障码实际 22 位。
 * S32K(Cortex-M, 小端)上绝不能 memcpy 整型↔字节，必须显式移位。
 */
void Uds_DtcToBytes(uint32 dtc, uint8 outBytes[3])
{
    outBytes[0] = (uint8)((dtc >> 16) & 0xFFu);
    outBytes[1] = (uint8)((dtc >> 8)  & 0xFFu);
    outBytes[2] = (uint8)( dtc        & 0xFFu);
}

uint32 Uds_DtcFromBytes(const uint8 inBytes[3])
{
    return ((uint32)inBytes[0] << 16)
         | ((uint32)inBytes[1] << 8)
         | ((uint32)inBytes[2]);
}

/* DTC 状态字节(DTCStatusMask) bit0=testFailed 等，统计当前激活的故障位数
 * —— 复用 04 篇的 Brian Kernighan 法 */
uint8 Uds_CountActiveStatusBits(uint8 statusMask)
{
    uint8 cnt = 0u;
    while (statusMask != 0u)
    {
        statusMask &= (uint8)(statusMask - 1u);   /* 清掉最低位的 1 */
        cnt++;
    }
    return cnt;
}
```

## 易错点与陷阱

1. **用 `1` 而非 `1UL`**：`1 << 31` 对有符号 int 左移溢出是 UB（MISRA 规则 1.3），必须 `1UL << 31`。
2. **宏参数不加括号**：`BIT(n+1)` 写成 `1UL << n+1` 展开成 `(1UL<<n)+1`，逻辑全错。每个参数都括起来（规则 12.1）。
3. **清零写成 `R & BIT(n)`**：那是测试不是清零；清零要 `R & ~BIT(n)`（先取反再与）。
4. **测试位写成 `if (R & BIT(n) == 1)`**：`==` 优先级高于 `&`，且位测试结果不是 0/1 而是 0/`BIT(n)`。正确：`if ((R & BIT(n)) != 0u)`。
5. **CAN ID 不掩码直接拼**：`(canId) | CAN_ID_XTD`，若 canId 超出 29 位会污染 XTD/RTR 位。务必先 `& MASK` 截断。
6. **DTC 字节序用 memcpy**：CAN/UDS 大端，S32K 小端，`memcpy(dtc, bytes, 4)` 拿到的整型字节序相反。手写移位才跨平台。
7. **翻转位用 `~` 而非 `^`**：`R = ~R` 翻转全部位，只想翻转第 n 位要用 `R ^= BIT(n)`。
8. **位段宏参数带副作用**：`FIELD_SET(*p++, ...)` 里 `p++` 会被展开多次求值。宏参数避免带副作用。

## 面试高频题

**Q1：写出置位/清零/翻转/测试第 n 位的代码。**
答：`R |= BIT(n)` 置位、`R &= ~BIT(n)` 清零、`R ^= BIT(n)` 翻转、`(R & BIT(n)) != 0u` 测试。其中 `BIT(n) = (1UL << (n))`。

**Q2：`BIT(n)` 宏为什么必须写 `1UL` 而不是 `1`？**
答：`1` 是有符号 int，`1 << 31` 左移溢出是未定义行为（MISRA 规则 1.3）；`1UL` 是无符号，左移溢出按 2^N 取模，是定义行为。顺带 `1UL << 32` 移位计数等于位宽仍是 UB（规则 12.2）。

**Q3：`if (flags & BIT(3) == 1)` 错在哪？**
答：两处错。其一 `==` 优先级高于 `&`，实际是 `flags & (BIT(3)==1)`，恒为 `flags & 0`；其二位测试结果不是 0/1 而是 0 或 `BIT(3)`，不能和 1 比。正确写法 `if ((flags & BIT(3)) != 0u)`。

**Q4：CAN 扩展帧 ID 寄存器如何组装（XTD/RTR + 29位ID）？**
答：先按帧类型置 XTD 并用掩码截断 ID——`reg = CAN_ID_XTD | (canId & CAN_EXT_ID_MASK)`，再按需 `|= CAN_ID_RTR`。关键是"先截断再或"，防止 ID 越界污染高位标志位。

**Q5：提取 32 位寄存器 `[n, n+w)` 位段，写出宏并解释。**
答：`#define FIELD_GET(reg,n,w) (((reg)>>(n)) & ((1UL<<(w))-1UL))`。先右移 n 位把目标位移到最低位，再用 `w` 个 1 的掩码截掉高位，得到纯位段值。

**Q6：UDS DTC 三字节与 24 位整型如何互转？为什么不能用 memcpy？**
答：`out[0]=dtc>>16; out[1]=dtc>>8; out[2]=dtc;` 反向用左移或起来。UDS 总线大端、S32K 内核小端，memcpy 按主机序拷贝字节序相反；显式移位与 CPU 字节序无关，可移植。
