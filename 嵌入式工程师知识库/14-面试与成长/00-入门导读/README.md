# 00-入门导读

> 上级目录：[14-面试与成长](../README.md)

## 定位

**半天建立面试视角。** 一篇导读把面试定义为"知识库的期末考试"：用考点地图摆正八大领域与高频题型的位置，用"背题 vs 理解"三层判卷口径告诉你哪些题才算真会，再用 STAR 模板把自我介绍与项目介绍变成可复用的骨架。读完你有了全区的检索地图与刷题纪律，再进题库就不会陷入"背了就忘"的循环。

- 主等级：**L1**（前置：无，可从零直接读；但读懂考点回链需要 01~13 区的背景）
- 何时进：准备笔试面试、做年度技能盘点、写自我介绍——都从这里起步；
- 何时离开：能不查资料说出"八大考点领域各自的主考区、STAR 四环节、判卷三层口径"，就可以进带刷题了——导读讲地图与纪律，不讲题目本身。

## 读完去向（L1/L2 带）

导读是本区所有路线的共同起点，之后按目的分流：

- **笔试/白板在即**：进 [1-L1基础/手写代码题](../1-L1基础/手写代码题/README.md)——memcpy/位操作/链表，每篇纸上写三遍；
- **技术面备弹药**：进 [2-L2进阶/汽车电子面试题库](../2-L2进阶/汽车电子面试题库/README.md)，从 [题库索引](../2-L2进阶/汽车电子面试题库/00-题库索引.md) 按目标岗位勾选领域篇；
