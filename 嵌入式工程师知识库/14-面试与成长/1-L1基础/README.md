# 1-L1基础

> 上级目录：[14-面试与成长](../README.md)

## 定位

**白板上的基本功。** 手写代码题是嵌入式笔试与现场面试的"白板三连"：memcpy/strcpy 考指针与重叠区的分寸、位操作考寄存器编程的手感、链表反转考数据结构与边界思维。题目本身都是 L1 基础（不依赖任何汽车电子背景），但"写对 + 讲清 + 扛住追问"需要 01 区的地基——每篇的考点解析都回链 01 区对应篇。

- 主标签：**【L1→L2】**（前置：无；01 区指针/位操作篇可同步读）
- 何时进：笔试前一周、技术面约在两周内——手写题是短期突击收益最高的部分；
- 何时离开：三篇每篇能在白纸上 10 分钟内写出无错版本、并能口头回答全部变形追问，即算过关——之后按问题回查本带。
