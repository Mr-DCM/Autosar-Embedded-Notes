# 03-链表反转

> 一句话定位：白板压轴题——三指针迭代反转考的是指针指向关系的想象力，写挂一处在白板上就整条链断给你看；连环追问一直延伸到环检测与中间节点。
> 等级：L2 ｜ 前置：[02-位操作题](02-位操作题.md)

## 题目描述

**题 A（单链表反转）**：给定单链表节点定义，实现 `Node *reverse(Node *head);` 将链表原地反转并返回新头。

**题 B（环检测）**：判断单链表是否有环；有环则返回入环点。

**题 C（找中间节点）**：一次遍历找到链表的中间节点（偶数长度返回后半段首节点）。

```c
typedef struct Node
{
    int          val;
    struct Node *next;
} Node;
```

白板时限：题 A 8 分钟，写完画图讲清每一步三个指针的变化。

## 手写参考实现

```c
#include <stddef.h>

/* ---- 题 A：三指针迭代反转，O(n) 时间 O(1) 空间 ---- */
Node *reverse(Node *head)
{
    Node *prev = NULL;      /* 已反转部分的头，初始为空（反转后原头指向它） */
    Node *curr = head;      /* 当前待处理节点 */
    Node *next = NULL;      /* 先存后继，防止断链 */

    while (curr != NULL)
    {
        next = curr->next;  /* 1) 备份后继：一旦改写 curr->next，后面的路就没了 */
        curr->next = prev;  /* 2) 掉头：当前节点指向前驱 */
        prev = curr;        /* 3) prev 前进一步 */
        curr = next;        /* 4) curr 前进一步，处理下一个 */
    }
    return prev;            /* 循环退出时 curr=NULL，prev 就是新头 */
}

/* 递归版：讲思路用，工程上栈深不可控（链长 1000 就要 1000 层栈帧） */
Node *reverse_rec(Node *head)
{
    if ((head == NULL) || (head->next == NULL))
    {
        return head;                    /* 空表或单节点：自己就是反转结果 */
    }
    Node *newHead = reverse_rec(head->next);  /* 反转后面的，拿到新头 */
    head->next->next = head;            /* 后继掉头指回自己 */
    head->next = NULL;                  /* 自己变成尾，封口 */
    return newHead;
}

/* ---- 题 B：快慢指针判环 + 入环点 ---- */
Node *detect_cycle(Node *head)
{
    Node *slow = head;
    Node *fast = head;

    while ((fast != NULL) && (fast->next != NULL))
    {
        slow = slow->next;        /* 慢指针一步 */
        fast = fast->next->next;  /* 快指针两步，先判 fast->next 非空防解引用 NULL */
        if (slow == fast)         /* 相遇 → 有环 */
        {
            Node *p = head;       /* 第二阶段：一个从头、一个从相遇点同速走 */
            while (p != slow)
            {
                p = p->next;
                slow = slow->next;
            }
            return p;             /* 再次相遇处即入环点（数学可证） */
        }
    }
    return NULL;                  /* fast 走到头，无环 */
}

/* ---- 题 C：快慢指针找中间 ---- */
Node *find_middle(Node *head)
{
    Node *slow = head;
    Node *fast = head;

    while ((fast != NULL) && (fast->next != NULL))
    {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;   /* 奇数长度：正中；偶数长度：后半段首节点（fast 恰好到尾） */
}
```

## 考点解析

1. **"先备份后继再掉头"是唯一正确顺序**：第 1、2 步交换顺序链就断——next 指针被覆盖后再也找不到剩余链表；这是本题唯一真正的考点，其余都是模板；
2. **返回 prev 而不是 head**：循环退出时 curr 已为 NULL、prev 停在原尾节点即新头——口误说"返回 head"（原头=新尾）是最常见的收尾翻车；
3. **递归版的价值与代价**：代码短、讲清"反转 k+1..n 再把 k 接到尾部"的分治思想；代价是 O(n) 栈深——嵌入式里链长不可控时禁用，这条对比就是面试官想听的工程判断（栈大小话题回链 [08 区栈大小确定](../../../08-操作系统/1-L1基础/RTOS通用原理/内存管理/01-栈大小确定.md)）；
4. **快慢指针的两个应用同源**：判环（速度差导致环内必然相遇）与找中点（速度 2:1 走完即半程）都是"相对速度"思想；判环第二阶段的"头指针与相遇点同速前进会在入环点相遇"可从设头到入环点距离 a、入环点到相遇点 b 推出 a = c + (n−1)·环长；
5. **嵌入式语境的真实链表**：AUTOSAR CDD、缓冲管理、CanIf 发送队列里全是侵入式链表（节点内嵌 next 指针）——反转练的是指针基本功，环形缓冲区才是嵌入式更常见的"表亲"（[01 区环形缓冲区](../../../01-编程语言/2-L2进阶/数据结构与算法-C实现/01-环形缓冲区.md)）。

## 常见写挂点

| 写挂点 | 现场表现 | 纠正 |
|---|---|---|
| 忘备份 next 直接掉头 | 链当场断裂，只剩一个节点 | 循环第一行永远是 `next = curr->next` |
| 返回 head / 返回 curr | 返回 NULL 或旧头（新尾） | 循环自然退出时返回 prev |
| while 条件写 `curr->next != NULL` | 尾节点没被掉头，链表断成两截 | 条件是 `curr != NULL` |
| 快指针不判 `fast->next` | 偶数长度无环时解引用 NULL 崩溃 | `while (fast && fast->next)` |
| 反转后忘处理旧头 | 旧头 next 仍指旧二节点，成环 | 迭代版天然正确；递归版要 `head->next = NULL` 封口 |
| 空表/单节点没单独想 | 递归版直接解引用 NULL | 入口 `(head==NULL || head->next==NULL)` 直接返回 |
| 在白板上不画图硬写 | 三步后指针关系全乱 | 每轮在旁边画出 prev/curr/next 三指针位置 |

## 变形追问

- **Q：每 k 个一组反转？**——外层按 k 计数截段，段内套三指针反转，段间用"前段尾"接"本段反转后新头"；LeetCode 25，追问到"不足 k 保持原序"的边界即可收；
- **Q：双向链表反转？**——每个节点交换 prev/next 两个指针，循环变量换成 tmp 先备份 prev；比单链表多一个指针但不会断链；
- **Q：不用递归不用迭代，还能怎么反转？**——头插法：逐个取节点插到新链头部，本质仍是迭代换了个记法；
- **Q：怎么判断两个链表相交？**——尾指针相同即相交；或长度对齐后同步前进比地址；追问"有环怎么判"就是题 B 的组合；
- **Q：销毁整条链表的正确姿势？**——`while (head) { next = head->next; free(head); head = next; }`——先备份再释放，与反转同一个纪律，嵌入式里再加"释放后置 NULL 防悬垂"。
