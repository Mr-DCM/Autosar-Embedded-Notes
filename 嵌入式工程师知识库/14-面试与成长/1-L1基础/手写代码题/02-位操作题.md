# 02-位操作题

> 一句话定位：嵌入式笔试的必考三分钟——掩码置位/清零/翻转、统计 1 的个数、不用临时变量交换，考的全是寄存器编程的日常手感。
> 等级：L1 ｜ 前置：[01-memcpy与strcpy](01-memcpy与strcpy.md)

## 题目描述

**题组 A（单字节寄存器 `reg`，bit0~bit7）**：写宏或函数完成——置位 bit3、清零 bit5、翻转 bit2、判断 bit7 是否为 1。

**题 B**：统计一个 `uint32_t` 二进制里 1 的个数（汉明重量）。

**题 C**：不使用临时变量，交换两个整数。

**题 D**：把任意正整数 x 向上对齐到 4 的倍数。

白板时限：10 分钟全组写完，并回答"为什么 1<<n 要加括号"。

## 手写参考实现

```c
#include <stdint.h>

/* ---- 题组 A：掩码三板斧，全部用 1U 防符号扩展 ---- */
#define BIT(n)          (1U << (n))

reg |=  BIT(3);          /* 置位 bit3：或上掩码，其余位不变 */
reg &= ~BIT(5);          /* 清零 bit5：与上掩码取反 */
reg ^=  BIT(2);          /* 翻转 bit2：异或掩码 */
uint8_t on = ((reg & BIT(7)) != 0U) ? 1U : 0U;  /* 判读 bit7：与掩码后判非零 */

/* 一次操作多位：置位 bit2~bit3 两位 */
#define MASK_23  (BIT(2) | BIT(3))
reg = (uint8_t)((reg & ~(uint8_t)MASK_23) | (value << 2)); /* 先清后置，写入 2 位字段 */

/* ---- 题 B：统计 1 的个数，三种写法 ---- */
/* 写法 1：逐位检查，n 位循环 n 次 */
uint32_t count_bits_loop(uint32_t v)
{
    uint32_t cnt = 0U;
    while (v != 0U)
    {
        cnt += (v & 1U);      /* 看最低位 */
        v >>= 1U;             /* 无符号右移，高位补 0 */
    }
    return cnt;
}

/* 写法 2：Brian Kernighan 法，有几个 1 循环几次——v&(v-1) 消掉最低的那个 1 */
uint32_t count_bits_bk(uint32_t v)
{
    uint32_t cnt = 0U;
    while (v != 0U)
    {
        v &= (v - 1U);        /* 关键一步：清最低置位位 */
        cnt++;
    }
    return cnt;
}

/* ---- 题 C：不用临时变量交换（用异或，限定整数） ---- */
void swap_xor(uint32_t *a, uint32_t *b)
{
    if (a != b)                       /* 同地址异或会把它清零！必须防 */
    {
        *a ^= *b;
        *b ^= *a;                     /* b = 原b ^ (原a^原b) = 原a */
        *a ^= *b;                     /* a = (原a^原b) ^ 原a = 原b */
    }
}

/* ---- 题 D：向上对齐到 4 的倍数 ---- */
uint32_t align4(uint32_t x)
{
    return ((x + 3U) & ~3U);          /* +3 进位，再清低 2 位；x 已对齐时不变 */
}
```

## 考点解析

1. **掩码三板斧是寄存器编程的字母表**：置位用 `|=`、清零用 `&= ~`、翻转用 `^=`——本质是"或置 1、与清 0、异或翻转"的真值表；AUTOSAR Mcal 的 Dio/Port、状态寄存器读写全是这套（[04 区 Port 配置](../../../04-MCAL与外设驱动/1-L1基础/Port与Dio/01-Port配置.md)）；
2. **`1U` 不是装饰**：有符号 int 的 `1<<31` 是 UB（移入符号位），`1U<<31` 得到 0x80000000 才是良定义；嵌入式代码统一用无符号位运算是 MISRA 的基本要求；
3. **Brian Kernighan 的 `v & (v-1)`**：v-1 会把最低的那个 1 变 0、其低位全变 1，与原值相与恰好消掉它——循环次数 = 1 的个数，比逐位快；追问到底时再补硬件 POPCNT 指令与查表法；
4. **异或交换的边界**：`*a` 与 `*b` 同地址时三连异或会把值清成 0——加 `a != b` 防护是工程分；面试官就在等这一句；
5. **对齐公式 `(x + mask) & ~mask`**：+（mask=2^n −1）保证"只要不是恰好对齐就借位到下一档"，再清低位——内存分配器、DMA 缓冲区对齐、NvM 块大小取整都靠它（[01 区内存对齐](../../../01-编程语言/2-L2进阶/内存管理/03-内存对齐与填充.md)）。

## 常见写挂点

| 写挂点 | 现场表现 | 纠正 |
|---|---|---|
| `1<<n` 忘加 U | n≥31 时 UB 或告警，白板上被当场问倒 | `BIT(n) (1U << (n))` 宏统一带 U |
| 宏参数不带括号 | `BIT(a+b)` 展开成 `1U<<a+b`，优先级错 | `(n)`、`(1U << (n))` 全括号 |
| 清零写成 `reg &= BIT(5)` | 恰好把其它位全清了，只有 bit5 保留 | 清零必须 `&= ~BIT(n)` |
| 判位写成 `if (reg & BIT(7))` 后直接当数值用 | 位运算结果是掩码值（0x80）不是 1 | `!= 0U` 归一成布尔 |
| 交换没防同地址 | 交换自己把值毁成 0 | 加 `a != b` 判断 |
| 对齐写成 `(x + 4) & ~3` | x 恰好对齐时被多推 4 字节 | +3（= mask），恰好对齐不动 |
| 有符号数右移 | `int8_t` 右移高位补符号，统计错 | 统一位运算全部用无符号类型 |

## 变形追问

- **Q：bit3~bit5 三位字段读出来、写回去？**——读：`(reg >> 3) & 0x07U`；写：先 `reg &= ~0x38U`（`0x38 = 0b111000`）再 `reg |= (val << 3)`——"先清后置"是字段写入的铁律；
- **Q：不用除法求 x % 8？**——`x & 7U`（x 为无符号）；同理 `x / 8` 可写 `x >> 3`，编译器会自动做，但笔试要你会手推；
- **Q：判断 x 是否是 2 的整数次幂？**——`x != 0 && (x & (x-1)) == 0`：2 的幂二进制只有一个 1；
- **Q：把 x 的最低置位 1 找出来？**——`x & (~x + 1)`（即 `x & -x`，补码性质）；优先级位图查找最高优先级就靠它；
- **Q：位域（bitfield）和位操作选哪个？**——位域写法清爽但位排布由编译器实现决定、跨编译器不可移植；硬件寄存器映射必须用掩码位操作，协议字段可按团队规范选（[01 区位域 vs 位操作](../../../01-编程语言/1-L1基础/位操作/02-位域vs位操作.md)）。
