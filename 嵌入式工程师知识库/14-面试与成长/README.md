# 14-面试与成长

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

知识库的期末考试周。面试不是新知识，而是把 01~13 区串起来的压力测试——本区按 L1~L3 分带组织：先用一篇导读建考点地图与判卷口径，再在 L1 带练手写代码白板三连，L2 带刷七大领域问答集（每题带答案与出处回链）并做职业路线规划。题库不新造知识，只做知识库的检索索引；职业发展是技术主线之外的人生选题。

## 四带结构

| 带 | 定位 |
|---|---|
| [00-入门导读](00-入门导读/README.md) | 半天面试视角：考点地图（八大领域×高频题型）+"背题 vs 理解"判卷口径 + STAR 模板。 |
| [1-L1基础](1-L1基础/README.md) | 白板三连：手写代码题（memcpy/strcpy、位操作、链表反转，题目描述/参考实现/考点解析/常见写挂点/变形追问五段式）。 |
| [2-L2进阶](2-L2进阶/README.md) | 问答密度区：汽车电子面试题库（七大领域分篇，每题带答案与出处回链）+ 职业发展（路径图/技能雷达/跳槽晋升/行业观察）。 |

> 3-L3 高级带不设：本区内容按"检索密度"组织而非按深水区递进，无 L3 素材时不建空带——需要深挖时直接跳对应技术区（01~13）。

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：面试=知识库的期末考试——考点地图、判卷口径、STAR 模板，先建纪律再刷题；
2. [1-L1基础/手写代码题](1-L1基础/手写代码题/README.md)：memcpy/strcpy → 位操作 → 链表反转，每篇纸上写三遍；
3. [2-L2进阶/汽车电子面试题库](2-L2进阶/汽车电子面试题库/README.md)：从 [题库索引](2-L2进阶/汽车电子面试题库/00-题库索引.md) 按目标岗位勾选领域篇，逐题回链验证；
4. [2-L2进阶/职业发展](2-L2进阶/职业发展/README.md)：路径图 → 技能雷达 → 跳槽与晋升 → 行业观察，跳槽窗口期或年度盘点时重读。
