# 2-L2进阶

> 上级目录：[14-面试与成长](../README.md)

## 定位

**问答密度区。** 汽车电子面试题库按七大领域分篇（C 语言/网络/诊断/AUTOSAR/OS/MCAL/调试与开放题），统一"**Q：…** / 答：…"格式，每题必带答案与"出处回链"——题库不新造知识，只做知识库的检索索引。职业发展讲路径图、技能雷达、跳槽晋升取舍与行业观察，是技术主线之外的"人生选题"。两个子目录一个向外变现（offer），一个向内规划（路线）。

- 主标签：**【L2】**（前置：00-入门导读；各领域篇前置 = 对应技术区的基本功）
- 何时进：技术面两周内开始刷题库；职业迷茫期或跳槽窗口期读职业发展；
- 何时离开：七大领域每篇抽查三题都能讲清 why、职业三问（要什么/凭什么/放弃什么）有了自己的答案，即算出师——题库按岗位勾选回查，职业篇按年度重读。
