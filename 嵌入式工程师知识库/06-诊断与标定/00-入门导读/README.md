# 00-入门导读

> 上级目录：[06-诊断与标定](../README.md)

## 定位

**半天入门车载诊断视角。** 一篇导读跟着诊断仪连上 ECU 后的前三条报文走一遍（10 进会话→27 解锁→22 读数据），用"话务员与内容提供者"的比喻分清 UDS/Dcm/Dem 三者分工，并把 7F 负响应翻译成人话——少公式、多直觉。读完后你有了本区地图与"懂协议→会配置→能排障"的判断力，再进 L1 带就不会在 SID/DID/DTC 里迷路。

- 主等级：**L1**（前置：无，可从零直接读；若已读过 [05 区导读](../../05-汽车网络通讯/00-入门导读/README.md) 更佳——诊断报文就坐在 CanTp 这辆货车上）
- 何时进：新接触 UDS/Dcm/Dem 术语、只会用诊断工具却没见过报文交互、分不清协议与配置——都从这里起步；
- 何时离开：能不查资料说出"连接后前三条报文是什么、7F 负响应怎么读、Dcm 与 Dem 谁管接线谁管记账"，就该进 [1-L1基础](../1-L1基础/README.md) 读 UDS 服务了——导读讲直觉，不讲逐服务的状态机。

## 读完去向（L1 带）

导读是本区所有路线的共同起点，之后进入 [1-L1基础](../1-L1基础/README.md)：

- **主线**：[UDS协议](../1-L1基础/UDS协议/README.md)（本区坡道第一站，从服务总览读起）；
- **了解级补充**：[OBD](../1-L1基础/OBD/README.md)（法规与模式，一篇带过）；
- 之后按 [区 README 入门坡道](../README.md) 进 [2-L2进阶](../2-L2进阶/README.md)（Dcm/Dem/DID 与 RID→XCP→诊断数据库）。
