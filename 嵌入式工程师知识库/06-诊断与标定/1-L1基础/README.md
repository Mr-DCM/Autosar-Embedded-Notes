# 1-L1基础

> 上级目录：[06-诊断与标定](../README.md)

## 定位

**协议地基。** UDS（ISO 14229）每服务一档、SID 前缀命名——诊断世界的"普通话"从 10/22/2E/19 四个高频服务学起；OBD 是法规视角的了解级，一篇带过。协议是配置的前提：不知道 27 的 seed-key 流程，配 Dcm 安全访问就是照猫画虎。

- 主标签：**【L1→L2】**（前置：读完 [00-入门导读](../00-入门导读/README.md) 即可进；UDS 内 SID29/SID34-37 两篇偏深，篇级头部行标【L2】）
- 何时进：读完导读、开始接触诊断报文或要配 Dcm；
- 何时离开：能不查资料说出常用 SID 的请求/响应格式、看懂一段 7F 负响应报文，就该进 [2-L2进阶](../2-L2进阶/README.md) 学配置落地了。
