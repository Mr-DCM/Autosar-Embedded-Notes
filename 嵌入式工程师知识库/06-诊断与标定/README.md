# 06-诊断与标定

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

主业深挖：UDS 每服务一档、Dcm/Dem 配置、XCP 标定与 Bootloader，按 L1~L3 分带组织——先用诊断仪的一次连接建全景地图，再在 L1 带打牢 UDS 协议地基，L2 带爬配置与设计主线，Bootloader 深水区点到即止。

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：连接后三步报文 + 三层分工 + 本区地图，先建全景；
2. [1-L1基础/UDS协议](1-L1基础/UDS协议/README.md)：从 01-服务总览起读，SID10 会话控制打头；
3. UDS 协议内 SID22 读 DID、SID27 安全访问连读——产线排查天天用的三板斧；
4. [2-L2进阶/Dcm配置](2-L2进阶/Dcm配置/README.md)：把协议落到 DSL/DSD/DSP 分层与 DID 路由；
5. [2-L2进阶/Dem配置](2-L2进阶/Dem配置/README.md) → [2-L2进阶/DID与RID设计](2-L2进阶/DID与RID设计/README.md)：故障账本与数据设计收口，配合 [09-调试与测试/总线工具](../09-调试与测试/2-L2进阶/总线工具/README.md) 用 CANoe/CANdela 对着报文实操。
