# 2-L2进阶

> 上级目录：[06-诊断与标定](../README.md)

## 定位

**配置与设计主线。** Dcm 配置讲 DSL/DSD/DSP 分层、DID 路由、会话与安全——诊断工程师八成的配置工作量在这里；Dem 配置讲事件与 DTC、冻结帧、老化——故障世界的账本；DID与RID设计管命名与字节序的工程约定；XCP与标定面向台架实时观测（A2L/CANape）；诊断数据库（ODX/CDD）把 ECU 的诊断能力"出版"给工具侧。

- 主标签：**【L2】**（前置：1-L1基础 的 UDS 协议地基；XCP 另需 05 区 CAN 基础）
- 何时进：UDS 服务语义已入门、开始在配置工具里配诊断或设计 DID；
- 何时离开：能独立配出一条 DID 路由与安全访问、设计一批命名规范的 DID、用 CANape 连上标定——即算出师，之后按问题回查本带。
