# 嵌入式工程师知识库

> 面向 AUTOSAR 汽车软件工程师（英飞凌 TC377 + NXP S32K，BSW/CDD 方向）的完整知识地图。
> 日常主线：CAN/LIN 通讯配置与诊断；补强线：MCAL 与硬件基础。

## 设计原则

1. **两位数字前缀**（00~99）控制目录排序与阅读顺序
2. **三层为限**，每个目录一个 README 作为索引
3. **难度分带**：01~03 区按 `00-入门导读 / 1-L1基础 / 2-L2进阶 / 3-L3高级` 组织，按需爬坡、不必顺序修完
4. **笔记与代码分离**：`序号-主题.md` + `examples/`
5. **图表即文本**：流程/时序/状态/架构图用 PlantUML 内嵌正文，见 [图表规范与模板](00-总览/图表规范与模板.md)
6. **归档隔离**：临时笔记先进 `99-归档`，周维护归位

## 难度分级体系（L0~L3）

| 等级 | 定位 | 本库覆盖 |
|---|---|---|
| L0 入门 | 能跑通 Demo | 不设内容（已越过） |
| **L1 基础** | 在指导下完成模块任务 | **主战场**：`1-L1基础` 带 + `00-入门导读` |
| **L2 进阶** | 独立负责子系统、能排障 | **主战场**：`2-L2进阶` 带 |
| L3 高级 | 系统级视野（5~10 年上限） | 点到即止：`3-L3高级` 带，概念 + 清单 + 指针 |

- **篇级标签**：`【L1】【L2】【L3】【L1→L2】【L2→L3】`，出现在笔记头部与各 README 条目中
- **篇头部行**：`> 等级：Lx ｜ 前置：链接（≤2 条，无则"无"）`
- 完整框架、L3 上限章程与各级自查表见 [学习路线图](00-总览/学习路线图.md)

## 笔记骨架模型（首尾固定 + 中段菜单）

**首尾三段全库统一**，保证任何区的笔记都有可预期的开头结尾：
- 首段：`> 一句话定位`（本篇解决什么问题、为何重要）+ `> 等级：Lx ｜ 前置：链接`（L3/L2→L3 篇另加"太长不看"开篇）
- 尾段：`## 易错点与陷阱` → 可替换收尾模块 → `## 延伸`（相对链接互链）

**中段按区组装**（同区内允许按题材适当自由调整，但双平台对照/位表/计算类硬信息不省略）：

| 区 | 中段模块（按序） | 收尾模块（选一） |
|---|---|---|
| 01-编程语言 | 原理(PlantUML) → 代码示例 | 面试高频题 |
| 02-芯片与体系结构 | 原理(PlantUML) → 寄存器与位表 → 双平台对照 → 代码/实操(可选) | 面试高频题 |
| 03-硬件基础 | 原理(WaveDrom/ASCII) → 计算与选型 → ECU 实例 → 与软件的关联 | 与软件的关联（并入中段时可用面试高频题收尾） |
| 04-MCAL与外设驱动 | 原理 → 双平台实现 → 配置要点 | 评审清单 / 面试高频题 |
| 05/06 通讯诊断 | 原理(时序图) → 帧格式/位表(表格) → 配置层 → 排障层 | 面试高频题 / 排障清单 |
| 07-AUTOSAR架构 | 原理(PlantUML) → 配置层 → 原理层 → 排障层 | 面试高频题 / 排障清单 |

图表工具按内容类型分派（PlantUML/WaveDrom/表格/ASCII），详见 [图表规范与模板](00-总览/图表规范与模板.md)。
