# 00-入门导读

> 上级目录：[13-标准与书籍笔记](../README.md)

## 定位

**半天建立"文献观"。** 一篇导读讲清三件事：为什么"读原著"是工程师的天花板（二手知识衰减链）、四类文献（标准/芯片手册/书/博客）在可信度地图上各在哪一层、AUTOSAR 标准与芯片手册各自的正确打开方式——读完你就知道遇到问题该翻哪本书、翻哪一章。

- 主等级：**L1**（前置：无，可从零直接读）
- 何时进：查资料只会搜博客、对"以哪个文档为准"没把握、面对几千页手册/几百份 PDF 不知从哪下手——都从这里起步；
- 何时离开：能说出"结论找第一梯队、事实查第二梯队、框架靠第三梯队、线索用第四梯队"，就该按问题进 [7-阅读笔记](../7-阅读笔记/README.md)，然后去对应资源架取原件了。
