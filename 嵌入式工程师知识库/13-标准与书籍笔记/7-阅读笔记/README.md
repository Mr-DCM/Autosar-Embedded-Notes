# 7-阅读笔记

> 上级目录：[13-标准与书籍笔记](../README.md)

## 定位

**原件的地图，不是原件的替身。** 1~5 号架收 PDF/DOC 原件，这里收"怎么读"：几千页的 UM 先翻哪章、几百份 SWS 用哪份查、ISO 标准按什么线走、书架怎么选书——每篇只给章节地图、反查路径与坑位提示，不抄原文。

## 使用方式

1. 翻原件前先来拿对应篇目的"章节地图"（如 UM 的模块-章节对照）；
2. 笔记里的坑章节提示（如 S32K 的 PCC 时钟门控）直接决定你的排障顺序；
3. 读完笔记回原件核细节——笔记的终点永远是"回到原文哪一章哪一节"。
