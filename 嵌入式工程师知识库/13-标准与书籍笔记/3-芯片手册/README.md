## 定位

官方芯片手册的**原件架**：TC3xx（Infineon AURIX）与 S32K（NXP）双平台对应的 UM/RM。手册读法与章节地图见 [7-阅读笔记/芯片手册](../7-阅读笔记/芯片手册/README.md)，官方下载见 [6-在线资源/01](../6-在线资源/01-官方标准下载指南.md)。

## 存放状态（2026-09 清点）

本架为**索引架**：下表 PDF 原件因版权与体积**不入 git**（`.gitignore` 已排除），当前未存于本目录——完整账本见 [_本地存档清单](../_本地存档清单.md)；各手册均可从厂商文档中心免费重新下载（表内"官方获取"列）。原件归位本地后，更新清单状态列即可。

## 归架约定

- 按"芯片族"分子目录（如 `TC3xx/`、`S32K/`），单篇散件可暂存根目录，超过 3 篇即建族目录；
- 下载时在文件名或本表补记**版本/日期**（UM 会被厂商静默更新，不记版本半年后对不上寄存器行为）；
- DS（Data Sheet）与 UM/RM 分开命名：`芯片-DS-vx.x.pdf` / `芯片-UM-vx.x.pdf`，两者用途不同（选型看 DS，写驱动看 UM）。
