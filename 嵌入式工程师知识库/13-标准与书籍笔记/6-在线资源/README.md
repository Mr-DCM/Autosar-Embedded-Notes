# 6-在线资源

> 上级目录：[13-标准与书籍笔记](../README.md)

## 定位

唯一"无 PDF 的架"——收**下载渠道与在线文库索引**：手上没有原件时从这里出发，按官方渠道把 PDF 落到本地，再按"资源架约定"归进 1~5 号架。本目录只记"去哪下、怎么搜、哪些免费"，不转载文件本体。

## 篇目清单

| 篇目 | 一句话 |
|---|---|
| [01-官方标准下载指南](01-官方标准下载指南.md) | AUTOSAR/ISO/SAE/协议规范/芯片手册的官方下载渠道总表：哪些免费、哪些要注册、哪些要购买，以及免费替代读法。 |
| [02-电子书与论文获取渠道](02-电子书与论文获取渠道.md) | 电子书（公开免费/购买/图书馆借阅）与论文（知网/Scholar/学位论文库）获取途径，附行业白皮书与好文来源。 |

## 使用约定

- 下载的原件按类型归架：协议与标准 → [1-诊断与通信协议](../1-诊断与通信协议/README.md) / [2-AUTOSAR标准](../2-AUTOSAR标准/README.md)，芯片手册 → [3-芯片手册](../3-芯片手册/README.md)，书 → [4-电子书](../4-电子书/README.md)，论文与好文 → [5-论文与好文](../5-论文与好文/README.md)；
- 引用渠道时注明"官方/付费/免费"，过期失效的渠道在原条目上标注日期。
