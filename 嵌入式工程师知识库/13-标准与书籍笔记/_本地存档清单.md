## 定位

13 区实体原件（PDF/DOC/zip）**不入 git**（版权与体积，见根目录 `.gitignore`），本清单是它们的**账本**：记录"有什么、什么版本、从哪来、在哪"。git 里管账不管货——原件以本地/备份留存，清点时以本清单对账。

**状态列口径**：

- `已入库`：小体积图片等已随 git 仓库入库；
- `未归位`：账面在册，当前未存于本区目录（原件在本地他处或备份盘，归位后改此列）；
- `已归位@路径`：归位后填实际路径（或备份盘卷标）。

## 维护约定

- **归位即记账**：原件放回对应架位时，把状态列改为 `已归位@路径`；换备份盘同步更新；
- **可选加校验**：归位后可补 SHA256（`Get-FileHash <文件>`），防止备份盘静默损坏后无据可查；
- **重下即核版本**：标准/UM 被厂商静默更新，重新下载后在"版本/说明"列记日期；
- 新原件先在对应架 README 登记，再到本清单补一行账。
