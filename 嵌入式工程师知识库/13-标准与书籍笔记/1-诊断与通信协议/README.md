## 下载与归架约定

- 新协议原件按"协议族"子目录归档，`协议名-版本.格式` 命名；中英版本共存时分开命名不覆盖；
- ISO/SAE 正式件的引用一律带"标准号+版本年份"；民间翻译版只作定位辅助；
- 怎么读这些协议原文 → [7-阅读笔记/ISO标准](../7-阅读笔记/ISO标准/README.md)；去哪下 → [6-在线资源](../6-在线资源/README.md)。
