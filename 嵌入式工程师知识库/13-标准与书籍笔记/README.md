**实体资料库：PDF/DOC 原件为主，markdown 笔记为辅。** 别的区教"怎么做"，本区解决"以哪个文档为准"——一手标准（AUTOSAR/ISO/J1939）、芯片手册、经典书与论文的原件都收在这里，按"资源架"分架存放；markdown 只做两类事：翻原件前的**阅读笔记**（7-阅读笔记）与**下载渠道索引**（6-在线资源），不抄原文。

## 使用方式：先导读，再笔记，后原件

1. 没建立过"文献观" → 先读 [00-入门导读](00-入门导读/README.md)，半天足够；
2. 手上没有原件 → 去 [6-在线资源](6-在线资源/README.md) 按渠道下载；
3. 面对几千页手册/几百份 PDF 不知从哪下手 → 先翻 [7-阅读笔记](7-阅读笔记/README.md) 对应篇目拿"章节地图"，再进对应资源架翻原件；
4. 行为/配置争议 → 直接回 1/2 号架的协议原文与 SWS 裁决，引用带版本号。

> 本区为按需检索型资料库，不要求通读；与实战笔记的分工：05/06/07/11 区讲"怎么做"，本区提供"依据在哪"。
