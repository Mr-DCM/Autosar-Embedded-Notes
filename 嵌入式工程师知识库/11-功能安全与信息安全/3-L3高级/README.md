# 3-L3高级

> 上级目录：[11-功能安全与信息安全](../README.md)

## 定位

**跨界进阶，点到即止。** HSM与SHE 讲的是"把密钥和加解密搬进独立硬件"这件事——TC377 的 HSM 是芯片里多出来的一个安全核，S32K 的 CSEc 是 SHE 级加密引擎，两者把 SecOC 的 CMAC、安全启动的验签从"主核软件自证"变成"独立安全核担保"。**本带声明：点到即止**——对 TC377/S32K BSW/CDD 方向的汽车工程师，HSM 固件管理、EVITA 级别与密钥体系以"认门牌 + 对照了解"为度（双平台对照了解即可），不深挖安全核固件开发与密码学细节。

- 主标签：**【L2→L3】**（前置：[2-L2进阶/SecOC](../2-L2进阶/SecOC/README.md) 的 CMAC 概念已通——知道"要保护什么"，再看"密钥放在哪"才是顺叙）
- 何时进：L2 带 Security 支线读完，想知道 CMAC 的密钥为什么不能放普通 Flash、HSM/CSEc 和主核如何分工；
- 何时离开：能说清 HSM 与 CSEc 的代际差异、安全启动信任链为什么从"软件自证"升级为"独立核担保"——即达标，不必恋战。
