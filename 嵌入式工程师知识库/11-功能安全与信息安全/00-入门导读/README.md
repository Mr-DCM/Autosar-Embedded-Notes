# 00-入门导读

> 上级目录：[11-功能安全与信息安全](../README.md)

## 定位

**半天建立"安全"的双支柱全景。** 一篇导读用一个"概率性刹车助力失效"的案例，把 ISO 26262 的驯化流水线（HARA→ASIL→安全目标→安全机制→验证）一次走通——让你看懂安全需求文档里每一行的来路；再把 E2E、WdgM、Lockstep、MPU 这些机制名词钉到全景链条上各自的位置；最后用一张双支柱图分清功能安全（防失效）与信息安全（防攻击）——少术语、多直觉。读完后你有了本区地图，知道每个子目录在回答哪个问题。

- 主等级：**L1**（前置：无，可从零直接读；若已读过 [08 区导读](../../08-操作系统/00-入门导读/README.md) 更佳——WdgM 监督的正是那边的任务与调度）；
- 何时进：分不清 Safety 和 Security、看不懂 HARA/ASIL/安全目标这些词、知道 E2E 和看门狗却说不清它们各自堵哪个失效路径——都从这里起步；
- 何时离开：能复述 HARA→ASIL→安全目标→安全机制→验证这条链、说出功能安全与信息安全各自防的是什么、把五个常见机制对号入座，就该进 [1-L1基础](../1-L1基础/README.md) 了——导读讲直觉，不展开任何标准的条款细节。
