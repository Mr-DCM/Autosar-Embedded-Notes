# 11-功能安全与信息安全

> 上级目录：[嵌入式工程师知识库](../README.md)

## 定位

26262、E2E、SecOC、HSM/SHE 与 21434，按 L1~L3 分带组织——先用一个"概率性刹车助力失效"案例走通 ISO 26262 全流程（HARA→ASIL→安全目标→安全机制→验证），建立"失效可以发生，但不允许演变成伤害"的核心直觉；L1 带吃透标准名词，L2 带逐个拆解机制原理（E2E/WdgM/SecOC/21434），HSM/SHE 双平台硬件安全引擎作为跨界方向点到即止。本区写标准与方法论本质；模块配置与栈实现（WdgM 配置、SecOC 栈、加密栈）在 [07 区](../07-AUTOSAR架构/README.md)，两区互链不重复。

## 入门坡道（起读序列）

1. [00-入门导读](00-入门导读/README.md)（1 篇）：刹车助力案例走通 26262 全流程，双支柱分清 Safety 与 Security；
2. [ISO-26262基础](1-L1基础/ISO-26262基础/README.md)：ASIL 分级与安全机制名词先混熟，读得懂安全需求；
3. [看门狗与监控](2-L2进阶/看门狗与监控/README.md)：从 WdgM 与窗口看门狗下手，最贴近日常开发；
4. [E2E保护](2-L2进阶/E2E保护/README.md)：profile 与 CRC，配合 [05 区通讯](../05-汽车网络通讯/README.md) 笔记理解保护对象；
5. [SecOC](2-L2进阶/SecOC/README.md)：CMAC 与新鲜度值，结合 [07-AUTOSAR架构/加密栈](../07-AUTOSAR架构/3-L3高级/加密栈/README.md) 点到即止——Security 支线可先读 [ISO-21434概览](2-L2进阶/ISO-21434概览/README.md)，[HSM与SHE](3-L3高级/HSM与SHE/README.md) 双平台对照了解即可；[安全分析入门](1-L1基础/安全分析入门/README.md) 的 FTA 可在任何阶段穿插补读。
