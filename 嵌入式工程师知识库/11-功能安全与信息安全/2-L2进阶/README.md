# 2-L2进阶

> 上级目录：[11-功能安全与信息安全](../README.md)

## 定位

**机制原理主阵地，Safety 与 Security 双线并行。** Safety 线：E2E保护拆 profile 与 CRC 如何在"报文被干扰"下保住数据完整性，看门狗与监控拆 WdgM 监督实体/检查点与窗口看门狗的"打卡-超时-处置"本质；Security 线：ISO-21434概览建立"假设有人要攻击你"的工程视角（威胁分析、安全循环），SecOC 拆 CMAC 与新鲜度值如何防"假报文/重放报文"。本带讲原理与标准要求；模块配置与栈实现互链 [07 区](../../07-AUTOSAR架构/README.md)（WdgM 配置、加密栈），不重复。

- 主标签：**【L2】**（前置：[1-L1基础/ISO-26262基础](../1-L1基础/ISO-26262基础/README.md) 的名词已通；E2E 建议配 [05 区](../../05-汽车网络通讯/README.md) 的 CAN 帧格式基础）
- 何时进：知道 ASIL 是什么、但说不清 E2E 的 CRC/计数器各防哪种失效、没想过 CAN 报文为什么能被伪造；
- 何时离开：能画出 E2E 保护字段布局、解释窗口看门狗防什么、说清 SecOC 新鲜度值为什么截断也不失效——即达标。
