## 定位

**标准名词主阵地。** ISO-26262基础 是本区概念起点——把入门导读里"刹车助力案例走通全流程"的直觉，落成可查、可引用的版本：ASIL 四级怎么从 S/E/C 三个维度打分出来、QM 与 ASIL A~D 意味着多严的开发纪律、常见安全机制（看门狗/E2E/Lockstep/MPU/冗余）各是名词表里的哪一格。读完这一带，别人开会甩出来的安全术语你都能对上号、看得懂一条安全需求的来路。

- 主标签：**【L1→L2】**（前置：无；读过 [00-入门导读](../00-入门导读/README.md) 更佳，全流程直觉已在导读建立）
- 何时进：看不懂 HARA/ASIL/安全目标/安全机制这串词、拿到安全需求文档只能逐词查——都从这里起步；
- 何时离开：能独立解释一条 ASIL 定级的推理链、把机制名词对上失效路径，即可进 [2-L2进阶](../2-L2进阶/README.md) 拆机制原理。
