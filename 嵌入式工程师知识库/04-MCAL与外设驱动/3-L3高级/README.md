# 3-L3高级

> 上级目录：[04-MCAL与外设驱动](../README.md)

## 定位

**深水区参考层。** DMA 专题覆盖 DMA 原理与双平台实现（TC377 DMA、S32K eDMA/DMAMUX），属于"用到再学"的性能优化主题——子目录标【L2→L3】，是本区唯一的 L2→L3 坡。

- 主标签：**【L2→L3】**（前置：2-L2进阶 对应模块基础，尤其 Adc/Spi 的大数据量场景）
- 何时进：不是"读完 L2 才准进"——遇到 Adc/Spi 长报文搬运、CPU 占用过高要上 DMA 时，随时进来查；
- 何时离开：没有"离开"——按问题驱动使用，读完即走。

## 点到即止声明

本带是**深水区参考层，不要求按序通读**。正确用法：**概念 + 排障清单 + 延伸指针**——DMA 先懂"谁搬运、什么时候打断 CPU、通道优先级"的概念框架，遇到 cache 一致性、搬运错位、通道冲突时按排障清单定位，细节以芯片手册 DMA 章节为准，**深入靠工程实践**，笔记目标不是替你背手册。没有对应问题时，本带可长期搁置。
