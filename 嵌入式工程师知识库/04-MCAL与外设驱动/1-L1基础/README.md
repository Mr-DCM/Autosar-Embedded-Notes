# 1-L1基础

> 上级目录：[04-MCAL与外设驱动](../README.md)

## 定位

**地基 + 热身。** 三个子目录都是"入门即用"的坡度内容：MCAL总览讲清分层位置、与 iLLD/RTD 的关系、配置生成流程（L1→L2 桥接篇）；驱动分层思想讲寄存器层到 IoHwAb 的抽象与移植性；Port与Dio 是最简单的两个模块，用来跑通第一次引脚配置与读写。

- 主标签：**【L1→L2】**（前置：读完 [00-入门导读](../00-入门导读/README.md) 即可进；三个子目录均为坡度篇，读完直接为 L2 铺路）
- 何时进：读完导读、想动手碰第一个 MCAL 模块；
- 何时离开：能说清"MCAL 在 AUTOSAR 分层哪一层、换芯片为什么少改应用、Port 与 Dio 怎么分工"，并在配置工具里跑通一次引脚输出，就该进 [2-L2进阶](../2-L2进阶/README.md) 逐模块推进了。
