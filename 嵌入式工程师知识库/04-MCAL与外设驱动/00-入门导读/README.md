# 00-入门导读

> 上级目录：[04-MCAL与外设驱动](../README.md)

## 定位

**半天入门 MCAL 视角。** 一篇导读用"控制一个引脚"这件最小的事，把 AUTOSAR 驱动分层、一次 Dio 调用的全链路、配置工具生成流程讲成大白话——少公式、多直觉、一张时序图。读完后你对 Dio/Port/Mcu 这些词有了骨架感，再进 L1 带逐模块深挖就不会迷路。

- 主等级：**L1**（前置：无，可从零直接读）
- 何时进：MCAL 是短板、看到分层图就晕、被配置工具生成的代码吓到过——都从这里起步；
- 何时离开：能不查资料说出"四层楼各干什么、Dio 与 Port 怎么分工、_Cfg.c 为什么不能手改"，就该进 1-L1基础 动手深挖了——导读讲直觉，不讲寄存器位。
